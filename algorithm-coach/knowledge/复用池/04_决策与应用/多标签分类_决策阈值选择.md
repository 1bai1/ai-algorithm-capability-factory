# 多标签分类决策阈值选择

## 能力说明

把多标签分类模型的 sigmoid 输出转成 0/1 标签集时，决定判决阈值 λ 的取值规则。阈值不是无关紧要的默认值：标签分布不平衡时，固定的 0.5 会系统性欠召，需要按验证集下调。

## 输入契约

- 一个多标签模型在各标签上的连续输出（sigmoid 分数）与对应的训练/验证标签集。
- 标签分布信息：每类样本数或长尾程度（用于判断是否属于不平衡场景）。
- 评测指标口径（本卡默认 sample-based F1）。

## 输出契约

- 一个固定的判决阈值 λ（写入评测报告），以及在该阈值下验证集上的 sample-based F1。
- 若做了阈值扫描，附上候选阈值与对应指标，说明选择依据。

## 调用方式

1. 先按默认 λ=0.5 跑一版，记录验证集指标。
2. 在验证集上扫描 λ ∈ {0.5, 0.4, 0.3, 0.2, 0.1}（0.1 步长）。
3. 结合标签平衡度判断：分布较平衡时可保留 0.5；长尾/不平衡时优先试 0.2。
4. 对编码器类模型与编码-解码类模型分别扫描（实测二者最优阈值可能不同）。
5. 锁定 λ 后再在测试集上评估，保证同一批对比用同一阈值。

## 关键参数

- 默认阈值 λ=0.5（sigmoid 输出逐类独立判决）。
- 不平衡场景的候选值：λ=0.2（文献报告优于 0.5）。
- 扫描范围：0.5 → 0.1，步长 0.1。
- 模型差异实测：编码器模型（BERT 系）在预实验中比较 0.2 与 0.5 后取 0.5；BART/T5 判别式变体上 0.2 的结果更好。
- 训练侧配套：多标签用二元交叉熵 + Adam；编码器微调常用 lr=5e-5、batch=4。

## 依赖

- 需要多标签模型的连续输出（sigmoid），不接受只有硬标签的输入。
- 需要一个从训练集划出的验证集（文献做法：从训练集随机取 20%）。
- 评测依赖 sample-based F1 的实现（逐文档算 P/R 调和平均再求平均）。

## 适用条件

- 多标签分类（一篇文档可属多个类）且类标签分布不平衡或长尾时。
- 需要在多个模型间做公平对比、要求判决规则一致时。
- 有验证集可用于扫阈值时。

## 不适用条件

- 单标签（互斥多类）分类：用 argmax 或 softmax 归一化，本卡的阈值不适用。
- 没有验证集、只能在测试集上调阈值时，不得使用（会污染测试评估）。
- 阈值只能部分弥补模型缺陷：如果模型对某类的排序能力本身很差，调阈值不会带来真实提升。

## 验证状态

原文给出真实实验数字与配置：预实验在 WideMLP 上从 λ=0.5 到 λ=0.1（步长 0.1）逐个测试，结果与既有文献一致——较小的 λ=0.2 在不平衡标签分布下更有利；编码器模型的预实验比较 0.2 与 0.5 后采用 0.5；BART/T5 判别式变体比较 0.2 与 0.5 后采用 0.2（更好）。原文未给出各阈值对应的具体指标数值，故选型依据是"哪一侧更优"而非精确点数。
