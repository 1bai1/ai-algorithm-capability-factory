# 文本分类模型选型：微调 SLM 与 LLM

## 能力说明

根据标注数据量、任务类型（单标签/多标签/层级）与成本约束，在"微调编码器小模型""冻结生成式大模型的少样本上下文学习""微调大模型"三类路线之间选型，并给出不该选的路线（无信息增益的图方法）。

## 输入契约

- 任务类型与标签结构：单标签 / 多标签 / 层级（标签是否有分类体系）。
- 可用标注样本量（每类量级，是否达到百级/千级）。
- 成本约束：一次性微调算力预算 vs 持续推理 token 预算；是否有 GPU 推理条件。
- 是否允许使用外部模型/闭源 API。

## 输出契约

- 一条推荐路线 + 1~2 个备选，附推荐依据（数据量档位、任务类型、成本）。
- 至少一个强基线（微调编码器）与一个词袋类基线（TF-IDF + 线性模型）的对照结果，用于验证推荐是否成立。

## 调用方式

1. 判断数据量：每类达到百级以上时以微调编码器模型为主路线；只有个位数到几十条样本时用冻结 LLM 的少样本/零样本上下文学习。
2. 按任务类型微调：单标签选编码器模型（BERT-base 量级足够，先调对学习率）；多标签优先试编码-解码的 T5-base；层级任务选带层级建模的序列模型（如把层级注入 BERT 的 HBGL、层级化损失的 HYDRA）。
3. 不要默认上大模型：BERT-large 相对 base 无实质增益，小数据集上甚至回退。
4. 不要默认上图方法：合成图（TextGCN/HeteGCN）与层级图编码器（HiAGM）在多数数据集上不如强基线。
5. 成本翻译：微调是一次性算力成本、推理便宜；上下文学习是零训练但持续 token 成本且占用长上下文。按调用量折算后再定。

## 关键参数

- 关键数字（原文实测/汇总）：BERT-base 在 20ng/R8/R52/ohsumed/MR 上 87.21 / 98.03 / 96.17 / 71.46 / 86.61；DeBERTa-base 87.60 / 98.30 / 97.10 / 75.94 / 89.98（同类最优）；BERT-large 提升不超过 1 点，20ng 反而降 1 点（85.83）。
- GPT-3.5 16-shot + CARP + 投票（用微调 RoBERTa-Large 选样本）：R8 98.78、MR 92.39；但样本选择依赖一个已微调的小模型。
- RGPT（k=7 个微调 Llama-2 集成，LoRA rank 8，每模型约 2.1M 可训练参数）：ohsumed 77.41，仅比 DeBERTa-base（75.94）高 1.47 点。
- 多标签：T5-base 判别式在 R21578 92.72、RCV1-V2 89.13、Amazon 88.93、DBPedia 97.68、NYT 80.79、GoEmotions 55.01，为序列方法中最强（GoEmotions 除外）。
- 层级：HYDRA（RoBERTa-base）WOS 86.91/81.22、NYT 81.96/72.35、RCV1-V2 87.79/70.08（Micro/Macro-F1）；专用层级图方法未稳定超过它。
- 数据量阈值：文献报告在某些单标签任务上每类约 100 条标注样本后，微调模型即可超过上下文学习；该阈值随任务而变，多标签因一篇多标签而更复杂。
- 推理/思维链提示：在分类上收益有限（简单 CoT 只有 1~3 个百分点的提升），复杂推理常不如简单基线，且推理过程可消耗高至两个数量级的 token。

## 依赖

- 微调路线：一个编码器/编码-解码预训练模型 + 分类头 + Adam + 交叉熵（多标签用二元交叉熵）。
- 上下文学习路线：一个生成式大模型 API 或本地部署 + 少量示例（16-shot 量级）+ 可能的示例选择器（需微调的小模型）。
- 基线：TF-IDF + 线性 SVM / 逻辑回归 / MLP。

## 适用条件

- 有明确标注数据、需要落地一个文本分类器时。
- 需要在成本与效果间做决策时（微调 vs 冻结模型调用）。
- 需要评估"新方法相比强基线是否真有提升"时。

## 不适用条件

- 无标注数据且无法调用 LLM 时，本卡两条主路线都不成立。
- 类别分布会漂移、测试期可能出现训练未见的新类时，闭集微调不够，需改走零样本/开放集路线（见相关边）。
- 超出英文主题分类/情感分类的场景（多语言、专门领域），本卡数字不可直接套用，只能借用选型逻辑。
- 基准数据可能已进入 LLM 预训练语料时，LLM 一侧的公开成绩不可作为选型依据。

## 验证状态

原文给出真实运行结果：作者自跑了 BERT-base/large、DistilBERT、RoBERTa-base、DeBERTa-base、ALBERTv2、ERNIE 2.0、BART-base、T5-base、WideMLP、SVM、XGBoost 在五个单标签数据集上的结果（5 次重复的均值与标准差），并汇总了多标签与层级数据集上的文献数字；上列关键数字均出自其表 III、V、VI。
