# 文本分类选型：数据规模、成本与指标

## 能力说明

接到一个文本分类任务后，按**数据规模、算力成本、任务形态（短文本/长文本/多标签）、可解释性要求**选择模型路线与评测指标的决策能力。判断依据来自综述的总评与各章小结：小数据选传统模型、数据充足优先预训练模型、长文本避开浅层 CNN、极多类别改用 P@K/NDCG@K，等等。同时本卡记录各数据集上的准确率参照值，用于设定预期与判断方案是否达标。

## 输入契约

- 任务画像：数据规模（条数）、类别数、平均文本长度、是否多标签、类别是否不均衡。
- 资源与约束：标注预算、算力预算、推理时延/吞吐要求、可解释性要求、领域（是否术语密集）。
- 可用外部资源：能否使用预训练权重、能否取得领域内无标注语料。

## 输出契约

- 推荐的模型路线（浅层 / CNN / RNN / 注意力 / 预训练，或它们的融合）及其理由与代价说明。
- 推荐的评测指标（accuracy / F1 / Micro-F1 / Macro-F1 / P@K / NDCG@K / MRR / Hamming Loss）。
- 该数据集上的参照成绩区间（留作验收基线）。

## 调用方式

按以下顺序判断（每条都对应综述的明确表述）：

1. **确认任务边界**：情感分析、新闻分类、主题标注、自然语言推理差异很大，综述提醒不能一概简化成同一个分类问题——先按任务形态选数据与指标，再选模型。
2. **看数据规模**：小数据集（万级、标注少）→ 先试传统模型（综述：算力复杂度约束下传统模型通常优于深度学习模型）；标注充足 → 优先试预训练语言模型（BERT/RoBERTa/XLNet），例外是 MR 与 20NG——综述汇总表中没有基于 BERT 的实验。
3. **看任务形态**：
   - 短文本 → 集成方法收益有限，不必优先；
   - 类别域交叉重叠多 → KNN 更合适（只看周围有限近邻）；
   - 高维非线性 → SVM；特征强相关 → 慎用朴素贝叶斯（独立假设失效）；
   - 要可读规则 → 决策树，但注意数据规模爆炸时低效；
   - 长文本 → 避开浅层 CNN（长距离特征捕获弱、池化丢位置信息），注意 Transformer 长序列注意力计算重、RNN 不可并行；
   - 需要文本结构信息 → 图神经网络，前提是能设计出有效图结构。
4. **看标注量**：无/少标注 → 无监督与半监督学习潜力大（VAT 类正则化只引入少量超参）；零样本/少样本仍是公开挑战，模型过度依赖大量标注。
5. **选指标**：
   - 单标签平衡数据 → Accuracy / ErrorRate；
   - 类别不均衡 → Precision / Recall / F1；
   - 多标签 → Micro-F1（考虑类别数，适合不平衡分布）或 Macro-F1（各类等权，易受高 P/R 类别影响）；
   - 类别数很多/极多 → P@K 或 NDCG@K；
   - 排序型问答 → MRR；多标签还可看 Hamming Loss。
6. **核成本与可解释性**：传统模型算力低但需人工特征、难迁移；深模型效果高但训练成本高、是黑箱；注意力只提供词/句级的部分解释。综述把"数据/算力与预测性能之间的权衡"列为待研究问题，没有给出统一的最优公式。

## 适用条件

- 需要在多条技术路线之间做取舍、且要先给出验收基线时。
- 数据规模处于边界地带（数千到数万条）——这是传统模型与预训练模型成绩最接近、选型最需要依据的区间。
- 需要在方案里显式说明成本（算力、时延、可解释性）取舍时。

## 不适用条件

- 任务不是单标签文本分类（如生成式问答、序列标注）——综述只讨论分类与抽取式问答。
- 需要的是具体实现细节而非路线选择：本卡不含网络结构参数、训练超参。
- 要求经统一复现验证的横向排名：综述汇总数字未统一数据划分与预处理，本卡不能提供严格的模型排名。

## 验证状态

已验证（文献报告值，非本库复现）。综述可用于选型的真实数字：

- 传统模型：SST-2 上 NB 81.8%、SVM 79.4%（说明小数据上传统模型的稳定性）。
- 各数据集汇总表最高值（Table 4）：SST-2 97.00（XLNet）、IMDB 96.21（XLNet-Large）、Yelp.P 98.45（XLNet-Large）、Yelp.F 72.20（XLNet-Large）、Amz.F 67.74（XLNet-Large）、DBpedia 99.38（XLNet）、AG 95.51（XLNet）、SNLI 92.60（RoBERTa）——预训练模型在多数数据集领先；MR 83.80（RNN-Capsule）与 20NG 96.50（BLSTM-2DCNN）是两个例外，综述明确这两个数据集没有基于 BERT 的实验。
- 结构路线的代价样本：TextGCN 在 AG 上只有 67.61%、在 MR 上 76.74%，而同表 AG 最高为 XLNet 95.51%、MR 最高为 RNN-Capsule 83.80%——说明 GNN 不是通用优解，图结构设计不到位时反而显著落后。
- 注意：以上均为各原文自报值、综述汇总，未统一复现与统一切分，只可作为量级参照，不能当作严格排名。
