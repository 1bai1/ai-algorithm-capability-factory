# MLP 神经网络预测（价格回归）

## 能力说明
用全连接前馈网络做价格/收益率的非线性回归预测：把滞后项、滚动统计与技术指标拼成宽特征向量，经互信息筛选后用 MLP 输出下一期价格。解决"线性模型抓不到非线性映射、而树模型又难做连续值外推"的中间场景，可作为深度学习侧的轻量基线（比 LSTM/GRU 更快、更少超参）。

## 输入契约
- 价格序列 + 派生特征。原文配方一（14-4）：滞后阶数 1–29 × 滚动窗口 2–59 的滞后与滚动统计，叠加技术指标（Indicator 函数输出）后与目标列拼接；互信息阈值 mic=3。
- 原文配方二（8-2）：仅单列对数收益率 `log(1 + pct_chg/100)`，监督样本错位一格构造（X=returns[:-1]、y=returns[1:]）。
- 数据规模示例：金价日频 2000–2022 的 OHLCV 五列（Gold 数据框）；茅台日线 2008-01-01 至 2023-09-01。
- 特征与标签必须各自缩放：原文用 PowerTransformer（使分布接近高斯，比 MinMax/Z-score 更能稳定极端行情下的分布）；标签也缩放，评估前再逆变换。
- 输入维 = 筛选后特征列数（示例 188 维），顺序由互信息分值排序 + 阈值截断决定。
- 训练/测试按时间顺序切分，示例为留出末尾 60 个样本（单次留出）。

## 输出契约
- 单目标回归值（价格），`n_steps` 直接取特征列数。
- 误差指标：MAE、RMSE——必须报告逆变换后的量纲值（归一化域误差没有业务含义）；原文示例同时给出逆变换前后的两套数值。
- 可视化为实际价格与预测价格对比曲线（示例末 60 个交易日）。
- 8-2 的评估补充：测试集 MSE + 实际/预测对比散点图 + 历史与预测回报趋势图。

## 调用方式
```python
# 金价流程（14-4 / 14-5）
Performance_tune(Data, col, Lag_list, Roll_window, mic)   # 串联特征、筛选、建模、评估
Performance(Data, col, Lag_list, Roll_window, mic)        # 通用版（不针对单一目标列调参）
# 内部：Prepare(Data, col, Lag_list, Roll_window) + Indicator(Data)
#       + mutual_information_lag(data, col, 100) → 阈值 mic 截断
#       → PowerTransformer.fit_transform(X / y) → X[:-60] / X[-60:] → model.fit

# 8-2 的 PyTorch 实现
class DeepMLP:  # nn.Linear(1,128) → ReLU → nn.Linear(128,64) → ReLU
                # → nn.Linear(64,32) → ReLU → nn.Linear(32,1)
optim.Adam(model.parameters(), lr=0.001, weight_decay=model.weight_decay)  # L2 正则
```
- Keras 结构（14-5）：`Dense(8*n_steps, relu, kernel_initializer='he_uniform')` → `Dense(64, relu)` → `Dense(32, sigmoid)`。
- Keras 结构（14-4）：输入 188 维 → `Dense(1425)` → Dropout → `Dense(1)`，合计约 27 万参数。
- 随机种子固定：`seed(111)`（14-x）；8-2 未给种子。

## 关键参数
| 参数 | 含义 | 原文取值 |
|---|---|---|
| Lag_list | 滞后阶数 | 1–29（另有调用示例 [2,3,4,5]） |
| Roll_window | 滚动窗口 | 2–59（另有示例 2） |
| mic | 互信息保留阈值 | 3 |
| 丢弃行数 | 窗口特征造成的无效首行 | 前 100 行 |
| 缩放器 | 特征与标签 | PowerTransformer（X、y 各自 fit） |
| 网络宽度 | 隐层 | 8×n_steps(ReLU) → 64(ReLU) → 32(Sigmoid)；或 Dense(1425)+Dropout |
| 测试段 | 样本外 | 末尾 60 个样本 |
| 优化器 | 训练 | Adam（8-2：lr=0.001 + weight_decay L2；MSE 损失） |
| 调参工具 | 超参搜索 | Optuna（14-1 声明，具体搜索空间原文未给出） |

## 依赖
TensorFlow/Keras（Sequential、Dense）、scikit-learn（PowerTransformer、mutual_info 相关函数、MAE/RMSE）、pandas/numpy/matplotlib；8-2 另需 torch；可选 optuna。

## 适用条件
- 已有一批滞后/滚动/技术指标特征（几十到几百维），目标是做连续价格回归而不是方向分类。
- 需要一条比 LSTM/GRU 更轻、调参更少、训练更快的深度基线；或作为树模型之外的对照。
- 数据含极端行情、分布偏斜明显时，用 PowerTransformer 稳定尺度（原文明确推荐）。
- 需要把"特征生成 → 互信息筛选 → 定维 → 建模"做成自动流水线时，接口形态（X 列数直接决定输入维度）便于参数化。

## 不适用条件
- 只喂单列日收益率：8-2 实测"预测值接近零 + 测试 MSE 很低"实为模型退化为输出均值，日收益率近似白噪声，该结果不能解读为预测力。
- 标准化在全量数据上 fit 后再切测试集：14-4 与 14-5 均在切分前对全量 X/y 做 fit_transform，测试集信息进入缩放参数，误差偏乐观，复用时必须在训练段 fit。
- 只留末尾 60 个样本做单次评估、无滚动/多折验证：金价单边行情下结果偶然性大。
- 标题/描述与实际结构不符的模型不要照抄：14-5 称"9 层 MLP"，代码只有 3 个 Dense 层。
- 用价格拟合精度替代业务评价：MAE≈8.96 未与"沿用上一期价格"的朴素基线对比，也没有交易信号与回测。
- 互信息在全样本上计算且阈值无依据（mic=3 的量纲与选取过程原文未解释），会造成信息泄露与主观性风险。

## 验证状态
原文给出真实运行结果：
- 14-4（金价 Gold，滞后 1–29、滚动 2–59、mic=3，188 维输入，测试集为最后 60 个样本）：逆变换前 MAE 0.0166 / RMSE 0.0183；逆变换后 MAE 8.96 / RMSE 9.89；随机种子 111。未与朴素基线对比，且存在全量标准化泄漏。
- 14-5（同数据集与同参数接口，另一种网络宽度）：只给出实际/预测对比曲线，原文未给 MAE/RMSE 数值，并自述"只实现初级功能、还存在一些问题"。
- 8-2（贵州茅台 600519.SH 日线 2008-01-01 至 2023-09-01，单特征对数收益率，DeepMLP 1→128→64→32→1 + L2）：原文称测试集 MSE 很低、未来一个月预测接近零，并据此判断"模型表现良好"——提炼材料判定这属误判（模型退化为输出均值），不构成有效性证据。
- 12-5：MLPClassifier 进入 8 模型对比池，但原文只公布 LogisticRegression 的 AUC=0.887，MLP 无结果数字。
- 14-1：仅模块说明（数据准备 → MLP 价格预测 → 策略设计 → 结果分析，用 Optuna 调参），无代码、无结构、无指标。
