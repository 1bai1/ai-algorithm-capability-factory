# 自回归族单变量时序预测（AR/MA/ARMA/ARIMA/SARIMA）

## 能力说明
单变量金融序列的标准统计预测能力：先平稳化（差分/对数），再用 ACF/PACF + AIC/BIC 定阶，用极大似然估计 AR/MA/ARMA/ARIMA/SARIMA，输出点预测与置信区间。解决"给定一条价格或收益率序列，产出短期外推值 + 不确定性区间 + 可作为复杂模型对照的基线"这一问题。

注意术语区分：此处的 MA 是"过去预测误差的加权移动平均"，不是行情软件里对价格做平滑的 SMA/EMA 均线；AR/MA 的 ACF/PACF 定阶规则与均线交叉信号无关。

## 输入契约
- 单变量序列 + 时间索引，等间隔、按时间升序；缺失值先 dropna。
- 实测样本规模：日频 891 条（茅台 2020-01-02 至 2023-09-01）、762 条（比特币 2020-01-01 至 2022-01-28）、4637 条（某股 2004-08-23 至 2023-01-23）；月频 423 条（IMF 锌价 1980-12 至 2016-02）。原文未给最小样本量门槛，可确认的最低实证规模为 423 条。
- 准入检验：ADF 单位根检验，p > 0.05 判非平稳，先差分或转对数收益率 r_t = ln(y_t) − ln(y_{t−1})。
- 可选外生变量（ARIMAX）：exog 列须在预测时点可得，原文示例为 Open/High/Low（此做法存在未来信息问题，见"不适用条件"）。
- 序列无稳定季节性时不要塞季节项。

## 输出契约
- 点预测：测试期拟合值 + 未来 h 步外推值（价格尺度或收益率尺度，取决于建模对象）。
- 区间：95% 预测置信区间（get_forecast 返回 forecast / upper_interval / lower_interval；statsmodels predict 需自行拼未来日期索引）。
- 参数表：系数、标准误、z、P>|z|、AIC/BIC/HQIC、sigma2、观测数。
- 残差诊断：Ljung-Box（自相关）、Jarque-Bera（正态性）、异方差检验、偏度、峰度。
- 误差指标：MSE/RMSE/MAE（原文要求在还原后的价格口径上计算）；MAPE、MASE（MASE = 测试集 MAE ÷ 训练集一阶差分平均绝对幅度，>1 不如朴素预测）。

## 调用方式
```python
from statsmodels.tsa.arima.model import ARIMA          # ARMA 即 ARIMA(p,0,q)
from statsmodels.tsa.statespace.sarimax import SARIMAX # SARIMA: order + seasonal_order
from statsmodels.tsa.stattools import adfuller
from statsmodels.graphics.tsaplots import plot_acf, plot_pacf

adfuller(series, autolag='AIC')            # p>0.05 → 差分/取对数收益率
model = ARIMA(train, order=(p, d, q)).fit()          # ARIMAX 传 exog=...
model.summary()                            # 系数显著性 + AIC/BIC/HQIC + 诊断
pred = model.get_forecast(steps=h)         # 或拼未来日期索引后 model.predict(start, end, dynamic=False)
```
- 自动定阶：`pmdarima.auto_arima(y, start_p=0, max_p=5, start_d=0, max_d=5, start_q=0, max_q=5, seasonal=False, trace=True)`，按 AIC 最小取阶。
- 跨模型横向搜索：对 (p,q) 用 itertools.product 做网格，逐个 fit 后取 AIC 最小。

## 关键参数
| 参数 | 含义 | 原文取值 |
|---|---|---|
| p | AR 阶数，PACF 截尾点 | 示例 p=3（AR/茅台）；(1,1,1)（比特币）；(2,0,1)（锌价月频） |
| q | MA 阶数，ACF 截尾点 | 示例 1；(2,1) 序列中 q=1 |
| d | 差分阶数 | 一阶差分后平稳取 d=1；auto_arima 搜索 0–5；月频锌价示例使用过 d=5（属过度差分，见下） |
| (P,D,Q,s) | 季节项 | s=22（月内交易日，人工指定）；示例 ARIMA(1,1,1)(1,1,1)_4 仅作演示 |
| ACF/PACF lags | 定阶探查窗口 | 5（股票示例）、20（比特币示例） |
| 训练/测试切分 | 按时序比例 | 8:2（茅台）、7:3（比特币 533/229）、按年份（2004–2019 训练 3867 行 / 2020–2023 测试 770 行） |
| 外推步长 | 未来 h 期 | 5（AR）、10（ARMA/ARIMA）、24（月频）、30（SARIMA） |
| 置信水平 | 区间 | 95%（alpha=0.05） |
| coverage / 分解周期 | 其他 | seasonal_decompose period=365 仅在 ADF 探查篇出现，未用于最终模型 |

选型依据：单变量且已平稳 → ARMA(p,q)；非平稳 → ARIMA(p,d,q)；有可信季节周期 → SARIMA；有实盘可得的外部变量 → ARIMAX；多变量互相反馈 → 改用 VAR/VEC（另卡）。

## 依赖
statsmodels（adfuller、plot_acf/plot_pacf、ARIMA/SARIMAX，原文注明需 ≥0.12）、pmdarima（auto_arima）、scikit-learn（mean_squared_error）、pandas / numpy / matplotlib、plotly（15-11 的区间可视化）。

## 适用条件
- 单只标的、单一序列、无可用外部因子时的首选基线；短期（1–5 个工作日，最长不过 30 期）外推。
- 样本量数百至数千条即可起步；对收益率类序列（对数收益率近似平稳）比价格序列更合适。
- 需要"预测区间"而不是单点值的风险场景（区间宽度可作仓位/风控输入）。
- 作为复杂模型（树模型、LSTM/GRU）的对照线；任何新模型应至少不劣于 ARIMA 与朴素基线（随机游走/上一期值）。
- 残差诊断通过（Ljung-Box 不拒绝、无显著异方差）时才可采信其区间估计。

## 不适用条件
- 直接对价格水平建模：应转对数收益率或做去趋势；对已去均值序列再做高阶差分属过度差分，会放大噪声（4-2-02 对已去 12 期滚动均值的对数序列再用 d=5）。
- 序列存在波动率聚集、厚尾、结构突变：实测残差 JB=9485.55(p=0.00)、峰度 10.67，高斯假设不成立，应改用 GARCH 族或稳健方法。
- 预测时点外生变量不可得：29-5-03 用当期 Open/High/Low 预测 Close，实盘中该信息在决策时点尚未产生，其 RMSE=0.7477 含乐观偏差，不可当作业绩参照。
- 需要长跨度外推：ARIMA 置信区间随步长迅速变宽，原文未讨论超过 10 步的实用性。
- 季节性周期无检验依据时不要上 SARIMA：s=22 为人工指定，1-2-4 原文自标"复制不成功"、代码不完整，不能作为可复用实现。
- 单次静态 8:2 切分的精度结论不能当稳健结论，必须配 walk-forward 或滚动重估。
- 想把 ARIMA 当收益发生器：原文所有结果都是价格/收益率拟合误差，未含交易成本与 A 股 T+1、涨跌停约束。

## 验证状态
原文给出真实运行结果（含数字），但也存在自相矛盾与不可采信处，逐条列明：
- 15-10（比特币日频对数价格，2020-01-01 至 2022-01-28，762 观测）：一阶差分 + auto_arima（p/d/q 搜索 0–5、seasonal=False）选中 ARIMA(1,1,1)+截距，**AIC = −2718.121**；训练 533 / 测试 229；实现了 walk-forward 逐步重训的 95% 区间预测。未给 RMSE/MAPE 等误差数字。
- 29-5-03（某股日频 OHLC 2004-08-23 起，训练 3867 行 / 测试 770 行）：ARIMA(1,1,1) + exog(Open/High/Low) 预测 Close，测试集价格尺度 **RMSE = 0.7477**；外生系数 Open −0.5615、High 0.7750、Low 0.7870（p≈0.000）；残差 Ljung-Box Q=0.19(p=0.67)、Jarque-Bera 9485.55(p=0.00)、偏度 0.10、峰度 10.67。该 RMSE 因使用当期 exog 而偏乐观。
- 1-2-3（茅台 891 条，2020-01-02 至 2023-09-01）：原文自相矛盾——正文称最优 (1,0) 对应 AIC −4506.06，拟合摘要中 ARIMA(1,0,0) 的 AIC 为 −3506.28 且观测数 712（与 891 条不符），常数项 p=0.437 不显著；该数值不可采信。
- 1-2-2（同标的）：ADF 统计量 −2.58、p=0.097，未通过 0.05 门槛；原文建模代码在"排序并 reset_index"处截断。
- 1-2-4（SARIMA 流程）：原始收盘价 ADF = −2.5801、p = 0.0972；无任何可用输出数字，代码不完整。
- 4-2-02（IMF 锌价月频 423 条，1980-12 至 2016-02）：ADF 对数价格 p=0.0238、去滚动均值后 p=2.8e-07；ARMA(2,0,1) 系数 ar.L1≈−1.083、ar.L2≈−0.528、ma.L1≈−0.997 均显著；未给任何误差指标，也未与随机游走对照。
- 4-2-01：auto_arima 在示例中选出 ARIMA(0,1,0)+截距（无阶数价值）；AR 滑窗版输出 MSE=0.00，疑样本内评估或泄漏，不可作性能参照。
- 29-5-01/02：仅 ADF（统计量 −0.198、p=0.939）与 ACF/PACF 绘图流程，无拟合与误差。
结论：可引用的数字只有 AIC −2718.121（15-10）与 RMSE 0.7477（29-5-03，偏乐观）；ARIMA 在 A 股个股上的实际增益未被任何一篇证明优于朴素基线。
