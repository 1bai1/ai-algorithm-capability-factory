# 向量自回归模型 VAR 多变量联合预测

## 能力说明
把一组相互关联的金融变量（个股、指数、利率、宏观指标）全部视为内生变量，用各变量自身的滞后项与其他变量的滞后项共同解释当前值，从而做多变量短期联合预测，并顺带产出冲击传导（脉冲响应）与波动贡献（方差分解）两类结构性解读。解决"单变量 ARIMA 无法利用跨资产联动信息"的问题。

## 输入契约
- 多列等间隔时间序列，同一时间索引对齐；日频示例 1564 条（2018-01-02 至 2023-12-29），变量为贵州茅台收盘价、沪深300 指数、10 年期国债收益率。
- 变换口径：价格序列转对数收益率 r_t = ln(y_t) − ln(y_{t−1})（原文示例再乘 100）；利率类取变化量而非水平值。
- 每个序列必须通过 ADF 平稳性检验（5% 水平）；不平稳则差分；若存在协整关系，应改建 VEC 模型而不是直接 VAR。
- 变量数不宜多：原文明确"参数随变量数平方增长，对变量个数敏感，易过拟合"。原文实例为 3 变量。

## 输出契约
- 最优滞后阶数 p（在 1–10 中按 AIC 选取，同时报告 BIC/HQIC/FPE）。
- 逐方程 OLS 估计系数与显著性；残差用 Ljung-Box 检验无自相关。
- 脉冲响应函数 IRF（示例 10 期）：单位冲击的传导时滞与幅度。
- 方差分解 VD（示例 10 期）：各变量对目标波动的解释占比，可作为因子有效性判据。
- 未来 10 个交易日的多变量联合预测（以最后 best_lag 期数据为输入外推）。

## 调用方式
```python
from statsmodels.tsa.vector_ar.var_model import VAR
from statsmodels.tsa.stattools import adfuller, grangercausalitytests

data = pd.DataFrame({'maotai_ret': ret1, 'hs300_ret': ret2, 'bond_chg': d3})
var_model = VAR(data)
order = var_model.select_order(maxlags=10)   # 按 AIC 选 p
results = var_model.fit(order.aic)
results.irf(10).plot()                        # 脉冲响应
results.fevd(10)                              # 方差分解
results.forecast(data.values[-p:], steps=10)  # 未来 10 个交易日联合预测
```
- 变量预筛：`grangercausalitytests`，p<0.05 视为存在引导关系，用来挑对目标标的具领先性的外生变量（例：判断大盘是否领先个股）。
- 非平稳或参数过多时的升级路径：VEC（协整）或贝叶斯 VAR（BVAR）。

## 关键参数
| 参数 | 含义 | 原文取值 |
|---|---|---|
| maxlags | 滞后阶搜索范围 | 1–10，按 AIC 最小取 p |
| 平稳化 | 收益率换算 | 对数收益率 ×100；利率取变化量 |
| irf periods | 脉冲响应期数 | 10 |
| fevd periods | 方差分解期数 | 10 |
| 预测步长 | 联合外推 | 10 个交易日 |
| 格兰杰检验 | 领先性筛选 | p<0.05 判定存在引导关系 |
| 样本量 | 日频记录 | 1564 条（3 变量） |

## 依赖
statsmodels（`statsmodels.tsa.vector_ar.var_model.VAR`、adfuller、grangercausalitytests）、pandas、numpy、matplotlib。

## 适用条件
- 有 2–5 个相互关联的日频序列（个股 + 板块指数 + 利率/汇率/商品），且关注的是"联动与传导"而不只是单序列外推。
- 需要判断一个候选因子是否对目标标的具领先性时，用格兰杰因果先筛，再决定是否入 VAR。
- 样本量充足（原文 1564 条 / 3 变量；变量数越多所需样本越多）。
- 作为跨市场风险溢出（美股→A股/港股）、货币政策传导时滞的解读工具，而非高频交易信号发生器。

## 不适用条件
- 变量数多：参数按变量数平方增长，过拟合风险高；原文明确对变量个数敏感。
- 存在非线性、非对称传导或结构突变时：VAR 是线性模型，无法刻画（原文自陈）。
- 序列不平稳且存在协整时：直接 VAR 会失真，应改用 VEC。
- 需要可交易的量化结果时：原文全程未给 MAE/MAPE、方向准确率，也无滚动样本外验证，不能据此上线。
- 样本跨越 2018 熊市、2020 疫情等结构变化而不分区间：单一全样本估计的稳健性未验证。
- 不能把 IRF/VD 图当作因果结论：原文图件未收录，且线性 VAR 的冲击解读依赖变量排序假设（原文未讨论）。
