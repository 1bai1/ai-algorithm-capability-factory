# 树模型预测（随机森林与梯度提升）

## 能力说明
用 bagging 树（随机森林）与 boosting 树（GradientBoosting / HistGradientBoosting / XGBoost / LightGBM / CatBoost / AdaBoost）做两类任务：把价格预测转成"下一期涨跌"二分类，或用滞后/滚动/技术指标特征做价格回归。原文档化的实测结论是负面的：在纯 OHLCV 或少量技术指标上做日频/周频方向分类，AUC 约 0.51–0.58、准确率 0.49–0.59，接近随机水平。本卡按"记录踩坑"处理，参数与流程可用，精度结论不可盲信。

## 输入契约
- 分类：X 为特征矩阵，y 为二分类方向标签。标签构造范例 `Target = (Close_t > Close_{t-1})`；全部特征必须先 `shift(1)`，用前一天及更早的数据预测下一日走势（不平移等于用当天数据预测当天目标）。
- 回归：价格序列 + 派生特征。示例配方（金价 13-4）：滞后期 2–5、滚动窗口 2、L-moments 窗口 5，并对 OHLCV 各列做同样扩展后横向拼接，截掉窗口造成的头部无效行；预测段固定留出末尾 90 天。
- 特征规模参考：9 列（sma_12、sma4_ratio、rsi、obv、4week_vol、12week_vol、acceleration、velocity、obv_divergence_12_weeks）；23 列（OHLC+Adj Close、K 线实体/影线比率、lag1 及 close 对 lag1~lag5 比值、9 日波动率与 9/20 日波动率比、RSI 与超买标记、CCI、OBV 背离 5/10 日、returns、close 对 EMA8 比率）；或 13 个 GRU 用过的价量衍生特征（见 LSTM/GRU 卡）。
- 划分必须按时间顺序（75/25、8:2、按年份），禁止随机 shuffle。
- 抗噪、免归一化是树模型的天然优势，但类别不平衡时须显式处理（原文用 RandomOverSampler）。

## 输出契约
- 二分类：`predict_proba(X)[:,1]` 正类概率 → 阈值 0.5 或自定义阈值 → 1/0 涨跌标签 → 可映射为 +1/−1/0 三态交易信号。
- 回归：价格预测值（原文口径在还原后的价格尺度上算 MAE/RMSE/R²）。
- 诊断件：分类报告（precision/recall/f1）、误分类计数图、训练/测试的 error 与 logloss 学习曲线、ROC 曲线与混淆矩阵。
- 特征重要性：`permutation_importance(n_repeats=100, random_state=42)` 按均值排序画水平条形图（原文认为优于树自带 importance，且可用于任意模型）。

## 调用方式

# Optuna 调参（31-7）：objective(trial) 返回 AUC，direction='maximize'，n_trials=1000

## 关键参数
| 模型/工具 | 原文参数 |
|---|---|
| XGBClassifier（基线） | max_depth=3，learning_rate=0.1，early_stopping_rounds=10，eval_metric=['error','logloss'] |
| XGBClassifier（调参） | 网格 max_depth ∈ {18,21,25}、reg_lambda ∈ {0.1,0.4,0.8}，cv=3；搜索最优为 max_depth=25/reg_lambda=0.1，但最终训练用 reg_lambda=0.8（原文前后不一致） |
| XGBRegressor（15-6） | n_estimators=100、learning_rate=0.3、max_depth=6、n_jobs=4、random_state=0（未调参，比较不公平） |
| HistGradientBoosting（Optuna 空间） | learning_rate 对数均匀 1e-3~0.1、max_iter 100~1000、max_leaf_nodes 2~100、max_depth 1~10、min_samples_leaf 1~15、l2_regularization 1e-4~0.1 |
| CatBoost（Optuna 空间） | learning_rate、depth（最优 depth=2，很浅的树）、l2_leaf_reg、random_strength、bagging_temperature、border_count、min_data_in_leaf |
| LightGBM 回归 | LGBMRegressor + verstack.LGBMTuner（Optuna 后端）；原文未给最终超参 |
| RandomForestRegressor（15-6） | max_depth=1000（其余默认） |
| AdaBoost / GradientBoosting / HistGB / CatBoost / XGB | 全部 random_state=seed（原文 seed=123） |
| 特征筛选（12-5） | SelectKBest(score_func=f_classif, k=len(X_train.columns)) + p<0.05 过滤 → 23 个特征 |
| 输出指标 | AUC、accuracy、precision/recall/f1、MAE/RMSE/R² |

## 依赖
scikit-learn（集成器、GridSearchCV、permutation_importance、roc_curve/auc/roc_auc_score）、xgboost、lightgbm、catboost、optuna、verstack（可选，LGBMTuner）、imbalanced-learn（RandomOverSampler）、matplotlib/seaborn/plotly。

## 适用条件
- 特征以结构化表格为主、维度高、含缺失或类别型字段（CatBoost 自动处理类别与缺失）、需要低延迟与可解释性时优先树模型。
- 已知有信息量的因子/微观结构特征（订单簿不平衡度、大额订单占比、量价衍生）时，随机森林/XGBoost 是默认首选（6-1-02/6-1-03）。
- 特征筛选后特征数适中（示例 23 列）且有明确标签构造纪律（shift 防未来函数）时，可作涨跌方向基线，并用 permutation_importance 做因子解释。
- 回归任务（价格/波动幅度）配滞后 + 滚动统计 + L-moments 特征，可做单标的短期价格拟合（13-1/13-4）。
- 作为集成学习的基学习器（见"集成与堆叠方法"卡）。

## 不适用条件
- 只有 OHLCV、目标是日频涨跌方向：实测 accuracy 0.49–0.50、类别 1 召回 0.92 而类别 0 召回仅 0.15（模型几乎全预测上涨），无预测力。
- 9 个技术指标 + 周频方向标签：AUC 仅 0.51–0.53；Optuna 调 1000 次后升到 0.55–0.58，仍接近随机，不要据此投入实盘。
- 样本极小：黄金示例仅约 30 个交易日（2024-11-22 至 2025-01-06）就上随机森林，极易过拟合。
- 用测试集调参或早停：Optuna 以测试集 AUC 为目标（31-7）、GridSearchCV 与 early_stopping 的 eval_set 含测试集（29-4）都会造成乐观偏差，不能作为选型依据。
- 类别重采样发生在切分之前：合成样本会同时进入训练与测试，测试集被污染（29-3 的 RandomOverSampler 即此问题），先切分再重采样。
- XGBoost 不做调参就参与横向比较（15-6 learning_rate=0.3），会得出"XGBoost 最差"的错误结论。
- 把 AUC/准确率等同于可盈利性：原文所有卡片都没有交易成本、回测收益与回撤。

## 验证状态
原文给出真实运行结果，但结果多为接近随机的负面证据，且若干流程含泄漏，故本卡标为"有缺陷"：
- 31-6（AAPL 周频方向，9 特征）：五个梯度提升分类器实测 AUC 最好 0.53（GradientBoosting），CatBoost 0.51。
- 31-7（同任务 Optuna 1000 trials）：HistGradientBoosting 0.51 → 0.55（单次试验分数在 0.47~0.55 波动）；CatBoost 0.51 → 0.58（最优 depth=2）。优化目标是测试集 AUC，属乐观偏差。
- 29-3（某日频 OHLCV，训练 3633 / 测试 1211）：XGBClassifier(max_depth=3, lr=0.1) accuracy 0.49，类别 1 召回 0.92、类别 0 召回 0.15；max_depth=7/15 后 accuracy 仍为 0.50。
- 29-4（同任务）：GridSearchCV 选出 max_depth=25/reg_lambda=0.1，实际训练用 reg_lambda=0.8；测试集 accuracy 0.55，类别 0 precision 0.71/recall 0.33/F1 0.45，类别 1 precision 0.49/recall 0.83/F1 0.62。
- 12-5（期货连续价格，23 个筛选后特征，8 个分类器横向对比）：原文只给出 LogisticRegression 的 AUC=0.887，其余 7 个模型（含 XGB/LGBM/CatBoost/RF/AdaBoost/GBDT/MLP）结果缺失，"选优"结论断链。
- 15-6（比特币周频收盘价，504 条，滑窗 15）：XGBoost MAE 0.0474/RMSE 0.0610（最差，且未调参）；随机森林居中；线性回归最好 MAE 0.0247/RMSE 0.0320。整体训练 R²≈0.988、测试 R²≈0.952，主要来自价格自相关，不等于可交易预测力。
- 13-4（金价，LightGBM 回归，留出末尾 90 天）：原文未给 MAE/RMSE 数值，也未与朴素基准对比。
- 6-1-02 / 6-1-03（黄金日频，约 30 个交易日）：随机森林/梯度提升做次日涨跌方向，无准确率数值，信号映射为 +1/−1/0。
- 3-2（用加密货币特征预测黄金，LASSO/随机森林/梯度提升树）：原文未给任何 R²/MSE 数值，代码几乎全缺。
- 1-2-7：RF/XGBoost/LightGBM 的定位是"抗噪、免归一化但易过拟合，SHAP 可补解释性"（叙述性，无实验）。
