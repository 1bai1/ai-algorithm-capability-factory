# 隐马尔可夫模型 HMM 市场状态识别

## 能力说明
假设市场由若干不可见的隐状态（本项目三状态被解释为"快速增长 / 较慢增长 / 下降"）驱动，通过观测到的价格序列反推各时点的状态后验概率，并由此合成"期望异常收益率（EAR）"作为择时打分。原文明确定位：HMM 是特征提取器，不是价格预测器——它输出状态与期望收益，供阈值型 0/1 择时策略使用。

## 输入契约
- 一维价格序列（日频），仅用对数收益率 R = log(P_t / P_{t−1}) 拟合。
- 训练必须取序列的连续前段（原文取第 100 天到第 600 天的 500 天），禁止随机抽样；其后数据作样本外测试（测试自第 600 天起）。
- 状态数：3（人工设定，原文未见 BIC/AIC 模型选择）。
- 数据源示例为 coinbaseUSD（2014-12-01 至 2019-01-09）与 bitstampUSD（2012-01-01 至 2019-03-13）的 1 分钟 OHLCV，按日聚合 Weighted_Price 均值成日频价格。
- 缺失日补缺规则（原文实现）：缺失日取"前一日值与下一个非缺失日值的平均"（0.5×(前+后)），若其后无有效数据则前向填充兜底；补缺后必须画图核对。

## 输出契约
- 拟合参数：各状态收益率均值 MU（示例 MU = [0.0787, 0.0014, −0.0859]）、3×3 状态转移矩阵 P、自回归系数 beta（示例 ≈0.184）。
- 每个时点的隐藏状态后验概率序列（用归一化价格叠加三状态概率曲线做可视化核对）。
- 期望异常收益率 EAR：由状态概率与转移矩阵计算的连续打分，供阈值化择时。
- 策略侧输出：按买入/卖出阈值生成的仓位状态（'c' 现金 / 'b' 持仓）与逐日组合价值。

- 阈值网格：`X = np.linspace(-0.1, 0.1, res)`（res=200），双层循环只遍历 sell ≤ buy 的组合；在训练段回测取收益最大的一对；收益存 R[res,res]、交易次数存 T[res,res]。
- 成本显式入目标：`FR = np.log(R) + T*np.log(1-f)`，对 100 档摩擦率（`np.linspace(0, 0.02, 100)`）各自 argmax。
- 模拟数据生成器（压力测试用）：`s = np.random.choice(range(3), p=hmm.TP[:, s])`；`r = hmm.beta*r + hmm.MU[s] + np.random.randn()*hmm.sig`；`Psampled = np.exp(np.cumsum(Rsampled))`。

## 关键参数
| 参数 | 含义 | 原文取值 |
|---|---|---|
| 状态数 | 隐状态个数 | 3（快速增长/较慢增长/下降），人工设定，无统计检验 |
| nstarts | NLL 多起点优化次数 | 10（非凸目标，取最优解） |
| 训练窗口 | 连续前段 | 第 100–600 天，共 500 天 |
| beta | 收益率自回归系数 | 拟合值 ≈0.184 |
| 阈值网格 | 买卖阈值搜索 | [−0.1, 0.1] 取 200 点，仅 sell ≤ buy |
| 摩擦率档位 | 成本敏感性 | 0–2% 共 100 档；单档展示取 0.5% / 1% / 1.5%（索引 25/50/75） |
| 优化器 | 参数估计 | scipy.optimize.minimize（无解析梯度，效率低） |

## 依赖
numpy、scipy.optimize.minimize、pandas、matplotlib。原文未使用 hmmlearn，为自写似然优化实现。

## 适用条件
- 需要把市场切成"涨/跌/震荡"式的状态标签，并让下游模型或风控据此调整仓位（0/1 仓位天然适配 A 股 T+1）。
- 作为特征提取器：输出状态概率或 EAR 作为择时因子，而不是直接当价格预测器。
- 有较长且相对连续的日频价格历史（原文 500 天起步）以估计状态参数。
- 需要低成本（约 0.5%）前提下做趋势择时，且愿意用摩擦率扫描验证存活边界。

## 不适用条件
- 指望 HMM 直接预测价格：原文自己澄清基准策略与含摩擦策略都未使用 HMM，HMM 是独立分析组件，且 (3-4-04) 明确"当前形态下 HMM 只作特征提取器，不作预测器"。
- 用 HMM 采样出的模拟行情去调阈值：原文自证失败——隐藏状态切换过快，合成序列与真实价格统计特性差异大，中高摩擦率下策略几乎不交易，效果远差于在真实数据上优化；原计划的强化学习调优也因此放弃。
- 摩擦率 ≥1%：策略相对直接持有的优势收敛至零，实盘可用性存疑。
- 状态数靠拍脑袋：3 是人工设定，2 状态时模型倾向区分"增长/快速增长"而非"增长/衰退"，状态语义属人工事后解释。
- 小样本 + 非凸优化：500 天窗口下状态划分可能不稳定，未做滚动/样本外重估；缺失 beta·r(t−1) 项时状态过于简单，难以支撑精细决策。
- 数据缺口靠前后均值插值：连续多日缺失会生成人造平滑段，扭曲波动率与收益率分布。
- 直接迁移到 A 股：7×24 与无涨跌停的制度差异大，状态定义与执行假设需重新设计。
- 全仓/空仓之间硬切换、无止损与仓位梯度的用法，暴露于单边下跌的执行风险。

## 验证状态
原文给出真实拟合输出，但策略收益只有图形与文字、没有数字：
- 拟合结果（比特币日频，训练第 100–600 天共 500 天）：MU = [0.0787, 0.0014, −0.0859]（与"快速增长/较慢增长/下降"的符号解释一致）、3×3 转移矩阵 P、beta ≈ 0.184；nstarts=10。原文未报告拟合的似然值或状态划分的一致性指标。
- 策略侧（样本外自第 600 天起，初始 1 美元）：原文结论为 HMM 阈值策略收益始终高于"前一天趋势跟随"与"直接持有比特币"两个基准；0.5% 摩擦下能更快跟涨并回避部分下跌，随摩擦率上升与直接持有的差距逐渐收敛至零；100 档摩擦率最终只落到 3 组不同阈值（参数分辨率极低），收益-摩擦率曲线呈分段线性。全部为文字与图形描述，无收益率、夏普、最大回撤数字，配图未收录。
- 失败复盘（3-4-04 / 28-5-02）：在 HMM 采样数据上优化的阈值样本外效果远不如真实数据上优化的阈值，中高摩擦率下策略干脆不交易——该结论可采信为"不要用拟合模型自产数据做策略优化"的证据。
- 附带基准（28-3 / 3-4-01）：前一日趋势跟随策略（r≥0 满仓、r<0 清仓）在无摩擦下长期显著跑赢直接持有，但几乎每日调仓，对交易成本极度敏感；原文只给出定性描述，无具体倍数。
