# 集成与堆叠方法（投票-堆叠-权重寻优）

## 能力说明
把多个已调参的基模型组合成一个更强的分类器/回归器，并给出"信号 → 仓位 → 收益 → 绩效对照"的落地模板。三种组合方式：硬投票（按预测类别计票）、软投票（按预测概率加权平均）、堆叠（用元学习器学习如何组合基模型输出）。原文的实测结论是：基模型 AUC 只有 0.55–0.58 时，集成最好也只有 0.57 / 59.5%，融合收益有限。

## 输入契约
- 已训练并调参的基模型（原文为 HistGradientBoostingClassifier 与 CatBoostClassifier，各带前文 Optuna 最优超参）。
- 同一份 X_train/X_test、y_train/y_test（AAPL 周频二分类，标签为周收益方向，阈值 0.5 二值化）。
- 组合权重寻优需要目标指标（原文用 Accuracy）与搜索范围（每个估计器权重 suggest_float(0,1)）。
- 策略落地需要测试集的 returns 列与预测列（Predicted）对齐；收益须统一换算为小数口径（百分数除以 100）。

## 输出契约
- 集成模型的类别预测与正类概率；ROC 曲线 + 混淆矩阵（复用 `plot_model_performance(name, y_test, y_pred)`）。
- 各基模型的最优权重（原文输出示例 `dict_values([0.8891, 0.3632])`，脚本内变量为 `best_weights = study.best_params.values()`）。
- 策略侧：position（1 多头/0 空仓，或 1/-1 多空）、model_returns 序列、QuantStats 完整绩效报告（策略与基准两列并排）。
- 绩效指标清单：累计回报、CAGR、Sharpe、Sortino（含 Smart 版）、年化波动率、最大回撤、恢复因子、Ulcer Index、Serenity Index、Beta、Time in Market、异常收益/损失比率。

## 调用方式
```python
from sklearn.ensemble import VotingClassifier, StackingClassifier
from sklearn.tree import DecisionTreeClassifier

# 三种组合
hard = VotingClassifier(estimators, voting='hard')
soft = VotingClassifier(estimators, voting='soft')
stack = StackingClassifier(estimators, final_estimator=DecisionTreeClassifier())

# Optuna 搜权重（目标 Accuracy），再落地为加权软投票
best_weights = study.best_params.values()
soft_w = VotingClassifier(estimators, voting='soft', weights=list(best_weights))

# 信号 → 持仓 → 收益（消除前视偏差的最小改动）
position = signal.shift(1)          # 或 X_test['Predicted'].shift(1)
model_returns = position * returns  # 周频，returns 为小数口径

# 绩效报告
import quantstats as qs
qs.reports.full(model_returns, benchmark=benchmark)
```
- 策略 2 的多空写法：`X_test['Predicted'].replace(0, -1)` 使预测列直接表达仓位方向；A 股不可做空时可把 −1 映射为 0 得到多头/空仓切换。

## 关键参数
| 参数 | 含义 | 原文取值 |
|---|---|---|
| voting | 投票方式 | 'hard' / 'soft' |
| meta learner | 堆叠元学习器 | DecisionTreeClassifier |
| 权重搜索 | Optuna suggest_float(0,1) | 最优 HBGB 0.8891 / CatBoost 0.3632 |
| 权重优化目标 | 主指标 | Accuracy（注意：与 AUC 结论相反） |
| 预测二值化 | 阈值 | >0.5 记为 1 |
| 回测区间 | 样本外 | 2014-06-02 至 2023-07-17（AAPL 周频） |
| 无风险利率 | 报告参数 | 0（显式记录） |
| 收益口径 | 送入 QuantStats 前 | 百分数 ÷ 100 转小数 |

## 依赖
scikit-learn（VotingClassifier、StackingClassifier、DecisionTreeClassifier）、optuna、quantstats（`qs.reports.full`）、pandas/numpy；基模型侧另需 lightgbm/catboost 与 xgboost。

## 适用条件
- 已有 2–3 个性能相近、错误模式不同的基模型，希望降低方差、提升稳健性（噪声大或类别不平衡的数据）。
- 需要把模型输出直接接入策略回测的完整链路：predict_proba → 阈值 → shift(1) 持仓 → 收益 → QuantStats 绩效表。
- 追求"风险调整后优于 Buy & Hold"的验证口径时，QuantStats 的指标清单可直接照用（必须同时看 Sharpe/最大回撤，不能只看累计收益）。
- 需要区分"策略差"与"市场好"时，用同区间 Buy & Hold 作基准并报告 Time in Market。

## 不适用条件
- 基模型本身没有信息量：AUC 0.55–0.58 的基模型集成后最好也只有 0.57 AUC / 59.5% 准确率，集成不能凭空造出 alpha。
- 用测试集搜权重：原文权重寻优直接在测试集上评估准确率，没有独立验证集，属过拟合测试集，其 59.5% 不可作为泛化能力。
- 指标口径不唯一时选型：同一模型在 Accuracy 与 ROC-AUC 下排序相反（加权软投票准确率最优但 AUC 更低），必须先确定唯一主指标再比较，否则结论自相矛盾。
- 无成本假设下的绩效数字：策略 1 有 94% 时间在市场且无交易成本、滑点、税费，多头偏向型策略在美股长期上行段（2014–2023）天然占优，不能外推到 A 股震荡/下行市。
- 做空策略：策略 2（满仓多空切换）累计收益与 CAGR 更高，但夏普更低、最大回撤更高，风险调整后更差；无融券费用与做空约束。
- 只报累计收益：必须同看夏普与最大回撤，原文明确"仅跑赢买入持有的累计收益不足以证明策略有效"。
- 堆叠未参与实盘：原文堆叠分类器只做评估，未用于策略构建。

## 验证状态
原文给出真实运行结果，但流程存在测试集调参与无成本假设两处明显缺陷，故标为"有缺陷"：
- 集成对比（AAPL 周频方向）：首次评估硬投票表现最好，ROC-AUC = 0.57；软投票与堆叠的 AUC 数值原文未给出，证据不完整。
- 权重寻优后：加权软投票测试集准确率 59.5%（原文称"迄今最好结果"），但 ROC-AUC 反而更低；最优权重约 HBGB 0.8891 / CatBoost 0.3632。
- 策略 1（看涨才买入，其余空仓；2014-06-02 至 2023-07-17）：累计回报 908.02%（基准 Buy & Hold 855.4%）、CAGR 19.09%（基准 18.61%）、Sharpe 2.49（基准 2.29）、Sortino 3.91（基准 3.56）、持仓时间占比 94%（基准 100%）；原文另称最大回撤与年化波动率显著更低、恢复因子更高、Beta 更低，但异常损失比率（尾部风险）更高。
- 策略 2（始终 100% 暴露，看空做空）：累计回报与 CAGR 优于买入持有，但夏普更低、最大回撤更高，原文结论为策略 1 更优。
- 31-9 结论：软投票分类器表现最佳并用 Optuna 搜索基估计器权重；两策略累计收益均超买入持有；明确未计入税收与交易成本。
