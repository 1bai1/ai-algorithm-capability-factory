# 波动率模型 ARCH 与 GARCH

## 能力说明
对收益率序列的条件方差（波动率）建模与预测：ARCH 把条件方差写成过去误差平方的函数，GARCH 再加入条件方差自身的滞后项，用更少参数刻画波动聚集与长期记忆。解决"预测未来波动率、算 VaR、给仓位与止损提供风险门控"的问题。它是风险侧模型，预测对象是波动幅度而不是价格方向。

## 输入契约
- 收益率序列（不是价格）：原文口径 `np.log(close).diff() * 100` 后 dropna。注：乘 100 会改变似然尺度，跨数据集比较 AIC 必须统一口径。
- 日频；实证样本 890 条（贵州茅台 2020-01-03 至 2023-09-01）。
- 按时间顺序切分，示例 8:2（训练 712 条，测试约 178 条），禁止随机打乱。
- 序列应存在波动聚集（可先画收益率平方图目视确认）。
- 均值方程可置零（mean='Zero'），只专注波动率。

## 输出契约
- 条件方差序列（模型输出的方差需开方才得到波动率：`np.sqrt(...)`）。
- 未来 horizon 步的波动率路径（示例 30 个交易日）。
- 模型摘要：参数估计、AIC（用于在 ARCH(1)/ARCH(2)/GARCH(1,1)/(1,2)/(2,1) 之间选阶）。
- 精度指标：MSE / RMSE / MAE，以测试集收益率的绝对值作"真实波动率"代理。
- 风险指标：VaR_95 = 1.645 × σ_pred（z=1.645 对应 95% 正态分位），可统计超限次数做覆盖性检验。
- 波动率序列本身可作为门控特征，供后续模型或仓位规则使用（高波动期降仓）。

## 调用方式
```python
from arch import arch_model

returns = np.log(df['close']).diff().dropna() * 100
am = arch_model(returns, vol='GARCH', p=1, q=1, mean='Zero')
res = am.fit(disp='off')
print(res.summary()); print(res.aic)

fc = res.forecast(horizon=30)
pred_var = fc.variance.values[-1, :]
pred_vol = np.sqrt(pred_var)

    ...  # 返回 (mse, rmse, mae)
```

- 选阶：先跑 ARCH(1)、ARCH(2)，再跑 GARCH(1,1)、(1,2)、(2,1)，比较 AIC。
- 长期波动率路径的日期索引用 `pd.date_range(freq='B')`（工作日）生成。

## 关键参数
| 参数 | 含义 | 原文取值 |
|---|---|---|
| vol | 波动率模型类型 | 'GARCH' |
| p, q | ARCH 项 / GARCH 项阶数 | 候选 {ARCH(1), ARCH(2), GARCH(1,1), GARCH(1,2), GARCH(2,1)}，AIC 选优；GARCH(1,1) 为原文推荐默认基线 |
| mean | 均值方程 | 'Zero'（置零，专注波动率） |
| horizon | 预测步长 | 30 个交易日 |
| z | VaR 分位数 | 1.645（95% 置信水平） |
| 切分 | 训练/测试 | 8:2，按时间顺序 |
| 参数个数 | GARCH(1,1) | 3 个参数即可拟合多数金融序列的波动率特征 |

## 依赖
arch（arch_model）、pandas、numpy、matplotlib、scikit-learn.metrics（MSE/RMSE/MAE）。

## 适用条件
- 收益率序列存在波动聚集（高波动后仍高波动）、需要风险度量（VaR）、资产配置与对冲（高波动期降仓）、修正期权定价中波动率恒定的假设。
- 样本量数百至上千条日频可用（示例 890 条）。
- 需要"波动率"作为特征/门控信号输入下游模型或仓位规则时。
- 作为 ARMA 残差的第二层模型：GARCH 可对 ARMA 残差建模，两模型可组合。

## 不适用条件
- 需要捕捉杠杆效应（负收益对波动率的影响大于正收益）：原文自陈 GARCH 假设波动率对称，做不到，应改用 EGARCH/TGARCH。
- 极端事件预测：原文自陈对极端事件预测有限。
- 预测目标是价格方向或收益均值：本模型输出的是波动幅度，不是方向；用 MSE 去拟合收益率本身是错的（见反例）。
- 以收益率绝对值作真实波动率代理：含噪，两模型 RMSE 接近时结论不稳健。
- 单次静态切分 + 单一标的（890 日）的选阶结论不能当稳健结论，未做滚动重估与多次样本外验证。
- 反例警示（5-3）：把"ARCH 模型"实现成 PyTorch 单个 nn.Linear 对日收益率做线性变换，用 MSE/Adam 训练 10000 轮，损失降到约 1e-16 却被当作拟合极好——该输出没有条件方差方程，不具备波动率的物理含义；同一实例中未标准化的大盘指数特征（3000 量级）使损失膨胀到 2046，原文却归因为"特征无益"，属归因错误。凡出现"单层线性回归冒名 ARCH"或"用 MSE 拟合收益率当波动率"的实现，一律不采用。
