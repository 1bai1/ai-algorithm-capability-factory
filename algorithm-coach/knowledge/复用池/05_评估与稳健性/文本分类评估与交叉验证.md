# 文本分类评估与交叉验证

## 能力说明
给文本分类流水线定指标与划分方式，保证评估数字可信：把向量化器与分类器装进同一个 pipeline
做交叉验证/网格搜索；深度学习侧在每个 epoch 评估、按指标留最佳权重。核心是让特征提取也随折重训，
而不是在全量语料上先 fit 词表再切分。

## 输入契约
- 待评估的 pipeline（特征提取 + 分类器）与带标签的数据集。
- HF Trainer 场景：`compute_metrics` 收到 `(logits, labels)` 二元组，需要自行 argmax。
- 要有独立于测试集的验证集，才能用「按验证指标选 checkpoint」这种策略。

## 输出契约
- sklearn：`cross_val_score` / `GridSearchCV` 的分数（每折一个，可看均值与方差）。
- HF：每个 eval 步/epoch 的指标字典（如 `{"accuracy": ...}`）与最佳 checkpoint。
- 指标的输入口径固定：logits 先 `np.argmax(axis=1)` 得到类别 id，再与 labels 比对。

## 调用方式
```python
# sklearn：向量化器随折 fit，避免词表泄漏
from sklearn.pipeline import Pipeline
from sklearn.model_selection import GridSearchCV
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.svm import LinearSVC

pipe = Pipeline([("vec", TfidfVectorizer()), ("clf", LinearSVC())])
GridSearchCV(pipe, param_grid, cv=5).fit(texts, labels)

# HF：训练中评估
import numpy as np, evaluate
accuracy = evaluate.load("accuracy")

def compute_metrics(eval_pred):
    predictions, labels = eval_pred
    predictions = np.argmax(predictions, axis=1)
    return accuracy.compute(predictions=predictions, references=labels)
```

## 适用条件
- 需要调向量化或模型超参时：把特征提取器放进 pipeline 一起交叉验证。
- 深度学习训练中要按指标保留最佳权重时。
- 需要比较候选模型族（浅层 vs 微调）时，用同一套划分与指标裁决。

## 不适用条件
- 类别不平衡数据：原文只给 accuracy，未涉及 precision/recall/F1、类别权重或分层抽样，不能照抄口径。
- 按时间到达的语料（新闻、评论）：原文的划分是随机折 / 固定 split，未讨论时序切分。
- 没有独立验证集时开 `load_best_model_at_end`：原文的 IMDb 例子把 `test` 当 `eval_dataset`，
  等于用测试集选模型，结果会偏乐观。
- 原文没有给出任何交叉验证或网格搜索得到的真实分数，本卡不能提供性能预期。
