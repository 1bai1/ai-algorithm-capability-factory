# VaR与尾部风险度量

## 能力说明
估计给定置信水平下的单期最大可能损失：参数法（正态分位 × 条件波动率）、蒙特卡洛/经验分位数法，并配套覆盖性检验与期望损失（EL）对照。解决"风险限额、尾部损失与极端行情压力"的量化环节。

## 输入契约
- 参数法：日收益序列 + 波动率预测 σ（来自 GARCH 条件方差开方，或滚动标准差）。
- 分位数法：损失分布样本或蒙特卡洛场景矩阵；组合层需逐笔敞口（EAD/EAL）、违约概率（λ 或 PD）、损失率（LGD）与到期时间。
- 置信水平：95% / 99% / 99.5% / 99.9%。
- 极小数量的合成参数即可跑通信贷组合示例，但结论无实际参考价值（见不适用条件）。

## 输出契约
- 单期 VaR：收益口径为负值（如日 VaR -1.58%）；或损失口径的金额分位数（2836.5 / 3201.5 / 4182.0）。
- 组合损失定义：`L = Σ EAL_i × LGD_i × 1{τ_i ≤ T_i}`（只有到期日前违约的贷款计入损失）。
- 配套产物：损失分布直方图、经验 CDF、拟合分布与经验分布对比图、超限次数（覆盖性检验雏形）。

## 调用方式
- 参数法：`VaR_95 = 1.645 × σ_pred`（σ_pred 为预测波动率），并标记超限的极端负收益用于覆盖性检查。
- 绩效报告内建：Pyfolio `perf_stats` 直接输出日 VaR（与年化收益、波动率、最大回撤并列）。
- 蒙特卡洛分位数：`np.percentile(total_losses[::-1], [99, 99.5, 99.9])` 取损失分布的高分位。
- 损失分布拟合：Beta 分布（值域 [0,1] 匹配 LGD）——矩估计 `alpha_mm = mean*((mean*(1-mean)/var)-1)` 与 `beta_mm = (1-mean)*(...)`；或 MLE `beta.fit(losses, floc=0, fscale=1)`。
- 场景模拟：`np.random.exponential(1/np.array(lambda_list), size=(N,10))` 生成违约时间矩阵，逐场景计算损失后排序取分位。

## 关键参数
- 95% 置信水平对应 z=1.645（1-2-5）。
- 信贷组合示例：n_loans=10、每笔 EAD=1000、到期 T=5 年、场景数 N=1e7、λ 需由 bps 除以 10000 换算。
- 组合层可迁移做法：逐笔损失 × 场景模拟 × 分位数流程，无需显式建相关矩阵，让各资产冲击在共同场景中叠加。
- 原文未给出：A 股单标的 VaR 的推荐窗口长度、历史模拟法的窗口参数、覆盖性检验的通过门槛。

## 依赖
numpy、scipy.stats（beta.pdf/beta.fit）、matplotlib；pyfolio（绩效报告内建 VaR）；arch（波动率来源）。

## 适用条件
- 单期风险限额、仓位上限、报告尾部损失；组合层需要"逐笔损失 × 场景 × 分位数"时。
- 需要把尾部风险与期望损失并列汇报时：EL 与高置信 VaR 量级差异巨大（示例约 1:40），缺一不可。

## 不适用条件
- VaR 不覆盖极端事件（5-2 明示其缺陷），必须与压力测试、上限基准或 CVaR 类指标并用。
- 假设各笔独立、未建模违约相关性的蒙特卡洛会系统性低估组合尾部风险（5-4-2 中示例即为独立假设）。
- 合成数据/人工参数算出的 VaR 数值无实际参考价值（5-4-2 全部为合成数据，EL/VaR 数字本身不可用）。
- 参数法依赖正态假设，与实测厚尾不符：29-5-03 残差 Jarque-Bera=9485.55、峰度 10.67，说明正态分位会低估尾部。
- 不同口径不可直接比较：经验分布 LGD 与固定 LGD=50% 两种设定下的 VaR 结果不能并列比较（5-4-2）。
- 只报 EL 会低估风险：示例 EL≈$107 与 99.9% VaR≈4182 相差约 40 倍，单一 EL 不足以支撑限额。
- 代码片段常以"# 定义参数"占位、无法完整复现时，不能照搬到生产（5-4-2）。
- 与本域其他方法一样，VaR 不解决方向预测问题；不要用它替代收益预测或信号生成（2-2-01 的定位是风险层）。

## 验证状态
原文给出真实运行结果，属已验证：
- 9-7（DRL 策略 vs 道指 ^DJI，约 336 个交易日）：策略日 VaR -1.58%、基准日 VaR -1.65%。
- 5-4-2（信贷组合，合成参数：10 笔、EAD=1000、T=5）：单点预期损失约 $107.30；10^7 场景模拟下损失 ≤ $107 的经验概率 0.1506；一组参数下 99%/99.5%/99.9% VaR ≈ (2836.5, 3201.5, 4182.0)，另一口径为 (2927.3, 3218.2, 3800.0)；LGD 固定 50% 时 VaR 为 (1500, 2000, 2000)，说明 LGD 假设对尾部损失影响巨大。
- 1-2-5：给出 VaR_95 = 1.645 × σ_pred 的实现与覆盖性统计雏形，未给数值。
