# 信号阈值与策略参数寻优

## 能力说明
把模型输出的概率或期望收益映射成可执行买卖信号：单阈值二值化、买卖双阈值、二维网格搜索，目标函数可选含交易成本项；并给出阈值稳健性与过拟合判读方法。解决"模型有打分但不知道该在哪动手"的环节。

## 输入契约
- 模型输出为连续打分：分类概率 `predict_proba(X)[:, 1]`、状态模型导出的期望异常收益率 EAR、回归预测值。
- 训练段数据用于寻优，测试段只用于评估；两者时间严格分离。
- 阈值搜索空间：单阈值区间或 (buy, sell) 二维网格；若目标含成本，还需要摩擦率档位数组。

## 输出契约
- 最优阈值（单值或 buy/sell 对）与对应信号序列（0/1、±1 或 -1/0/1 三态）。
- 网格寻优产物：收益矩阵 R 与交易次数矩阵 T（形状 res×res），可事后画阈值热力图与交易频率图。
- 阈值分布结论：同一阈值在全样本/不同成本档下的稳定性（落地了多少组不同阈值）。

## 调用方式
- 单阈值二值化：`preds = model.predict_proba(test[predictors])[:, 1]` 后按业务阈值（原文 0.6）转 0/1；阈值应作为可调参数而非固定 0.5。
- 阈值由分布定：把预测概率切成 8 等份（每份 12.5%），`np.quantile` 取切点 → `pd.cut` 分箱 → `pd.crosstab(classes, y_test)` 看每档真实标签分布，选分布翻转处的分位点作为阈值。
- 双阈值网格（训练集寻优）：`X = np.linspace(-0.1, 0.1, res)`，双层循环 `j` 从 0 到 res、`i` 从 `j` 到 res（保证 sell ≤ buy），逐对回测取收益最大，结果写入 R/T 矩阵。
- 含成本目标：`FR = log(R) + T*log(1-f)`，对每档摩擦率 `np.argmax`，用 `np.mod(ix, res)` 反解出 (buy, sell) 下标。
- 两参数策略网格（价格容忍型）：`low_add`、`high_loss` 在 `np.arange(0, 5, 0.1)` 上双层遍历，以累计利润排序取最优。
- 概率区间带：`p>0.55` 持有、`p<0.45` 空仓，形成带观望带的仓位决策。
- 双确认门槛：模型概率超阈值 + 技术指标（如均线交叉）同时满足才开仓。

## 关键参数
- 单阈值：0.6（29-5，原文建议在 0.6~1 之间试不同阈值）；0.5(31-8-02）；0.607（12-6，由概率分位分布确定）。
- 双阈值网格：区间 [-0.1, 0.1]、点数 res=200，且只搜索 sell ≤ buy（28-5-01 / 3-4-03）。
- 策略参数网格：`np.arange(0, 5, 0.1)`（13-5）。
- 概率带：上界 0.55、下界 0.45（3-3）；6-3-01 用概率 >55% 加均线交叉双确认。
- 原文未给出：阈值的置信区间、最小交易次数门槛、判定参数不稳定的量化标准（只给"100 档只选出 3 组"这类观察）。

## 依赖
pandas/numpy（np.linspace、np.quantile、pd.cut、pd.crosstab）；模型需支持 predict_proba；回测循环（配合滚动回测引擎）。

## 适用条件
- 输出为概率或连续打分的模型（XGBoost/树模型、HMM 的 EAR、集成分类器）。
- 已有训练/测试时间切分，且能接受"在训练段做二维网格穷举"的计算量。
- 需要把"信号强度-交易频次"的权衡显性化时（提高阈值以牺牲召回换精确率）。

## 不适用条件
- 在测试集上挑选的阈值不能用：12-6 的 0.607 是在同一段测试集上选出（原文自认存在阈值选择偏差）；13-5 的 grid search 与评估用同一批 89 天数据、无样本外验证。
- 训练期最优不等于测试期最优（28-5-01 原文自述）；需要滚动重估或至少留出独立验证段。
- 参数对成本不敏感不等于稳健：100 档摩擦只产生 3 组阈值说明分辨率低、训练期最优解不稳定（28-5-01）。
- 默认 0.5 阈值在类别不平衡时产生偏多输出：29-3 的模型几乎把一切都预测成上涨，类别 0 召回仅 0.15，错误率与随机猜测无异。
- 目标函数不含成本项会选出高频微利阈值，在真实摩擦下失效（28-5-02）。
- 调参与执行必须一致：29-4 网格选出 reg_lambda=0.1 而实际训练用 0.8，调参结论作废。
- 用"放宽阈值以确保有信号输出"制造交易记录，属事后调参（6-3-02）。

## 验证状态
原文给出真实运行结果，属已验证：
- 12-6（活牛期货 Live Cattle，周频，2013-05-27~2023-05-15）：概率分 8 档后确定 0.607 为分界；策略（±1 信号、下一期仓位）累计收益 62.16%，买入持有 37.56%，Sharpe 0.75、Sortino 1.1、年化波动 44.19% 对 44.21%、最大回撤 -39.84%、最差一次回撤持续 1043 天（无交易成本）。
- 13-5（黄金日频）：low_add/high_loss 网格 [0,5) 步长 0.1；初始资金 1000，默认参数 (0,0) 利润约 111，调参后约 245，理想上界约 497；自称 3 个月超 20% 利润（样本 89 个交易日、无样本外验证）。
- 28-5-01：100 档摩擦率分别寻优后仅落地 3 组不同阈值，收益-摩擦率曲线呈分段线性。
- 29-5：阈值 0.6 下类 1 精确率 0.85，较默认 0.5 的 67.83%（原文口径）提升至 85.28%（含特征扩充，非纯阈值效果）。
