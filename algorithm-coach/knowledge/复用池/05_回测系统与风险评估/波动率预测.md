# 波动率预测

## 能力说明
对条件方差建模并外推未来波动率（GARCH/ARCH 族，或轻量滚动波动率），输出可作为 VaR 输入、仓位门控条件与模型选型依据的波动率路径。解决"风险水平随时间变化、不能用常数方差"的环节。

## 输入契约
- 单标的日频收盘价（多标的需逐个建模）；收益率预处理：`np.log(close).diff() * 100` 后 dropna。
- 最小样本量：原文未给出硬门槛；实例为茅台日线 2020-01-03~2023-09-01 共 890 条，按 8:2 时序切分（训练 712 条）。
- 波动率评估需要测试期"真实波动率"代理（原文用收益率绝对值）。

## 输出契约
- 条件方差/波动率序列：`.forecast(horizon=N).variance.values[-1, :]` 取条件方差 → `np.sqrt` 转波动率；示例可输出未来 30 个交易日路径（freq='B'）。
- 模型对比表：AIC（选阶用）、MSE/RMSE/MAE（预测精度）。
- 轻量替代产物：滚动标准差波动率列（`Pct_Change.rolling(5).std()`）、年化日波动率（`returns.std()*np.sqrt(252)`）。

## 调用方式
- 基线配置：`arch_model(returns, vol='GARCH', p=1, q=1, mean='Zero').fit(disp='off')`；用 `.aic` 与 `.summary()` 读结果。
- 选阶：在 ARCH(1)/ARCH(2) 与 GARCH(1,1)/(1,2)/(2,1) 之间按 AIC 最小筛选。
- 预测：`.forecast(horizon=N).variance.values[-1, :]` → `np.sqrt(...)` 得未来波动率。
- 评估：自定义 `evaluate_volatility(actual, predicted, model_name)` 返回 (mse, rmse, mae)，actual 取测试期收益绝对值。
- 风险联动：`VaR_95 = 1.645 × σ_pred`；波动率序列可作门控特征供仓位规则或后续模型使用。
- 无 GARCH 依赖的轻量版：`Price_Change = Close.diff()`、`Pct_Change = Close.pct_change()*100`、`Volatility = Pct_Change.rolling(5).std()`、`High_Low_Range = (High-Low)/Open*100`。

## 关键参数
- GARCH(1,1) 作为默认基线（3 个参数，原文称可拟合多数金融序列的波动率特征）。
- 均值方程：mean='Zero'（专注波动率）。
- 预测步长：horizon=30、freq='B'（30 个交易日）为实例设定。
- 滚动窗口：5 日（2-2-02，经验值，未做敏感性分析）。
- 年化换算：×√252（年）/ ×√21（月）（8-5-5）。
- 原文未给出：GARCH 阶数的自动选择流程（靠人工枚举 AIC）、波动率预测精度的验收门槛、最优窗长的调参方法。

## 依赖
arch、pandas、numpy、matplotlib、scikit-learn（指标）。

## 适用条件
- 单标的日频序列（A 股个股/指数），需要条件方差而非常数方差的场景。
- 作为 VaR 的输入、高波动期降仓的触发条件、异常检测的风险特征。
- 需要给 GARCH 类模型作统计基线时（与 LSTM/GRU 波动率预测对照，2-2-01 的路线）。

## 不适用条件
- 默认 GARCH 假设波动率对称、无法捕捉杠杆效应，对极端事件预测有限，应改用 EGARCH/TGARCH（1-2-5 原文自述）。
- 单标的、约 890 日、无滚动重估与多次样本外验证时结论不稳健（1-2-5）；样本过短不要据此定阶。
- 以收益绝对值作波动率代理本身含噪，两模型 RMSE 接近时不能下"谁更好"的结论（1-2-5）。
- 收益率乘 100 会改变似然尺度，跨数据集比较 AIC 必须口径一致（1-2-5）。
- 不要把线性回归当"ARCH"：5-3 用单个 nn.Linear 拟合日收益率、把输出当波动率（损失降到 1e-16 是恒等映射，无波动率物理含义）；加入量纲未处理的大盘指数特征会让损失失控到 2046 量级，属标准化缺失而非特征无效。
- 没有平稳性检验、残差检验与滚动回测的波动率流程不可信（5-3 全文均无）。
- 描述性波动率统计不能当预测：8-5-4 只有时序图、密度图与标准差，无模型、无年化、无样本外。
- 波动率预测不等于方向预测，不能直接当交易信号（8-5-4 明确）。

原文未给出可用于验收的完整数值，本卡按未验证处理：
