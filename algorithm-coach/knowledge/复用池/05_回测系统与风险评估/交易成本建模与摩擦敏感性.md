# 交易成本建模与摩擦敏感性

## 能力说明
把手续费、买卖价差、滑点、冲击成本统一成可调成本项，量化"策略在多少成本下失效"，并给出摩擦率扫描、三档压力测试与"预知未来上限"参照系。解决回测收益虚高、高频微利策略不可用的问题。

## 输入契约
- 粗算版只需两个数：无摩擦回测终值 V0[-1] 与交易次数 ntrades。
- 精细版需要逐笔成交序列（买卖方向、成交价、数量）与单边费率 f 或分买卖费率。
- 费率档位数组：实例 `friction = np.linspace(0, 0.02, 100)`（0–2%，100 档）；压力测试常取 0.5% / 1% / 1.5% 三档（对应档位下标 i=25/50/75）。
- A 股实现还需：印花税、佣金、过户费、最小交易单位与 T+1 约束（原文只给出合并费率，未细分口径）。

## 输出契约
- 摩擦率-回报曲线：横轴摩擦率、纵轴对数回报，含策略曲线、直接持有资产水平线、时间旅行者上限曲线及上限对应交易次数。
- 盈亏平衡摩擦率（策略终值等于直接持有的成本水平）与"策略优势归零"的成本边界。
- 分档净值曲线（0.5%/1%/1.5% 各一条）与该档的交易次数。

## 调用方式
- 粗算侵蚀：`V0[-1] * (1 - friction) ** ntrades`，仅需终值与交易次数，适合放回测摘要一行（28-3 / 3-4-01）。
- 逐笔扣除：卖出实得 `(1-f)·b·p`、买入实得 `(1-f)·c/p` 个资产；回测循环内 `rate = 1 - friction[i]` 逐档结算（28-3 / 3-4-04）。
- 三条对照曲线：策略（按摩擦衰减）、`BC_Prices[-1]/BC_Prices[0]` 的买入持有水平线、以及预知未来价格的 UB 上限与其交易次数 TR（`np.zeros(100)` 逐档重置求解）。
- 寻优目标含成本：`FR = log(R) + T*log(1-f)`，对每档摩擦率取 argmax 得最优阈值（28-5-02 / 3-4-04）。
- A 股成本落地：FinRL 环境买卖分开 `buy_cost_pct=6.87e-5`、`sell_cost_pct=1.0687e-3`（卖出约为买入的 15.6 倍，含印花税）；或固定佣金 0.001 + 滑点 0.0005（6-3-02）。
- 成本敏感性作为回测必选项：把 f 从 0 扫到 0.02 逐档重算终值即可回答"策略在多少成本下失效"（28-3）。

## 关键参数
- 摩擦扫描范围与档数：`np.linspace(0, 0.02, 100)`（28-3 / 3-4-01）；压力档 0.5% / 1% / 1.5%（28-5-01）。
- A 股成本量级：买入 0.00687%、卖出 0.10687%（8-4-2）；佣金 0.001、滑点 0.0005（6-3-02）。
- 执行成本四类清单：滑点、佣金税费、市场冲击、未成交的机会成本；执行质量三指标：执行差额（Implementation Shortfall）、成交率、TWAP 偏离度（6-3-02）。
- 原文未给出：滑点与冲击成本的规模依赖模型、融券费用、A 股印花税与过户费的拆分口径、成本参数的经验推荐值（仅给上述实例设定）。

## 依赖
numpy（linspace/power）、matplotlib（semilogy 对数坐标）；FinRL 环境（成本参数注入）。

## 适用条件
- 换手率高的择时策略上线前必做，尤其是"几乎每日调仓"的趋势跟随类（28-3 / 3-4-01 的基准策略在无摩擦下表现极佳但每日交易）。
- 需要判断"策略优势是否只是零成本幻觉"、需要给成本容忍上限时。
- 需要给策略与基准做同等成本口径对照时。

## 不适用条件
- 高换手策略在摩擦升到 1% 以上基本失去优势，若回测不含成本则任何结论都不成立（28-5-02 / 3-4-03 的结论）。
- 把手续费、价差、冲击统一压成与规模无关的常数 f，对大资金不成立（28-3）。
- 不要用参数对成本不敏感当作稳健性证据：100 档摩擦率只选出 3 组阈值，说明目标函数分辨率低、训练期最优不稳定（28-5-01）。
- 成本口径必须统一：HMM 策略逐笔扣费与对照策略 `(1-f)^n` 近似口径不一致时，策略与基准不可比（28-5-01）。
- 时间旅行者上限是带未来信息的理想化参照，不能当作可实现收益，也不能据此宣称策略有改进空间以外的结论（28-3）。
- 交易次数统计口径必须先定义（买入+卖出算一笔还是两笔），它直接决定 `(1-f)^ntrades` 的幂次（28-3）。
- 用预测概率阈值放宽来"确保有信号输出"是事后调参，不能靠它提升成本敏感性结论（6-3-02）。
