# 方向预测评估指标

## 能力说明
涨跌/信号方向二分类的评价口径：ROC-AUC、PR 曲线、混淆矩阵、precision/recall/F1/特异度，以及把"精确率"解释为买入信号可靠性的用法。解决"方向模型到底比抛硬币好多少"的环节。

## 输入契约
- y_true 为 0/1 方向标签（如 Target = Close_t > Close_{t-1}，或下周收益为正）；y_pred 必须为概率 `predict_proba(X)[:, 1]` 才能画 ROC/PR；画混淆矩阵与分类报告时可用硬标签（阈值或 round() 二值化）。
- 类别可轻微不平衡：实例训练集正类占比 53.7%（31-4）；不平衡严重时需对比过采样/SMOTE 口径。
- 训练/测试必须按时间切分，指标要训练集与测试集成对输出。

## 输出契约
- AUC：0.5 等于随机；实例有效区间参考 0.51~0.98（见验证状态）。
- 混淆矩阵四元组 TN/TP/FP/FN 与类别级 precision/recall/f1；classification_report 的 support 用于核对样本量。
- ROC 曲线（含随机猜测虚线、AUC 标注）、PR 曲线（类别极不平衡时的补充）。
- 学习曲线：Log Loss 与分类错误率随迭代轮次的双曲线（训练/测试各一条），用于判断过拟合/欠拟合。

## 调用方式
- 多模型统一循环：`for (name, clf) in classifiers: clf.fit(X_train, y_train); y_pred = clf.predict_proba(X_test)[:, 1]; fpr, tpr, _ = roc_curve(y_test, y_pred); auc(fpr, tpr)`，再调 `plot_model_performance(name, y_test, y_pred)` 输出 ROC 与混淆矩阵。
- 评估函数骨架：`RandomizedSearchCV(cv=10, scoring='roc_auc', n_jobs=-1)` → 用 best_estimator_ 在训练集与测试集分别 predict / predict_proba → 汇总 AUC/Accuracy/Sensitivity(=Recall)/Specificity/Precision/F1 与混淆矩阵 → 画 ROC 与 PR 曲线。
- 交易侧口径：`precision_score(...)` 与 `classification_report(...)` 衡量"预测为正且实际也为正"，即买入信号可靠性；再配错误样本计数图与 `time.time()` 计时。
- 学习曲线：`history.evals_result_['validation_0'|'validation_1']['error'|'logloss']`，`epochs = len(...)`，叠加训练/测试两条曲线。
- 不平衡任务应以 Log Loss 与类别级 precision/recall 为主，而不是总体 accuracy。

## 关键参数
- 随机种子：seed=123（31-6）、random_state=42（12-5）、random_state=23（11-3-7）。
- 交叉验证：cv=10、n_jobs=-1（11-3-7，随机 K 折，非时序安全）；cv=3（29-4 的 GridSearchCV）。
- 早停与监控：`early_stopping_rounds=10`、`eval_metric=['error','logloss']`、`eval_set=[(X_train,y_train),(X_test,y_test)]`（29-4；把测试集放进 eval_set 会产生乐观偏差）。
- 二值化阈值：0.5（31-2 的 round()、31-8-02）；0.6（29-5）。
- 原文未给出：AUC 的最低可用门槛（但给出 0.51~0.53 接近随机、0.887 被视为可用的参照）。

## 依赖
scikit-learn（roc_curve、auc、roc_auc_score、confusion_matrix、classification_report、precision_recall_curve、RandomizedSearchCV）、xgboost/lightgbm/catboost、seaborn/matplotlib（热图与曲线）。

## 适用条件
- 涨跌方向/信号可靠性的二分类任务；多模型粗筛与选型；类别不平衡时配合 PR 曲线与类别级指标。
- 需要把分类指标与交易指标并列汇报时（精确率对应买入信号质量）。

## 不适用条件
- AUC 与盈亏脱节：12-5 的 AUC=0.887 与 12-2 的 0.887 均未给回测收益与成本对照；31-6 的 AUC 0.51~0.53 说明 9 个技术指标对周度方向几乎无预测力。
- 测试集不能参与调参或筛选：31-7 用测试 AUC 作 Optuna 目标函数、29-4 把测试集放进早停 eval_set、11-3-7 用测试集做模型筛选，均会带来乐观偏差。
- 概率与硬标签语义不能混用：11-3-7 计算 AUC 时传入 predict 的硬标签；31-2 的 ROC 若拿到硬标签会退化为单点。
- 只看 accuracy 会被不平衡掩盖：29-3 accuracy 0.49~0.50、类别 0 召回 0.15~0.21（模型几乎全预测上涨）；29-4 accuracy 0.55、类别 1 召回 0.83、类别 0 召回 0.33。
- 异常高的 AUC 要先排查泄漏：11-3-7 的测试 AUC 0.9802 未排查特征/标签泄漏；29-3 在切分前做 RandomOverSampler 污染测试集。
- 学习曲线判读不能自相矛盾：训练/测试误差趋同是欠拟合信号，不能当作"稳定性提升"（29-3 的原文表述与数据不符）。
- 单次留出集上 0.51 与 0.53 的差异不具统计意义（31-6），不能据此选模型。

## 验证状态
原文给出真实运行结果，属已验证：
- 11-3-7（以太坊账户二分类）：CatBoost+SMOTE 测试集 AUC 0.9802、Accuracy 0.9827、Precision 0.9439、Recall 0.9758、Specificity 0.9846、F1 0.9596，混淆矩阵 TN=766、TP=202、FP=12、FN=5；GradientBoosting+oversampling 交叉验证 best score 0.9994。
- 31-6（AAPL 周频，9 特征）：5 个梯度提升分类器 ROC-AUC 最好 0.53（GradientBoosting）、CatBoost 0.51。
- 31-7：Optuna 1000 次试验后 HBGB 的 ROC-AUC 由 0.51 提升至 0.55、CatBoost 由 0.51 提升至 0.58（最优 depth=2）。
- 12-5 / 12-2（期货趋势跟踪）：LogisticRegression 测试集 AUC=0.887（其余 7 个分类器结果原文缺失）。
- 29-5（GOOG）：分类报告 support 3637，accuracy 0.82，类 0 精确率 0.80/召回 0.85，类 1 精确率 0.85/召回 0.80，macro 与 weighted F1 均 0.82；类 1 精确率较特征扩充前 67.83% 提升到 85.28%。
- 29-4：测试集 1211 条，accuracy 0.55，类 0 precision 0.71/recall 0.33/F1 0.45，类 1 precision 0.49/recall 0.83/F1 0.62。
- 29-3：accuracy 0.49（max_depth=3）、0.50（max_depth 7/15），类 1 召回 0.92、类 0 召回 0.15。
