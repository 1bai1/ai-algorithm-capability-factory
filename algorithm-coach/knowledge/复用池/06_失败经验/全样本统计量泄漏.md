# 全样本统计量泄漏

## 错误模式

在训练/测试切分之前，用**全量数据**拟合任何依赖样本统计量的环节，使测试段信息进入变换参数或筛选结果。典型载体：标准化/归一化器（StandardScaler、MinMaxScaler、PowerTransformer）、特征筛选器（互信息、相关系数、方差阈值）、分位数阈值、多尺度均值类特征。

## 触发场景

- 价格序列先 `scaler.fit_transform(整个 df)` 再按位置切训练/测试（14-4、14-5、15-6、29-6-01 全部如此）。
- 归一化只对训练段 fit 的正确做法未交代，或未说明是否重拟合（3-3 直接对全量变换；11-4-9 未说明是否重拟合 scaler；9-3 标准化方式未说明，若用全样本统计量即前视）。
- 用互信息在全样本上筛特征/选滞后阶（14-4 的 MI 阈值 3 在全样本算；3-2 的相关性筛特征在全部数据上做）。
- 技术指标与滚动特征先在全序列 `rolling()` 再切窗，窗口边界含未来值（1-2-7 的 MA20/RSI/Momentum）。
- 分类/分位阈值用全样本统计量确定（12-2 的阶段划分与分位数阈值）。
- 特征里混入预测日同期的量（13-4 的特征含同期 Open/Close/Volume 及互补价列）。

## 如何识别

1. 在代码里定位 `fit` / `fit_transform` / `quantile` / `corr` / `mutual_info` 的调用位置：只要出现在 `train_test_split`、按日期切分或 `iloc[:n]` 切分**之前**，即为泄漏。
2. 检查 `scaler.fit_transform(X)` 的 `X` 是全量还是 `X_train`。
3. 检查特征筛选的入参行索引范围是否覆盖了测试段。
4. 对每个特征追问"在预测时点 t 是否已经可得"；尤其是同期的 OHLC、同期均值、全样本分位数。
5. 审查滑动窗口的生成顺序：应先切窗再算指标，而不是先算指标再切窗。

## 后果

- 测试集误差被系统性低估：14-4 报 MAE 8.96、14-5 与 15-6 报测试 R² 约 0.95、29-6-01 的归一化会连带污染后续切分，这些数字都无法代表真实泛化能力。
- 特征筛选结果不可复现：换一段时间就选出不同特征。
- 训练时看起来收敛良好，实盘/样本外失效，且失效原因被误判为"模型不够复杂"。

## 修复规则

1. **统计量只在训练段估计**：`scaler.fit(X_train)` → `transform(X_train)` 与 `transform(X_test)`；预测后 `inverse_transform` 还原量纲（15-6 的逆变换闭环是正确的一半，缺的是仅在训练段 fit）。
2. **时序任务改用滚动拟合**：把 scaler、编码器、填充统计量、特征筛选器全部移入滚动循环内部；29-5 给出了可直接照搬的判据——滚动均值本身是后视不构成泄漏，但"需要跨样本拟合的变换（标准化、编码、填充统计量）必须移入滚动循环内部"。
3. **特征计算统一 shift(1)**：14-3 的做法可作为模板——所有滚动统计与技术指标计算前统一滞后一期，只用截至上一期的信息。
4. **特征筛选与阈值只在训练段定**，且不得用测试段做二次筛选（参见"测试集参与调参与模型选择"卡）。
5. **特征清单逐个过"是否含预测日当期信息"**：含同期 OHLC 或互补价列的特征必须剔除或改为滞后版（13-4 未做此检查）。

## 验证状态

原文均未验证泄漏影响量级，也没有一篇给出"仅训练集 fit"的对照运行结果。各篇报出的误差（14-4 逆变换后 MAE 8.96、15-6 测试 R²≈0.952、14-5 无误差数值）因泄漏不可采信。其中 3-3、9-3、(3-2)AI金融实战仅"未说明/未提及正确约束"，属沉默性缺陷；14-4、14-5、15-6 是代码里明确写出的 `全量 fit_transform`，属原文实现自证错误，价值更高。
