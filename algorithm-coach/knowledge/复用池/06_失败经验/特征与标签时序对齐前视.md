# 特征与标签时序对齐前视

## 错误模式

特征或标签在时间轴上错位，导致建模时用了预测时点尚不可得的信息。五种可复现的形态：

1. **用当期/未来可得价做逐步预测**：预测 t 期 Close 时把 t 期的 Open/High/Low 作为外生变量传入。
2. **标签口径与阈值统计口径不同期**：阈值来自"当期 ratio 对当期收益"的统计，标签却是"下一期 ratio 是否超阈值"。
3. **目标列构造与滞后对齐规则未定义**：特征生成函数没有声明与目标列的对齐方式。
4. **全样本相关性用于因子筛选**：相关性按全样本计算，未按训练/验证窗口切分。
5. **事件时点未对齐**：新闻/公告的发布时点（盘前/盘后、时区）与交易日未做映射。

## 触发场景

- ARIMAX 逐步外推时把测试段每一期的 Open/High/Low 喂进 `model_fit.forecast(exog=...)`（29-5-03）。
- 先用分位数收益表选出 0.998 这个阈值，再把 target 定义为"下一期 ratio 是否 > 0.998"（12-4）。
- 特征生成函数（Add_Lag / Roll_Stats / add_diff）未交代与目标列的对齐规则（14-3）。
- 用全样本线性相关矩阵筛因子（15-5），或用 `corr()` 在全部数据上筛特征（3-2）。
- 新闻标题只有发布时间戳，未处理盘前/盘后归属（30-1）。
- 按当日收益率决策但成交时点未定义（28-3）。

## 如何识别

1. **逐个特征问"t 时点能否拿到"**：凡是 t 期当日的 OHLC、当日成交量、当日情绪分，一律不可作为 t 期预测的输入。
2. **把标签定义与阈值/分位数的统计口径并列写出来**，检查是否同一期（12-4 的错位就发生在这一步）。
3. **验证 `shift` 的方向与位置**：29-3 给出了正确范式——`Target = (Close_t > Close_{t-1})`，且**全部特征整体 `shift(1)`**；若特征未 shift 而标签用了当期，等于用当天数据预测当天。
4. **检查相关性/IC 的计算窗口**：是否只用训练段。
5. **检查事件表的时间戳到交易日的映射规则**，以及复权口径（31-5 的 `cat_target` 阈值与收益窗口定义原文未交代）。

## 后果

- 29-5-03 的 RMSE = 0.7477 因使用当期 Open/High/Low 而系统偏低，属乐观偏差，原文未讨论。
- 12-4 的 0.998 阈值迁移带有未声明的隐含假设，标签与阈值不同源。
- 事件类特征整体不可用：30-1 未做时点对齐，情绪与收益的先后关系无法确定。
- 回测不可复现：成交时点未定（28-3），当日成交与次日成交的结论可以完全相反。

## 修复规则

1. **特征统一滞后**：全部特征 `shift(1)`，标签取 t 期或 t+1 期，保证"用截至 t−1 的信息预测 t"（29-3 的范式）。
2. **滚动统计/技术指标先 shift 再 rolling**：14-3 的约定可直接照搬——所有滚动统计与技术指标计算前统一滞后一期。
3. **阈值与标签同源**：若阈值来自当期关系统计，标签必须同期；若标签是下一期量，阈值必须在训练段用同期口径重新估计（12-4 的做法缺这一步）。
4. **外部信息按"可得时点"入模**：新闻/公告按发布时点对齐，盘后发布归入次日；基本面按披露日而非报告期对齐。
5. **明确成交时点并做敏感性测试**：信号 `shift(1)` 决定仓位是最小改动（12-6、31-8-02/03 的 `position = signal.shift(1)` 是正面样本）；对"当日成交 / 次日开盘成交"两种假设各跑一次，把差异报出来（28-3、3-4-01 均未做）。
6. **逐步外推禁止传入当期外生变量**：若必须使用，须显式标注为"不可实盘的乐观上界"，并把不含外生变量的版本作为正式结论。

## 验证状态

无一篇给出修正后的对照数值。29-5-03 的 RMSE 0.7477、ARIMAX 摘要（Open −0.5615、High 0.7750、Low 0.7870）属在含未来信息的设定下取得，不可作为预测力证据；12-4 未给模型与回测结果，无法判断阈值是否有预测力。该卡记录的全部是"原文实现中已经发生、原文未意识到或未讨论"的对齐错误，而非作者自述局限。
