# 缺失值填充错误

## 错误模式

填充统计量的作用域错位（跨标的、跨时段共享一个均值）或填充方法忽略缺失结构（连续多日缺口被插值成平滑人造价格）。伴生错误：不做缺失体检直接建模，以及用错误的方式判断缺失（`if x != None` 对 `NaN` 失效）。

## 触发场景

- **跨标的填充污染**：多股票行情表按**整列**取均值填充，未按 `ts_code` 分组（3-1）。原文实例中 AAPL 开盘价、TSLA 开盘价被填成 1066.48 这类不属于任何单只标的的量级。
- **按时间轴两端均值插值且不计缺失时长**：连续多日缺失时生成一段人造平滑价格，扭曲波动率与收益率分布（28-2）。
- **均值/众数填充不分层**：未按类别或时间分层，低估方差（10-2-04）。
- **填充策略未交代**：只说"会处理缺失"，未写前向填充还是常量（8-4-1）；`dropna()` 造成的样本损失未统计（31-5）。
- **缺失体检缺失**：未查缺失值、零成交时段与重复日期（11-4-2、15-4）；"无缺失"不等于数据可用（15-3——未查重复日期、时间连续性、节假日缺口与异常单日成交量）。
- **缺失判断写错**：`if i != None` 无法识别 `NaN`，可能把缺失值写入结果文件（6-4）。

## 如何识别

1. **先体检再填充**：逐列打印空值占比与连续缺失长度。29-5 给出了可照搬的做法——逐列统计缺失比例（周均值 0.13%、季均值 1.92%、年均值 7.85%），并指出"滚动窗口越长，早期空值比例越高"。
2. **检查 `fillna` 的入参作用域**：`df[col].fillna(df[col].mean())` 在多标的表上必然跨标的；应用 `df.groupby('ts_code')[col].transform(...)` 或按标的分组。
3. **看缺失是否成段**：用 `isna()` + 游程长度统计连续缺口；成段缺口不能用插值。
4. **检查缺失掩码是否保留**：`fillna` 之后是否还知道哪些位置是补的。
5. **检查 NaN 判断方式**：用 `pd.isna()` / `np.isnan()`，不要用 `!= None` / `== None`。
6. **检查删行损失**：`dropna()` 前后行数差是否统计并披露。

## 后果

- 填充值本身是错误的量级，整列不可用（3-1 的 1066.48 跨标的污染），且箱线图对比无法暴露这类错误。
- 人造平滑段使波动率被低估、收益率自相关被抬高，进而污染 HMM/波动率类模型的状态划分（28-2 未统计缺失数量与占比，无法评估影响程度）。
- 方差被低估、极端情形被抹掉，风险度量失真（10-2-04）。
- 缺失以 `NaN` 形式残留到结果文件与下游指标（6-4），或在 `dropna` 中静默损失训练样本（31-5）。

## 修复规则

1. **分组填充**：所有填充统计量必须按标的分组计算；跨标的共享的统计量只允许用于"该列本身与标的无关"的场景（时间戳、统一费率）。
2. **先量化再决策**：输出缺失比例表与连续缺口长度表，再决定方法；缺口长度超过阈值的区段标记为"不可交易区间"并排除，而不是插值。
3. **区分缺失类型**：随机单点缺失可前向填充；结构性缺失（停牌、休市、零成交）保留为 NaN 并配掩码，不得插值成连续价格。
4. **不依赖序数删除**：报告 `dropna()` 造成的样本损失（百分比 + 时间分布），确认损失不集中在特定时段。
5. **NaN 判断统一用 `pd.isna()`**，并在写盘前做一次空值计数断言。
6. **零成交/零价先检出**：成交量或 OHLC 为 0 的时段先识别（12-3 早期 Volume 为 0 使 OBV/ADI 严重失真），再谈填充。

## 验证状态

- 3-1：给出了填充后的实际输出值（AAPL/TSLA 开盘价填成 1066.48），是**结果级证据**，原文未意识到这是错误。
- 10-2-04：`df['LoanAmount'].fillna(df['LoanAmount'].mean())` 与类别列众数填充，原文给的是流程而非评估结果。
- 28-2：插值逻辑已实现但未统计缺失数量与占比，效果不可评估。
- 6-4、8-4-1、31-5、11-4-2、15-3、15-4：均无修复前后对照数据。
