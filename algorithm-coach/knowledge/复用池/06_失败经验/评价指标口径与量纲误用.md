# 评价指标口径与量纲误用

## 错误模式

指标名称相同但计算空间、量纲或语义不同，导致跨表、跨模型、跨配置的数值不可比，甚至被反向解读。可复现的具体形态：

1. **上下界互换**：`plot_forecast` 内部把 `upper` 赋给 `lower_series`、`lower` 赋给 `upper_series`，画出的区间带被调换。
2. **变换空间不一致**：MAPE 在**对数空间**计算（`get_mape(result.Close, result.forecast)`），而可视化用 `np.exp` 还原到价格空间，两处口径不一致。
3. **朴素误差方向写反**：MASE 分母用 `y_train.shift(-1)` 构造朴素误差，与常用的 `shift(1)` 方向相反。
4. **量级变化下的指标冲突**：测试集 RMSE 比训练集扩大近 9 倍，MAPE 反而更低（66.15 → 54.91），原因是测试期币价量级更高。
5. **归一化域误差被当作性能**：同一模型报出逆变换前 MAE 0.0166 与逆变换后 MAE 8.96，只有后者有业务含义。
6. **在价格水平而非收益率上评估**：RMSE 被价格量级主导，掩盖相对误差。
7. **指标语义被误读**：把夏普比率 0.53 说成"53% 的超额年回报"（夏普是风险调整比率，不是百分比收益）。
8. **同一指标在不同环节用不同参数**：模拟循环 `rf_rate = 0.0`，`negativeSR` 内 `rf_rate = 0.025`，散点颜色（夏普）与最优点标准不同源；正文称"夏普比率最高（0.953%）"与权重表的 0.8496 不符。
9. **概率与硬标签混用**：`plot_model_performance` 直接把 `y_pred` 传入 `roc_curve`，若上游给的是硬标签则 ROC 退化为单点；11-3-7 的 AUC 用硬标签计算，与概率版 ROC 语义不一致。
10. **似然尺度不统一**：收益率乘 100 会改变似然尺度，跨数据集比较 AIC 需口径一致（1-2-5）。

## 触发场景

对数变换建模 + 原始空间展示、归一化 + 未逆变换、价格与收益率混用、概率/标签混用、多模型多配置横向比较表、同一报告里同一指标出现两次。

## 如何识别

1. **自查同名指标的数值是否唯一**：同一份报告里出现两个夏普（0.953% 与 0.8496）、两个无风险利率（0.0 与 0.025），即为口径错误。
2. **检查指标的输入是否在同一空间**：所有误差指标在计算前先 `inverse_transform` / `np.exp` 还原；对数空间仅用于拟合，不用于报告。
3. **检查区间序关系**：绘图前断言 `upper >= point >= lower`（15-11 的 bug 就是这里没断言）。
4. **检查朴素基线的方向**：MASE/差分类分母要确认 `shift(1)` 还是 `shift(-1)`。
5. **价格量级变化时同时看绝对与相对指标**：RMSE 与 MAPE 结论冲突时，回溯价格区间再解读（11-4-5 的判据）。
6. **分类指标先确认输入类型**：ROC/AUC 必须喂概率或得分；若只有硬标签，改用非阈值的替代指标。
7. **跨配置比较前统一尺度**：收益率是否 ×100、AIC 是否在同一数据变换下计算。

## 后果

- 结论被反向解读：11-4-5 中"RMSE 扩大 9 倍"与"MAPE 下降"同时出现，若只看一个数会得出完全相反的结论。
- 报告不可比：8-5-6 的散点颜色与最优点标准不同源，最优组合的夏普被算错。
- 指标失去诊断能力：ROC 退化为单点、AUC 语义错位后无法判断模型真实排序能力。
- 误差数值无法解释：归一化域的 MAE 0.0166 无法回答"这个模型能不能用"。

## 修复规则

1. **所有指标在原始量纲上计算并标注单位**：金价用"元/美元"、收益率用小数或百分比，且全流程统一（14-4 明确要求报告逆变换后的量纲值）。
2. **区间类输出加断言**：`assert (upper >= lower).all()` 后才绘图；`plot_forecast` 的上下界入参名与内部变量名必须一一对应。
3. **建立指标字典**：每个指标写明计算空间（对数/原始）、输入类型（概率/标签/价格/收益）、年化口径与无风险利率取值；一个报告里同一指标只允许一个定义。
4. **绝对误差与相对误差成对报告**，并在价格量级变化显著的区间做分段解读（11-4-5）。
5. **分类指标分清输入类型**：AUC 用 `predict_proba[:,1]`；若用硬标签须换指标或改调用。
6. **跨配置比较前统一似然尺度与变换**（收益率是否 ×100、是否取对数、是否差分）。
7. **夏普等比率类指标不得表述为收益率**；报告时给出频率与年化方法（9-6 的问题之一即"夏普频率与年化口径未说明"）。

## 验证状态

- 15-11：给出可运行的 MAPE/MASE 实现与 `plot_forecast` 代码，上下界互换与对数空间计算都是从代码直接读出的实现缺陷，属**自证错误**；未给 MAPE/MASE 的具体数值。
- 11-4-5：给出成对的训练/测试指标——训练 CORR 0.594、R² 0.290、RMSE 2868、MAE 2218、MAPE 66.15；测试 CORR −0.213、R² −1.358、RMSE 25532、MAE 19314、MAPE 54.91，是"指标冲突需结合价格区间解读"的实证样本。
- 14-4：逆变换前 MAE 0.0166 / RMSE 0.0183，逆变换后 MAE 8.96 / RMSE 9.89。
- 29-5-03：RMSE = 0.7477（价格水平）；1-2-5：贵州茅台 2020-01-03 至 2023-09-01，890 条（训练 712 条），GARCH(1,1) 的 RMSE 低于 ARCH(1)。
- 8-5-5：夏普 0.53 被解释为"53% 的超额年回报"；8-5-6：正文 0.953% 与权重表 0.8496 不符，rf 0.0/0.025 两套。
- 11-4-4：mean_test_MAPE = 60.13，三折分别 116.93 / 34.5 / 28.96，mean_train_MAPE = 73.62；原文未讨论 60 量级是否可接受。
