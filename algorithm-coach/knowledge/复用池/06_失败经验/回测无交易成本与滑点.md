# 回测无交易成本与滑点

## 错误模式

回测收益按"无摩擦、按理想价格全额成交"计算，把高频换仓的策略收益系统性高估。**换手率越高，高估幅度越大**，因此该错误对日频/周频调仓策略的杀伤力远大于低频策略。

## 触发场景

- 每周换仓但不计成本：12-6 原文明确说明"未计入交易成本与滑点，每周换仓的摩擦会明显削减 62% 的累计收益"。
- 94% 时间在市场却能胜出，成本对结论的影响被忽略（31-8-02）。
- 含做空策略未计融券费用与做空约束（31-8-03）；结论明确未计税收和交易成本（31-9）。
- 几乎每日调仓的策略在无摩擦环境下"远优于买入持有"（3-4-01）；摩擦率升到 1% 以上后策略优势基本消失（3-4-03）。
- 执行层只用固定滑点与佣金近似，未真实建模冲击成本（6-3-02）。
- 未计税费与滑点（13-5）；权重逐日变动却无换手约束（9-6）；无成本、滑点、冲击成本与流动性约束说明（9-7）；每日调仓但完全未考虑成本、印花税与最小交易单位（9-8）。
- 只有满仓/空仓切换、无手续费与滑点（15-12）。
- 交易成本仅按固定百分比计，未建模冲击成本、滑点与流动性限制（9-4）。
- 迁移到 A 股时未处理涨跌停、停牌与 T+1（12-3）。

## 如何识别

1. **搜回测代码里的成本项**：有没有 `cost`、`commission`、`slippage`、`fee`、印花税；没有即为零成本回测。
2. **算换手率与持仓时间占比**：持仓 94%（31-8-02）、每日调仓（9-6、9-8）、每周换仓（12-6）都是高危信号。
3. **看是否有摩擦率敏感性分析**：只有单点无成本产出的，结论不可判断。
4. **看成本模型是否与交易规模有关**：把手续费、买卖价差、冲击成本统一压成一个与规模无关的常数 f，对大资金不成立（28-3）。
5. **看是否遗漏制度性成本**：印花税、融券费用、最小交易单位、涨跌停导致的无法成交。

## 后果

- 策略优势完全由零成本假设支撑：3-4-03 中摩擦率升到 1% 以上后策略优势基本消失，实盘可用性存疑。
- 累计收益被高估到无参考价值（12-6 的 62.16% 需先扣除每周换仓摩擦）。
- 日频调仓类 RL 策略的收益会被换手成本显著侵蚀（9-6、9-8）。

## 修复规则

1. **强制成本项**：手续费 + 印花税 + 滑点三者必须计入回测（6-2-01 明确列为回测规范）；做空策略补融券费用与做空约束。
2. **做摩擦率敏感性扫描**：把 f 从 0 扫到 0.02（100 档），逐档重算终值，给出"策略在多少成本下失效"的答案（3-4-01、28-3 的 `np.linspace(0, 0.02, 100)` 是可照搬的做法）。
3. **用 (1−f)^交易次数 做成本侵蚀上限估算**：只需终值与交易次数两个数即可放进回测摘要（28-3）；同时必须定义交易次数口径（买入+卖出算一笔还是两笔）。
4. **区分规模相关与无关成本**：大资金场景需对冲击成本单独建模，不能沿用常数 f（28-3）。
5. **报告换手率与持仓时间占比**，两者与成本共同决定净收益（31-8-02 的正面做法）。
6. **迁移 A 股必须补制度约束**：T+1、涨跌停、停牌、集合竞价与最小交易单位。

## 验证状态

- 12-6：给出完整回测数字——策略累计收益 62.16%、买入持有 37.56%、夏普 0.75、Sortino 1.1、年化波动 44.19% 对 44.21%、最大回撤 −39.84%、最差一次回撤持续 1043 天；原文明确说明这是历史数据上的模拟结果，未计入交易成本与滑点。
- 31-8-02：累计回报 908.02%（基准 855.4%）、CAGR 19.09%（18.61%）、Sharpe 2.49（2.29）、Sortino 3.91（3.56）、持仓时间占比 94%，无成本。
- 31-8-03：累计回报与 CAGR 优于买入持有，但夏普更低、最大回撤更高（原文自述风险调整后表现不及基准与策略 1）。
- 3-4-01：无摩擦环境下基准策略长期显著跑赢买入持有，几乎每日调仓；摩擦率—回报曲线与"时间旅行者"上限基准。
- 3-4-03：100 档摩擦率只落到 3 组不同阈值；0.5% 摩擦下策略仍占优，1% 以上优势基本消失。
- 9-6：期末总资产 1,363,804（约 +36.4%）、Sharpe 1.8078，无成本与基准对比。
- 9-7：Alpha 0.00、Beta 0.94，夏普 1.81 与最大回撤与道指基准（1.84、−8.93%）接近，未见成本与流动性约束说明。
- 9-8、13-5、15-12、9-4、6-3-02：均无成本项，也未给成本敏感性结果。
