# 分类指标与盈亏脱节

## 错误模式

涨跌方向分类任务的评价停在 AUC / Accuracy 层，既不检查类别级召回，也不换算到交易层面，导致"指标可用"与"策略可用"之间存在未验证的落差。具体形态：

1. **AUC 与盈亏脱节**：8 个分类器只报 LogisticRegression 的 AUC=0.887，随即判定"可以继续开发策略"，未给回测收益、成本或与 Buy & Hold 的对比。
2. **接近随机的 AUC 被当作成果**：0.55~0.58（31-7）、0.51~0.53（31-6）、0.57（31-8-01）都只略高于随机且无基准对照。
3. **accuracy 被不平衡类别主导**：accuracy 0.49/0.50 而类别 0 召回仅 0.15~0.21（29-3）；accuracy 0.55 而类别 0 召回 0.33（29-4），原文仍称"稳定性"提升。
4. **AUC 与 accuracy 结论互相矛盾**：31-8-01 中加权软投票准确率最好（59.5%）但 AUC 反而更低。
5. **模型间差异落在噪声内**：31-6 的 0.51 与 0.53 来自单次留出集，差异不具统计意义。
6. **AUC 高得异常**：约 0.98 未排查特征泄漏或标签泄漏（11-3-7）。
7. **只给准确率不给类别级指标**：类别不平衡时准确率会误导（30-6）。

## 触发场景

任何"价格涨跌二分类 / 情绪二分类"任务；训练集正类占比明显偏离 50%（31-4 指出 AAPL 训练期 53.7% 的正收益基准使难度被人为降低）；含做空方向的策略。

## 如何识别

1. **检查是否只有 AUC/accuracy**：没有 precision/recall/F1、混淆矩阵、类别分布的，一律视为未完成评估。
2. **看少数类召回**：特别关注"下跌"类的召回（29-3 的 0.15~0.21、29-4 的 0.33），它直接决定策略能否在下行市存活。
3. **看类别分布**：正类占比 53.7%（31-4）这类接近对半的分布下，accuracy 接近 0.5 就是没有信息。
4. **看指标间是否排序一致**：同一组模型在 AUC 与 accuracy 下排序相反时，先定主指标再谈优劣（31-8-01）。
5. **看 AUC 是否 > 0.95**：金融横截面/时序任务上出现 0.98 应优先排查泄漏（11-3-7）。
6. **看有没有从分类指标到交易指标的桥接**：精确率提升 10 个百分点是否带来净值提升，必须实测。

## 后果

- 模型选型无法裁决（31-8-01 的 AUC/accuracy 矛盾）。
- 偏多输出在下行市不可用：29-3 的模型几乎把一切都预测成上涨，直接用于多空决策风险极大。
- 用分类指标替代回测，使"模型有效"与"策略盈利"之间的空白被默认填平（12-5、31-6、12-2）。

## 修复规则

1. **建模前唯一确定主指标**（31-8-01 的教训），并写明选择理由；主指标之外的指标只作诊断。
2. **不平衡任务以 Log Loss 与类别级 precision/recall 为主**，不以总体 accuracy 定优劣（29-4 给出的判据："Log Loss 专为二分类设计，对错误分类的惩罚重于准确率，更适合不平衡分类的评估"）。
3. **强制报告概率/得分输入**：ROC/AUC 必须用 `predict_proba[:,1]`（12-5 的 `clf.predict_proba(X_test_best)[:,1]` 是正确写法），硬标签计算 AUC 语义不一致。
4. **必须补交易层验证**：把分类信号按 `position = signal.shift(1)`、`model_returns = position * returns` 换算成收益，并计成本、与 Buy & Hold 对比（12-5、31-6、30-5 均缺这一步）。
5. **给出随机基准**：正类占比 53.7% 时，全预测为 1 就有 53.7% 的准确率，必须把这个数作为对照写出来。
6. **AUC 异常高先排查泄漏**，再讨论模型。
7. **模型间比较需报显著性**：单次留出集上的 0.51 vs 0.53 不构成结论（31-6）。

## 验证状态

- 12-5：LogisticRegression AUC = 0.887（其余 7 个分类器结果缺失），单变量 f_classif + `SelectKBest(k=len(X_train.columns))` 实际未降维、真正生效的是 p<0.05 过滤，入选 23 个特征；AUC 与策略盈亏未接通。
- 31-7：HBGB 0.51→0.55、CatBoost 0.51→0.58，1000 次 Optuna 试验，单次试验分数在约 0.47~0.55 波动。
- 31-8-01：硬投票 AUC 0.57，加权软投票准确率 59.5%（最优权重 HBGB 0.889、CatBoost 0.363）。
- 31-6：5 个模型 AUC 0.51~0.53，单次留出集，差异不具统计意义。
- 29-3：accuracy 0.49（max_depth=3）、0.50（max_depth=7/15），类别 1 召回 0.92、类别 0 召回 0.15；29-4：accuracy 0.55，类别 0 recall 0.33。
- 11-3-7：AUC 约 0.98，原文未排查特征泄漏或标签泄漏。
- 30-6：训练准确率 0.9996、验证约 0.97，只给准确率，无精确率/召回率/F1 与类别分布。
- 30-5：CART/RF 训练准确率 1.0，结论"LR 更好"只在默认参数下成立。
- 12-2：AUC 0.887 未说明样本量与验证方式，存在过拟合或数据泄露的可能。
