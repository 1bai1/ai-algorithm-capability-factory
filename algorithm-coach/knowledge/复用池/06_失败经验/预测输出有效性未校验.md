# 预测输出有效性未校验

## 错误模式

模型或求解器产出了物理/经济上不可能、或者干脆缺失的值，而流程没有做任何后置校验就直接进入指标计算、绘图与报告。具体形态：

1. **非负量出现负值**：价格的预测区间下界为负（−2914 ~ −3112）；递归多步预测结果出现负股价。
2. **输出残缺**：偏度/峰度为 NaN；最大回撤的 Recovery date 为 NaT；FCFF 衰退情景的列表为空。
3. **求解失败被静默吞掉**：`ARIMA(5,0,5)` 每期重估频繁报 Schur decomposition solver error，原文未说明异常后的实际行为，也未报告失败率。
4. **缺失值穿透到输出**：`if i != None` 无法识别 NaN，可能把缺失值写入结果文件。
5. **指标超出常识范围而未讨论**：交叉验证 MAPE 均值 60 量级（百分比误差远超 50%），原文未讨论该结果是否可接受；14-3 的 `Prepare_Data` 对 `Roll_window<2` 只打印提示不中止。

## 触发场景

- 用正态/对称残差假设构造预测区间，遇上非负的价格序列（11-4-7）。
- 递归多步外推（ARIMA/LSTM 滚动预测）时把预测值写回序列继续预测，误差累积并越界（6-2）。
- 统计函数在样本过短、方差为零或全 NaN 的切片上计算（9-7）。
- 数值优化在重估频率高、参数多时求解失败，代码用 try/except 捕获并 `print` 后继续（15-12）。
- 结果写盘前不检查空值（6-4）。

## 如何识别

1. **数值域检查**：价格、成交量、方差、波动率等非负量是否出现负值；预测区间是否满足 `lower <= point <= upper`；下界是否 ≤ 0。
2. **空值检查**：对每个输出列做 `isna().sum()`；对统计量额外检查是否为 NaN/±inf。
3. **失败率统计**：凡有 try/except 捕获数值求解错误的循环，统计失败次数占比并在报告中披露。
4. **指标范围检查**：相对误差指标（MAPE）超过 50、AUC 超过 0.95、R² 为负、损失趋近 0 都属需要回溯的异常信号。
5. **参数合法性前置校验**：窗口、滞后阶数等参数在入口处做硬校验并抛异常，而不是打印提示后继续（13-3 的反例）。

## 后果

- 不可执行的输出：负价格无法转为交易指令；负区间下界使风险度量与可视化失真（11-4-7）。
- 报告建立在部分失败的拟合上却未声明（15-12 的 Schur 报错），结论可靠性未知。
- 缺失值以 NaN 形式进入指标，使均值/方差等统计量整体变质（9-7 的 Skew/Kurtosis 为 NaN）。
- 指标异常低调或异常好时无人追问，掩盖了上游的数据或模型问题（11-4-4 的 MAPE 60、11-3-7 的 AUC 0.98）。

## 修复规则

1. **输出后置校验清单（每次预测后强制执行）**：非负约束、区间序关系、NaN/NaT 计数、值域上下限、与上一期值的偏离幅度。
2. **不可行值不得静默通过**：负价格与非负量的负区间应触发告警或中止，而不是进入绘图与指标。
3. **求解失败显式处理**：统计并报告失败率；失败样本从指标中剔除并计入缺失比例，不得静默继续。
4. **参数前置校验抛异常**：窗口/滞后/阶数的合法性在函数入口断言。
5. **异常指标必须归因**：出现 MAPE > 50、AUC > 0.95、R² < 0、loss → 0 时，先排查数据泄漏、标签泄漏与量纲问题，再考虑模型本身。
6. **写盘前做空值断言**，并对结果文件做一次抽样回读校验（6-4 的反例）。

## 验证状态

- 11-4-7：给出具体数值——预测区间下界 −2914 ~ −3112，对非负价格不合理，属**结果级证据中的实现缺陷**，原文未讨论。
- 15-12：ARIMA(5,0,5) 每次重估需拟合，169 次迭代约 2 分钟并频繁报 Schur decomposition solver error，原文未说明异常后的实际行为；样本仅 2021-04-01 至 2021-10-01 共 169 个交易日，44% 回报不具统计意义。
- 9-7：Skew/Kurtosis 为 NaN，输出不完整；第二段最大回撤的 Recovery date 为 NaT，说明区间末端尚未恢复；回测区间仅约 336 个交易日。
- 6-2：文中预测结果出现负股价，作者承认模型未能捕捉真实波动。
- 11-4-4：mean_test_MAPE = 60.13 未讨论是否可接受。
- 6-4、13-3、14-3：属输入参数与空值校验缺失（`if i != None`、`Roll_window<2` 只打印提示、`std` 变量实际存方差）。

- 常见误用：[[自回归族时序预测（AR-MA-ARMA-ARIMA-SARIMA）|自回归族单变量时序预测（AR/MA/ARMA/ARIMA/SARIMA）]] —— 递归多步外推把预测值写回序列继续预测，负股价与求解失败都出现在该能力的落地用法上，需配输出后置校验。
