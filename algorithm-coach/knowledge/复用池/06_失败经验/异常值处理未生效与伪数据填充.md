# 异常值处理未生效与伪数据填充

## 错误模式

清洗动作在报告里被宣称已完成，但**输出未发生变化**；或者为了凑齐数组形状而用固定值伪造数据点。两类错误都会让后续所有指标建立在一个与描述不符的数据集上。

1. **异常值处理空转**：正文宣称某段极端波动需要处理，程序输出 `Outliers` 为空、`Cleaned Data` 与原始数据完全一致。
2. **伪数据补位**：序列头部用硬编码 0 补位（`add_diff` 前两行）、缺失值统一 `fillna(0)`。
3. **阈值不稳健或未给出**：均值 ± 标准差本身受异常值影响；"极大值"、倍数阈值等参数原文未给。
4. **整行剔除过于激进**：IQR 1.5 倍法则对金融厚尾数据会丢掉极端行情样本。
5. **清洗顺序未论证**：异常值与插值的先后顺序无依据（先替换异常值再插值 vs 反之，结果不同）。

## 触发场景

- 用均值 ± 标准差定义异常阈值并替换为均值（3-1）。
- 滚动均值比率类特征在序列早期为空，统一 `fillna(0)`（29-5）。
- 一阶差分函数对前两个位置直接补 0（14-3）。
- 只删除"含极大值与 NaN 的列"而不给"极大值"的阈值（14-3）。
- 剔除 OHLC 为 0 的行（13-3，正确动作）与未检出零成交时段（12-3，漏检）并存。
- 用 IQR 整行剔除后再均值填充（10-2-04）。

## 如何识别

1. **强制前后对照**：行数变化、被替换值计数、被修改单元格清单、分布对比图。若"异常值数量 = 0"而正文仍在描述异常，就是空转（3-1 的原型）。
2. **搜 `fillna(0)` / `np.zeros` / 硬编码补位**：任何非"该值本身即为 0"的 0 填充都是伪数据。
3. **检查阈值来源**：是否给出具体倍数/分位数，是否是稳健统计量（中位数、MAD、分位数）。
4. **检查零值语义**：Volume=0 是"无成交"还是缺失？OHLC=0 是坏记录还是停牌？语义不同处理方式不同。
5. **检查顺序**：异常值替换与插值的调用先后是否有明确理由并写进流程。

## 后果

- **最危险的一类**：3-1 的清洗脚本产出的 `Cleaned Data` 与原始数据完全一致，但流程与结论都按"已清洗"呈现，下游全部指标建立在一份未处理的数据上。
- 29-5 的 `fillna(0)` 使早期样本的多尺度均值比率变成 0 或虚假持平信号，模型可能学到"早期即异常"的伪模式（原文自认"不是最优做法"）。
- 14-3 的前两行补 0 直接污染前两期训练样本。
- 12-3 中早期 Volume 为 0 未被识别，OBV、ADI 等量价类特征严重失真。
- 10-2-04 的 IQR 整行剔除丢掉极端行情样本，而极端行情恰是金融模型最需要学的部分。

## 修复规则

1. **清洗后置断言**：如果 `outlier_count == 0` 或"清洗前后数据完全相同"，必须报错中止并回溯，不允许静默通过。
2. **禁止用固定值伪造序列头部**：应截断窗口不足的前若干行（`data.tail(data.shape[0]-100)` 这类显式裁切是可行做法），或保留 NaN 并配掩码，不得补 0。
3. **用稳健统计量定阈**：中位数 ± k·MAD、分位数、或直接按业务定义（如单日涨跌幅超过制度上限）；阈值必须写成显式参数。
4. **异常值处理与插值的顺序固定并写入流程**，先异常值再插值可避免用被污染的值插值。
5. **谨慎整行剔除**：厚尾数据优先 winsorize（缩尾）而非删除，保留极端样本但限制其杠杆。
6. **零值先做语义判定**：OHLC ≤ 0 判为坏记录剔除（13-3）；Volume = 0 判为无成交，量价类特征在该段置为不可用而非参与计算（12-3）。

## 验证状态

- 3-1 给出了结果级证据：程序输出 Outliers 为空、Cleaned Data 与原始数据完全一致，与正文"收盘价由 160 涨到 250 再跌回 190 属极端波动需处理"的描述直接矛盾。这是本卡最有价值的样本，属**原文数据自相矛盾**而非作者自述局限。
- 29-5 明确自认 `fillna(0)` 不是最优做法，属自述局限。
- 14-3 的补 0、13-3 的剔除 0 值行、10-2-04 的 IQR 剔除均未给清洗效果对照数值。
