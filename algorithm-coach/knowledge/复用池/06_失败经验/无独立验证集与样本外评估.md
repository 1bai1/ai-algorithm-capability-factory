# 无独立验证集与样本外评估

## 错误模式

模型在训练数据上完成训练与"验证"，没有任何时间在后的独立样本外数据。三种典型形态：

1. **训练集直接当验证集**：变量名叫 `val_data`，取值来自 `train_df`。
2. **完全没有切分**：直接在训练 DataFrame 上构造 X/y、训练、报训练损失。
3. **验证/测试口径前后不一致**：标题写"准备训练和验证数据"，实现只有 train/test 二划分。

## 触发场景

- `val_data = train_df` 后 `reset_index(drop=True)` 并称之为"验证数据集"（27-4，27812 条小时级记录）。
- 直接在 `df_train` 上构造 X/y，只有训练 loss 曲线，无 RMSE/MAE，无早停与随机种子（11-4-8）。
- 未给训练/验证/测试的时间划分，只有训练期奖励（8-4-2，训练 10000 步）。
- 全部指标来自训练期，无独立测试期（9-5：总资产翻 4~5 倍被质疑是过拟合环境的产物）。
- 环境构建时把交易集的 `data_split` 行注释掉，只演示训练集（9-4）。
- 正文标题写"验证数据"，实际只做 train/test 二划分，验证集口径前后不一致（31-4）。
- 未说明切分与验证方式（13-1）；无样本外验证说明（11-4-6）；纯概述篇的性能宣称未经证实（15-1、31-1）。
- 基准策略结论来自无摩擦假设且为**样本内**结果（3-4-01）。

## 如何识别

1. 全局搜索 `val` / `valid` / `test` 变量定义：只要出现 `= train`、`= df_train`、`= train_df`，立即判为无验证集。
2. 检查是否存在三段（train/validation/test）且时间不重叠；只有两段又同时用于调参与评估的必然有问题。
3. 检查报告的指标类型：只有 loss、reward、训练集 MSE/R² 的，一律视为未经样本外验证。
4. 检查 DataFrame 切分语句是否被注释掉（9-4 的原型）。
5. 检查文档描述的切分与代码实际切分是否一致（31-4 的标题 vs 实现）。

## 后果

- 无法评估过拟合：27-4 原文自认"没有样本外数据，无法评估过拟合"，却仍称之为"验证数据集"。
- 训练期指标被误当作策略有效性证据：8-4-2 的训练期奖励、9-5 的训练期总资产翻 4~5 倍、11-4-8 的 loss 0.0095 都不能支撑任何有效性结论。
- 策略在样本外失效时无预警机制，且失效原因无从归因。

## 修复规则

1. **三段硬隔离**：train / validation / test 按时间先后切分，互不重叠；测试段在最后一次评估前不得被任何代码路径读取。
2. **命名即约定**：变量名必须反映数据来源，禁止把训练集赋给带 `val`/`test` 前缀的变量。
3. **无样本外数据就不下结论**：只报"训练期指标"时必须显式声明，禁止使用"策略有效""表现良好"等表述。
4. **RL 场景同样适用**：环境回测段必须是训练段之后的时间窗（9-4 注释掉 `data_split` 是典型反例）；报告累计收益、夏普、换手等指标而非仅 reward。
5. **单次留出不等于验证**：仅用末尾 N 条做一次留出测试方差不可知（参见"过拟合与结果不稳定"卡），应配滚动或多折时序验证。

## 验证状态

- 27-4：明确给出 `val_data = train_df`、`val_data.reset_index(drop=True)` 与数据规模（27812 条、18 列、起点 2020-08-17 04:00），属**代码级自证错误**，原文却称之为验证数据集。
- 11-4-8：明确给出训练代码（`X_train = training_set[0:len(training_set)-1]`，无切分），loss 从 0.2960 降到 0.0095，属自证无样本外。
- 9-4：`data_split` 行被注释，本篇无训练、无回测、无绩效数字。
- 8-4-2、9-5、13-1、11-4-6、15-1、31-1、3-4-01：均为文本级缺失（未给切分或未做样本外），无对照数值。
