# 模型假设与适用边界失效

## 错误模式

模型在假设不成立的数据上被使用，且没有任何检验环节拦截。分为四类：

1. **分布假设不成立**：GARCH 假设波动率对称、无法捕捉杠杆效应，对极端事件预测有限，应改用 EGARCH/TGARCH（1-2-5 原文自述）；ARIMA 的残差非正态、厚尾且异方差，高斯假设不成立，理应改用 GARCH 类或稳健方法（29-5-03）。
2. **线性与平稳性假设不成立**：ARMA/AR 的线性假设 + 平稳性依赖是硬边界，结构性突变（政策、涨跌停）下易失效（1-2-3、1-2-2）；VAR 无法刻画非线性与非对称传导（1-2-6）。
3. **模型名与实现不符**：名为 ARCH 实为单层线性回归，没有条件方差方程，模型输出不具备波动率的物理含义（5-3）。
4. **独立性假设被忽略**：假设各贷款违约时间独立，未建模违约相关性，会系统性低估组合尾部风险（5-4-2）。

配套的两类过程性错误：**阶数/状态数人工指定**（季节周期 s=22 人工指定、HMM 状态数取 3 未见 BIC/AIC、ACF/PACF 靠肉眼判断截断且 lags 只取 5）与**诊断与处理自相矛盾**（ADF 在 5% 水平已判定对数价格平稳，却仍继续做去滚动均值处理；对已去均值序列再做 5 阶差分属过度差分）。

## 触发场景

- 用 GARCH(1,1) 做波动率预测与 VaR，但不检验杠杆效应（1-2-5）。
- 用 ARIMA 拟合收益率并外推，残差诊断显示非正态、厚尾、异方差后仍继续沿用高斯区间（29-5-03）。
- 对股票**价格**做 365 天季节分解（价格通常无稳定年度季节性，假设过强）（29-5-01）。
- 季节性模式失效时无自适应或再训练机制（1-2-4）。
- 单变量、线性、无外部变量的模型面对结构性突变（4-2-02）。
- 用 MSE 拟合收益率本身来充当"波动率模型"（5-3）。
- 组合风险模型中忽略违约相关性（5-4-2）。
- HMM 状态语义属人工事后解释，状态划分在 500 天小样本 + 非凸优化下可能不稳定（28-4）。

## 如何识别

1. **诊断清单化**：平稳性（ADF）、白噪声、残差自相关（Ljung-Box）、正态性（Jarque-Bera）、异方差、偏度与峰度——29-5-03 的残差诊断清单可直接作为模型验收项。任一不通过就要换模型族或换稳健方法。
2. **诊断结论与处理动作是否一致**：ADF 已判平稳就不要再去趋势/差分；差分阶数不是越高越好（4-2-02 的 d=5 属过度差分）。
3. **阶数是否有模型选择依据**：p/q 用 AIC/BIC，季节周期用检验而非人工指定，HMM 状态数用 BIC/AIC 或稳定性检验。
4. **模型名与方程是否一致**：叫 ARCH/GARCH 就必须有条件方差方程；检查是否只有 `nn.Linear` 或 OLS。
5. **独立性假设是否被检验**：组合风险模型必须检查违约相关性/共同因子结构。
6. **ACF/PACF 判断是否可靠**：`lags=5` 可能漏掉更高阶结构，肉眼判断截断主观性强（29-5-02）。

## 后果

- 风险度量失真：对称波动率假设下 VaR 对极端负收益的覆盖不足；忽略违约相关性会系统性低估组合尾部风险。
- 预测区间不可用：残差正态假设不适配时，区间下界会越出非负边界（11-4-7 的 −2914 ~ −3112）。
- 过度差分放大噪声，使模型拟合"看起来更好"但预测更差。
- 用错误的模型名承载错误的方法：5-3 的 1e-16 损失被当作拟合极好，实际是恒等映射。

## 修复规则

1. **建模前做准入检验，建模后做残差诊断**，把检验结果写进报告；不通过则不进入下一步。
2. **假设不成立就换族**：GARCH → EGARCH/TGARCH（捕捉杠杆效应）；高斯 ARIMA → GARCH 类或稳健方法；线性模型 → 非线性/树/状态切换模型；截面分类模型 → 时序模型（另见"时序任务使用随机切分与随机K折"卡）。
3. **阶数与状态数用准则定**：AIC/BIC、信息准则或滚动稳定性检验，禁止人工指定后不做敏感性分析。
4. **差分最小化**：以平稳性检验通过为上限，不做多重差分；差分后必须复检平稳性并说明最终建模对象是原序列还是差分序列（1-2-2 的悬置问题）。
5. **非负量的模型要用适配的分布/变换**：价格、波动率等非负量的区间估计不得使用对称正态假设（11-4-7）。
6. **命名与方程一致**：模型名必须反映实际估计的方程；用 MSE 拟合收益率不得称为波动率模型。
7. **组合风险补相关结构**：显式建模违约相关性或共同因子（5-4-2）。
8. **声明边界并做分区间稳健性检验**：单一样本区间的结论不得外推；含 2018 熊市、2020 疫情等结构变化的数据应分区间复核（1-2-6）。

## 验证状态

- 1-2-5：原文自述"假设波动率对称、无法捕捉杠杆效应，对极端事件预测有限，应改用 EGARCH/TGARCH"；样本为贵州茅台 2020-01-03 至 2023-09-01 共 890 条（训练 712 条），以收益绝对值作波动率代理本身含噪，两模型 RMSE 接近时结论不稳健。
- 1-2-3：常数项系数 0.0006、p=0.437 不显著，模型对收益率均值几乎没有解释力；除 AIC 矛盾外，单次 8:2 划分无滚动重估。
- 1-2-6：原文完全没有给出预测精度的量化评价（无 MAE/MAPE、方向准确率），也没有滚动样本外验证；1564 条记录跨 6 年含结构变化，单一全样本 VAR 未做分区间稳健性检验。
- 4-2-02：ADF P=0.0238 已判平稳仍做去滚动均值处理，且对已去均值序列再做 5 阶差分（d=5）属过度差分；summary 与代码模型标注不一致。
- 29-5-03：Jarque-Bera=9485.55（p=0.00，非正态）、异方差检验显著、偏度 0.10、峰度 10.67（尖峰厚尾），ARIMA 的高斯假设不成立。
- 29-5-01：对股票价格做 365 天季节分解的假设较强；未给出 p/d/q 定阶与精度。
- 29-5-02：ACF/PACF 靠肉眼判断截断，lags 只取 5 可能漏掉更高阶结构；对 MA(q) 的表述不严谨。
- 1-2-4：s=22 为人工指定而非检验得出；AIC 网格搜索范围未给出；标题标注"复制不成功"。
- 5-3：名为 ARCH 实为单层线性回归，无条件方差方程；损失 1e-16 意味着线性输出与目标几乎完全重合。
- 5-4-2：全部为合成数据，EL/VaR 数值本身无实际参考价值；假设各贷款违约时间独立，未建模违约相关性，会系统性低估组合尾部风险（原文虽声称考虑了相关性，示例代码中未见相关结构）。
- 28-4：500 天小样本 + 非凸优化下状态划分可能不稳定，未做滚动/样本外重估；状态语义属人工事后解释。
- 1-2-2：示例 ADF 未通过 0.05 阈值，差分后是否再次平稳、最终用于建模的是原序列还是差分序列，原文未交代。
