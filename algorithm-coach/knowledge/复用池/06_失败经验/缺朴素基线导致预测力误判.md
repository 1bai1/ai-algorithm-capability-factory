# 缺朴素基线导致预测力误判

## 错误模式

只报绝对误差或拟合优度，不与"上一期值""历史均值"等朴素预测对比，导致**退化模型**（输出均值、复制上一期）被当作有效模型。最典型的三类误判：

1. **低 MSE = 模型好**：日收益率近似白噪声，模型退化为输出均值，"预测值接近零 + MSE 很低"被解读为"表现良好"。
2. **损失趋零 = 拟合好**：损失降到 1e-16 被当作拟合极好的证据，实际是线性输出与目标近乎恒等映射。
3. **高 R² = 有预测力**：R² 0.95 拟合的是**价格水平**，来自价格序列的强自相关，与收益率层面的预测力无关。

## 触发场景

- 单特征（仅前一日收益率）预测日收益率，用 MLP 输出接近零的值（8-2）。
- 用 MSE 拟合收益率本身却宣称在预测波动率（5-3）。
- LSTM 用"前一日价格预测当日价格、时间步长 1"，loss 收敛到 0.0095（11-4-8）。
- 单变量价格预测报测试 R² ≈ 0.95（15-6）、0.9457（15-7）；只报 MSE 0.003459（29-6-02）。
- 用末尾 60/90 天做一次性样本外检验但不给基线对照（13-4、14-4）。
- 加了 35 个特征但预测增益未验证（12-3）；ARIMA 只有检验与分解，效果无法评估（29-5-01）。

## 如何识别

1. **查报告里有没有这三条线**：随机游走（预测值 = 上一期值）、历史均值（恒定预测）、以及至少一个线性基线。缺任何一条，绝对误差都不可解读。
2. **看评价对象是价格还是收益率**：价格水平上的 R²/RMSE 会被趋势主导，必须追问"在收益率上表现如何"。
3. **看模型输出是否退化为常数或上一期值**：把预测序列与实际序列画在一起，若预测几乎是实际序列的平移，即为复制上一期。
4. **看损失量级是否可疑**：训练损失趋近 0、MSE 远低于同量级序列的方差，先怀疑退化或泄漏。
5. **追问特征增益**：加特征前后的对照实验是否在同一模型、同一切分、同一随机种子下完成（29-5 的 67.83% → 85.28% 未说明是否同超参与同种子，属不可比）。

## 后果

- 无预测力的模型被判定可用，后续策略收益完全无支撑（8-2、5-3、15-7）。
- 计算资源与工程投入被浪费在不断堆叠模型上，而问题在标签与评价口径。
- 12-3 的 35 个特征预测增益从未验证，特征工程投入的收益无法归因。

## 修复规则

1. **任何时序预测必须并列朴素基线**：随机游走（`shift(1)`）与历史均值两条线至少各一条；15-11 的 MASE 定义（测试集 MAE ÷ 训练集一阶差分 MAE）可直接作为门槛指标，**MASE < 1 才说明模型有价值**。
2. **收益率层面评估**：价格预测须额外报告收益率上的方向准确率或 IC，避免被价格自相关虚高的 R² 误导。
3. **加特征必须做同条件对照**：固定模型、切分、超参与随机种子，只替换特征集，才能把指标变化归因于特征（29-5 的做法值得照搬）。
4. **损失异常低时先排查**：检查是否输出退化为常数、是否泄漏、是否标签与特征同源。
5. **报误差必须带量纲与基线差值**，形如"MAE 8.96，朴素基线 MAE 12.3"。

## 验证状态

- 8-2：只输入前一日单一收益率，测试集 MSE 很低但"未来回报预测接近零"，原文据此判断"模型表现良好"——属**结论与数据不符**，是最值钱的样本。
- 5-3：单层线性模型损失降到约 1e-16，原文把它当作拟合极好的证据；加入大盘指数特征后损失扩大到 2046 量级，原文归因为"加入该特征无益"，实为指数量纲未标准化。
- 11-4-8：loss 从 0.2960 降到 0.0095，未做反归一化与真实价格对比，未与朴素基线比较。
- 15-6：测试 R² ≈ 0.952（训练 0.988）；15-7：训练解释方差 0.9850 / 测试 0.9457。
- 29-6-02：只报 MSE 0.003459，未给 RMSE、方向准确率或朴素基准；13-4 未给 MAE/RMSE 数值。
- 14-4：MAE 8.96 未与"沿用上一期价格"基线对比；12-3：训练仅 465 周，35 个特征的增益未验证。
- 15-11 给出正面范式：`base = Close.shift()` 朴素基线 + MASE < 1 的判据（但原文的 base 列后文未见参与最终对比）。
