# 过拟合与结果不稳定

## 错误模式

模型在训练数据上表现完美，在样本外崩塌；或同一方法在不同折/不同随机种子/不同训练预算下结论剧烈波动，使模型比较与参数选择失去意义。识别信号不是"过拟合"这个词，而是**训练-验证差距 + 折间方差 + 比较条件不对等**三件事。

## 触发场景

- **训练-验证差距极大**：训练准确率 0.9996 而验证约 0.97，10 轮内即饱和，无早停/正则/dropout（30-6）；训练准确率 1.0（3-2 的 CART/RF、30-5）。
- **样本外直接崩塌**：训练集 CORR 0.594 / R² 0.290，测试集 CORR −0.213 / R² −1.358，连均值预测都不如（11-4-5）。
- **特征数远超样本承载力**：35 个特征对 465 周训练样本，无任何特征选择步骤（12-3）。
- **比较条件不对等**：五种算法训练步数不统一（30k~80k）、未做同预算调优、无随机种子与重复实验，Sharpe 0.80~0.835 的差异不具统计显著性（9-5）；XGBoost 用 `learning_rate=0.3` 且未调参，与其他模型比较不公平（15-6）。
- **单次评估上的微小差异被当作结论**：0.51 vs 0.53 来自单次留出集（31-6）；单次试验分数在 0.47~0.55 间波动（31-7）。
- **折间方差巨大**：三折 MAPE 分别 116.93 / 34.5 / 28.96（11-4-4）。
- **优化过程本身不稳定**：未用解析梯度、依赖多次随机初值，存在陷入局部最优的风险（3-4-02）；HMM 状态数取 3 是人工设定，未见 BIC/AIC 检验。
- **对输入估计误差极敏感**：均值-方差优化未做收缩估计、重采样稳健性检验（8-5-6）。
- **1000 次"模拟"未说明随机性来源**（ARIMA 与规则逻辑均为确定性），分布图的统计意义存疑（15-12）。
- **高维状态空间**：28×28 协方差矩阵高维展开，易过拟合，未做降维与敏感性分析（9-4）。
- **小样本上的完美指标**：每类只有 50 条评估样本（5-3-02）；96 维平均向量上树模型明显过拟合（30-4）。

## 如何识别

1. **算训练-验证差距**：把 train 与 validation/test 指标并列。差距本身比绝对值更重要（30-6 的 0.9996 vs 0.97）。
2. **看折间方差而非均值**：交叉验证必须按折报告并关注折间方差，而不只看排名（11-4-4 的明确结论）。
3. **检查样本量/特征数比**：特征数是样本数的量级以上时先降维。
4. **检查比较是否同预算**：训练步数、调参预算、随机种子、评估切分是否一致；不一致则模型排序无效。
5. **检查正则与早停开关**：`Dropout` 是否真的启用（15-7 导入但未使用）、是否配 `EarlyStopping(restore_best_weights=True)`、是否有 `random_state`。
6. **看优化器的收敛证据**：是否报告收敛性检查；RL 场景看 reward 是否随训练变化（8-3 中 Episode 10 与 Episode 20 的 Reward 完全相同 6673009.12，训练是否真正更新策略存疑）。
7. **看重复实验**：单次留出、单次随机初始化的结论一律降级。

## 后果

- 模型选择结论不可靠：9-5 的 Sharpe 差异、31-6 的 0.51 vs 0.53 都在噪声内；31-8-01 的 AUC/accuracy 矛盾无法裁决。
- 样本外崩塌无预警：11-4-5 的 R² = −1.358 说明模型在样本外不如均值预测，而训练期指标完全掩盖了这一点。
- 特征工程投入无法归因：12-3 的 35 个特征从未验证增益。
- 参数优化产物不可用：3-4-02 的局部最优风险 + 人工指定状态数使状态划分可能不稳定。

## 修复规则

1. **正则与早停必须显式配置**：`EarlyStopping(monitor='val_loss', patience=15, restore_best_weights=True)` + `ReduceLROnPlateau(factor=0.5, patience=5, min_lr=1e-6)`（1-2-7 给出的可复用组合）；Dropout 必须真的加在层间而不是只 import。
2. **固定随机种子并重复实验**：报均值与标准差，而非单次数值。
3. **同预算比较**：模型对比前统一训练步数、调参预算与评估切分；不统一则声明不可比。
4. **特征数与样本量匹配**：先做特征选择/降维，再用 `permutation_importance` 或增益对照验证特征价值。
5. **交叉验证按折报告**：给出每折分数、折间标准差、每折拟合/评分耗时；折间方差大时按市场状态/时间段分段评估（11-4-4）。
6. **输入估计误差的稳健化**：组合优化至少做收缩估计或重采样检验，并报告参数敏感性。
7. **优化失败的诊断**：使用解析梯度或多起点重启，并对收敛性做显式检查；对确定性流程不宣称"模拟分布"。
8. **RL 训练必须留独立测试期**（9-5），并把累计收益、夏普、换手与回撤作为验收指标。

## 验证状态

- 30-6：训练准确率 0.9996、验证约 0.97，10 轮内即饱和，原文未做早停、正则或 dropout 的讨论。
- 11-4-5：训练 CORR 0.594 / R² 0.290 / RMSE 2868 / MAE 2218 / MAPE 66.15；测试 CORR −0.213 / R² −1.358 / RMSE 25532 / MAE 19314 / MAPE 54.91——样本外连均值预测都不如。
- 9-5：训练步数 30k~80k 不统一；Sharpe 0.80~0.835；无随机种子与重复实验说明；总资产翻 4~5 倍若来自训练期极可能是过拟合环境的产物。
- 31-6：5 个模型 AUC 0.51~0.53，单次留出集。
- 31-7：1000 次 Optuna 试验，单次试验分数在约 0.47~0.55 波动。
- 11-4-4：mean_test_MAPE = 60.13，三折 116.93 / 34.5 / 28.96；mean_train_MAPE = 73.62（train 反而高于 test，说明整体精度不足而非过拟合）。
- 12-3：35 个特征 vs 训练 465 周；早期 Volume 为 0 使量价特征失真。
- 3-2：示例数据集为虚构或极小样本，MSE≈1.93 与准确率 1.0 无实际参考价值，原文亦承认过拟合。
- 30-5、30-4、5-3-02、15-12、8-5-6、9-4、3-4-02：均有明确的过程性证据但无对照数值。
