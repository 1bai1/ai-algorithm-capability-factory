# 行情降采样与频率统一

## 能力说明
把高频行情（1 分钟）聚合到日频，或把不同来源的序列统一到同一采样频率（日/周），供建模使用。解决"数据频率与分析目标不匹配"和"不同源频率不一致无法合并"的问题。

## 输入契约
- 分钟级原始数据：时间戳列（Unix 秒，字段名 `Timestamp`）+ 价格列（`Weighted_Price` 加权平均价、OHLC、双币种成交量）。无成交的时间戳对应字段为 NaN。
- 可用的真实数据集规格：
  - Bitstamp 1 分钟，2012-01-01 至 2021-03-31（BTC/USD）。
  - coinbaseUSD 1 分钟，2014-12-01 至 2019-01-09；bitstampUSD 1 分钟，2012-01-01 至 2019-03-13。
- 日/周频原始数据：Date + OHLCV（含 Adj Close），如 BTC-USD 日线 2587 条（2015-01-01 起）。
- 聚合前需自行确保时间戳可解析、缺失与零成交时段有处理方案——原文多篇直接聚合、未处理。

## 输出契约
- 日频价格序列：按自然日分组后的标量序列（列名可自定义，原文为 `Price` / `Close`），日期为索引；示例把 2012-2021 的分钟数据压成日频后只保留 2017 年及以后。
- 完整自然日序列：按日期逐一推进、缺值填 NaN，得到等间隔日序列（示例 2014-12-01 至 2019-01-07 每一天一个价格值）。
- 截取后的日频区间示例：2020-01-01 至 2022-01-30 共 761 行，且行数与区间日历天数一致（说明无日期缺口）。
- 周频数据示例：CME 活牛期货周线每行代表一周（2002-03-04 至 2023-05-29，1104 行）。
- 聚合的固有损失：日频值抹平日内信息，不适合日内/高频策略。

## 调用方式
```python
# Unix 秒 → 日期 → 按日聚合（用加权均价，弱化单笔异常成交）
df['date'] = pd.to_datetime(df['Timestamp'], unit='s').dt.date
price = df.groupby('date')['Weighted_Price'].mean().to_frame().reset_index()
price = price[price['date'] >= '2017-01-01']        # 时间窗过滤
price = price.set_index('date')

# 已索引序列的时间窗截取（含缺口体检）
BTC = BTC_data.set_index('Date', drop=True)         # 或 pd.to_datetime 后设索引
sub = BTC[BTC.index >= '2020-01-01']                # 761 行
```
必要前后处理：聚合后先画价格走势图或对照"行数 vs 日历天数"检查缺口；`info()` 看 dtype 与非空计数；把窗口起点显式记录为参数（原文多处起点给得很随意）。

## 关键参数
| 参数 | 含义 | 原文取值 |
| --- | --- | --- |
| 聚合函数 | 日价格代表值 | `mean()`（对 `Weighted_Price`） |
| 时间窗起点 | 过滤条件 | ≥2017-01-01（未说明理由）；≥2020-01-01（761 行） |
| 预测步长 | 下游用 | `prediction_days = 50`（仅记录，非本卡参数） |
| `unit` | 时间戳解析 | `'s'`（Unix 秒） |
| 频率分层 | 概念参照 | tick/微秒、分钟/小时、日、周月季（宏观低频需对接到日频后再入模） |

## 依赖
pandas（`to_datetime` / `groupby` / `set_index` / 布尔切片）；numpy；datetime（手工构造等间隔日期时）。

## 适用条件
- 手上有分钟级原始数据、建模目标是日频或更长周期时。
- 需要构造等间隔、无缺口的时间轴（缺失日显式留 NaN）以便差分、插值、自相关计算时。
- 需要把周/月频宏观指标对接到日频个股面板作外生变量时（原文只给原则，未给实现）。
- 单标的或少量标的（原文明细均为单标的：BTC、活牛期货）。

## 不适用条件
- 日内/高频策略：日均价会把日内路径与波动全部抹掉，不能用来做日内择时或盘口类研究。
- A 股场景直接套用自然日推进：A 股有交易日历与停牌，按自然日补 NaN 会产生大量假缺口，必须改用交易日历。
- 零成交时段多的标的：直接 `mean()` 不作零成交/停牌标记，会把"无交易"静默等同为"有价格"。
- 需要跨源频率对齐后又做时序建模时：低频变量上采样到日频会引入前视偏差（原文未给处理方法，属需另行解决的环节）。
- 起点被无理由截断的样本：原文多篇只保留 2017 年后或 2020 年后数据且未给依据，若照搬会把样本压到 761 天量级，深度模型会欠样本。

已验证（有真实运行结果）：
- Bitstamp 1 分钟（2012-01-01~2021-03-31）成功聚合为日频序列，并只保留 2017 年及以后。
- 2014-12-01 至 2019-01-07 的逐日 BTC 价格序列构造成功，缺失日以 NaN 表示后完成补缺并绘图核对。
- 2020-01-01 至 2022-01-30 截取后 761 行，行数与区间日历天数一致（据此判定无日期缺口）。
- 原文未给出聚合前后统计对比（如日内波动损失量级），也未给零成交时段处理结果。
