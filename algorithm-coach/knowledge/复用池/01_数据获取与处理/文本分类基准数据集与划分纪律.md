# 文本分类基准数据集与划分纪律

## 能力说明

提供文本分类常用基准数据集的规模、类数、标准划分与取数纪律，使不同方法的数字有共同的比较地基。核心规则是：用数据集的标准划分与标准类数，不做让任务变简单的额外预处理，测试样本在测试前不可见（归纳式设置）。

## 输入契约

- 目标任务类别：单标签 / 多标签 / 层级分类，以及语种与文本长度量级。
- 数据集的原始语料与其官方（或文献公认）划分，含类数、每类样本数与标签层级信息。

## 输出契约

- 一份数据说明：数据集名、样本总量、训练/测试条数、类数、平均文本长度（或标签数/篇）。
- 明确的划分文件与预处理脚本，且预处理只对训练集拟合、对测试集只做变换。
- 若使用非标准划分或修改类数，必须在结果表中标注为不可比。

## 调用方式

1. 按任务类型从基准清单选数据集（见关键参数）。
2. 对每个数据集取文献标准划分；无默认划分的（如多标签部分数据集）沿用原论文或公认来源的划分并在报告中注明。
3. 核查类数是否被改动、是否做过使任务更简单的预处理（去类名关键词、截断等）。
4. 保持归纳式：测试文档不参与训练，也不参与任何需要全量语料的预处理（如构图、词表统计）。
5. 层级数据集注意标签集包含从叶到根的路径标签。

## 关键参数

- 单标签基准（总量 / 训练 / 测试 / 类数 / 平均长度）：20ng 18,846 / 11,314 / 7,532 / 20 / 551；R8 7,674 / 5,485 / 2,189 / 8 / 119；R52 9,100 / 6,532 / 2,568 / 52 / 126；ohsumed 7,400 / 3,357 / 4,043 / 23 / 285；MR 10,662 / 7,108 / 3,554 / 2 / 25。
- 多标签 / 层级基准（总量 / 训练 / 测试 / 类数 / 标签数每篇）：R21578 10,788 / 7,769 / 3,019 / 90 / 1.24；RCV1-V2 804,414 / 23,149 / 781,265 / 103 / 3.24；EconBiz 1,064,634 / 994,015 / 70,619 / 5,661 / 4.36；GoEmotions 48,837 / 43,410 / 5,427 / 28 / 1.18；Amazon-531 49,145 / 29,487 / 19,658 / 531 / 2.93；DBPedia-298 245,832 / 196,665 / 49,197 / 298 / 3.00；NYT AC 36,471 / 29,179 / 7,292 / 166 / 7.59；WOS 46,985 / 37,588 / 9,397 / 141 / 2.00。
- 分布漂移场景常用语料（总量 / 类数）：AG News 127k / 4；DBPedia 630k / 14；20 Newsgroup 18k / 20；Yahoo! Answers 1.4m / 10；SST-2 69k / 2；IMDb 50k / 2；Amazon Product Reviews 50k / 50；TMNtitle 32.6k / 7；R21578title 10.8k / 90。
- 划分来源纪律：R21578 用 NLTK 划分；RCV1-V2 用 Lewis 等的划分；EconBiz 用作者提供的划分并与之对齐；GoEmotions 用原论文划分；Amazon-531/DBPedia-298 用 TaxoClass 的划分；NYT AC 用 HiAGM 的训练-验证-测试划分。

## 依赖

- 数据集获取入口：20ng（bydate 版）、ohsumed、MR（Cornell 影评数据）、R8/R52/R21578、GoEmotions、WOS/NYT AC/Amazon-531/DBPedia-298 各自的官方或论文配套仓库。
- 无框架依赖；本卡是取数与切分环节的约束，不涉及建模代码。

## 适用条件

- 任何要与公开结果对比、或要在多个方法间横向比较的文本分类任务。
- 需要用文献数字做选型参照（如"BERT 在该数据集上大概多少分"）时。
- 需要在标准语料上改造出分布漂移/开放集评测集时（见 不适用条件 的说明与相关边）。

## 不适用条件

- 自有业务语料且无公开基准时，本卡的清单不适用，只能借它的纪律（固定划分、不动类数、测试不可见）。
- 语料为中文等非英文场景时，本卡列出的英文基准不可直接当参照，需另找对应语料的基准。
- 需要开放集/零样本评测时，不能直接用这些数据集的原划分，必须按漂移场景重新预留未知类（见相关边指向的框架卡）。

## 验证状态

原文给出真实数字：上表全部规模、划分与类数均来自综述整理的原始统计（含标准差版原文），是"各文献在标准划分下报告结果"这一纪律的事实基础；漂移综述附录另给出漂移场景常用语料及其适用设定标记。
