# 数据质量体检与缺失值处理

## 能力说明
在建模前对行情/表格数据做体检（结构、类型、缺失规模、重复），并按数据性质选择填充策略（价格类前向填充、指标类均值/中位数、收益率补 0、时序插值、局部平均）。解决"缺失值静默传播到特征与模型"的问题。

## 输入契约
- 数据形态两大类：
  - 时序行情：Date + OHLCV（含 Adj Close/adjcp），日期可能是 object 需转 datetime；分钟级数据无成交的时间戳字段本身为 NaN。
  - 静态表格（信贷/财务）：数值列与类别列混合，缺失按列统计（示例逐列计数：Gender 13、Married 3、Dependents 15、Self_Employed 32、LoanAmount 22）。
- 体检调用要求：至少 `shape`、`head()/tail()`、`info()`、`describe()`、`isna().sum()`；表格数据加 `value_counts(dropna=False)` 与缺失可视化。
- 处理前必须先量化缺失规模，再决定填充还是删除；原文明确反对"直接 dropna"。
- 若用 sklearn 的填充/缩放器，必须先 `fit` 训练集、再 `transform` 测试集。

## 输出契约
- 体检输出：各列缺失计数、dtype、非空计数、分布摘要；时序数据还要做"行数 vs 日历天数"对照来判断缺口。
- 填充输出分文件落盘：删除路线产出 `cleaned_*.csv`，填充路线产出 `filled_*.csv`，用箱线图前后对比。
- 分类型填充规则（原文口径）：价格类 → 前向填充；指标类 → 均值填充；收益率 → 补 0；表格类别列 → 众数，数值列 → 均值/中位数。
- 时序插值输出：`interpolate(axis=0)` 或"前值+后值取半"的局部平均，尾部无后续值时退化为前向填充。
- 处理完后必须画序列图核对连续性（原文以此为收尾）。

## 调用方式
```python
# 体检
df.info(); df.describe(); df.isna().sum()
df.isnull().sum()                      # 表格型逐列计数 + missingno 条形图

# 按列类型填充（表格）
df['Gender'] = df['Gender'].fillna(df['Gender'].mode()[0])
df['LoanAmount'] = df['LoanAmount'].fillna(df['LoanAmount'].mean())

# 时序价格：双向填充（无方向信息时）
df = df.sort_values('Date'); df = df.ffill().bfill()

# 时序价格：局部平均插值（手工实现）
# 缺失日 = 0.5 * (前一个有效值 + 后一个有效值)，尾部退化为前向填充

# 管道化（GreyKite 口径）
# ColumnSelector(ts) / ColumnSelector(y) → ZscoreOutlierTransformer → NullTransformer(impute_algorithm='interpolate', axis=0)

# sklearn 填充的边界
imputer = Imputer(strategy='median').fit(X_train)     # 只在训练集 fit
X_test = imputer.transform(X_test)
```
注意：多标的行情必须按标的分别填充，不能对整列取全局统计量（原文的错误示范见下）。

## 关键参数
| 参数 | 含义 | 原文取值 |
| --- | --- | --- |
| `strategy` | sklearn 填充策略 | `'median'`（中位数） |
| 填充方式 | 表格 | 类别列众数、数值列均值 |
| 填充方式 | 时序价格 | 前向填充 / 双向 ffill+bfill / 局部平均 0.5*(前+后) |
| 填充方式 | 分类型规则 | 价格前向填充、指标均值填充、收益率补 0 |
| 插值方法 | GreyKite | `impute_algorithm='interpolate'`，`axis=0` |
| 缺失计数阈值 | 决定删除/填充 | 原文未给出（只说"先量化再决定"） |
| 缺失率上限 | — | 原文未给出 |

## 依赖
pandas（`fillna` / `ffill` / `bfill` / `interpolate` / `isna`）；numpy（`np.nan`、`np.isnan`）；sklearn（`Imputer` / `MinMaxScaler`）；missingno（缺失可视化，可选）；GreyKite（管道化场景）。

## 适用条件
- 行情时序存在零散缺口（交易所停机、采集失败、无成交时段）时，用前向填充或局部平均保持序列连续。
- 表格型金融数据（信贷、财务）分列类型做众数/均值/中位数填充。
- 需要把缺失处理注册进建模管道（Pipeline）时，可用 NullTransformer 式的独立环节。
- 入模前明确要求无空值的模型（孤立森林、DBSCAN、距离类算法）时的兜底填充。

## 不适用条件
- A 股停牌缺口：不行简单插值——停牌本身携信息且复牌常跳空，应前向填充并加"停牌"标记。
- 连续多日缺失：局部平均会生成一段人造平滑价格，直接扭曲波动率与收益率分布，使后续波动建模失真。
- 多标的行情整列填充：按列全表均值而不按标的代码分组，会把 A 股的价位填到 B 股上（原文示例中 AAPL、TSLA 开盘价被填成 1066.48）。
- 财务字段：把缺失兜底置 0 会混淆"未披露"与"真为 0"，污染信号。
- 缺失非随机（如停牌、退市、极端行情）时：任何均值/插值都低估方差与尾部风险。
- 需要保留缺失信息的场景（缺失本身是特征）：先补值再入模会丢掉这个信息。

## 验证状态
有缺陷——本卡记录的是被原文自身或示例暴露缺陷的做法，按要求纳入"踩坑"口径：
- （3-1）示例填充逻辑错误：未按股票代码分组，AAPL 开盘价、TSLA 开盘价被填成 1066.48 这类跨标的污染值；同一篇的异常值示例输出与原始数据完全一致（处理未生效）。
- （28-2）插值只按时间轴取前后均值，未考虑缺失时长；连续多日缺失会生成人造平滑价格，扭曲波动率与收益率分布。
- （26-5-02）缺失兜底置 0，未区分"真的为 0"与"未披露"。
- （10-2-04）SMOTE 在 train/test 划分前对全量数据过采样，合成样本进入测试集（数据泄漏），与"填充测试集"同类的边界问题。
- 可用的真实数字：信贷数据逐列缺失计数（13/3/15/32/22）；时序数据体检得到"逐列缺失全为 0"并据此跳过清洗（该结论原文亦被批评为"无缺失≠数据可用"）；贵茅日线、BTC 等序列处理后行数完整。
