# 复权口径与复权价选用

## 能力说明
决定价格序列用原始价还是复权价、用哪种复权（A 股前复权 qfq、Yahoo 的 Adj Close、含公司行为字段的 adjClose 族），并保证同一研究里价格口径一致。解决除权除息导致的假跳空、收益率失真与"同一列名不同含义"的混用问题。

## 输入契约
- 数据源需提供复权能力或复权列：
  - A 股（Tushare）：取数时显式传 `adj='qfq'`（前复权），或用 `adjusted_close`。
  - Yahoo/美股：返回列里自带 `Adj Close`；含公司行为的数据集另给 `divCash`（分红现金）与 `splitFactor`（拆股因子）。
  - FinRL 面板：复权列名为 `adjcp`。
- 使用前必须确认：哪一列是复权价、复权基准日是什么、复权方法（前复权/后复权）是什么。原文多篇数据只有一个复权列、未给口径说明。
- 收益率计算要求：相邻两期价格必须同一口径，不能一期原始价、一期复权价。

## 输出契约
- 收益率/累计收益一律以复权价为口径：周收益示例 `np.round(Adj Close.pct_change()*100, 2)`，首行为 NaN；累计收益曲线也以 Adj Close 为基准。
- A 股前复权序列：`pro_bar(..., adj='qfq')` 返回的 close 已是前复权价格，随新的除权事件整体重算。
- 复合口径数据（原始+复权成对）字段：`close/adjClose`、`high/adjHigh`、`low/adjLow`、`open/adjOpen`、`volume/adjVolume`，加上 `divCash`、`splitFactor`，可支持自定义复权。
- 注意事项：原文多处把 Close 与 Adj Close 同时留在表里且未声明收益用哪一个；也有把 `high/low/open` 用原始列、`close` 用 Adj Close 混搭画 K 线的情况。

## 调用方式
```python
# A 股：取数时就要求前复权，而不是取回原始价再自己算
df = ts.pro_bar(ts_code='600519.SH', freq='D', adj='qfq',
                start_date='20200101', end_date='20230901')

# 美股：收益/累计收益统一走 Adj Close
df['returns'] = np.round(df['Adj Close'].pct_change() * 100, 2)
```
工程约定：落盘快照时同时保留原始价与复权价两列并写清口径；跨时间复用同一只股票的前复权历史值时，必须整段重新拉取，不能增量拼接旧序列与新序列。

## 关键参数
| 参数 | 含义 | 原文取值 |
| --- | --- | --- |
| `adj` | Tushare 复权方式 | `'qfq'`（前复权，唯一出现过的取值） |
| 复权列 | 美股/FinRL | `Adj Close`、`adjcp`、`adjusted_close` |
| 公司行为字段 | 分红/拆股 | `divCash`、`splitFactor` |
| 收益率口径 | 复权价 pct_change | 乘 100 后保留两位小数（示例） |
| 复权基准日 | — | 原文未给出（所有来源均未说明） |

## 依赖
pandas；tushare（`pro_bar(adj=...)`）；yfinance（Adj Close 列）。

## 适用条件
- 任何跨除权除息日的价格序列研究：收益率、累计收益、训练标签、回测净值都必须用复权价。
- A 股：`pro_bar` 直接给前复权序列，是最省事的路径。
- 需要自己处理公司行为（分红再投资、拆股调整）时，用 `divCash`/`splitFactor` 或 adjClose 族字段。

## 不适用条件
- 只看单日价格展示、不做跨期比较时，原始价与复权价差别不构成问题（但混用仍会误导）。
- 需要"当时的真实成交价"（如按当日价格撮合、计算涨跌停、下单模拟）时，不能用前复权价——前复权价是按当前时点回算的，历史价格已被改写。
- 需要跨快照严格可比的长历史序列：前复权序列会随新除权事件整体变化，昨天保存的 CSV 和今天拉取的同一段历史不相等。
- 复权口径未知的数据源：原文多篇未说明复权方式，直接用于收益率计算时结论不可追溯，属于不该直接采信的情形。

## 验证状态
原文未给出复权处理的效果验证：没有任何一篇做"用/不用复权价"的收益或模型对比，也没有复权基准日说明。可引用的真实运行数字仅限使用复权列之后的下游结果：AAPL 周频用 Adj Close 计算收益率并统计（Adj Close 跨度 0.10~195.83），以及 Tushare 前复权序列被直接用于 891 条日线落盘等，均与"复权选择本身的效果"无关。故本卡定位为待验证：方法论与字段契约可用，效果未验证。
