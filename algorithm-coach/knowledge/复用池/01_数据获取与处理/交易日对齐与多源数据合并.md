# 交易日对齐与多源数据合并

## 能力说明
把行情表与新闻/指数/无风险利率/财务等多来源数据按日期（必要时再加标的代码）对齐合并，并处理自然日与交易日历的差异。解决"两张表日期对不上、合并后样本被静默删光、或补齐方式把未来信息带进来"的问题。

## 输入契约
- 每张待合并的表都必须有可解析的日期键：行情用交易日期，新闻用发布时间（示例带时分秒），利率/指数用各自频率的日期。
- 日期列可能不是 datetime：示例里有 `Date` 为 object、`trade_date` 为字符串、`pd.to_datetime(df['Date'], format='%m/%d/%Y')` 需要指定格式等情形，合并前必须统一转换。
- 标的键命名需统一：新闻表的 `ticker`（由标题字段抽取、去 `/symbol/` 前缀得到）与行情表的代码列要一致。
- 对齐基准：A 股用交易日历（停牌日同样形成缺口），加密资产按自然日连续采样，美股有自身节假日表；不同市场的日历不能混用。
- 多源合并需先确认各源的价格/量纲口径一致（示例：个股与大盘指数量纲差两个数量级）。

## 输出契约
- 左连接 + dropna 的结果形态：舆情×行情示例合并后保留 `[ticker, headline, date, eventRet, Close]`，共 3142 行 × 5 列、覆盖 12 只股票；`dropna` 天然剔除了休市日与无对应行情的记录。
- 合并前新闻侧原始记录 110,711 条，合并去空后被压到 3142 行——这个删失比例必须在结果里显式记录，不能默认忽略。
- 个股×指数：个股 `trade_date` 改名 `Date` 后与同区间指数、市场成交量按日期合并，得到含市场辅助特征的表。
- 资产×无风险利率：两者各自算收益率后用 `reindex` + `ffill` 对齐日期，得到可做超额收益回归的序列。
- 多标的宽表对齐：`pivot_table(index='date', columns='tic', values='close')` 后，各标的在同一日期网格上，缺失格为 NaN，`pct_change().dropna()` 会按行丢弃。
- 财务类多来源合并：按日期去重后求并集、支持指定必须保留的日期集合，缺失兜底为 `{date: None, value: 0}`（有把"未披露"与"真 0"混淆的风险）。

## 调用方式
```python
# 日期解析 + 索引化
df['Date'] = pd.to_datetime(df['Date'], format='%m/%d/%Y')
df = df.set_index('Date').sort_index()

# 新闻×行情：按 标的+日期 左连接，再去空
merged = news.merge(price, on=['date', 'ticker'], how='left')
merged = merged[['ticker', 'headline', 'date', 'eventRet', 'Close']].dropna()

# 资产×无风险利率：reindex 对齐 + 前向填充
excess = ret.sub(rf.reindex(ret.index).ffill(), axis=0)

# 多标的宽表对齐
px = df.pivot_table(index='date', columns='tic', values='close')
```
必要前后处理：合并前统一日期 dtype；合并后核对行数变化（示例从 11 万条降到 3142 行）；对量纲差异大的辅助列先做标准化再入模，否则损失量级会失控（原文第二模型损失从 1e-16 量级变为 2046 量级，即源于未处理的大盘指数级别）。

## 关键参数
| 参数 | 含义 | 原文取值 |
| --- | --- | --- |
| 连接键 | 舆情×行情 | `date` + `ticker`（左连接） |
| 去空方式 | 合并后 | `dropna()`（保留 5 列） |
| 事件窗口 | 收益标签 | [t, t+1] 两日收益之和（口径需先固定） |
| 对齐填充 | 资产 vs 无风险利率 | `reindex` + `ffill` |
| 日频对齐 | 面板 | `pivot_table(index='date', columns='tic')` |
| 日历类型 | 各标的 | A 股：交易日历（原文未实现，只给原则）；加密：自然日 |
| 合并结果 | 示例规模 | 3142 行 × 5 列 / 12 只股票；110,711 条新闻 |

## 依赖
pandas（`to_datetime` / `merge` / `reindex` / `ffill` / `pivot_table` / `sort_index`）；numpy。

## 适用条件
- 舆情/新闻 + 行情的因子构造（日期+代码双键）。
- 需要给个股模型加入市场层特征（大盘指数、市场成交量）时。
- 需要计算超额收益（资产收益 − 无风险利率）时。
- 多标的横截面/协方差计算前的宽表对齐。

## 不适用条件
- A 股停牌与节假日缺口：原文的对齐逻辑按自然日推进，直接搬到 A 股会造出大量假交易日；应改用交易日历并把缺口显式标记。
- 需要"新闻发布时间落在盘中/盘后"的精细对齐：原文只按日期对齐，未处理时区与盘前盘后，事件研究的精度不够。
- 需要保样本量的任务：合并后 `dropna` 会大幅删失（示例 11 万→3142），若不做删失统计就当成有效样本，会引入严重选择偏差。
- 需要区分"未披露"和"真 0"的财务字段：缺失兜底置 0 会污染信号。
- 低频变量上采样对齐到日频后直接入模：会把未来信息带进当日特征（原文未给处理方法）。
