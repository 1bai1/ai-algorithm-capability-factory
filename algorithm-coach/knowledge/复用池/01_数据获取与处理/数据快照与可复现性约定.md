# 数据快照与可复现性约定

## 能力说明
把"取数—落盘—建模"拆成可重跑的固定链路：原始数据取一次即落盘快照，后续脚本只读本地文件；同时固定随机种子、锁定数据源库版本、记录数据集规格。解决"每次重跑数据都变、结果对不上、环境无法重建"的问题。

## 输入契约
- 数据来源可重复获取（或允许用快照替代取数）：取数脚本与建模脚本分离，取数结果以 CSV 等形式落盘。
- 落盘内容需要的最小元信息：标的、时间区间、行数、字段清单、频率、复权口径。
- 随机性来源需可枚举：数据划分、模型初始化、采样/过采样、超参搜索、随机种子位置。
- 依赖版本需可固定（示例 `yfinance==0.2.3`），凭据通过环境变量注入而非明文。
- 目录约定需事先确定（示例四类：数据、模型、TensorBoard 日志、结果；或 datasets/data/weights 目录创建函数）。

## 输出契约
- 数据快照产物：本地 CSV（示例 `maotai_stock_data.csv` 891 条、`combined.csv` 合并结果、`data_featured.csv`），后续脚本从本地读取，避免每次重新请求。
- 可复现的最小输出集合：固定随机种子 + 固定数据划分 + 版本锁定 + 记录数据区间与字段 + 完整脚本（不依赖图片展示数值）。
- 文件名可用正则清洗日期等非法字符（示例 `re.sub(r'[^\w]', '_', 日期)`），UTF-8 保存。
- 反例的"输出"：无随机种子、无早停、无正则导致结果无法复现；工作路径与文档不一致（`/working` vs `/kaggle/working`）导致环境不可重建；只把关键数值放在图里、脚本不全。

## 调用方式
```python
# 1) 取数脚本（独立文件）：拉一次，立刻落盘
df = pro.daily(ts_code='600519.SH', start_date='20200101', end_date='20230901')
df.to_csv('maotai_stock_data.csv', index=False)

# 2) 建模脚本：只读快照，日期解析 + 排序 + 字段校验后再用
df = pd.read_csv('maotai_stock_data.csv')

# 3) 随机性固定（示例值仅供参考，需全脚本一致）
seed = 111          # 或 123 / 21 / 42 / 23 / 32 / 0，随机状态与 np/random 同步固定
train_test_split(X, y, test_size=0.2, random_state=0)
SMOTE(random_state=42).fit_resample(X_train, y_train)   # 只对训练集

# 4) 目录初始化
check_and_make_directories([config.DATA_DIR, config.MODEL_DIR, config.TENSORBOARD_DIR, config.RESULT_DIR])
```
必要前后处理：固定种子必须覆盖全流程（划分、模型、采样、超参搜索），只固定其中一处等于没固定；快照落盘后记录区间与行数，重跑时用行数/首尾日期核对是否为同一份数据。

## 关键参数
| 参数 | 含义 | 原文取值 |
| --- | --- | --- |
| 随机种子 | 可复现开关 | seed=123（31-1）、random_state=42（12-5，全部随机过程）、random_state=0（10-2-04）、random.seed(21)（14-3）、seed(111)（14-4/14-5）、random_state=23（11-3-07）、random_state=32（10-3-05-01，分层 9:1） |
| 版本锁定 | 数据源库 | `yfinance==0.2.3` |
| 目录清单 | 工程约定 | 数据/模型/TensorBoard/结果四类目录 |
| 落盘格式 | 快照 | CSV（`index=False`），UTF-8 |
| 凭据 | token/代理 | 必须环境变量注入（原文多处硬编码，属反例） |

## 依赖
pandas（`read_csv`/`to_csv`）、os / pathlib（目录与凭据）、re（文件名清洗）；各模型库的随机种子接口（numpy.random、random、sklearn random_state、框架 seed）。

## 适用条件
- 同一数据集需要反复建模/调参（多次重跑、对比多模型）时，用本地快照替代重复请求。
- 结果需要交付或复现（回测报告、模型对比）时。
- 涉及随机性的实验（划分、训练、采样、超参搜索）。
- 需要长期维护的数据管道（目录约定 + 增量快照）。

## 不适用条件
- 研究复权、增量拼接等"快照会过期"的场景：前复权序列随除权事件变化，旧快照与新取数据不可直接拼接，需整段重取。
- 需要当日最新行情（实盘/每日更新）时，快照不能代替实时取数。
- 只固定随机种子而依赖旧版库：锁定 `yfinance==0.2.3` 这类老版本会让脚本在接口变化后失效，锁定与升级需要权衡。
- 把凭据写进脚本的实现：不可复现（凭据会失效/泄露），也不能提交到仓库。
- 工作路径、依赖清单、数据区间未记录的项目：换环境后无法重建，本卡的方法帮不上。
