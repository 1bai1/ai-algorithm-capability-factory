# 复用池

复用池把提炼池中的内容组织成 Agent 在实际任务中可以直接检索和调用的量化能力。它是模型选择、代码生成、验证和修复的依据，不是原始材料归档区。

复用池采用面向量化业务的能力分类：

- `01_任务能力/`：任务输入输出和业务约束。
- `02_数据契约/`：数据字段、质量规则和时间切分要求。
- `03_特征工程/`：可调用的特征方案和计算组件。
- `04_预测模型/`：模型实现、接口、参数和适用条件。
- `05_交易策略/`：信号、持仓、成本和基准实现。
- `06_评价指标/`：统一评价和排序规则。
- `07_股票画像/`：个股画像计算和模型匹配依据。
- `08_市场状态/`：趋势、震荡、波动和流动性识别组件。
- `09_验证证据/`：可以参与模型选择的历史验证记录。
- `10_失败经验/`：代码修复、数据泄漏和回测错误处理规则。

复用池中的节点必须给出输入、输出、实现位置、依赖、调用方式、适用条件和验证状态。提示词属于 Agent 编排层，不再作为复用池的一级分类。
