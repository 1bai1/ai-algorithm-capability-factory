# 预测点位跨日配对买卖策略

## 能力说明
当模型预测的是价格点位（Low/High）而不是方向时，用它构造"低买高卖"的配对交易规则：给预测买价加容忍溢价、给预测卖价加减容忍折让，用两个容差参数吸收预测误差。解决"每日预测高低点但没有当日先后顺序信息"这类不可执行预测的落地问题。

## 输入契约
- 日频 Low、High 实际值，以及与之对应的预测值。
- 时序约束：第 i 天的预测只能由第 i-2 天及之前的信息完成（预测领先实际两天）。这是该策略成立的前提。
- 回测区间由代码内循环长度决定，原文硬编码为 89 个交易日；初始资金 1000。
- 预测与实际必须严格按日期对齐，且预测的领先期数要在建模阶段就固定。

## 输出契约
- 逐笔交易记录与两套利润：
  - 模型利润（按交易规则实际可实现的累计利润）；
  - 理想利润（对同样预测、假设总能买在预测低价并卖在预测高价的上界）。
- 排序后的参数—利润字典，及最优参数组合 `best_parameters`。

## 调用方式
交易规则（第 i-1 天买、第 i 天卖）：
```
买入条件：实际低价 ≤ 预测低价 + low_add 且（预测低价 + low_add）< 次日预测高价
卖出条件：实际高价 ≥ 预测高价 − high_loss
```
- 因只有日频 Low/High、无法判断当日高低点先后顺序，原文明确放弃了"当日低买高卖"，改成上述跨日配对。
- 回测骨架：外层循环遍历买点，内层循环等待卖点，末笔以预测最后一天的低/高均值平仓。
- 参数寻优：
```
def trading_strategy(money, pre_Low, pre_High, low_add, high_loss):  -> (模型利润, 理想利润)
def tune_strategy(low_prediction, high_prediction):                  -> best_parameters + 按利润降序字典
for low_add in np.arange(0, 5, 0.1):
    for high_loss in np.arange(0, 5, 0.1): ...
```
- 评价方式：模型利润与理想上界并排对照，用于衡量预测质量而不是只看绝对收益。

## 关键参数
| 参数 | 含义 | 原文取值 |
|---|---|---|
| low_add | 买入容忍溢价（预测买价 + low_add） | 网格 [0, 5)，步长 0.1；默认取 0 |
| high_loss | 卖出容忍折让（预测卖价 − high_loss） | 网格 [0, 5)，步长 0.1；默认取 0 |
| 初始资金 | 账户起点 | 1000 |
| 回测长度 | 交易日数 | 89（代码内硬编码，未参数化） |
| 预测领先期 | 信息可用性 | 2 天 |

## 依赖
numpy。

## 适用条件
- 模型输出为价格点位（Low/High、目标价）而非涨跌方向。
- 标的日内波动足以覆盖交易成本，且预测误差可以由容差参数吸收。
- 可用于评估"预测质量上限"：把模型利润与理想利润对比，判断是模型不行还是策略参数不行。

## 不适用条件
- 预测领先期不足：如果预测用到第 i-1 天及以后的信息，则在第 i-1 天买入会引入前视，策略失效。
- 成交假设过于乐观的场景：按预测低价成交依赖当日出现该价位，实际低点多为瞬时价，未必能成交。
- 参数在同一批数据上网格搜索且无样本外验证：典型过拟合，最优的 (low_add, high_loss) 不可直接外推。
- 未计交易成本、税费与滑点：原文明确未计，且 3 个月 20% 的结论仅基于小样本。
- 只有日频 Low/High、无更细粒度数据的场景：无法判断日内高低点顺序，任何"当日低买高卖"的变体都不可执行。

## 验证状态
原文给出真实运行结果（黄金日频，约 89 个交易日，初始资金 1000）：
- 默认参数 (0, 0)：利润约 111。
- 调参后（low_add、high_loss 网格搜索）：利润约 245。
- 理想上界：约 497，即模型策略优于买入持有但远低于理想值。
- 原文结论自称"3 个月获得超过 20% 的利润"。
- 原文自承缺陷：参数在同一批数据上网格搜索取最优、无样本外验证，属典型过拟合；未计交易成本；"在预测低价买入"的成交假设偏乐观；把理想利润 497 与模型 245 并列易高估策略水平；函数内 89 天硬编码，未参数化。
