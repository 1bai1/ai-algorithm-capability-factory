# 情绪驱动的舆情交易策略

## 能力说明
把新闻标题（或公告、股吧、研报）转成个股日频情绪因子，并与事件收益对齐，供下游选股/择时模型使用。这一卡给的是"文本 → 情绪标签 → 因子面板 → 有效性检验"的完整数据工程链路，而不是一套已验证能赚钱的策略。

## 输入契约
- 文本源：新闻/舆情标题。原文用 RSS 新闻标题 JSON（内嵌 HTML 需 lxml 解析）+ GitHub 专家标注标题集；替换到 A 股可用股吧、公告、研报标题。
- 行情源：与文本同标的、同频率的价格（原文用 yfinance 取 2010-01-01 至 2018-12-31 的 12 只美股收盘价）。
- 股票池与规模（原文）：AAPL、MSFT、AMZN、GOOG、AMD、NVDA、TSLA、YELP、NFLX、ADBE、BA、AIG 共 12 只；新闻原始 110711 条，按 date+ticker 左连接并 dropna 后建模样本 3142 行 × 5 列；专家标注数据集 9470 条（另有自标注 2146 条）。
- 标签口径必须先固定：事件收益 = 事件日 t 与 t+1 两日收益之和（收盘价 `pct_change()` 后当日 + `shift(1)` 次日），比只看事件当日更稳。
- 文本列名与标签列名约定：语料列 `headline`，标签列 `sentiment`（通用模型）或 `perc_sent`（自标注），按 ticker 组织数据便于后续按标的对齐成因子。

## 输出契约
- 情绪因子面板字段：`ticker, headline, date, eventRet, Close, <情绪分>`。
- 三种情绪分来源可并列对照：`sent_blob`（TextBlob，取值 [-1,1]）、`vader_sent`（VADER + 金融词典，连续分）、`lstm`（深度学习推断的 0/1 标签）。
- 下游用法：把日期+标的键上的情绪分并入行情面板，成为可与技术/基本面因子拼接的时序特征，或直接二值化成交易信号。

## 调用方式
1. 构建事件表：解析 RSS JSON → xpath 抽标题与主股票代码（`//h4[contains(@class,'media-heading')]/a/text()`）→ 与行情按 `date + ticker` 左连接 → 保留 `[ticker, headline, date, eventRet, Close]` 后 dropna。
2. 打标签（优先序可直接移植到 A 股股吧/新闻标题）：
   - 先抽数值型情感：正则提取标题中的涨跌幅百分比（如 "(WFMI) -5.2%"），最客观；
   - 用情感词典兜底：`data_df['sent_blob'] = data_df['headline'].apply(lambda r: TextBlob(r).sentiment.polarity)`；
   - 用事件词覆盖财报新闻：标题含 'misses' 标 0、含 'beats' 标 1；
   - 汇总：`ldf = tdf.loc[~tdf['perc_sent'].isna()]`，`replace({False:0, True:1})`。
3. 领域词典修正：`nltk.sentiment.vader.SentimentIntensityAnalyzer` 初始化后与自建金融情感词典 CSV（原文用 Oliveira 等人的词典）合并，再对 headline 逐条打分生成 `vader_sent`。
4. 文本特征：静态词向量句向量（spaCy `en_core_web_sm` 96 维 / `en_core_web_lg` 300 维），标题内词向量取平均。基线无需微调大模型。
5. 深度学习路线：`vocab=20000`、`maxlen=50`（超出截断、不足补零）、100 维可训练嵌入 + LSTM、Adam + 二元交叉熵、10 epochs；外层 90/10 切训练/测试，训练集内再 60/40 切验证；训练到约 0.97 验证准确率后 `inference(df,'headline')` 对新数据批量推断 0/1 标签。
6. 有效性初筛：按 ticker 分面画散点（`px.scatter(x='vader_sent', y='eventRet', facet_col='ticker')`）+ `ldf.corr()` 相关矩阵，比对三种情绪方法与事件收益的相关性强弱，再决定入模哪一路。
7. 多模型横评：LR、KNN、CART、SVM、RF 同一份句向量上跑 k 折 + 训练/测试准确率差，用差值识别过拟合。
8. 情绪因子的下游用法（原文未落地，可自行接）：情绪分并入行情面板 → 作特征或阈值信号 → 与「预测阈值转持仓信号」卡对接。

## 关键参数
| 参数 | 含义 | 原文取值 |
|---|---|---|
| 事件收益窗口 | 标签口径 | [t, t+1] 两日收益之和 |
| 词表 | vocab size | 20000 |
| 最大序列长度 | maxlen | 50 |
| 嵌入维度 | embedding dim | 100（可训练）；词向量路线 96 / 300 维 |
| 数据划分 | 外层/内层 | 90/10；内层 60/40 |
| 训练轮数 | epochs | 10（验证准确率第 1 轮 0.9449，稳定在 0.97 附近） |
| 情绪标签体系 | 类别 | 0/1 二分类（另有 {积极, 消极, 中性} 三分类的概念方案，未落地） |
| 任务配置 | 文件/列名 | 语料列 headline、标签列 sentiment/perc_sent |

## 依赖
pandas、numpy、yfinance、lxml.etree、zipfile/json、nltk（VADER + 分词）、TextBlob、spaCy（预训练词向量）、scikit-learn（LogisticRegression/KNN/DecisionTree/SVC/RandomForest）、Keras/TensorFlow（Tokenizer/Embedding/LSTM）、plotly。

## 适用条件
- 个股层面的事件驱动研究：新闻/公告发布日可对齐到交易日，且标的存在明显的短期事件反应。
- 需要低成本情绪因子做初筛时：LR 在 300 维句向量上是强基线，优先于 KNN/CART/RF。
- 标注数据量充足、标签质量可控（专家标注 9470 条量级）时再上深度模型。

## 不适用条件
- 用通用情感词典直接打金融文本：TextBlob 训练自电影评语料、VADER 默认词典亦非金融领域，原文明确结论是必须换成金融定制词典；A 股需重建中文金融感情词典。
- 自标注 + 高维嵌入的小数据集：2146 条上换 300 维嵌入 LR 测试仅从约 0.73 微升到 0.740、交叉验证无改善，原文结论是小数据集吃不下高质量嵌入；同一操作在 9470 条专家标注集上才明显提升（LR 测试 0.869）。
- 只看训练准确率：原文实例训练准确率 0.9996、验证约 0.97，两者差距即过拟合幅度。
- 用随机切分验证文本因子：原文 90/10 随机划分与"用历史预测未来"的实际用法不一致，同一事件重复报道还会跨集泄漏；应按时间切分。
- 把 0/1 二分类情感当充分信号：标签无法表达强度与中性，情绪因子信息量受限。
- 直接照搬英文规则到 A 股：百分比抽取、beats/misses 关键词、词向量与词典都需要重建。

## 验证状态
原文给出真实运行结果，但全部为情感分类精度，没有任何策略回测收益：
- 深度学习（100 维嵌入 + LSTM）：验证准确率从第 1 轮 0.9449 稳定在 0.97 附近，训练准确率升到 0.9996。
- 传统模型（9470 条专家标注，300 维 spaCy 嵌入）：LR 交叉验证 0.872、测试 0.869（混淆矩阵 330/62/62/493），RF、SVM、KNN 同步改善。
- 传统模型（2146 条自标注，96 维）：LR 交叉验证均值 0.733、测试 0.725；换 300 维后测试约 0.740。
- TextBlob 情绪分与事件收益：原文只给散点图与分组相关系数柱状图，结论是整体相关性偏低、无稳定线性关系，未给出相关系数数值与显著性检验。
- 原文明文承认：情绪因子到交易策略的收益表现（含交易成本）完全缺失，情绪到收益的因果链未打通，结论章只有方法论结论。因此本卡 status 为待验证。
