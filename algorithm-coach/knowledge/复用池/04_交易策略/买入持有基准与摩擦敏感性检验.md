# 买入持有基准与摩擦敏感性检验

## 能力说明
为任何策略提供最低对照线（买入持有）与两个进阶参照系：可承受成本的量化边界（摩擦敏感性）和理论天花板（时间旅行者上限）。回答"策略是真有 alpha，还是靠零成本高频调仓"。

## 输入契约
- 标的价格序列（日频即可，长度 ndays），用于构造买入持有净值 `P_t / P_0`。
- 策略侧的逐日净值序列或逐笔交易记录，至少需要两个数：无摩擦终值 `V0[-1]` 与交易次数 `ntrades`。
- 统一的摩擦率标量 f：把手续费、买卖价差、冲击成本合并为单一费率。
- 可比性要求：策略与基准必须用同一 start/end、同一收益口径（小数）、同一无风险利率（原文显式取 0）。

## 输出契约
- 三条对数坐标曲线（纵轴取对数）：
  1. 策略终值按 `V0[-1] * (1-f)^ntrades` 衰减；
  2. 直接投资标的的水平线（不受摩擦影响，`BC_Prices[-1]/BC_Prices[0]`）；
  3. 时间旅行者上限 UB —— 假设能提前看到全部未来价格时的理论最大回报，并同时记录其交易次数。
- 一行式成本指标：`终值 × (1-f)^交易次数`，适合放进回测摘要。
- 判定输出：策略在多少摩擦率下失去优势（与买入持有曲线交点）。

## 调用方式
```
friction = np.linspace(0, 0.02, 100)                       # 0–2%，100 档
plt.semilogy(friction, V0[-1] * np.power(1 - friction, ntrades),
             label='previous day trend follower')
plt.semilogy([0, 0.02], [BC_Prices[-1] / BC_Prices[0]] * 2, label='bitcoin investment')
# 上限：对每档摩擦率重置 c=1、b=0、tc=0、tb=0，逐日调整现金与持仓比例以最大化终值
UB = np.zeros(100); TR = np.zeros(100)
```
- 组合记账最小骨架（两个状态 + 四个变量）：`Portfolio0 = np.zeros((ndays, 2))`，第 0 列现金、第 1 列持仓；`Portfolio0[0,0] = 1`；状态标识 `a ∈ {'c','b'}`，配 pc（现金）、pb（持仓量）、ntrades（交易次数）。
- 摩擦在交易中扣除：卖出实得 `(1-f)·b·p`，买入实得 `(1-f)·c/p`。
- 基准策略实现（前一天趋势跟随，可作第二参照）：当日对数收益率 r ≥ 0 则全部换成标的，r < 0 则全部换回现金，逐日收盘后更新并累计交易次数。
- 交易次数统计口径（测试段基准）：`ntrades = np.sum(Portfolio[train_end:-1] * Portfolio[train_end+1:] > 0)`。
- 分档净值曲线：`V1[i, train_end:] / V1[i, train_end]`，i=25/50/75 对应 0.5%/1%/1.5% 摩擦，用作压力测试三档。

## 关键参数
| 参数 | 含义 | 原文取值 |
|---|---|---|
| friction | 单边摩擦率扫描 | `np.linspace(0, 0.02, 100)`，即 0–2% 共 100 档 |
| 压力档 | 重点审查档位 | 0.5% / 1% / 1.5% |
| 初始资金 | 基准起点 | 1（货币单位） |
| 无风险利率 | 基准口径 | 0；持有现金无利息 |
| 坐标 | 净值曲线 | 对数坐标（semilogy） |
| A 股成本参考 | 买卖费率 | 买入 6.87e-5（约万分之 0.687）、卖出 1.0687e-3（约千分之 1.07，含印花税），卖出约为买入的 15.6 倍 |
| 成本必含项 | 回测成本 | 手续费 + 印花税 + 滑点三项必须计入 |

## 依赖
numpy、matplotlib（semilogy + legend）；绩效对照可用 quantstats / pyfolio。

## 适用条件
- 策略换手较高（日频或每周换仓）时必做：成本项对结论的影响随交易次数指数放大。
- 单标的择时策略：直接持有同一标的即是最公平的基准。
- 需要区分"策略不行"与"市场本来就没机会"时：用时间旅行者上限做参照系，比只对比买入持有更有信息量。
- 上线前定容量：由 `(1-f)^n` 反推策略可承受的最大交易频率与盈亏平衡摩擦率。

## 不适用条件
- 把时间旅行者上限当可实现目标：它带未来信息，只是理想化参照，不代表可实现的策略；上限的求解方式原文只描述为"逐日调整比例取最大"，未证明全局最优。
- 把手续费、价差、冲击成本压成一个与交易规模无关的常数 f：对大资金不成立。
- 策略与基准的成本口径不一致时做对比：原文一处 HMM 策略按逐笔摩擦扣减、基准用 `(1-f)^交易次数` 近似，两者比较不完全公平。
- 交易次数口径未定义就套公式：买入+卖出算一笔还是两笔，直接决定 `(1-f)^ntrades` 的幂次。
- 只比累计收益：策略累计收益跑赢买入持有不等于策略有效——必须同看夏普与最大回撤（原文有一例收益更高但夏普更低、最大回撤更大）。
- 单标的、单区间结论外推：原文的基准结论均来自单一标的与单一历史区间，无跨市场稳健性验证。

## 验证状态
原文给出真实运行结果：
- 买入持有基准被作为硬性对照：活牛期货案例中策略累计 62.16% 对 Buy & Hold 37.56%；AAPL 策略 1 累计 908.02% 对 Buy & Hold 855.4%（CAGR 19.09% 对 18.61%、Sharpe 2.49 对 2.29、Sortino 3.91 对 3.56）；AAPL 策略 2 累计与 CAGR 更高但夏普更低、最大回撤更高，被判定为更差。
- 前一天趋势跟随基准：无摩擦环境下长期显著跑赢直接买入持有比特币，但几乎每个交易日都调仓，对交易成本极度敏感（原文未给出具体倍数）。
- 摩擦敏感性：HMM 阈值策略在低摩擦（约 0.5%）下明显优于直接持有比特币，随摩擦率上升优势逐渐收敛至零；摩擦率越高，最优买卖阈值间距越大（策略要求更极端的信号才愿意动手）。
- 时间旅行者上限：能给出各摩擦率下的理论最大回报与所需交易次数，用于观察高摩擦环境下最优交易者也会主动降低交易频率；上限只报告了图形，未给出具体数值。
- A 股实测：某 DRL 策略在 2019-08-01 至 2019-12-31 区间期末资产 952,511（初始 100 万）、Sharpe -0.366、成交 608 笔、成本 68.68，即成本与负收益环境下策略被基准击败。
