# 强化学习组合持仓权重策略

## 能力说明
把多标的组合交易建模为 MDP，用 DRL 代理直接输出每只标的的仓位权重（而非买卖信号），并与环境逐步交互最大化账户价值。可用于生成"每日权重矩阵"这一输出形态的策略，也可用单标的离散动作版本做最小实现。本卡记录的两条实际路线（FinRL 组合权重、单标的离散动作）都存在明显缺陷，采用前必须补齐样本外与成本验证。

## 输入契约
- 多标的日频面板（长表），字段：`date/open/high/low/close/adjcp/volume/tic/day` + 技术指标 + `cov_list` + `return_list`；A 股路线用 TuShare 取数，指标集固定 8 个：macd、boll_ub、boll_lb、rsi_30、cci_30、dx_30、close_30_sma、close_60_sma。
- 数据流水线顺序：download → clean_data → fillna → add_technical_indicator → fillna → data_split（加指标后必须再 fillna）。
- 状态空间维度：`state_space = stock_dim × (指标数 + 2) + 1`（每股贡献"指标数 + 现金/持仓 2 维"，整体再加 1 个时间步）。示例 15 × 10 + 1 = 151；道指案例 28 只标的。
- 时间切分必须三段分离：训练 / 验证 / 交易（样本外）。A 股示例：训练 2015-01-01 至 2019-08-01，交易段 2019-08-01 至 2020-01-03；道指案例交易段 2020-07-01 至 2021-10-31。
- 加密货币路线（小时级）字段：`date, symbol, open, high, low, close, volume usdt, tradecount`，另派生 hour 与 day（Monday=1…Sunday=7）；实验用 BTC，区间 2020-08-17 04:00 至 2023-10-19 23:00。

## 输出契约
- 多标的组合形态：`(df_daily_return, df_actions)` 两个 DataFrame —— 每日回报率 + "日期 × 各 ticker"权重矩阵；典型权重取值 0.0267~0.0725，首日等权（0.035714）。
- A 股形态：`df_account_value` 与 `df_actions`（日期 × 股票代码的买卖股数矩阵，0=不动，1000=买卖 1000 股）。
- 训练期每 Episode 监控字段：begin/end_total_asset、total_reward、total_cost、total_trades、Sharpe、time_elapsed。
- 单标的离散动作形态：state = [cash, holdings]，action = {买入, 卖出, 持有}。

## 调用方式
多标的（FinRL + Stable-Baselines3，统一调用链）：
```
env_train, _ = e_train_gym.get_sb_env()          # DummyVecEnv 向量化环境
agent = DRLAgent(env=env_train)
model = agent.get_model("a2c"|"ppo"|"ddpg"|"sac"|"td3", model_kwargs=PARAMS, policy_kwargs=...)
trained = agent.train_model(model=model, tb_log_name=..., total_timesteps=...)
trained.save('/content/trained_models/trained_x.zip')
# 样本外
df_daily_return, df_actions = DRLAgent.DRL_prediction(model=trained, environment=e_trade_gym)
```
环境关键参数（`StockPortfolioEnv` / `StockTradingEnv`，必填 8 项）：`hmax`（单次最大交易股数）、`initial_amount`、`transaction_cost_pct`（或买卖分开的 `buy_cost_pct` / `sell_cost_pct`）、`state_space`、`stock_dim`、`tech_indicator_list`、`action_space`（=股票数）、`reward_scaling`。
- 动作归一化：`softmax_normalization(actions) = np.exp(a)/np.sum(np.exp(a))`，保证权重和为 1。
- 奖励：组合价值变化 `r(s,a,s') = v' - v`，经 `reward_scaling` 缩放（常规取 1e-4）。
- reset 约定：`asset_memory` 置 `[initial_amount]`、`day=0`、动作记忆初始化为等权 `[1/stock_dim]`；终止条件 `self.day >= len(self.df.index.unique()) - 1`。
- 逐日记录：`save_asset_memory()` 输出 date+daily_return，`save_action_memory()` 输出逐日持仓。
- A 股适配：`hundred_each_trade=True` 按一手 100 股成交、`initial_buy` 控制是否开局建仓、买/卖成本分开设置。
- 加密货币单标的形态（PPO + 自定义 Gym 环境 `CryptoTradingEnv`，action = 买/卖/持有，reward 由账户余额与持仓收益变化给出）。

## 关键参数
算法超参（原文给出的可直接起点，注意五组训练步数不同、无法横向比较）：

| 算法 | 超参 |
|---|---|
| A2C | n_steps=5、ent_coef=0.005、learning_rate=0.0002，50,000 步（另一实例 ent_coef=0.01、lr=0.0007） |
| PPO | n_steps=2048、ent_coef=0.005、learning_rate=0.0001、batch_size=128，80,000 步 |
| DDPG | batch_size=128、buffer_size=50,000、learning_rate=0.001，50,000 步（A 股实例 batch=256、buffer=50,000、lr=0.0005、NormalActionNoise(mu=0,sigma=0.1)，10,000 步） |
| SAC | batch_size=128、buffer_size=100,000、learning_rate=0.0003、learning_starts=100、ent_coef="auto_0.1" |
| TD3 | batch_size=100、buffer_size=1,000,000、learning_rate=0.001，30,000 步 |

环境与成本参数：
| 参数 | 含义 | 原文取值 |
|---|---|---|
| initial_amount | 初始资金 | 1,000,000（美元/人民币口径原文未澄清） |
| hmax | 单标的最大持仓 | 1000 股 |
| buy_cost_pct | 买入成本 | 6.87e-5（约万分之 0.687） |
| sell_cost_pct | 卖出成本 | 1.0687e-3（约千分之 1.07，含印花税；卖出约为买入的 15.6 倍） |
| reward_scaling | 奖励缩放 | 1e-4 |
| 单标的 RL | 状态/动作 | state=[cash, holdings]，3 个离散动作；策略网络 128→64→动作数；L2 正则 l2_reg=0.01；10,000 episodes |

## 依赖
FinRL（DRLAgent、StockPortfolioEnv/StockTradingEnv、data_split、plotter）、Stable-Baselines3（A2C/PPO/DDPG/SAC/TD3、DummyVecEnv）、gym + shimmy>=0.2.1、TensorBoard、pandas/numpy；评估用 pyfolio 与 FinRL 的 get_baseline/get_daily_return/backtest_stats；单标的版本用 torch + gym。

## 适用条件
- 多标的、可日频连续调仓、允许做空且能接受整数股约束改造的美股场景。
- 需要"权重矩阵"型输出（便于集中度与归因分析）而非 0/1 信号的组合策略。
- 已有隔离的样本外区间，且能对权重逐日变动的换手成本做压力测试。

## 不适用条件
- 无样本外区间的自我验证：原文一处直接把训练集赋给验证集（`val_data = train_df`），该"验证"不成立。
- 只看训练期指标就下结论：DDPG/SAC/TD3 训练期总资产 436~485 万（期初 100 万）、Sharpe 0.80~0.835 都是训练期数字，极可能是对环境的过拟合。
- A 股 T+1、涨跌停、融券限制下直接照搬：连续权重动作空间、允许做空、每日调仓的假设全部不成立。
- 交易成本被忽略或只按固定百分比计：环境未建模冲击成本、滑点与流动性限制，`hmax` 只约束单次股数。
- 配置前后不一致的项目：A 股案例训练 A2C 却调用 `trained_ddpg` 预测，结果不可信。
- 状态空间含高维协方差展开（如 28×28）：易过拟合，原文未做降维与敏感性分析；且 `state_space` 参数与实际拼接维度口径不一致时照抄会直接报错。
- 单标的 RL 用 [现金, 持仓] 当状态：不含价格、持仓成本或技术指标，策略无法感知行情位置，等价于对价格序列做无信息决策（原文实例即因此奖励恒为 6673009.12、训练未见更新）。

## 验证状态
原文给出真实运行结果：
- 道指 30 只成分股，交易段 2020-07-01 至 2021-10-31，A2C：期末总资产 1,363,804（对初始 100 万约 +36.4%），Sharpe = 1.8078；每日权重典型取值 0.0267~0.0725，首日等权。样本外仅约 336 个交易日。
- 同一策略经 pyfolio 评估：年化 26.11%、累计 36.38%、年化波动 13.33%、Sharpe 1.81、Calmar 3.32、Stability 0.91、最大回撤 -7.87%、Sortino 2.74、日 VaR -1.58%、Alpha 0.00、Beta 0.94。
- 同期基准（道指 ^DJI）：年化 27.90%、累计 38.84%、波动 13.91%、Sharpe 1.84、Calmar 3.12、最大回撤 -8.93%、日 VaR -1.65%。即策略的 Alpha 为 0.00、Beta 0.94，收益基本来自跟随大盘，略逊于基准。
- 训练期各算法：DDPG 期末总资产约 436.6~436.9 万、Sharpe 约 0.80~0.82；SAC 约 485 万、Sharpe 约 0.817；TD3 约 479.8 万、Sharpe 约 0.835（均为训练期，非样本外）。
- A 股 15 只沪市股票，回测段 2019-08-01 至 2019-12-31，初始 100 万：期末资产 952,511、total_reward -47,488.68、Sharpe -0.366、成交 608 笔、成本 68.68。原文未分析原因，且训练 A2C 却用 DDPG 预测，配置不一致。
- 比特币单标的 [现金, 持仓] 状态版本：Episode 10 与 Episode 20 的 Reward 完全相同（6673009.12），未归一化且不随训练变化，训练是否真正更新策略存疑。
- DRL 比特币系统的"测试验证"把训练集当验证集，只有奖励与交易次数输出、无累计收益与夏普，代理表现无结论。
