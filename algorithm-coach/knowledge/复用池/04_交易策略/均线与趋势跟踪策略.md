# 均线与趋势跟踪策略

## 能力说明
用移动平均线判定趋势方向与强度，产出"趋势向上做多、转弱离场"的二态信号。提供两条实现路线：纯规则均线形态（金叉死叉、均线站上/单调/拐点）与"价格对均线偏离度 + 分类模型"的模型化趋势跟踪。

## 输入契约
- 日/周/月频 OHLCV，含复权收盘价（Adj Close）。A 股可用 TuShare `pro_bar(ts_code, freq, adj='qfq', start_date, end_date, ma=[短,长])` 直接返回指定均线列。
- 均线可自行计算：`df['close'].rolling(window=N, min_periods=1).mean()`（SMA）、EMA 用 `ewm(span=N).mean()`。
- 训练/测试按时间切，禁止随机划分；期货案例按年份硬切：2002–2012 训练、2013–2023 测试。
- 模型化路线还需要标签：先做因子分位数收益表，再定二分类阈值。
- 最小样本量原文未给出；参考：活牛期货周频 1104 行（训练特征表 465 行 × 35 列），贵州茅台日线 891 行。

## 输出契约
- 规则路线：命中股票清单（ts_code + 基础信息）或 1/0 信号序列。
- 模型化路线：看涨概率 → （阈值化后）1/0 或 ±1 仓位 → 策略周收益序列 → Quantstats 报告。
- 回测输出：累计收益、超额、年化波动、夏普、Sortino、最大回撤、回撤持续天数、恢复因子。

## 调用方式
纯规则五式（`（6-4）量化选股程序`，函数名与示例参数可直接落地为信号函数）：
| 策略 | 规则 | 示例参数 |
|---|---|---|
| Cross | 短均线在长均线之上，且过去 n 个周期内出现过金叉 | Cross('W', 13, 55, 2) |
| GoldenCross | Cross 再加"金叉后 m 天内价格上涨" | GoldenCross('D', 8, 21, 3, 1) |
| Suppress | K 线站上均线 | Suppress('M', 8, 10) |
| Trend | 均线连续 n 个周期单调递增 | Trend('W', 55, 50) |
| Bottom | 均线出现拐点且拐点后 m 天上涨 | Bottom('D', 55, 10, 2) |

模型化趋势跟踪（活牛期货，12-2/12-3/12-4/12-5/12-6 全链路）：
1. 因子：`close_to_ema8_ratio = Close / EMA8`（8 周期 EMA，α=2/(n+1)）；<1 在均线下方偏空、>1 在上方偏多，偏离 1.0 越远趋势越强。
2. 定标签：对该比率取八分位（`np.arange(0, 1.125, 0.125)`）→ `pd.cut` → `groupby('ranges')['returns'].mean()` 看各桶平均收益单调性；实测 0.998 以下各桶收益均值为负（-2.44 / -0.99 / -0.43），0.998 以上为正（0.03 起，最高 2.68），故取阈值 0.998：`target = np.where(ratio <= 0.998, 0, 1)`，再 `shift(-1)` 对齐下一期。
3. 不平衡处理：`SMOTE(random_state=42).fit_resample`，只对训练集过采样，测试集保持原分布。
4. 特征筛选：`SelectKBest(f_classif, k=全部特征数)` + `pvalues_ < 0.05`，最终入选 23 个特征。
5. 建模：8 种分类器同表横跑，用测试集正类概率 AUC 选优；原文 LogisticRegression AUC = 0.887 最好的结果。
6. 转信号与回测：见「预测阈值转持仓信号」卡（阈值 0.607 + shift(1)）。
7. 三段式混合信号（金价案例）：5/20 日均线交叉 + RSI 超买超卖过滤 + 20/60 日均线中期趋势确认，最终落成持仓/空仓两态。
8. 均线 + 量能 + 偏离度（HFT 降级案例）：收盘价 > SMA20 且成交量 > 过去 5 日均量的 1.2 倍 → 买入；(收盘价 - SMA50)/SMA50 < -2% → 买入，> +2% → 卖出。

## 关键参数
| 参数 | 含义 | 原文取值 |
|---|---|---|
| 均线类型 | SMA / WMA / EMA | EMA 响应更快但对噪声与假突破更敏感；原文鼓励替换均线类型做对照 |
| 周期 | 短/中/长 | 因子基线 EMA8；特征里用到 lag1~lag5、9/20 日波动率比；选股示例 8/21/55；混合信号 5/20 与 20/60 |
| 分类阈值 | ratio 二值化切点 | 0.998（八分位收益由负转正的临界点） |
| 信号概率阈值 | 见信号卡 | 0.607 |
| 特征筛选 | 显著性 | f_classif p < 0.05 |
| 随机种子 | 复现 | random_state = 42 |

## 依赖
pandas、numpy；技术指标用 `ta`（RSI/CCI/OBV/ADX/ADI）；建模 sklearn（LogisticRegression、SelectKBest、f_classif、permutation_importance），可选 XGBoost/LightGBM/CatBoost/AdaBoost/RF/GBDT/MLP；不平衡用 imblearn.SMOTE；绩效用 quantstats；A 股取数用 tushare；绘图 plotly（蜡烛图 + EMA 叠加）。

## 适用条件
- 标的处于中长期趋势行情；趋势形态在样本期内可重复。
- 对时间框架不敏感，5 分钟到月线均可套用（原文明确说明）。
- 特征侧建议用比率类而非原始价格：K 线实体/影线比率、滞后比率、均线偏离度，跨标的与跨时段迁移性更好。

## 不适用条件
- 长期横盘震荡市场：活牛期货 2002–2011 就是长期无趋势横向区间，此时趋势信号会被反复打脸。
- 把均线当预测器而不是状态过滤器：均线是滞后指标，原文明确要求配合成交量、MACD 等综合判断。
- 用 `min_periods=1` 且不做处理：序列前段由不足窗口样本计算，早期均线不可靠、易产生虚假交叉。
- 只报形态不报回测就上线：`（6-4）量化选股程序` 全篇无回测、无胜率与回撤，参数为经验取值，过拟合风险高。
- 未处理期货展期、停牌、涨跌停、除权对均线连续性的影响时，不要直接套用到 A 股个股。

## 验证状态
原文给出真实运行结果：
- 活牛期货（Live Cattle Futures，yfinance LE=F）周频：训练 2002–2012、测试 2013-05-27 至 2023-05-15；LogisticRegression 测试 AUC 0.887；最终策略累计收益 62.16%，买入持有 37.56%；Sharpe 0.75、Sortino 1.1、年化波动 44.19%（基准 44.21%）；最大回撤 -39.84%。结果为历史模拟，未计交易成本与滑点，阈值 0.607 在同一测试集上挑出，原文自承回撤控制不足。
- 贵州茅台 600519.SH 日线（2020-01-01 至 2023-09-01，891 条）与 A 股选股五式：原文未给出任何回测或胜率结果，属未验证。
- 均线混合信号（金价案例）：原文只有流程描述与"累计收益/夏普"的展示计划，未给出数值。
