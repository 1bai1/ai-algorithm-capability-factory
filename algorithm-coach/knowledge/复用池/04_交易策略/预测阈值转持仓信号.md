# 预测阈值转持仓信号

## 能力说明
把模型输出的概率或预测收益转换成可执行的持仓，打通"预测 → 信号 → 仓位 → 收益"这一段。三个必须做对的点：阈值在数据上标定而不是默认 0.5、仓位必须滞后一期、持仓用状态机管理（含观望带与趋势确认）。

## 输入契约
- 模型输出，与收益序列共用同一时间索引，两种形态皆可：
  - 分类正类概率 `predict_proba(X)[:, 1]`，取值 [0,1]；
  - 连续预测值：预测收益率或期望收益（可正可负），如 ARIMA 一步预测、HMM 期望异常收益率 EAR。
- 必须另外提供对齐的同期收益率列 `returns`，用于合成策略收益。
- 最小样本量原文未给出；各案例规模可作参考：AAPL 周频测试段 2014-05-19~2023-07-17、GOOG 日频回测有效样本 3637 行、比特币 169 个交易日。
- 频率：周频、日频均可。频率越高，交易成本对结论的破坏力越大。

## 输出契约
- 逐期 `position`（1/0 或 1/-1）与 `strategy_return = position * returns`。
- 报告字段：累计回报、CAGR、Sharpe、Sortino、年化波动率、最大回撤、持仓时间占比（Time in Market），并与买入持有基准并列。
- 参考实测：策略1 持仓时间占比 94%（基准 100%），用以判断"择时到底避开了多少时间"。

## 调用方式
```
preds   = model.predict_proba(X_test[predictors])[:, 1]
signal  = (preds > THRESHOLD).astype(int)   # 1 看多 / 0 看空
position = signal.shift(1)                  # 关键：滞后一期，消除前视
model_returns = position * returns
qs.reports.full(model_returns / 100, benchmark=buy_hold / 100)  # 入参须为小数
```
- 阈值标定流程（活牛期货案例）：对预测概率取 `np.quantile` 八分位切点 → `pd.cut` 分箱 → `pd.crosstab(真实标签, 箱)` 看每箱中 0/1 哪边占多数，取"多数类别发生翻转"的边界作为阈值；原文由此把默认 0.5 换成 0.607。
- 多空形态：`Predicted.replace(0, -1)` → `shift(1)` → 与收益相乘，即满仓多空切换。A 股不可做空时把 -1 映射为 0，退化成多头/空仓二态。
- 双阈值观望带：概率 > 0.55 持有、< 0.45 空仓，中间区间维持原仓位（金价树模型案例）。
- 门槛 + 技术确认双条件：预测上涨概率 > 55% 且均线交叉确认才开仓（LSTM 量化案例）；另一实例用 概率 > 0.5 且 趋势强度 > -0.01 买入，预测下跌或趋势转弱卖出。
- 三态信号：概率经阈值映射为 {+1 买, -1 卖, 0 不动}，而非直接预测收益率。
- 连续预测值形态：ARIMA 一步预测收益 > 阈值才开仓，阈值需要网格试（原文试过 0、0.001、0.005、0.01）。
- 阈值应作为可调参数而非硬编码 0.5，但阈值只能由训练集/样本内确定，随后原样用于样本外。

## 关键参数
| 参数 | 含义 | 原文取值 |
|---|---|---|
| 概率阈值 | 正类概率二值化切点 | 0.607（活牛期货八分位标定，实测最优）；0.6（GOOG 手工设定，原文建议在 0.6~1 之间再试）；0.5（AAPL 默认二值化）；0.55/0.45 双阈值（金价）；0.55+均线确认（LSTM 量化）；0.5+趋势强度>-0.01（DeepQuantStrategy） |
| 信号→仓位映射 | 多头/空仓 或 多空 | 1/0 或 1/-1，A 股取 1/0 |
| 杠杆 | 是否放大 | 不加杠杆（原文案例均为满仓切换） |
| 无风险利率 | 送入 quantstats 的 rf | 0（AAPL 案例显式设为 0） |
| 收益口径 | 单位 | 统一小数，送入 quantstats 前除以 100 |

## 依赖
pandas、numpy；绩效报告用 quantstats（`qs.reports.full`）。

## 适用条件
- 已有方向/收益预测模型，且预测力偏弱（AUC 0.55~0.6 量级也可用）时，用"看涨才持有"规避下跌段的价值最大。
- 单标的或少量标的的择时；周频、日频。
- 标的存在明显下跌段——否则空仓只会削弱收益。

## 不适用条件
- 不可做空市场直接照搬 1/-1 多空映射（A 股需改 1/0，否则信号语义不成立）。
- 预测输出与收益序列未严格按时间对齐：`shift` 方向搞错、或 `X_test['returns'] = df['returns']` 这类拼接错位会直接造成隐性数据泄漏。
- 高换手场景：每周/每日全仓切换时，未计成本的结果不可采信（AAPL 案例持仓 94% 仍胜出，但原文完全未计交易成本、滑点与税费）。
- 阈值在测试集上挑选且无独立样本外复验：属于阈值选择偏差，不可上线。
- 尾部风险敏感的资金：满仓多空策略（AAPL 策略 2）在原文中就表现为"收益更高但夏普更低、最大回撤更大"。

## 验证状态
原文给出多组真实运行结果：
- 活牛期货（Live Cattle Futures）周频，回测区间 2013-05-27 至 2023-05-15，无成本、无滑点、满仓多空：策略累计收益 62.16%，买入持有 37.56%；Sharpe 0.75、Sortino 1.1；年化波动 44.19% 对基准 44.21%；最大回撤 -39.84%，最差一次回撤持续 1043 天（原文把缩短回撤列为后续改进重点）。
- AAPL 周频，2014-06-02 至 2023-07-17：策略 1（仅看涨时持有）累计 908.02% 对 Buy & Hold 855.4%，CAGR 19.09% 对 18.61%，Sharpe 2.49 对 2.29，Sortino 3.91 对 3.56，持仓时间占比 94%；策略 2（满仓多空）累计与 CAGR 更高但 Sharpe 更低、最大回撤更高，原文结论为策略 1 更优。两策略均未计交易成本与税费。
- GOOG 日频：阈值 0.6 下，扩充特征后精确率由 67.83% 提升到 85.28%（分类报告 support 3637，准确率 0.82），无净值与收益结果。
- 比特币日频 2021-04-01 至 2021-10-01（169 个交易日，初始 1000）：ARIMA(1,1,1) + 阈值 0.01 → 1060.22；ARIMA(1,0,0) + 阈值 0.001 取得约 44% 回报；纯规则"上一个收益为正就买入"最终约亏损 5%。
