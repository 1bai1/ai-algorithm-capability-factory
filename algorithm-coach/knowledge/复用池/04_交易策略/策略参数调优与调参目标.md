# 策略参数调优与调参目标

## 能力说明
给定一套策略/模型的参数空间，选对调参工具、目标函数与验证协议，并把交易成本并入目标。本卡按"调参目标"分层给出可直接照搬的四种协议：模型指标类（AUC/Accuracy）、交易利润类（累计利润最大化）、阈值+成本联合类（`log(R) + T*log(1-f)`）、结构参数类（ARIMA 阶数）。

## 输入契约
- 待调参数与其搜索范围必须显式声明（见下表）。
- 训练/验证/测试三段必须按时间切分，禁止随机 K 折用于时序调参（原文明确：参数优化用时间序列交叉验证而非随机 K 折）。
- 寻优目标需要的数据：模型的 `predict_proba` 输出、或逐期收益序列（用于利润/含成本目标）、或逐笔交易记录（用于交易次数 T）。
- 参数个数的硬约束：参数超过 5 个即危险；参数取值必须符合市场逻辑。

## 输出契约
- 最优参数组合 + 对应目标函数值（`study.best_params` / `best_params_` / `best_parameters`）。
- 建议同时输出参数稳定性证据：同一目标在不同子样本/不同成本档下是否收敛到同一组参数（原文 HMM 案例：100 档摩擦率只落到 3 组阈值，即参数对成本不敏感——这是判断过拟合的关键信号）。
- 敏感度曲线：目标函数随某个参数的变化曲线，用于判断最优解是尖峰还是平台。

## 调用方式
四种协议按目标选择：

1）模型指标类（Optuna，最大化 ROC-AUC）
```
def objective(trial):
    params = {...trial.suggest_float/loguniform...}
    model = ModelX(**params, random_state=seed).fit(X_train, y_train)
    return roc_auc_score(y_test, model.predict_proba(X_test)[:, 1])
study = optuna.create_study(direction='maximize'); study.optimize(objective, n_trials=1000)
best = study.best_params
```
集成权重搜索同理：对每个基估计器 `trial.suggest_float(0, 1)` 生成权重，用软投票模型的 Accuracy 作目标，最后以 `VotingClassifier(estimators, voting='soft', weights=best_weights)` 落地。

2）交易利润类（双层网格，最大化累计利润）
```
for low_add in np.arange(0, 5, 0.1):
    for high_loss in np.arange(0, 5, 0.1):
        profit = trading_strategy(money, pre_Low, pre_High, low_add, high_loss)
# tune_strategy 返回 best_parameters 与按利润降序的字典
```
思路是把预测误差转成可调容差阈值：买价加容忍溢价 `low_add`、卖价加减容忍折让 `high_loss`。

3）阈值 + 成本联合类（HMM/择时适用，最大化含成本回报）
```
FR = np.log(R) + T * np.log(1 - f)     # R=策略收益矩阵，T=交易次数矩阵，f=单边摩擦率
ix = np.argmax(FR); i1 = np.mod(ix, res)   # 反解出 (Buy_Price, Sell_Price) 下标
```
对每一档摩擦率 f 独立寻优一次，输出 100 组阈值对。

4）结构参数类（ARIMA 阶数）
```
for order in [(1,1,1), (1,0,0), (5,0,5)]:
    run_simulation(returns, prices, amt=1000, order=order, thresh=t)
```
结论：提高 ARIMA 阶数并不改善效果，反而使滚动重估成本剧增（ARIMA(5,0,5) 169 次迭代约 2 分钟）且频繁报 Schur decomposition solver error。

其他必备配套：
- 早停配置（XGBoost）：`early_stopping_rounds=10`、`eval_set=[(X_train,y_train),(X_test,y_test)]`、`eval_metric=['error','logloss']`，用 `history.evals_result_['validation_0'/'validation_1']['logloss']` 画训练/测试双曲线诊断过拟合。
- 随机种子固定（原文统一 `random_state=42` / `seed`）保证可复现。
- 特征选择与调参的先后：先 `SelectKBest` + p<0.05 过滤，再在筛选后的特征上跑多族模型横评。

## 关键参数
| 场景 | 参数空间 | 原文取值 |
|---|---|---|
| HBGB（AAPL 周收益二分类） | learning_rate 对数均匀 0.001~0.1；max_iter 100~1000；max_leaf_nodes 2~100；max_depth 1~10；min_samples_leaf 1~15；l2_regularization 1e-4~0.1 | 1000 trials，方向 maximize AUC |
| CatBoost | learning_rate、depth、l2_leaf_reg、random_strength、bagging_temperature、border_count、min_data_in_leaf | 最优组合为很浅的树 depth=2 |
| XGBoost（GOOG 方向） | max_depth ∈ {18,21,25}；reg_lambda ∈ {0.1,0.4,0.8}；cv=3 | 网格选中 max_depth=25、reg_lambda=0.1 |
| 集成投票权重 | 每个基模型权重 ∈ [0,1] | 最优约 HBGB 0.889、CatBoost 0.363 |
| 交易容差阈值（黄金） | low_add、high_loss ∈ [0,5)，步长 0.1 | 最优组合由累计利润排序得到 |
| 择时阈值（HMM） | (Buy_Price, Sell_Price) ∈ [-0.1, 0.1]，res=200，仅遍历 sell ≤ buy | 每档摩擦率一个最优对 |
| 摩擦率扫描 | friction ∈ [0, 0.02] | 100 档 |
| 开仓阈值（ARIMA） | thresh ∈ {0, 0.001, 0.005, 0.01, ...} | ARIMA(1,0,0)+0.001 回报 44% |
| 调参纪律 | 参数个数、验证方式 | 参数 >5 个即危险；时间序列 CV，回测覆盖牛熊震荡 |

## 依赖
optuna（create_study / study.optimize / best_params）、sklearn（GridSearchCV、cross_val_score、roc_auc_score、roc_curve、VotingClassifier、StackingClassifier、SelectKBest/f_classif）、xgboost/catboost/lightgbm、statsmodels（ARIMA）、numpy、pandas。

## 适用条件
- 有明确的单一主指标：必须先定主指标再调参——同一模型在 Accuracy 与 ROC-AUC 下的排序可能相反（加权软投票准确率 59.5% 最优但 AUC 更低）。
- 目标函数能表达业务意图：策略类调参优先用累计利润或 Sharpe，而不是分类准确率；成本敏感场景用 `log(R) + T*log(1-f)`。
- 低信噪比金融分类任务：浅树（depth=2）在调优中胜出，可作为先验起点；深树容易过拟合。
- 有独立验证集（或样本外滚动窗口）可做最终确认。

## 不适用条件
- 用测试集当优化目标：Optuna 目标函数直接返回测试集 AUC（或集成权重在测试集上评 Accuracy）会让测试集参与调参，产生乐观偏差；必须切出独立验证集或嵌套验证。
- 用随机 K 折对时序任务调参：会引入信息泄露，须改时间序列 CV 或滚动前向。
- 参数个数超过 5 个仍继续网格搜索：过拟合风险迅速上升。
- 参数前后不一致：原文一处网格选出 reg_lambda=0.1，最终训练却用 0.8，这类不一致会让"最优参数"结论失效，必须让最终训练严格使用 `best_params`。
- 把分类指标当策略结论：AUC 0.55~0.58、准确率 0.55（类别 0 召回仅 0.33）已接近随机，此时继续调参的边际收益极低，应先解决特征与标签问题。
- 只报最优值不报稳定性：同一批数据上一次性选出的最优参数若无跨期/跨成本档复核，不能判断稳健性。
- 目标函数不含成本时做高频调仓策略的参数选择：未扣除摩擦的寻优结果本身偏乐观。

## 验证状态
原文给出真实运行结果：
- AAPL 周收益二分类（Optuna 1000 trials，目标测试集 ROC-AUC）：HBGB 由 0.51 提升到 0.55（试验分数在约 0.47~0.55 间波动）；CatBoost 由 0.51 提升到 0.58，最优组合为 depth=2 的浅树。
- 集成权重搜索：最优权重约 HBGB 0.889、CatBoost 0.363，加权软投票测试集准确率 59.5%（原文标注为至今最好），但其 ROC-AUC 反而更低；首次评估中硬投票 ROC-AUC 0.57 为最好，软投票与堆叠分数未给出。
- XGBoost 网格调参（GOOG 方向）：网格选出 max_depth=25、reg_lambda=0.1，但实际训练用 reg_lambda=0.8（原文未解释）；测试集 1211 条分类报告 accuracy 0.55、类别 0 precision 0.71/recall 0.33、类别 1 precision 0.49/recall 0.83，明显偏向预测类别 1。
- 黄金跨日策略阈值网格：初始资金 1000，默认参数 (0,0) 利润约 111，调参后约 245，理想上界约 497；原文自称 3 个月获得超过 20% 的利润（无样本外验证）。
- ARIMA 阈值实验（BTC，169 个交易日）：ARIMA(1,1,1)+阈值 0.01 → 1000 增至约 1060.22；ARIMA(1,0,0)+阈值 0.001 取得 44% 回报；对照"上一期收益为正就买入"约亏损 5%。
