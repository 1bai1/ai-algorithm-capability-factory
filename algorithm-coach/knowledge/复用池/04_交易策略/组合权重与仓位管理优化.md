# 组合权重与仓位管理优化

## 能力说明
在两个层次上决定"买多少"：组合层用均值-方差/最小方差/有效前沿求各标的权重，仓位层用固定比例、波动率反向、最大回撤熔断等规则约束单笔与总暴露。附带组合风险度量（相关性、年化波动、夏普、Beta）作为前置检查。

## 输入契约
- 组合层：多标的日频收益率矩阵 `returns`（列=标的，含基准指数列，如 GSPC/S&P 500 或 399300）。原文样本：GOOG/AAPL/META/AMZN/MSFT/GSPC 六列。
- 年化因子必须显式：美股一年约 252 个交易日、一月约 21 个交易日。无风险利率须显式设定（原文默认 rf = 0.025）。
- 最小方差路线（PyPortfolioOpt）需要每期的收益率协方差矩阵 `Sigma`（原文从数据集的 `return_list` 字段取 `df_temp.return_list[0].cov()`）。
- 先做分散化前置检查：算收益率相关热力图，高相关资产堆叠时不要进优化。

## 输出契约
- 权重向量（各标的小数权重，和=1），与标的代码顺序对齐。
- 组合绩效三元组：年化预期收益、年化波动率、夏普比率。
- 可视化：散点云（横轴年化波动、纵轴年化收益、颜色为夏普）+ 有效前沿曲线 + 最大夏普（红星）/最小方差（绿星）标记。
- 组合净值：`(账户价值.pct_change() + 1).cumprod() - 1`，与基准指数曲线同图对比。

## 调用方式
PyPortfolioOpt 最小方差（最简）：
```
from pypfopt.efficient_frontier import EfficientFrontier
ef = EfficientFrontier(None, Sigma, weight_bounds=(0, 0.1))   # 0.1 上限强制分散
w  = ef.clean_weights()
```
日频组合推进（原文账户价值递推）：`shares = 资金 × 权重 / 当日 close`；`下一期账户价值 = Σ shares × 次日 close`；`initial_capital = 1000000`，按 `for i in range(len(unique_trade_date)-1)` 逐日循环。

自实现均值-方差三目标（scipy）：
```
expected_returns = np.sum(mean_returns @ w) * 252
expected_vol     = np.sqrt(np.dot(w.T, sigma @ w)) * np.sqrt(252)
# 最大夏普：目标函数取 -(return_p - rf)/vol_p 交给 minimize
# 约束：({'type':'eq','fun': lambda x: np.sum(x)-1})；bounds=((0,1),)*n_assets；method='SLSQP'
# 初值：np.random.dirichlet(np.full(n_assets, 0.05)).tolist()
```
- 组合云模拟：Dirichlet（浓度 `np.full(n_assets, 0.05)`）随机生成 2673 组权重，逐组算收益/波动/夏普。
- 有效前沿：对目标收益网格 `np.linspace(return_min, 1.02, 100)` 逐点求最小波动，双等式约束（组合收益=target、权重和为 1）。
- 风险度量（组合前置检查）：
  - 年化波动率 `returns[col].std() * np.sqrt(252) * 100`，月度用 `np.sqrt(21)`；
  - 夏普 `(serie.mean()*252 - rf) / (serie.std()*np.sqrt(252))`，rf 默认 0.025；
  - Beta `cov.iloc[资产, 市场] / cov.iloc[市场, 市场]`（对月度协方差乘 12 年化后取比值等价）。
- 仓位与风控规则（跨多篇汇总，可直接落成参数表）：单标的仓位上限、波动率反向调仓、固定比例/波动率止损、最大回撤熔断、持仓只数上限。

## 关键参数
| 参数 | 含义 | 原文取值 |
|---|---|---|
| weight_bounds | 单资产权重上下限 | (0, 0.1)，上限 0.1 强制分散 |
| 无风险利率 rf | 夏普计算 | 0.025（年化）；注意原文组合云模拟用 0、优化用 0.025，口径不一致 |
| 年化因子 | 日→年 | 252（年）/ 21（月） |
| 模拟组合数 | 组合云 | 2673 组（Dirichlet 浓度 0.05） |
| 有效前沿网格 | 目标收益 | `np.linspace(return_min, 1.02, 100)` |
| 求解器 | 优化 | SLSQP |
| 单标的仓位上限 | 风控 | ≤10%（LSTM 量化）；单笔仓位 ≤5%（交易模型） |
| 单笔止损 | 风控 | 单笔亏损达 5% 平仓；单日亏损 ≤ 总资产 1% |
| 杠杆上限 | 风控 | ≤2 倍 |
| 最大回撤熔断 | 风控 | 亏损 10% 暂停（资产定价文） |
| 持仓集中度 | 风控 | 同时持仓不超过 5 只 |
| 调仓触发 | 再平衡 | 定期（月/季）+ 触发式（跌幅超阈值、VIX 飙升） |
| 波动率调仓 | 仓位 | 高波动降低仓位上限，低波动提高 |

## 依赖
pandas、numpy、scipy.optimize.minimize、matplotlib/seaborn（相关性热力图）、PyPortfolioOpt（`pypfopt.efficient_frontier.EfficientFrontier`、`pypfopt.risk_models`）、plotly（累计收益曲线）。

## 适用条件
- 多标的组合配置，标的间相关性不过高（先看收益率相关热力图再决定是否优化）。
- 需要一条"不依赖预测、只用历史协方差"的静态基线对照策略时（最小方差是原文 DRL 项目的对照基线）。
- 组合规模适中、调仓频率可承受成本时（原文为日频，实际换手成本需自行压力测试）。

## 不适用条件
- 高相关资产堆叠：原文实测 S&P 500 与微软、亚马逊与微软、微软与谷歌、谷歌与苹果均强正相关，分散化空间有限；此时优化出来的权重看着分散、风险却没降。
- 均值-方差直接吃历史均值：对输入估计误差极敏感（历史均值噪声大），原文未做收缩估计、重采样稳健性检验或样本外验证，最优权重易过拟合。
- 每日按收盘价无成本调仓：原文完全未考虑交易成本、滑点、印花税与最小交易单位，日频换手会显著侵蚀最小方差组合收益。
- 只看累计收益一条线：原文最小方差部分只有累计收益对比，缺波动率、夏普、最大回撤，无法判断"最小方差"目标是否真的降低了风险。
- 无风险利率前后不一致地使用（模拟用 0、优化用 0.025）会让散点颜色与最优点标准不同源。
- 需要真实冲击成本建模的机构级执行：VWAP/TWAP/冰山/智能路由在原文只有概念，实例仅用固定滑点与佣金近似。

## 验证状态
原文给出真实运行结果：
- 组合优化（美股 GOOG/AAPL/META/AMZN/MSFT/GSPC，日频）：最大夏普组合权重以 MSFT 0.4695、AAPL 0.2695、AMZN 0.2096 为主，年化收益 23.16%、波动 24.31%、夏普 0.8496；最小方差组合以 GSPC 0.6434 为主，收益 15.23%、波动 18.97%、夏普 0.6713。
- 单资产风险度量：年化波动率 META 40.12% 最高，AMZN 32.28%、AAPL 29.07%、GOOG 26.82%、MSFT 26.76%、S&P 500 17.39%（月度口径同序，META 11.58% 最高、GSPC 5.02% 最低）；Beta：GOOG≈1.12、AAPL≈1.17、META≈1.20、AMZN≈1.13、MSFT≈1.19、GSPC=1.0；S&P 500 夏普约 0.53，原文结论为微软风险调整后相对更优。
- 注意原文自身口径问题：正文称"夏普比率最高（0.953%）"与权重表的 0.8496 不符；模拟阶段 rf=0 与优化阶段 rf=0.025 不一致。
- 最小方差（PyPortfolioOpt 路线）：原文只给了三条累计收益曲线（A2C 组合、最小方差组合、道指基准）的对比方式，未给出具体收益数字。
