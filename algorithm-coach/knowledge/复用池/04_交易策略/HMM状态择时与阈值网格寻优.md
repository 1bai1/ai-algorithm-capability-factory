# HMM 状态择时与阈值网格寻优

## 能力说明
用隐马尔可夫模型从价格序列推断市场隐藏状态（快速增长/慢增长/下降），把状态后验概率与转移矩阵合成为"期望异常收益率 EAR"，再对 EAR 设买入/卖出双阈值做满仓/空仓择时。核心资产是三段可复用的工程件：EAR 的构造、双阈值在二维网格上以收益（含成本）为目标寻优、按摩擦率分档的稳健性检验。

## 输入契约
- 单标的日频价格序列（原文为比特币日频 `BC_Prices`，日频序列可由交易所 1 分钟 CSV 按日取 `Weighted_Price` 均值聚合得到）。
- 时序切分：训练只能取序列连续前段，禁止随机切分。原文取第 100 天到第 600 天共 500 天训练，第 600 天起为"未见过"的测试段。
- 模型输入特征为对数收益率 `R = np.log(Prices[1:] / Prices[:-1])`。
- 需要预先确定状态数：原文固定 3 状态，并用各状态收益率均值的符号校验解释是否合理（快速增长 / 慢增长 / 下降）。
- 样本量：原文训练 500 天；模拟数据路线用到 5000 天。

## 输出契约
- 训练集寻优输出：收益矩阵 `R`（res×res）与交易次数矩阵 `T`（res×res），索引对应阈值对 (sell, buy)。
- 测试集回测输出：`Portfolios`（100 × n × 2，记录每日现金与持仓数量）与 `Value`（100 × n，各摩擦率下的逐日净值）。
- 每档摩擦率给出一个最优 (Buy_Price, Sell_Price) 阈值对。
- 模型侧输出：状态收益率均值 MU、3×3 转移矩阵 P、自回归系数 beta，以及逐时点隐藏状态概率与 EAR 序列。

## 调用方式
1. 拟合 HMM（类 `MHH`）：
```
mdl.fit_HMM(Prices, nstarts=10)            # 内部：log 收益率 + scipy.optimize.minimize 多起点求 NLL 最小
probs = mdl.get_hidden_state_probabilities(Prices)
EAR   = mdl.get_expected_abnormal_rates(Prices)   # 由状态概率与转移矩阵计算，择时只使用 EAR
```
NLL 非凸，必须用多个随机初值（nstarts=10）重复优化后取最优。
2. 双阈值状态机（只做多、单标的、不加杠杆）：
```
a='c'; pc=1; pb=0; ntrades=0
if a=='c' and EAR[t] > Buy_Price:   pb = pc / Prices[t]; pc = 0; a='b'; ntrades += 1
if a=='b' and EAR[t] < Sell_Price:  pc = pb * Prices[t]; pb = 0; a='c'; ntrades += 1
```
3. 训练集二维网格寻优：`X = np.linspace(-0.1, 0.1, res)`，`res=200`，双层循环且只遍历 `sell ≤ buy` 的组合（`i` 从 `j` 到 `res`），按训练期收益取最大者。
4. 含成本的寻优目标（模拟数据路线）：`FR = log(R) + T * log(1 - f)`，把交易次数 T 与单边摩擦 f 显式并入适应度；用 `ix = np.argmax(FR)` 后 `i1 = np.mod(ix, res)` 反解阈值下标。
5. 摩擦分档回测：`friction = np.linspace(0, 0.02, 100)`，对 100 档各自寻优一次阈值，再画"摩擦率—对数回报"曲线；单档净值用 `V1[i, train_end:] / V1[i, train_end]`，i=25/50/75 分别对应 0.5%/1%/1.5%。
6. 必须并列三条对照曲线：HMM 阈值策略、前一天趋势跟随、直接持有比特币。
7. 状态语义复核：把价格取对数归一化到 [0,1]，与三个状态概率曲线叠加观察。

## 关键参数
| 参数 | 含义 | 原文取值 |
|---|---|---|
| 状态数 | 隐状态个数 | 3（原文未做 BIC/AIC 检验，属人工设定） |
| nstarts | 多起点优化次数 | 10 |
| 训练窗口 | 训练段 | 第 100–600 天（500 天） |
| res | 阈值网格密度 | 200 |
| 阈值区间 | EAR 双阈值搜索范围 | [-0.1, 0.1] |
| 约束 | 阈值关系 | sell ≤ buy |
| friction | 摩擦率扫描 | `np.linspace(0, 0.02, 100)`，100 档；压力档取 0.5%/1%/1.5% |
| 初始资金 | 账户起始 | 1（货币单位） |
| 寻优目标 | 适应度 | 训练期收益；另一路线为 `log(R) + T*log(1-f)` |
| 仓位 | 暴露 | 全仓/空仓二值，无杠杆、无仓位梯度 |

## 依赖
numpy、scipy.optimize.minimize、matplotlib；模拟数据路线用 numpy.random。

## 适用条件
- 单标的日频择时，标的存在明显的上涨/下跌状态切换。
- 需要"把模型输出的连续打分变成开关型仓位"的场景：EAR 天然适合做双阈值信号。
- 需要把交易成本显式纳入参数搜索的场景：该网格框架能直接给出"成本越高、阈值越宽"的回答。

## 不适用条件
- A 股照搬前需重定义状态与执行假设：比特币 7×24 连续交易，A 股有 T+1、涨跌停与休市（原文明确提示）。
- 高摩擦环境：摩擦升至 1% 以上时策略优势基本消失，该形态的实盘可用性存疑。
- 样本太小：500 天小样本 + 非凸优化下状态划分可能不稳定，且原文未做滚动/样本外重估。
- 用模型自产模拟数据来调参：原文明证此路不通——HMM 自采样序列与真实价格统计特性差异大，在其上优化的阈值样本外效果远不如真实数据上的阈值，中高摩擦下策略干脆不交易；原计划的强化学习优化也因此放弃。
- 直接采用单次训练期最优阈值而不做滚动重估：原文自述训练期最优不保证测试期最优，存在策略选择偏差。
- 追求精细决策的场合：原文自陈模型设定对结果影响很大（去掉 r 的自回归项 beta*r(t-1) 后状态过于简单；状态切换过快时 2 状态模型会退化为区分"增长/快速增长"而非"增长/衰退"）。

## 验证状态
原文给出真实运行结果（BTC 日频，训练第 100–600 天，测试自第 600 天起、初始 1 美元）：
- 样本外 HMM 阈值策略收益始终高于"前一天趋势跟随"与"直接持有比特币"两个基准；随摩擦率上升，相对直接持有比特币的优势逐渐收敛至零。
- 0.5% 摩擦下能更快跟涨并回避部分下跌；高摩擦下只能部分避损。
- 100 档摩擦率最终只落地 3 组不同阈值，"收益—摩擦率"曲线呈分段线性；摩擦率越高，最优买卖阈值间距越大（要求更极端的信号才动手）。
- 拟合示例：MU = [0.0787, 0.0014, -0.0859]（对应快速增长/慢增长/下降，符号与解释一致），beta ≈ 0.184。
- 原文未给出收益、夏普、最大回撤等定量数字，只有图形描述，且部分配图未收录；代码片段多处被截断，无法完整复现。基准策略与含摩擦策略本身不依赖 HMM，HMM 在该项目中定位为特征提取器而非价格预测器。
