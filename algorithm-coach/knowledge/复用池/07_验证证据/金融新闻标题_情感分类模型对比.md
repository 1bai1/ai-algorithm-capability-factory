# 金融新闻标题 × 情感分类模型对比

## 能力说明
本卡把同一任务（英文金融新闻标题的三分类/二分类情感识别）上五条技术路线的真实准确率合并记录：词向量+传统分类器、Keras LSTM、FinBERT 微调、Llama-2-7B+LoRA、Gemma+LoRA。用途是给"情感分析到底能做到什么水平、代价是什么"提供可对照的数字。

## 输入契约
- 语料（多套，来源不同、不可混用）：
  1. Financial PhraseBank 风格 all-data.csv（字段 sentiment/text），用于 FinBERT、Llama-2、Gemma；
  2. 自标注新闻标题集 2146 条（标签列 perc_sent，96/300 维句向量）；
  3. 专家标注集 newsdata_labelled_v3.csv 9470 条（字段 datetime/headline/ticker/sentiment，覆盖 12 只以上美股）；
  4. FinancialNewsHeadline.csv 4846 条（neutral 2879 / positive 1363 / negative 604，来源前序章节）；
  5. 舆情交易项目主表：RSS 标题 110711 条 → 与 12 只美股 2010–2018 行情按 date+ticker 左连接，清洗后 3142 行 × 5 列（ticker/headline/date/eventRet/Close）。
- 标签来源：标题中的百分比数字（perc_sent 的 True/False 分别为 1429 / 589，另有 1124 条缺失）、TextBlob 极性、财报 beats/misses（177 行）。
- 事件收益 eventRet = 事件日与次日收益之和（由收盘价 pct_change 得到）。

## 输出契约
- 分类指标：accuracy、逐类准确率、classification_report（精确率/召回/F1）、混淆矩阵；交叉验证给出 cv 均值与标准差。
- 情感分列：sent_blob（TextBlob 极性）、vader_sent（定制金融词典的 VADER 分数）、lstm（深度模型推断标签）可与 eventRet 做逐 ticker 相关。
- 交易侧：情感分与事件收益的关系用散点图与相关矩阵呈现。

## 调用方式
```
# 词向量 + 传统分类器
evals = nlp_evals(df=ldf, corpus='headline', label='perc_sent', spacy_model='en_core_web_sm'|'en_core_web_lg')
evals.tts(); evals.define_models(models); evals.kfold(); evals.plot_results()
# FinBERT
AutoModelForSequenceClassification.from_pretrained("ProsusAI/finbert", num_labels=3)
finbert_tokenizer.batch_encode_plus(..., max_length=150, return_attention_mask=True, pad_to_max_length=True)
# Llama-2 4bit + LoRA
AutoModelForCausalLM.from_pretrained(model_name, quantization_config=BitsAndBytesConfig(load_in_4bit=True, bnb_4bit_quant_type="nf4", ...))
SFTTrainer(model=model, peft_config=LoraConfig(r=64, lora_alpha=16, lora_dropout=0.1, target_modules="all-linear"), args=TrainingArguments(num_train_epochs=3, ...))
# VADER + 金融词典
SentimentIntensityAnalyzer() 合并 lexicon_sentiment.csv → 逐条打分
```

## 关键参数
- 传统分类器：LogisticRegression / KNeighborsClassifier / DecisionTreeClassifier / SVC / RandomForestClassifier；90/10 划分 + 4 折交叉验证；spaCy en_core_web_sm（96 维）/ en_core_web_lg（300 维）静态词向量取平均。
- Keras LSTM：词表 20000、最大长度 50、100 维可训练嵌入、二元交叉熵 + Adam、10 epoch、160 步/epoch；先 90/10，再在训练集内 60/40 切验证。
- FinBERT：max_length=150、batch_size=5、AdamW(lr=1e-5, eps=1e-8)、线性 warmup、epochs=2、85/15 分层划分（random_state 2022）。
- Llama-2-7B：4bit nf4 量化 + LoRA r=64/alpha=16/dropout=0.1/all-linear、3 epoch、batch 1、梯度累积 8、paged_adamw_32bit、lr=2e-4；测试集 900 条（每类 300）。
- Gemma：1B 基座 + LoRA，训练 900 条、测试 900 条、评估集每类约 50 条。

## 依赖
TextBlob、nltk（VADER）、spaCy（en_core_web_sm/lg）、scikit-learn、TensorFlow/Keras、transformers/PEFT/TRL/bitsandbytes/torch、pandas、plotly。

## 适用条件
- 英文财经新闻标题级情感识别，样本 900–9500 条；需要选型"传统模型 vs 预训练模型 vs 大模型微调"时可参考本卡的量级与代价。
- 需要"标签源（自动/自标注/专家标注）如何影响结果"的实证参照时，本卡给出三档对照。

## 不适用条件
- 不要横向比较不同语料上的数字：900 条 vs 2146 条 vs 4846 条 vs 9470 条、二分类 vs 三分类，指标不可直接比大小。
- 不要把百分比标签模型当作情感模型：标签直接来自标题中的涨跌幅数字（如 "(WFMI) -5.2%"），模型只要学会读数字即可拿高分，与"情绪能否预测收益"无关。
- 不要把验证准确率 0.97 当作可交易信号：主项目的事件收益相关性检验没有给出任何显著结论，情感与收益的相关系数整体偏低（原文自述"整体偏低，模型难以找到新闻内容与收益之间的关系"）。
- 该系列全部为英文文本，迁移到中文财经语料需重建词典/重训。

## 验证状态
原文给出真实运行结果（各语料口径见输入契约）：
- 词向量 + 传统分类器（30-5）：
  - 专家标注 9470 条 × 96 维：LR cv 0.732841（std 0.004658）、train 0.741640、test 0.725449。
  - 专家标注 9470 条 × 300 维：LR cv 0.871642（std 0.003123）、train 0.896281、test 0.869060，混淆矩阵 [[330, 62], [62, 493]]；原文称 RF/SVM/KNN 同步改善（未给数值）。
  - 自标注 2146 条 × 300 维：LR 0.733817 / 0.834801 / 0.739535；KNN 0.696528 / 0.799586 / 0.693023；CART 0.632300 / 1.000000 / 0.665116；SVM 0.719323 / 0.720870 / 0.772093；RF 0.725531 / 1.000000 / 0.744186。
- Keras LSTM（30-6）：验证准确率第 1 轮 0.9449，后续稳定在 0.97 附近（最高 0.9716），训练准确率升到 0.9996；10 epoch、160 步/epoch。推断结果并入主表形成 ticker/headline/date/eventRet/perc_sent/lstm 六列。
- FinBERT（9-4-2）：4846 条标题、85/15 分层划分（训练 negative 513 / neutral 2447 / positive 1159，验证 91 / 432 / 204）；第 1 轮后即过拟合（训练损失降、验证损失升），取第 1 轮模型逐类正确数：neutral 385/432、negative 81/91、positive 170/204。
- Llama-2-7B（5-5-02）：零样本直接预测 accuracy 0.373（逐类 0.027 / 0.937 / 0.157，混淆矩阵 [[8, 287, 5], [1, 281, 18], [0, 253, 47]]）；LoRA 训练 loss 0.802000 → 0.516500，验证 loss 0.700182 → 0.714122（已现过拟合）；微调后 accuracy 0.847（逐类 0.890 / 0.870 / 0.780，混淆矩阵 [[267, 31, 2], [10, 261, 29], [1, 65, 234]]）；对照基准 Conv1D+双向 LSTM accuracy 0.623（逐类 0.620 / 0.590 / 0.660）。
- Gemma（5-3-02）：零样本整体准确率 0.550（中性类召回 0.14、消极类查全 0.90 但精确率 0.44，macro/加权 F1 约 0.51）；微调后整体 0.853（消极 0.977、中性 0.753、积极 0.830），训练 loss 0.8318860807589122。
- 标签与数据规模（30-2/30-4）：RSS 标题解析后 110711 条记录；按 date+ticker 合并后建模样本 3142 行 × 5 列；百分比标签 True 1429 / NaN 1124 / False 589；beats/misses 事件标签 177 行；自标注建模集约 2146 条、词向量矩阵 2146×96。
- TextBlob/VADER 与收益的关系：原文只给出散点图与相关矩阵，**未给出任何相关系数或显著性数值**，并明确说关系"整体偏低"。

### 可信度评估
- 样本量：小样本集 900–2146 条、大样本集 4846–9470 条；三分类任务下每类 300 条左右的测试集，指标误差范围大。
- 泄漏：① 百分比标签直接摘自标题文本，模型读取数字即可命中标签（这是本任务最大的方法学问题）；② LSTM 的 0.97 验证准确率建立在标签可由标题数字直接推出之上，并非语义情感能力；③ FinBERT/Llama/Gemma 的三套语料与划分互不相同。
- 基准对比：Llama-2 卡有 Conv1D+BiLSTM 基准（0.623）与零样本对照（0.373），是本卡的亮点；其余路线无统一基准。
- 结论稳定性：偏弱。能站住的结论只有两条：标签质量（专家标注 > 自标注）比模型复杂度更重要；预训练大模型零样本直接判金融情感不可用（0.373/0.550），必须微调。其余数字受语料、标签与口径影响，不可跨表比较。本卡按"指标陷阱"标记为有缺陷。
