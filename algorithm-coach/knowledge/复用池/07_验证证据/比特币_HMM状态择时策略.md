# 比特币 × HMM 状态择时策略

## 能力说明
本卡记录"3 状态 HMM 提取市场状态 → 用期望异常收益率 EAR 做买卖阈值择时"在比特币日线上的真实表现：参数估计完整、结论明确（低摩擦有效、高摩擦优势归零、模拟数据寻优失败），但**没有给出任何绝对收益数字**。

## 输入契约
- 数据来源：coinbaseUSD 1 分钟 OHLCV，2014-12-01 至 2019-01-09；另有 bitstampUSD 1 分钟，2012-01-01 至 2019-03-13（无成交的时间戳字段为 NaN）。
- 频率与构造：Unix 秒时间戳转日期 → 按日分组取 Weighted_Price 均值 → 日频价格序列 BC_Prices；缺失日按局部平均插值补齐（2014-12-01~2019-01-07 逐自然日）。
- 切分：必须用序列前段训练，取第 100 天到第 600 天共 500 天；第 600 天之后为样本外测试段。
- 模型输入为对数收益率 R = ln(P_t / P_{t-1})。

## 输出契约
- HMM 参数：beta（自回归项）、MU（各状态收益率均值向量）、P（状态转移矩阵）、隐藏状态概率序列、期望异常收益率 EAR。
- 择时策略：EAR > 买入阈值 → 全仓买入；EAR < 卖出阈值 → 全部卖出；只做多、单标的、不加杠杆、0/1 两态。
- 回测输出：100 档摩擦率下的组合净值 V1（100×n）与持仓 Portfolios（100×n×2），以及三条对比曲线（前一天趋势跟随、HMM 策略、直接持有比特币）。

## 调用方式
```
class MHH: fit_HMM(Prices, nstarts=10); get_hidden_state_probabilities(Prices); get_expected_abnormal_rates(Prices)
R, T = back_train_pol(mdl, Prices)                     # 阈值网格寻优（res=200）
Portfolios, Value = back_test_pol(mdl, friction, Buy_Price, Sell_Price, Prices)
fit = minimize(NLL, 10 个随机初值取最优)                 # scipy.optimize.minimize
```

## 关键参数
- 隐藏状态数 3（语义：快速增长 / 较慢增长 / 下降）；优化起点 nstarts=10；训练期 train_start=100、train_end=600。
- 阈值网格：res=200 个点，范围 [-0.1, 0.1]；摩擦率 100 档，`friction = np.linspace(0, 0.02, 100)`。
- 摩擦率下标 i=25 / 50 / 75 分别对应 0.5% / 1% / 1.5%；初始资金 1 美元；回测窗口从第 600 天起。
- 模拟数据：3 状态 HMM 采样 5000 天，r = beta·r_{t-1} + MU[s] + ε，价格 exp(cumsum(r))。

## 依赖
numpy、scipy.optimize.minimize、pandas、matplotlib、datetime。

## 适用条件
- 日频、单标的、可自由全仓进出的资产；研究者希望把"市场状态"作为特征提取器（而非预测器）来做择时实验。
- 需要研究交易成本如何侵蚀择时收益时，本卡提供了可直接复用的成本敏感性框架（把 f 折算成 (1-f)^交易次数）。

## 不适用条件
- 不能作为生产策略：原文自述训练期最优阈值不保证测试期最优，存在策略选择偏差；且 100 档摩擦率最终只落到 3 组阈值。
- 高摩擦环境下不要用：随摩擦率上升，HMM 策略相对直接持有比特币的优势收敛到零。
- 不要用 HMM 采样数据去调阈值：原文实测失败（状态切换过快，模拟序列与真实数据不像）。
- 无 A 股 T+1/涨跌停/做空约束处理，直接迁移到 A 股需要额外改造。

## 验证状态
原文给出真实运行结果（比特币日频，训练第 100–600 天，测试第 600 天起）：
- HMM 拟合参数：beta = 0.18410712066037063；MU = [0.0787117, 0.00143514, -0.08588966]；P = [[0.24128017, 0.00912846, 0.45111676], [0.64218189, 0.97773754, 0.34719952], [0.11653793, 0.013134, 0.20168372]]。
- 样本外结论（文字表述，无具体收益数字）：HMM 策略总是优于"直接持有比特币"与"前一天趋势跟随"两个基准；但随摩擦率上升，优势与直接持有之间的差距趋近于零；0.5% 摩擦下能更快跟涨并回避部分下跌，更高摩擦下只能部分跟涨/避损。
- 结构特征：检查 100 档摩擦率后只选出 3 组不同阈值，因此"收益-摩擦率"曲线呈分段线性。
- 模拟数据实验：5000 天 HMM 采样数据上寻优的阈值，在中等以上摩擦率下几乎不交易，样本外效果远差于在真实数据上寻优的阈值；原计划的强化学习优化因此放弃。
- 原文未给出任何绝对收益、夏普、回撤或胜率数字。

### 可信度评估
- 样本量：训练 500 天、测试约 900 天，对 3 状态 HMM 勉强够用；模拟实验 5000 天。
- 泄漏：训练/测试按时间切分正确；阈值在训练段寻优后原样用于测试段，属于标准的样本外流程。但"只落地 3 组阈值"意味着泛化路径很窄。
- 基准对比：有两条基准（前一天趋势跟随、直接持有），这是本卡的强项；但三条曲线只有图形，没有数值表。
- 结论稳定性：中等。定性结论（低摩擦有效、高摩擦失效、模拟数据不可用）在原文中被反复确认，可信度较高；任何收益数字都无法引用，因为原文没给。本卡按"记录方法缺陷与失败尝试"标记为有缺陷。
