# 以太坊账户 × 梯度提升非法账户识别

## 能力说明
本卡记录"账户级特征 + 梯度提升树 + 重采样"这一组合在以太坊非法账户识别任务上的真实指标（AUC 0.9802 / F1 0.9596 等）。对本复用池的意义是：在类别不平衡的金融异常识别任务中，重采样 + 树模型的典型表现量级，以及该量级背后的评估陷阱。

## 输入契约
- 数据：以太坊账户级特征数据集（特征构造见该系列前文），原文未列出字段清单，源码与数据集通过网盘提供。
- 训练输入为重采样后的训练集：X_train_ro（oversampling）与 X_train_smote（SMOTE）两套；测试集保持原始分布不重采样。
- 目标：二分类（是否非法账户）；正例在测试集中占比很低（由混淆矩阵可见）。
- 全流程：10 折交叉验证 + RandomizedSearchCV 调参。

## 输出契约
- 评估函数 `model_fit_evaluation2(model_model, params, X_train, y_train, X_val, y_val, algo=None, sampling=None)` 一次输出：最优估计器、最优参数、best_score_、训练集指标、测试集指标、ROC 曲线与 Precision-Recall 曲线。
- 指标清单：AUC、Accuracy、Sensitivity（=Recall=TPR）、Specificity、Precision、F1、混淆矩阵，训练集与测试集分别输出。

## 调用方式
```
rcv = RandomizedSearchCV(model_model, params, cv=10, scoring='roc_auc', n_jobs=-1, verbose=1, random_state=23)
rcv.fit(X_train, y_train)
y_test_prob1 = rcv.best_estimator_.predict_proba(X_test)[:,1]   # 概率（用于 PR 曲线）
y_test_pred  = rcv.best_estimator_.predict(X_test)              # 硬标签
metrics.roc_auc_score(y_test, y_test_pred)                      # 注意：AUC 用的是硬标签
model_fit_evaluation2(model_LGBM, params_lgbm, X_train_ro, y_train_ro, X_test, y_test, 'LightGradientBoosting', 'Over smapling')
```

## 关键参数
- 交叉验证与调参：RandomizedSearchCV，cv=10，scoring='roc_auc'，n_jobs=-1，random_state=23。
- 采样技术：oversampling 与 SMOTE 两种，各与 GradientBoosting / LightGBM / CatBoost 组合，共 5 个"模型 × 采样"实验。
- GradientBoosting 最优参数：learning_rate=0.5、n_estimators=50。
- 原文明说：训练集性能远高于测试集，需警惕过拟合；类别极不平衡时以 Precision-Recall 曲线作补充评估。

## 依赖
scikit-learn（RandomizedSearchCV、metrics、precision_recall_curve）、LightGBM、CatBoost、imbalanced-learn（SMOTE/RandomOverSampler）、matplotlib、pandas。

## 适用条件
- 账户/用户/交易级别的金融异常识别（欺诈、洗钱、非法账户），特征为聚合行为指标、正例占比 <1% 的场景。
- 需要"重采样 + 树模型 + 多指标（含 Specificity 与 PR 曲线）"这套评估模板时可直接复用。

## 不适用条件
- 不要用准确率 98% 作为卖点：测试集正例极少，即使全部判为负类准确率也很高；必须同时看 Recall/F1/PR 曲线。
- 不要沿用原文的 AUC 计算方式：它把 `predict` 的硬标签传给 roc_auc_score，与绘图时用的概率口径不一致，得到的数值不是标准 ROC-AUC。
- 不能把 0.9994 的交叉验证分数当泛化能力：重新采样后同一少数类样本会在多个折中出现，交叉验证分数被抬高。
- 数据集与字段未公开，模型不可直接迁移到其它链或交易所。

## 验证状态
原文给出真实运行结果（以太坊账户级特征，10 折交叉验证，测试集保持原始分布）：
- GradientBoosting（learning_rate=0.5, n_estimators=50）：RandomizedSearchCV 输出 "Fitting 10 folds for each of 10 candidates, totalling 100 fits"，best score 0.9993991240384741，耗时约 72.88 秒。
- CatBoost + SMOTE（测试集）：AUC 0.9802106230517987、Accuracy 0.9827411167512691、Sensitivity 0.9758454106280193、Specificity 0.9846、Precision 0.9439、Recall 0.9758、F1 0.9596；混淆矩阵 TN 766、TP 202、FP 12、FN 5。
- 其余 4 个"模型 × 采样"组合（GB+SMOTE、LightGBM+oversampling、LightGBM+SMOTE、CatBoost+oversampling）原文只描述流程，未给出数值。
- 原文明确提醒：训练集性能远高于测试集，需警惕过拟合。

### 可信度评估
- 样本量：测试集规模很小（混淆矩阵四项合计约千例量级），且正例仅 200 余例，指标置信区间宽。
- 泄漏：重采样发生在训练集内部（X_train_ro/X_train_smote 与 X_test 分离），这一点正确；但 10 折交叉验证在重采样数据上做，折间存在重复少数类样本，使 best_score 0.9994 虚高。评估函数内部又直接使用全局 X_test/y_test，函数签名（X_val/y_val）与实际使用的数据不一致，易误用。
- 基准对比：没有与未采样模型、无信息分类器的对照，无法判断重采样带来的增益。
- 结论稳定性：中等。测试集指标（0.98 系列）可用作量级参照，但需用概率重算 AUC 并补 PR 曲线；训练侧 0.9994 不可引用。
