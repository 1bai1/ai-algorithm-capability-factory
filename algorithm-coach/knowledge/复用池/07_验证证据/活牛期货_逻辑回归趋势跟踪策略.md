# 活牛期货 × 逻辑回归趋势跟踪策略

## 能力说明
本卡记录"周频趋势特征 + 二分类模型 + 满仓多空择时"这条完整链路在 CME 活牛期货上的真实表现，含 AUC、回测收益、夏普、最大回撤与五次最差回撤明细，是本复用池里数字最完整的一条例证。

## 输入契约
- 标的：CME Live Cattle 期货（yfinance 代码 LE=F），周线 2002-03-04 至 2023-05-29，共 1104 行 × 6 列（Open/High/Low/Close/Adj Close/Volume）；早期多周 Volume 为 0。
- 切分：按年份硬切，2002–2012 训练、2013–2023 测试（时间外推，不随机）；训练集特征工程后 465 行 × 35 列，加 target 后 464 行 × 36 列。
- 核心特征：ema8（8 周期 EMA，α=2/(n+1)）与 close_to_ema8_ratio = 收盘价 / EMA8。
- 标签：close_to_ema8_ratio ≤ 0.998 记 0、> 0.998 记 1，再 `shift(-1)` 对齐下一周；训练集正类占比 62.1%；SMOTE(random_state=42) 过采样平衡训练集。

## 输出契约
- 特征选择：SelectKBest(f_classif) 以 p<0.05 筛出 23 列（OHLC 与 Adj Close、价格形态比率、lag1~lag5 比率、9 日/9-20 日波动率、rsi、cci、obv_divergence_5/10_days、returns、close_to_ema8_ratio）。
- 模型输出正类概率 → 依概率八分位表选定阈值 0.607 → 信号 ±1 → `position = sign.shift(1)` → `model_returns = position × returns`。
- 绩效报告：Quantstats `qs.reports.full(model_returns/100, benchmark=buy_hold/100)`，含累计收益、夏普、Sortino、最大回撤、最差 5 次回撤、月收益热图。

## 调用方式
```
clf = LogisticRegression(random_state=42).fit(X_train_best, y_train)
preds = clf.predict_proba(X_test_best)[:, 1]
octiles = np.arange(0, 1.125, 0.125); intervals = np.quantile(y_pred, octiles)
sign = np.where(y_pred > 0.607, 1, -1)
X_test['position'] = pd.Series(sign, index=X_test.index).shift(1)
X_test['model_returns'] = X_test['position'] * X_test['returns']
qs.reports.full(model_returns/100, benchmark=buy_hold/100)
```

## 关键参数
- EMA 周期 8；目标阈值 0.998；SelectKBest 显著性 p<0.05 → 23 个特征；SMOTE random_state=42；分类器 LogisticRegression(random_state=42)；置换重要性 n_repeats=100。
- 信号阈值 0.607（由概率八分位的真实标签分布确定）；仓位用 shift(1) 后移一期。
- 回测假设：无交易成本、无滑点、无保证金约束、始终满仓（Time in Market 100%）、无风险利率 0。

## 依赖
pandas、numpy、plotly、scikit-learn（SelectKBest、f_classif、LogisticRegression、permutation_importance、roc_curve/auc）、imblearn（SMOTE）、quantstats。原文另导入 XGBoost/LightGBM/CatBoost/AdaBoost/RandomForest/GradientBoosting/MLP，但未给出它们的分数。

## 适用条件
- 中低频（周线）、单品种、可做多做空的期货或连续合约；样本 1000+ 周级别的价格序列。
- 适合"趋势跟踪 + 二分类方向"这一范式的可行性演示。

## 不适用条件
- 不能把 62.16% / 夏普 0.75 当作可实现收益：回测不计任何交易成本与滑点，且 Time in Market 100%、无风险利率 0，几乎每周反手。
- 判决阈值 0.607 与目标阈值 0.998 都是在同一段数据上定的，没有样本外重估；单次硬切分不能说明稳健。
- 最大回撤 -39.84%、单段回撤持续 1043 天，风险预算紧的组合不可用。
- 8 个分类器只公布了 LogisticRegression 一个分数，不能据此认为"逻辑回归优于树模型"。

## 验证状态
原文给出真实运行结果（LE=F 周频，训练 2002–2012，测试/回测 2013-05-27 至 2023-05-15）：
- 模型：LogisticRegression 测试集 AUC = 0.887（同一循环里另有 7 个分类器，原文未给出它们的 AUC）。
- 特征比例统计（训练期）：close_to_ema8_ratio 中位数约 1.006144；分位区间平均收益 -2.441034（(0.895, 0.971]）、-0.432414（(0.988, 0.998]）、0.031034（(0.998, 1.006]）、2.680517（(1.033, 1.091]）；训练集正类 62.1%。
- 回测（Quantstats，Strategy vs Benchmark=Buy & Hold）：累计收益 62.16% vs 37.56%；夏普 0.75 vs（基准夏普未给出）；Sortino 1.1；年化波动 44.19% vs 44.21%；最大回撤 -39.84%；时间在市 100%（双方）。
- 最差 5 次回撤（天数 / 最大回撤）：1043 天 / -39.838492；1001 天 / -30.979316；413 天 / -21.498145；553 天 / -15.920119；14 天 / -9.711640（对应 2017-05-01~2020-03-09 等区间）。
- 原文自述后续改进重点是缩短回撤持续时间与幅度。

### 可信度评估
- 样本量：1104 周（约 21 年），训练 465 行、测试段约 520 周，样本量对周频策略够用。
- 泄漏：特征按 train/test 分别计算；标签 shift(-1) 与 position shift(1) 处理正确，未见前视。但特征筛选（p<0.05）、SMOTE、阈值 0.607、模型选择都在训练/验证数据上完成，测试段只用于最终评估，这点较规范。
- 基准对比：有 Buy & Hold 基准，且给出同口径的累计收益/波动，是本池里少数做了基准对比的卡片；但基准夏普、Sortino 未给出，无法逐项对照。
- 结论稳定性：中等偏弱。AUC 0.887 只来自一次切分；策略波动率 44.19% 极高；收益优势（62.16% vs 37.56%）在十年尺度上仅约 1.5 倍，若计入每周反手的交易成本极可能消失。可以用，但必须重新做含成本的回测。
