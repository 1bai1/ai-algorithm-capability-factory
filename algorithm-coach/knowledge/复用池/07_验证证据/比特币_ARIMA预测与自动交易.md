# 比特币 × ARIMA 预测与自动交易模拟

## 能力说明
本卡记录"ARIMA 滚动重估 + 阈值择时"在比特币日线上的自动交易模拟结果：169 个交易日、初始 1000 美元下的几次真实终值，以及阈值/阶数选择对结果的巨大影响。

## 输入契约
- 数据：BTC/USD 日频（yfinance `yf.Ticker("BTC-USD").history` 或本地 BTC-USD.csv）；本地 CSV 全量 2587 条、2015-01-01 起、7 列且无缺失；建模段截取 2020-01-01 之后共 761 行，2020-01-01 至 2022-01-30。
- 建模对象：对数价格（np.log）；ARIMA 用 statsmodels，自动定阶用 pmdarima.auto_arima。
- 训练/测试：按时间顺序 70%/30%，得到训练 533 点、测试 229 点（合计 762 个观测，2020-01-01 至 2022-01-28）。
- 交易模拟段：2021-04-01 至 2021-10-01，共 169 个交易日；初始金额 1000（部分实验用 100）。

## 输出契约
- 定阶输出：各候选 ARIMA 的 AIC 与耗时（trace），最优阶数与 AIC。
- 预测输出：get_forecast(10) 的均值列 + 置信区间两列；walk-forward 验证输出 forecast / lower_interval / upper_interval 三列 DataFrame。
- 模拟输出：逐笔 (方向, 日期, 收益) 事件、最终金额、1000 次重复模拟的终值分布图。
- 评估指标定义：MAPE（平均绝对百分比误差）、MASE（测试集 MAE / 训练集朴素差分 MAE，>1 表示不如朴素预测）。

## 调用方式
```
ARIMA(y, order=(1,1,1)).fit()                       # 手动态
pm.auto_arima(y, start_p=0, max_p=5, start_d=0, max_d=5, start_q=0, max_q=5,
              seasonal=False, trace=True)          # 自动定阶（AIC 最小）
walk_forward_validation(n_train, test)             # 逐点扩展训练集、每次只预测一步
run_simulation(returns, prices, amt, order, thresh, verbose=False, plot=True)
#   order 支持 (p,d,q) / 'last'（上一期收益为正则买）/ float（把 thresh 置空）
```

## 关键参数
- 最优阶数 ARIMA(1,1,1) + 截距，AIC = -2718.121；搜索范围 p/d/q 均 0–5，seasonal=False。
- 模拟函数从 `returns.iloc[14:]` 开始（预留 14 期初始窗口）；每到新日期用截至前一日的全部收益重估模型并预测下一期；预测值 > 阈值才开仓；只有满仓/空仓两态。
- 阈值实验：0.01（配 ARIMA(1,1,1)）、阈值 0.001 / 0.005 / 0（配 ARIMA(1,0,0)）、阈值为 None 的 'last' 规则、ARIMA(5,0,5) 同阈值组。
- 假设：无手续费与滑点、按日收盘价全额成交、只做多不做空。

## 依赖
statsmodels（ARIMA、plot_acf/plot_pacf）、pmdarima（auto_arima）、pandas/numpy/plotly、tqdm、matplotlib/seaborn。

## 适用条件
- 单标的日频、想验证"预测驱动择时"是否优于朴素规则时的对照实验；样本 500–1000 个交易日。
- 需要 walk-forward（滚动重估）框架时可复用 run_simulation / walk_forward_validation 的思路。

## 不适用条件
- 不要采信"44% 回报"当作策略能力：没有手续费与滑点，且同一模型族不同阈值/阶数差异极大（ARIMA(1,1,1)+0.01 只有约 6% 收益）。
- 169 个交易日的样本量太小，任何结论都不稳；ARIMA(5,0,5) 每次重估都要拟合，169 次迭代约 2 分钟并频繁报 Schur decomposition solver error，工程上不可直接用于实盘。
- 日志价格 + 一阶差分只解决了趋势，ARIMA 对波动率聚集/突变无能为力。

## 验证状态
原文给出真实运行结果（BTC/USD 日频，模拟段 2021-04-01~2021-10-01，169 个交易日，初始 1000）：
- 定阶：auto_arima 逐步搜索，最优 ARIMA(1,1,1)(0,0,0)[0] 带截距，AIC = -2718.121；对比候选 ARIMA(0,1,0)+截距 AIC -2711.370、ARIMA(1,1,0)+截距 -2714.174、ARIMA(0,1,1)+截距 -2713.778、ARIMA(2,1,0)+截距 -2713.663 等。
- ARIMA(1,1,1) + 阈值 0.01：1000 美元 → 约 1060.22 美元。
- ARIMA(1,0,0) + 阈值 0.001：实现 44% 回报（原文称"非常出色"）。
- 纯规则对照 'last'（上一期收益为正就买）：1000 美元总体亏损约 5%。
- 1000 次重复模拟（初始 1000、阈值 0.5）用于画终值分布图，未给出分布统计数字。
- ARIMA(5,0,5)：169 次重估耗时约 2 分钟，过程中反复出现 Schur decomposition solver error。
- 数据侧：本地 CSV 2587 条、7 列、无缺失；截取 2020 年后 761 行；训练 533 / 测试 229。

### 可信度评估
- 样本量：训练 533 点、模拟 169 天。对 ARIMA(1,1,1) 参数个数而言够用，但 169 天的样本外长度不足以支撑任何收益结论。
- 泄漏：run_simulation 每次只用 `returns[:date]` 重估，属严格样本外滚动，这一点规范；但阈值 0.01/0.001 是在同一段数据上挑出来的，含选择性偏差。
- 基准对比：有 'last' 动量规则对照（约 -5%），但没有与"直接持有比特币"在同一模拟函数下的对照数字（原文在另一章只做了持有曲线）。
- 结论稳定性：差。同一项目内 ARIMA(1,1,1) 与 ARIMA(1,0,0) 给出的回报从 ~6% 到 44%，说明结果对阶数与阈值极端敏感；无成本假设进一步高估收益。
