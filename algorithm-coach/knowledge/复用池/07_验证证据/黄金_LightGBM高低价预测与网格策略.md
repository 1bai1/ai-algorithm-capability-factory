# 黄金 × LightGBM 高低价预测与跨日网格策略

## 能力说明
本卡记录"互信息选滞后特征 + LightGBM 回归预测每日 High/Low + 用预测价构造跨日买卖规则"在黄金日线上的真实利润数字，是量化"预测→策略"链路落地效果的一条证据。

## 输入契约
- 数据：黄金日频 OHLCV，2000-08-31 至 2022-10-06，清洗后 5545 行 × 5 列（文件 'gold price - 2000 edited.csv'，剔除开高低收为 0 的异常行）。
- 特征工程三件套：Add_Lag（互信息挑滞后期）、Roll_Stats（滚动均值/统计量，固定 lag=2）、L_moment（滚动窗口上 1–5 阶 L-矩 + 基尼系数）。
- 模型目标：对 Low、High 两列各建一个 LGBMRegressor；预测窗口固定为数据末尾 90 天。
- 训练/检验切分：`data.values[:-90, :-1]`，即留出最后 90 天不做训练。

## 输出契约
- 每个目标列返回：预测值、实际值、MAE/RMSE 评估、预测趋势图。
- 策略函数返回 (模型利润, 理想利润) 二元组；调参函数返回 best_parameters 与按利润降序的字典。
- 组合特征表：对 Open/Close/Volume 一律做同样特征工程并入模；预测 High 时并入 Low 的特征（反之亦然）。

## 调用方式
```
prediction(Data, col, Lag_list, Roll_window, Lmoment_window)   # 内部调用 Prepare_Data
prediction(Gold,'Low',[2,3,4,5],2,5); prediction(Gold,'High',[2,3,4,5],2,5)
trading_strategy(money, pre_Low, pre_High, low_add, high_loss) # 返回(模型利润, 理想利润)
tune_strategy(low_prediction, high_prediction)                # 网格搜索 low_add/high_loss
```

## 关键参数
- 特征：互信息对 Close 评估 100 个滞后取前 10；滞后列表 [2,3,4,5]；Roll_window=2；Lmoment_window=5。
- 模型：LGBMRegressor + verstack 的 LGBMTuner（底层 Optuna）自动调参。
- 策略：第 i 天的预测由第 i-2 天及更早信息完成 → 第 i-1 天低价买入、第 i 天高价卖出；买入条件 `实际低价 ≤ 预测低价 + low_add` 且 `预测低价 + low_add < 次日预测高价`；卖出条件 `实际高价 ≥ 预测高价 − high_loss`。
- 网格：low_add、high_loss ∈ [0, 5)，步长 0.1；初始资金 1000；策略主循环 89 个交易日。

## 依赖
pandas、numpy、lightgbm、verstack（LGBMTuner）、matplotlib。

## 适用条件
- 日频、只做多、以"次日获利了结"为目标的贵金属/商品，样本 20 年以上；可作为"预测结果能否转成利润"的端到端范例。
- 需要研究"参数网格调优能提升多少利润"时，本卡给出了同段数据上调参前后的对照（111 → 245，理想上界 497）。

## 不适用条件
- 不能把 245 或 497 当作可实现收益：未计手续费与滑点；89 天单次回测；参数在同一段数据上用利润网格搜索后再报该段利润，属样本内择优。
- 原文"3 个月获得超过 20% 利润"的结论与数据不符（默认参数利润 111.39 对初始 1000 是约 11%），引用时必须打折。
- 该策略依赖"预测低价买、预测高价卖"的成交假设，真实盘口中高价/低价的先后顺序无法保证（原文自己也因此放弃了日内高低点策略）。
- LGBMTuner 报出的 RMSE 等误差数值原文未给出，无法评估预测精度本身。

## 验证状态
原文给出真实运行结果（黄金日频 2000-08-31~2022-10-06，5545 行；预测最后 90 天；策略回测 89 个交易日，初始资金 1000）：
- 默认参数 (low_add=0, high_loss=0)：模型利润 111.38654507711067，资本 1111.3865450771107。
- 调参后（low_add/high_loss 在 [0,5) 步长 0.1 网格搜索取利润最大）：模型利润 245.00996400255326，资本 1245.0099640025533。
- 理想上界（同样规则下用"最优情形"计算）：利润 497.60533648553314，资本 1497.6053364855331。
- 特征工程参数：Close 的互信息滞后选择评估 100 个滞后、取前 10；Low/High 建模使用 lag=[2,3,4,5]、Roll_window=2、Lmoment_window=5。
- 原文结论段自述"3 个月内获得超过 20% 的利润"，并称模型策略优于简单买入持有。
- 原文未给出 LGBM 的 MAE/RMSE 数值，也未给出买入持有的对照利润。

### 可信度评估
- 样本量：5545 个交易日（22 年）训练充分，但只用最后 90 天做预测、89 天做回测，评估段过短。
- 泄漏：预测用第 i-2 天及更早信息，时点设计正确；但 low_add/high_loss 在回测段上做网格择优，等于用评估段调参，利润 245 是被高估的样本内成绩。
- 基准对比：有"理想上界"（497.6）作为上限参照，但没有买入持有的可比数字，无法判断"优于买入持有"。
- 结论稳定性：中低频、单次回测、无成本。可采信的是"这套流程能在 89 天上产生正向利润，且调参幅度约 2 倍"，不可采信任何年化/胜率类推论。
