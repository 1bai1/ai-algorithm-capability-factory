# 贵州茅台 × GARCH 波动率预测

## 能力说明
本卡记录"用 ARCH/GARCH 族模型对 A 股个股日频收益率做条件波动率预测，并据此算 VaR"这一次真实运行的结果与可信度，供判断该范式能否直接复用到其它 A 股个股。

## 输入契约
- 标的：贵州茅台（600519.SH）日线，close 列；数据文件 maotai_stock_data.csv（Tushare，日期格式 %Y%m%d）。
- 区间与样本量：2020-01-03 至 2023-09-01，共 890 条有效记录；按时间顺序 8:2 切分，训练 712 条。
- 频率：日频。预处理：`np.log(close).diff() * 100`（对数收益率乘 100 放大尺度），dropna。
- 均值方程固定为零（mean='Zero'），只对波动率建模。

## 输出契约
- 条件方差序列 → 开方得预测波动率 σ_pred；可外推未来 N 个交易日（原文示例 30 天，freq='B'）。
- 误差三指标 (mse, rmse, mae)；VaR_95 = 1.645 × σ_pred（95% 置信、z=1.645）；并可标记实际收益低于 -VaR 的超限点。

## 调用方式
```
arch_model(train_returns, vol='ARCH'|'GARCH', p=1, q=1, mean='Zero').fit(disp='off')
fit.forecast(horizon=len(test_returns)).variance.values[-1, :]  # 取条件方差
np.sqrt(...)                                                    # 转波动率
```
评价函数 `evaluate_volatility(actual, predicted, model_name)`，actual 用测试期收益的绝对值近似。

## 关键参数
- 候选阶数：ARCH(1)/ARCH(2)、GARCH(1,1)/(1,2)/(2,1)，按 AIC 选阶；原文推荐默认基线 GARCH(1,1)（3 个参数）。
- 切分：train_size = int(len(df) * 0.8) → 712/178。
- 长期预测 horizon=30；VaR 置信水平 0.95、z_score=1.645。
- 原文未给出 GARCH(1,1) 的 omega/alpha/beta 具体估计值。

## 依赖
pandas、numpy、matplotlib、arch（arch_model）、sklearn.metrics（mean_squared_error、mean_absolute_error）。

## 适用条件
- 单标的日频收益率序列、样本数百到数千条；需要的是一个"波动率/风险"侧指标（VaR、仓位门控、期权定价修正），而不是方向预测。
- 作为 A 股个股波动率建模的入门基线可跑通：数据只要"日期 + 收盘价"。

## 不适用条件
- 不能用于捕捉杠杆效应（原文自述假设波动率对称，对负收益冲击更大这一点无法刻画），极端事件预测能力有限，需要时改 EGARCH/TGARCH。
- 样本仅 890 日、单次 8:2 切分且无滚动重估，不能据此认为参数在其它股票或其它时段稳定。
- 收益率乘 100 会改变似然尺度，跨数据集比较 AIC 时必须口径一致。
- 以 |收益| 作为真实波动率代理本身噪声大，两模型 RMSE 接近时排序不可靠。

## 验证状态
原文给出真实运行结果（贵州茅台 2020-01-03~2023-09-01，890 条，训练 712 条）：
- ARCH(1)：Log-Likelihood -1522.10，AIC 3048.20，BIC 3057.33，No. Observations 712；omega = 4.0098（std err 0.354，t=11.342，p=8.097e-30），alpha[1] = 0.0515（std err 5.713e-02，t=0.902，p=0.367，不显著）。
- 原文以文字结论给出："在本案例中，GARCH(1,1) 的 RMSE 低于 ARCH(1) 的 RMSE"，但**未打印两个 RMSE 的具体数值**；MSE/MAE 同样只有计算结果没有数值。
- ARCH(2)、GARCH(1,2)、GARCH(2,1) 的 AIC 在代码中打印，但收录文本未给出数值输出。
- VaR 部分只有作图与"标记超出 VaR 的极端负收益"，未给出超限次数或 VaR 数值。
- 原文未给出任何交易/回测结果（无手续费、收益、夏普），只到风险指标为止。

### 可信度评估
- 样本量：890 日、单标的，对 GARCH(1,1) 足够，但只有一次固定切分，无滚动重估/多窗口验证，模型选择与评估在同一段数据上完成。
- 泄漏：按时间切分，未见未来信息泄漏；但"用 |测试期收益| 当真实波动率"只是代理，且预测 horizon 覆盖整个测试集长度（一次性多步外推）而非逐日滚动。
- 基准对比：只与 ARCH(1) 对比，且关键对比（RMSE 高低）没有数值，ARCH(1) 的 alpha 显著性地板（p=0.367），说明这一步的结论非常薄弱。
- 结论稳定性：低。可以复用的是"流程与调用方式"；数字层面唯一可采信的是 ARCH(1) 的 AIC/系数与"GARCH(1,1) 略优"的文字结论。
