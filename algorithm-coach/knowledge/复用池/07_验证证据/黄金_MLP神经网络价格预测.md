# 黄金 × MLP 神经网络价格预测

## 能力说明
本卡记录"TA-Lib 全指标 + 滞后 + 滚动统计 → 互信息筛选 → MLP 回归预测金价"的真实误差数字（含逆变换前后两套口径），可用于评估该特征工程机器在贵金属价格回归上的量级。

## 输入契约
- 数据：金价日频 OHLCV，承接 2000-08 至 2022-10 的 Gold 数据集；目标列为 Close。
- 特征构造：Prepare（滞后项 + 滚动窗口）+ Indicator（TA-Lib 全技术指标，先整体 shift(1) 再删除极大值与 NaN 列）+ add_diff（一阶差分）；窗口与滞后范围 1~29（滞后）、2~59（滚动）。
- 切分：丢弃最前面 100 行（窗口特征造成的无效样本）；`X[:-60] / X[-60:]`，即测试集固定为最后 60 个交易日。
- 标准化：X 与 y 各自用 PowerTransformer 拟合；随机种子固定 seed=111。

## 输出契约
- 返回预测结果、实际值与对比表（Close[2] 为实际/预测对照表）；输出逆变换前与逆变换后的 MAE/RMSE。
- 可视化：实际价格与预测价格对比曲线。
- 互信息筛选：对滞后列与目标列计算互信息，保留 MI > mic 的列，其余删除；筛选时只用量纲 <1e6 的列。

## 调用方式
```
Performance_tune(Data, col, Lag_list, Roll_window, mic)   # 14-4：MLP(188→1425→dropout→1)
Performance(Data, col, Lag_list, Roll_window, mic)        # 14-5：9 层 MLP
# 调用示例
Performance_tune(Gold,'Close',[i for i in range(1,30)],[i for i in range(2,60)],3)
Performance(Gold,'Close',[1..29],[2..59],3)
```

## 关键参数
- 滞后 1~29、滚动窗口 2~59、互信息阈值 mic=3；筛选后特征数 188（14-4）。
- 网络（14-4）：输入 188 → Dense(1425) → Dropout → Dense(1)，总参数 270,751（269,325 + 1,426）。
- 网络（14-5）：输入 n_steps（=特征数）→ 8×n_steps(ReLU) → 64(ReLU) → 32(Sigmoid)，全部 he_uniform 初始化；测试集同样取最后 60 个样本。
- 标准化：X/y 各自 PowerTransformer；评估前对 y 逆变换。

## 依赖
pandas、numpy、TA-Lib（talib.get_function_groups）、scikit-learn（mutual_info_regression、PowerTransformer）、TensorFlow/Keras（Sequential、Dense、Dropout）、matplotlib、random（seed 111/21）。

## 适用条件
- 单标的、日频、价格序列 20 年以上（约 5000+ 条），希望用"技术指标 + 滞后 + 滚动统计"做价格回归的场合。
- 可作为"特征选择阈值（mic）如何影响最终误差"的调参实验模板。

## 不适用条件
- 不能把 MAE 8.96 美元当成满意精度：金价在样本末段约 1700–1800 美元，8.96 的相对误差约 0.5%，但这是"用最后 60 天、且输入包含同源滞后价格"的样本内式评估。
- 无朴素基线对照（上一交易日收盘价），无法证明 MLP 比"直接沿用昨日价"更好。
- 互信息筛选在全部数据上计算（切分之前），存在特征选择层面的前视；测试段只有 60 个点，任何指标都极不稳。
- 无交易成本、无策略回测，"3 个月 20% 利润"的声称在本系列中无数字支撑。

## 验证状态
原文给出真实运行结果（黄金日频，目标列 Close，测试集为最后 60 个交易日）：
- 特征与网络规模：筛选后 188 个特征；MLP 结构 Dense(1425) + Dropout + Dense(1)，总参数 270,751（可训练 270,751）。
- 误差（14-4）：逆变换前 MAE 0.016588、RMSE 0.018311；逆变换后 MAE 8.961983、RMSE 9.891533。
- 配置：Lag_list 1→29、Roll_window 2→59、MI 阈值 mic=3、seed=111。
- 14-5 的 9 层 MLP：只给出结构与调用方式，**未给出任何误差数值**。
- 14-1 声称"策略在 3 个月内获得超过 20% 的利润"，属文字结论，无对应数字或回测过程。

### 可信度评估
- 样本量：全量约 5000+ 个交易日，但测试段只有最后 60 天（约 3 个月），评估窗口过短。
- 泄漏：互信息筛选基于全样本（含测试段）完成后再切分，属特征选择前视；滞后/滚动特征本身按 shift 处理，方向正确。训练/测试不是随机切分，顺序正确。
- 基准对比：无。缺"上一期价格"基准与线性基线，只有 MLP 自身两套口径的误差。
- 结论稳定性：不确定。MAE 8.96 在 2000–2022 金价尺度下属可接受量级，但缺少对照与重复运行，不能断言神经网络有效；可复用的是特征工程 + 阈值筛选的管线。
