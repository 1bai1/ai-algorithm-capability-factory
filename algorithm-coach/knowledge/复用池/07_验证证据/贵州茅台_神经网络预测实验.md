# 贵州茅台 × 神经网络预测实验（伪 ARCH 与 MLP）

## 能力说明
本卡记录茅台日线数据上三次"用神经网络预测收益率/波动率/股价"的真实输出，核心价值是它暴露的坑：把单层线性层命名为 ARCH、用 1e-16 的 MSE 当作拟合成功、把收盘价 MSE 当作预测精度，都会误导下游 Agent。

## 输入契约
- 标的：贵州茅台 600519.SH；数据由 `pro.daily(ts_code='600519.SH', start_date='20200101', end_date='20230901')` 获得（maotai_stock_data.csv，字段 ts_code/trade_date/open/high/low/close/pre_close/change/pct_chg/vol/amount）。
- 二套外部特征 macroeconomic_data.csv：同区间市场指数（Market_index）与成交量（Trading_volume）。
- 第三组实验（8-2）用 2008-01-01~2023-09-01 的日线，以 `pct_chg/100` 构造对数收益率，用"t 日收益率 → t+1 日收益率"作样本。
- 因变量构造：`pct_change()` 计算日收益率并删 NaN 后转 PyTorch 张量。

## 输出契约
- 每个模型输出训练损失序列（每 100 轮打印一次）与预测曲线；第三个模型额外输出测试集 MSE 与真实/预测收盘价对比图。
- 原文未给出训练/测试切分比例、标准化方式与随机种子，输出不可复现。

## 调用方式
```
# 所谓 ARCH：只有一个线性层
arch_model = nn.Linear(输入维, 输出维); loss = nn.MSELoss(); optim = torch.optim.Adam(...)
for epoch in range(10000): ...   # 每 100 轮打印 Loss
```
文件划分：maotai.py（取数）、economic.py（取市场指数/成交量）、maofeng1.py（单层线性）、maofeng2.py（加市场指数）、maofeng3.py（预测收盘价）。（8-2）为 DeepMLP：nn.Linear(1,128)→ReLU→(128,64)→(64,32)→(32,1)，Adam(lr=0.001, weight_decay=模型属性)。

## 关键参数
- 训练轮数 10000；每 100 轮打印；损失 MSE；优化器 Adam。
- 原文未给出学习率（DeepMLP 部分为 0.001）、未给出 weight_decay 具体值、未给出批量大小。
- 特征集：第一模型只用日收益率；第二模型加市场指数特征；第三模型用两份数据预测收盘价。

## 依赖
tushare、torch（nn.Linear / nn.MSELoss / optim.Adam）、pandas、numpy、matplotlib；中文字体 SimHei 设置。

## 适用条件
- 只适合作为"跑通 PyTorch 训练循环"的教学示例；如果要复用，最多拿它当输入输出管道的骨架。
- 需要"损失数值极小"以外的实证结论时不要使用。

## 不适用条件
- 不能把本卡的"ARCH"理解为 ARCH/GARCH 波动率模型（它只是对收益率做线性变换，输入与输出同为收益率，没有条件方差结构）。
- 不能引用其 MSE 作为预测精度：损失 1e-16 说明模型把输入几乎原样映射为输出，而不是学到了波动率；收盘价 MSE 2.3159 对应的价格量级约 1700 元，但没有与"直接沿用昨日价"的朴素基线比较，也没有说明测试集大小。
- 加入大盘指数后损失从 ~1e-16 量级跳到 2046，说明未做特征标准化/量纲处理就直接拼接多源特征，该结论"特征越多越差"不能外推。

## 验证状态
原文给出真实运行结果（贵州茅台 2020-01-01~2023-09-01 日线）：
- 模型 1（单层线性拟合日收益率）：Loss 0.5639897584915161（第 100 轮）→ 0.434192031621933（200）→ 0.3285294473171234（300）→ 0.24391025304794312（400）→ 0.17737139761447906（500）；原文给出的最终损失为 1.069562862353439e-16。
- 模型 2（加入大盘指数特征）：Loss 2046.394287109375（100）→ 1810.597412109375（200）→ 1595.75634765625（300）→ 1400.595947265625（400）→ 1223.8880615234375（500）→ 1064.450439453125（600）→ 921.142822265625（700）；原文最终给出的损失仍为 2046.394287109375，并据此判断加特征后性能变差。
- 模型 3（预测收盘价）：Loss 0.0023103163111954927（100）→ 0.0008260658942162991（200）→ 0.0005894469795748591（300）→ 0.00046775813098065555（400）→ 0.0003872515808325261（500）→ 2.469860874043661e-06（9600）→ 6.936197678442113e-06（9700）；测试集 MSE = 2.31587815284729。
- （8-2）DeepMLP 实验：原文只有文字结论（"测试集 MSE 很低、未来回报预测接近零"），**未给出任何数值**；2008-01-01~2023-09-01 日线。

### 可信度评估
- 样本量：约 890 个交易日（5-3）；训练/测试划分未说明，无法判断测试 MSE 用了多少样本。
- 泄漏：无明确前视证据，但也无任何切分说明；MSE 2.3159 很可能在同一段数据上评估。
- 基准对比：无。既没有与买入持有/随机游走比，也没有与"预测值=昨日收盘价"比。
- 结论稳定性：差。1e-16 的损失是恒等映射信号；加特征后损失爆炸说明工程实现有误（未标准化）；原文也自述"MSE 小不等于模型可靠"。本卡按"踩坑记录"标记为有缺陷。
