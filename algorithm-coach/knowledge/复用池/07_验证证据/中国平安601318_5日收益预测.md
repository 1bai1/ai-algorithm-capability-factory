# 中国平安601318 × 5日收益预测（regime shift 判负）

## 能力说明
本卡记录「均线趋势偏离度 + 量价特征 → 逻辑回归方向分类器 → 训练段条件均值映射为期望收益」这条链路在 A 股 601318（中国平安）日线 5 日收益预测上的真实验证结果。harness 20 项检查通过 16、未通过 4，四项判负同一根因：训练段（熊/震荡）与样本外（强牛）市场状态相反，训练段学到的负截距与负条件均值使模型在样本外系统性偏空，样本外方向准确率 0.539 低于「全猜涨」基线 0.578。本卡的价值是**一条被真实数字证伪的路线**，以及 regime shift 下「样本内外差距改善」与「实际预测力」脱钩的实证。

## 输入契约
- 标的与数据：601318.SH 日线 OHLCV + amount，共 2022-01-04 ~ 2025-12-26、966 行；**未复权**（无 adjusted close 列）。
- 切分由 harness 控制，算法不自行切分：cutoff = 2024-07-01，训练段 2022-04-07 ~ 2024-06-28（601 行），样本外 2024-07-01 ~ 2025-12-26（365 行，其中 360 行有真值）。
- 标签：`label = close.shift(-5)/close - 1`（manifest `horizon=5, type=simple`）；harness 用 close 独立重算，961 个标签与算法输出逐行一致（最大偏差 0）。
- 13 个特征：`r1/r5/r10/r20/r60`（log 收盘 1/5/10/20/60 期差分）、`px_ma5/px_ma20/px_ma60`（log close − log 均线）、`vol20/vol60`（r1 的 20/60 期滚动标准差）、`rsi14`（(RSI−50)/50）、`amp`（(high−low)/close）、`vol_ratio`（log(volume / 20 日均量)）。
- 训练段特征缺失值以训练段中位数填充，中位数随模型一起保存供 predict 复用。

## 输出契约
- `predict` 返回长度 = 测试集行数（365）的一维数组，取值 `[-0.01621, 0.0117]`，与收益标签同量纲、全部有限。
- 期望收益映射：`pred = mu_down + p_up × (mu_up − mu_down)`，其中 `mu_up`/`mu_down` 为训练段标签在 `label>0`/`label≤0` 两组的条件均值；`p_up` 为分类器正类概率。
- 策略口径（harness）：预测 > 训练段预测中位数（0.003796）→ 次日建仓、持有 5 日、非重叠；单边成本 0.050%。

## 关键参数
- 特征数 13；分类器 `LogisticRegression(C=best_C, class_weight="balanced", max_iter=2000)` + `StandardScaler`；`C ∈ {0.01, 0.1, 1.0, 10.0}` 由训练段 `TimeSeriesSplit(n_splits=5)` 选（早段单一类别的折跳过）。
- 持仓阈值 = 训练段预测中位数 `0.003796`；持有期 5 日、非重叠；单边费率 0.0005（×2 = 0.001、×3 = 0.0015）。
- `seed=42`、`budget_seconds=300`；实测 `build_features` 0.5s、`fit/predict` 0.7s。
- 市场状态对照（`robustness_check.py`）：训练段 5 日收益均值 **-0.1080%**、上涨占比 **0.433**、零预测 RMSE 3.8812%；样本外 **+0.7942%**、**0.578**、零预测 RMSE 4.1762%、常数均值 RMSE 4.1057%。
- 训练段趋势状态的条件均值（解释模型为何在样本外偏空）：`close>MA20=True` n=242、均值 -0.0283%、上涨占比 0.417；`close>MA20=False` n=359、-0.1618%、0.443；`close>MA60=True` n=229、**-0.5348%**、0.341；`close>MA60=False` n=372、+0.1547%、0.489。

## 依赖
pandas、numpy、scikit-learn（`LogisticRegression`、`StandardScaler`、`TimeSeriesSplit`、`roc_auc_score`、`make_pipeline`）；harness（`harness/contract.py` 契约与 `report.json`/`report.md`）；稳健性核查脚本 `robustness_check.py`。

## 适用条件
- 单标的 A 股日线、5 日 simple 收益标签、可切出 500 行以上训练段的场景，作为「趋势跟踪分类器 → 期望收益映射」链路的**可复现起点**：接口规范 6 项、功能正确性 4/5、运行稳定性 4 项全过，样本内外方向准确率差距仅 1.0pp，工程上是干净的。
- 评估 regime shift 假设时，可复用它作为「样本内外差距小」的对照样本，检验「差距小是否等于有预测力」。
- `px_ma*` 与 `vol*` 特征的构造方式可直接迁移到其它标的（改 manifest 的 symbol 即可）。

## 不适用条件
- **不得当作成功案例复用。** 样本外方向准确率 0.539 低于「全猜涨」基线 0.578 达 3.9 个百分点，RMSE 4.18% 与零预测基线 4.18% 持平，IC -0.019；策略累计 +27.06% 跑不过买入持有 +72.46%，夏普 0.96 < 1.51；harness 结论为「未通过」（16/20）。
- 训练段（熊/震荡）与样本外（强牛）属结构性 regime shift，模型负偏置由训练段决定；换标的、换 cutoff、换时段结论未必成立。
- 未复权收盘价在除权日有向下跳空，会污染 5 日收益标签；生产环境应改用前复权序列。
- 单标的、单 cutoff、单样本外窗口，未做多窗口 walk-forward，任何指标都不可外推。
- 「加大正则」在这条 regime shift 上是错方向：8 特征 + 更强正则的 Ridge 反而使样本内外差距从 13.9pp 恶化到 16.0pp。

## 验证状态
任务目录 `knowledge/任务池/2026-10-01_601318_5日收益预测/` 给出真实运行结果。harness 最终结论：**未通过（通过 16 / 未通过 4 / 跳过 0）**，四个未通过项（朴素基线对比、精度账、交易账、成本敏感度）同一根因。

**接口与功能正确性**：提交物齐全、manifest 合法、模块可导入、契约函数齐全、签名正确、冒烟运行全过；行数守恒 966→966（date 列未改动）；标签口径对账 961 个标签逐行一致（最大偏差 0.00e+00）；截断一致性（反前视）全量与前 676 行两次运行 21 列特征逐行一致（最大偏差 0.0e+00）；预测输出 365 个全部有限，取值范围 `[-0.01621, 0.0117]`。

**精度账（样本外 360 行）**：RMSE **4.18%**（零预测基线 4.18%）；方向准确率 **0.539**（全猜涨 0.578 / 明日=今日 0.483）；IC（Spearman）**-0.019**。

**交易账（样本外，策略 vs 买入持有）**：

| 指标 | 策略 | 买入持有 |
|---|---|---|
| 累计收益率 | **+27.06%** | **+72.46%** |
| 年化收益率 | +17.98% | +45.68% |
| 年化波动率 | 18.99% | 27.49% |
| 夏普比率 | **0.96** | **1.51** |
| 最大回撤 | **-16.53%** | **-21.33%** |
| 胜率（按笔） | 0.531 | — |
| 盈亏比（按笔） | 1.62 | — |
| 年化双边换手 | 26 | — |
| 交易笔数 | 32 | 1 |
| 超额收益 / 夏普差 | -45.40% / -0.55 | — |

回撤约束通过（策略 -16.53% < 买入持有 -21.33% × 1.5 = -32.00%）。

**成本敏感度**：×1（单边 0.050%）+27.06%、夏普 0.96、回撤 -16.53%；×2（0.100%）+24.67%、0.89、-16.70%；×3（0.150%）+22.32%、0.82、-16.87%。成本翻倍后仍不敌买入持有 +72.46%，判负。

**样本内外差距**：方向准确率样本内（训练段）**0.549** / 样本外 **0.539**，差 **+1.0pp**（上限 15）；RMSE 样本内 3.78% / 样本外 4.18%。

**三轮对照**（同一数据与 cutoff）：

| 轮次 | 模型 | 通过 | 样本外方向准确率 | 样本内 | 样本内外差距 |
|---|---|---|---|---|---|
| round0 | 基线 Ridge（13 特征，alpha=10） | 16/20 | 0.458 | 0.597 | 13.9pp |
| round1 | 8 特征 + TimeSeriesSplit 选 alpha 的 Ridge | **15/20** | 0.439 | 0.599 | **16.0pp（越过上限）** |
| round2/3 | 趋势分类器 → 训练段条件均值映射（交付） | 16/20 | 0.539 | 0.549 | **1.0pp** |

round1 说明「加大正则」在这条 regime shift 上把预测进一步压向训练段负漂移；round2 换族后诊断指标（样本内外差距）全面改善，但**仍无预测力**——样本内外差距从 13.9pp 降到 1.0pp，方向准确率却没有超过朴素基线。

**被否决的候选信号**（`robustness_check.py`）：在交付版本之外，探索出 `pred = 训练段波动率中位数 − 当期 vol60` 这一因果信号，在本次样本外窗口表现优异——acc 0.586、RMSE 4.10%、累计 +88%、夏普 1.92，同时通过精度账与交易账。但它的 walk-forward（阈值只用该段之前的数据）显示该信号只在最后一段牛市有效：

| 窗口 | vol60 累计 / 夏普 / acc | 买入持有累计 / 夏普 |
|---|---|---|
| 2022-07-01 ~ 2023-06-30 | **-15.65%** / -0.43 / 0.479 | +53.82% / 0.61 |
| 2023-01-01 ~ 2024-06-28 | **-8.67%** / -0.32 / 0.446 | +52.81% / 0.69 |
| 2024-07-01 ~ 2025-12-31 | +27.88% / 1.07 / 0.575 | +73.65% / 1.52 |

（vol20 同向更差：-17.06% / -4.68%；vol120 为 +5.44% / -6.53%，同样只有末段有效。）该候选是**看着样本外结果挑出来的**，故不交付。

### 可信度评估
- 样本量：全样本 966 行，训练 601 行、样本外 365 行（360 行有真值）。日频、单标的，对「5 日 horizon、32 笔交易」的策略评价偏少，胜率/盈亏比的置信区间很宽。
- 泄漏：未见前视。特征全部为当期及滞后的滚动量；训练段中位数填充；正则强度 C 由训练段内层 TimeSeriesSplit 选，不接触样本外；标签口径经 harness 独立重算对账；截断一致性检查通过。但**信号选择阶段消费了样本外**——vol60 候选正是用样本外表现反选出来的（已否决、未交付）。
- 基准对比：完整。harness 内置「全猜涨 / 明日=今日」朴素基线与买入持有基准，并给出成本 ×1/×2/×3 敏感度，本卡据此判定模型无预测力、策略跑输持有。这正是本任务判负可信的原因。
- 结论稳定性：弱。单标的、单 cutoff、单样本外窗口，且样本外恰好是强牛段（买入持有 +72.46%、夏普 1.51），训练段是熊/震荡段，二者状态相反。被否决的 vol60 信号在三个 walk-forward 窗口中只 1 个有效，说明该窗口的结论本身不稳。**本卡的每一条数字都不可外推到其它标的或时段**，它只证明「在这一次 regime shift 上，静态监督模型被全猜涨基线判负」。
