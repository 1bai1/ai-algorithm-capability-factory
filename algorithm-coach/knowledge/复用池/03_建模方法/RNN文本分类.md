# RNN 文本分类：LSTM 与双向编码

## 能力说明

把文本视为序列、按位置递推建模的分类模型族：每个词先转成词向量，逐个送入循环单元，参数在所有位置共享，最终用末层隐状态预测类别。它天然捕获长距离依赖与词序信息，但**必须按序计算、不能并行**——综述把它列为 RNN 在"模型越来越深、参数越来越多"趋势下难以成为主流的根本原因。梯度连乘导致的梯度消失用 LSTM 缓解（一个记忆单元 + 输入/遗忘/输出三个门），LSTM 的遗忘门能过滤无用信息、更好捕获上下文词之间的联系。代表实现：LSTM/BiLSTM、Tree-LSTM（结构树化）、BLSTM-2DCNN（BiLSTM + 二维池化）、TextRCNN、RNN-Capsule（胶囊化）、TopicRNN（长文本主题建模）。

## 输入契约

- 词向量序列：每个输入词用词嵌入技术表示成定长向量，按顺序逐个送入循环单元（嵌入来自 word2vec/GloVe 或随机初始化/共训）。
- 标注数据；树结构模型（Tree-LSTM）需要句法树/二叉分析树输入。
- 长文本任务可加主题/记忆组件（TopicRNN 用潜主题捕获全局语义依赖）。

## 输出契约

- 每个循环单元输出与输入同维度的向量并送入下一隐层；分类标签由隐层最后输出（或双向拼接后的表示）预测。
- 胶囊化实现（RNN-Capsule）额外输出带情感倾向的词语，作为类别属性的指示。
- 对抗训练路线（对词嵌入做扰动而非扰动原始文本）输出的是更稳健的嵌入与更不易过拟合的模型。

## 调用方式

- 标准流程：词嵌入 → 逐词送入 RNN/LSTM 单元 → 隐状态传给下一层 → 末状态接输出层分类。
- BiLSTM 编码 + 匹配：NLI 类任务用 BiLSTM 编码两段文本、双向匹配、再用一层 BiLSTM 聚合为定长匹配向量，最后全连接判定。
- 树结构扩展：Tree-LSTM 把序列 LSTM 扩展到树，可用遗忘门丢掉对结果影响小的整棵子树。
- 正则化：对词嵌入施加虚拟对抗训练（VAT）类扰动，提升嵌入质量与鲁棒性。
- 与 CNN 融合：BLSTM-2DCNN（BiLSTM + 二维卷积 + 二维最大池化）、MTNA（BiLSTM + CNN 做方面类别分类与方面词抽取）。

## 关键参数

- 循环单元类型：RNN / LSTM（cell 状态 + 三个门）/ Tree-LSTM（树结构版）；LSTM 是缓解梯度消失的默认选择。
- 方向：单向 / 双向（BiLSTM 同时利用左右上下文）。
- 与卷积/池化的组合方式（BLSTM-2DCNN 的二维最大池化）。
- 对抗扰动的强度（施加在词嵌入上，属半监督正则化超参）。

## 依赖

- 上游依赖"文本表示：词袋到上下文嵌入"提供词嵌入序列（RNN 自身不产出词表，需外部嵌入）。
- 树结构模型依赖句法分析结果；长文本主题模型依赖潜主题组件。

## 适用条件

- 词序与长距离依赖重要的任务（语言模型式地学习历史信息，位置信息对分类有用）。
- 需要捕获上下文词之间联系的长文本：LSTM 的遗忘门使文献主张其"有助于提升分类器的整体捕获能力"。
- 序列需要双向上下文时用 BiLSTM（如 NLI 的双向匹配）。
- 结构与句法相关：Tree-LSTM 在句法树上建模。

## 不适用条件

- 对训练/推理吞吐要求高的场景：RNN 按序递推、无法并行，综述把它列为难以随模型加深加参数趋势演进的短板。
- 长文本且以局部判别短语为主：RNN 逐词处理成本高，CNN 的并行局部卷积更划算。
- 想单纯靠堆层数提升：序列递推的并行瓶颈让深层 RNN 训练成本迅速上升（综述在模型效率挑战中把网络深度、正则化、学习率等列为技术限制）。

## 验证状态

已验证（文献报告值，非本库复现）。综述 Table 4 汇总的准确率：

- BLSTM-2DCNN：MR 82.30、SST-2 89.50、20NG 96.50（综述明确指出这是 20NG 上的最佳成绩，归因于二维最大池化得到定长表示 + 二维卷积采样更丰富的矩阵信息）。
- RNN-Capsule：MR 83.80（综述明确指出这是 MR 上的最佳成绩，归因于按类别建胶囊、无需语言学知识即可输出带情感倾向的词）。
- oh-2LSTMp：IMDB 94.10、Yelp.P 97.10、Yelp.F 67.61、20NG 86.68、AG 93.43、DBpedia 99.16。
- Multi-Task：SST-2 87.90、IMDB 91.30；TopicRNN：IMDB 93.72；TextRCNN：20NG 96.49；Tree-LSTM：SST-2 88.00。

上述数字均为各模型原文自报、由综述汇总，未统一复现与统一切分。
