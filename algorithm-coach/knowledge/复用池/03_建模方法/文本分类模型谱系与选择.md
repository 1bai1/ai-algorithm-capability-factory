# 文本分类模型谱系与选择

## 能力说明
按数据量、算力与可解释性要求在两大族之间选型，并据此决定输入表示：浅层族（基于规则/决策树、
朴素贝叶斯、SVM、kNN）吃稀疏词特征；深度族（ReNN、MLP、RNN/LSTM、CNN、注意力/HAN、Transformer、GNN）
吃序列或预训练表示。选型的判据是「小数据量、低成本任务用传统算法；数据与算力充足、要语义表示时上预训练模型」。

## 输入契约
- 浅层路线：定长稀疏向量（词袋 / tf-idf / 二值计数），见相关卡。
- 深度路线：词或子词序列、预训练模型的隐藏表示。
- 标签形态决定输出层：单标签二分类 / 多分类（可由二分类组合实现）/ 多标签。

## 输出契约
- 类别标签或类别概率。
- 浅层模型多可解释（线性权重、类别条件概率），深度模型为黑盒，原文把可解释性与复现性列为待解挑战。

## 调用方式
```python
from sklearn.pipeline import Pipeline
from sklearn.svm import LinearSVC
from sklearn.feature_extraction.text import TfidfVectorizer

# 浅层基线的官方示例入口：稀疏特征 + 线性模型
Pipeline([("tfidf", TfidfVectorizer()), ("clf", LinearSVC())])

# 无监督：文档聚类 KMeans；话题提取 NMF
```

## 适用条件
- 浅层：高维稀疏小样本（原文给 SVM 的评价最高）、需要快速基线与可解释权重、算力受限。
- 深度：数据与算力充足、需要上下文/语义级表示、任务超出词袋表达能力。
- 无监督：文档聚类（KMeans）与话题提取（NMF）。
- 多分类：可用二分类组合实现。

## 不适用条件
- kNN 不适合大训练集：懒学习，预测时要与全部训练样本算距离，存储与时间随样本数增长。
- 朴素贝叶斯的条件独立假设在真实文本上不成立（原文自承词组之间并不独立）。
- SVM 参数多且敏感（原文称「参数的不同对分类结果显示出较大差异性」），复杂度随样本与类别数上升，
  核变换还会抬高维数与开销。
- 深度模型在黑盒、可复现性、对抗样本鲁棒性上都有已知缺陷（原文列为挑战），小数据上不占优。
- 原文的性能判断（「SVM 几乎可以说是传统机器学习算法中最好的」等）没有实验数字，不能当结论使用。
