# 预训练语言模型文本分类：BERT 系列

## 能力说明

"大规模无标注语料预训练 + 少量标注微调"的文本分类范式：预训练阶段用无监督目标学通用语言表示，微调阶段只在预训练模型上接一个输出层适配目标任务。三条代表路线：ELMo（双向 LSTM、特征式表示，可直接插入已有模型）、GPT（单向 Transformer、无监督预训练 + 监督微调两阶段，且预训练语料域不必与目标任务域相似）、BERT（双向 Transformer，每一层联合左右上下文、以掩码词预测为预训练目标）。综述判断 BERT 兼取 ELMo 与 GPT 之长故效果更好，并把 BERT 的出现视为文本分类发展的转折点。后续改进：RoBERTa、XLNet、ALBERT、BART、SpanBERT、ERNIE。综述汇总表的总评是：预训练模型在多数数据集上取得最好成绩，实现文本分类任务应优先尝试 BERT/RoBERTa/XLNet 一类模型。

## 输入契约

- 预训练阶段：大规模无标注文本（RoBERTa 用 30G 中文语料、3 亿句、100 亿词），预训练语料域不必与目标任务域相似。
- 微调阶段：带标注的任务数据（数量可远小于从零训练所需）；上下文嵌入路线的 ELMo 只需把它产出的表示接入已有模型的输入。
- 复用路线：已预训练好的权重与配套分词器。

## 输出契约

- 上下文相关的词/句表示（同一个词在不同语境下向量不同），以及任务标签。
- 微调成本低：只需在预训练模型上加一个额外输出层即可构造分类模型。

## 调用方式

- 两阶段范式：先用无监督目标预训练（掩码预测 / 下一句预测 / 排列 / 去噪重构），再用监督目标适配目标任务。
- RoBERTa（BERT 改进）：改为动态掩码（每次喂入序列现生成掩码模式）、去掉下一句预测任务、训练更久（近 20 万步、看过近 16 亿训练数据）、batch 更大（8K）、序列更长、全词掩码。
- XLNet：第一阶段不用带掩码的去噪自编码器，改用自回归语言模型，通过最大化全排列的期望似然学习双向上下文，并吸收 Transformer-XL 的思路。
- ALBERT：用嵌入分解缩短向量长度并在各编码器间共享参数，把下一句匹配任务替换为下一句顺序任务。
- BART：Seq2Seq 去噪自编码器——先用噪声函数破坏文本，再让模型重构原文，其中"随机打乱句子顺序 + 用单个掩码标记填充文本片段"效果最好。
- SpanBERT：随机掩码连续片段（span masking）、增加 span 边界目标（用边界两侧的 token 预测 span）、去掉 NSP。
- ERNIE：知识增强，掩码词与实体等语义单元，模型由 Transformer 编码器加任务嵌入构成。

## 关键参数

- 预训练目标与掩码策略：静态 / 动态掩码（RoBERTa）、span 掩码（SpanBERT）、全词掩码。
- 训练规模：数据量、步数、batch 大小、序列长度（RoBERTa 的配置为更长训练、8K batch、更长序列）。
- 参数量：ALBERT 通过嵌入分解与跨编码器参数共享压缩。
- 方向性：ELMo 与 BERT 双向、GPT 单向从左到右。
- 微调时的输出层结构与学习率（综述未给具体取值）。

## 依赖

- 上游依赖"注意力机制文本分类"：BERT 与 GPT 属基于 Transformer（自注意力）的微调式方法，自注意力是其底层编码机制（ELMo 则用双向 LSTM）。
- 上游依赖大规模无标注语料与算力，以及（复用路线）他人发布的预训练权重与分词器。

## 适用条件

- 标注数据充足、追求最高准确率：综述的汇总表显示预训练模型在多数数据集上最优，并明确建议优先尝试。
- 跨领域迁移：GPT 一类方法的预训练语料域不需要与目标任务域相似，目标任务可用有限适配完成迁移。
- 需要消解一词多义：上下文嵌入按语境产生不同表示，优于静态词向量。
- 目标是文档级/句子级通用分类且算力可支撑微调。

## 不适用条件

- MR 与 20NG：综述明确指出这两个数据集在汇总表中**没有基于 BERT 的实验**，"预训练模型优先"在它们上面没有本表证据支撑。
- 领域术语密集的小语料：综述指出金融、医疗一类文本含大量专有词/缩写，现有预训练词向量难以直接生效。
- 长序列：综述提到 Transformer 的注意力计算量大，长序列尤其重（已有针对计算复杂度的改进模型）。
- 没有微调算力或只有几千条样本的极窄任务：传统模型在小数据上反而更稳（见"浅层文本分类：朴素贝叶斯与 SVM"）。

## 验证状态

已验证（文献报告值，非本库复现）。综述 Table 4 汇总的准确率：

- BERT-base：SST-2 93.50、IMDB 95.63、Yelp.P 98.08、Yelp.F 70.58、Amz.F 61.60、SNLI 91.00；BERT-large：94.90 / 95.79 / 98.19 / 71.38 / 62.20 / 91.70。
- XLNet-Large：SST-2 96.80、IMDB 96.21、Yelp.P 98.45、Yelp.F 72.20、Amz.F 67.74；XLNet：SST-2 97.00、AG 95.51、DBpedia 99.38。
- RoBERTa：SST-2 96.40、SNLI 92.60；MT-DNN：SST-2 95.60、IMDB 83.20、SNLI 91.50。
- 综述 Table 4 另列 ULMFiT：IMDB 95.40、Yelp.P 97.84、Yelp.F 71.02、AG 94.99、DBpedia 99.20（正文未展开其机制）。

综述据此的结论性判断："预训练模型在多数数据集上取得更好结果"（MR、20NG 无 BERT 实验）。所有数字均为各原文自报、由综述汇总，未统一复现与统一切分；MT-DNN 在 IMDB 的 83.20 明显低于同表其他预训练模型，引用需回原文核对。
