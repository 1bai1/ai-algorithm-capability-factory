# CNN 文本分类：TextCNN 与 DPCNN

## 能力说明

把文本当成"一维图像"做卷积的分类模型族：词向量逐词拼接成矩阵，用多个不同尺寸的卷积核同时作用于序列的不同片段，池化后拼接得到定长文本向量，再分类。与 RNN 的最大结构差别是**可以并行**——同一层的多个卷积核同时处理多个片段，不依赖时序递推。代表实现：TextCNN（Kim，单层卷积 + 最大池化）、DCNN、CharCNN（字符级）、DPCNN（深层金字塔）。综述给出的结构层结论：CNN 能并行、改进版本能保留位置信息，但**长距离特征捕获能力弱**，且因优化方法与池化的位置信息损失，"更深层并不带来显著提升"。

## 输入契约

- 词向量拼接成的嵌入矩阵（词向量可固定，也可随训练更新）；嵌入粒度可字符级、词级或句子级。
- 标注数据；半监督版本额外使用无标注数据先训练文本区域嵌入，再用标注数据训练。
- 字符级模型输入的是字符序列（不需要词表，可处理未登录词）。

## 输出契约

- 池化并拼接后的定长文本向量，经全连接层输出类别预测。
- 不同 kernel 尺寸对应不同粒度的判别性片段特征；TextCNN 用最大池化层挑出对判别最有用的短语。

## 调用方式

- 标准流程：词向量拼矩阵 → 卷积层（若干不同尺寸 filter）→ 池化层 → 拼接 → 输出分类。
- TextCNN：只保留一层卷积，词向量保持静态（训练时只学除词向量外的超参数），用一层卷积 + 最大池化确定判别性短语。
- DPCNN：靠加深网络提升精度，shortcut 全部用简单恒等映射（无维度匹配的复杂处理，比 ResNet 的 shortcut 更纯粹）。
- CharCNN / 字符级 CNN：字符级嵌入解决未登录词问题；多语言场景有专门的字符级 CNN（MGTC）。
- 与 RNN 融合：BLSTM-2DCNN（双向 LSTM + 二维最大池化，二维卷积从矩阵中采样更丰富信息）、MTNA（BiLSTM + CNN 组合，做方面类别分类与方面词抽取）。
- 句子级封装：TransCap 把句子级语义表示封装为语义胶囊，迁移文档级知识。

## 关键参数

- 卷积核的数量与尺寸——决定捕获特征的粒度；核越大覆盖的局部上下文越长，但长距离依赖仍靠多层堆叠。
- 词向量是否固定（TextCNN 的做法是固定词向量、只学其余超参数）。
- 网络深度：加深有收益但综述明确提示更深层不一定带来显著改进。
- 嵌入粒度（字符 / 词 / 句子）——决定 OOV 与跨语言能力。

## 依赖

- 上游依赖"文本表示：词袋到上下文嵌入"提供嵌入矩阵（词向量可随机初始化或取自 word2vec/GloVe 等）。
- 可选依赖无标注数据（两视角半监督预训练嵌入）；字符级路线不依赖分词。

## 适用条件

- 需要高吞吐、可并行的场景（CNN 相对 RNN 的核心优势）。
- 判别信息集中在局部短语/n-gram 上的任务（卷积核大小直接对应这个粒度）。
- 字符级 CNN：多语言文本、拼写不规范、未登录词多的语料。
- 与序列模型融合：需要同时利用"局部特征 + 上下文序列"时用 BLSTM-2DCNN / MTNA 一类组合结构。

## 不适用条件

- 长距离依赖为主的任务：综述明确说 CNN 对长距离的特征捕获能力弱。
- 想靠单纯加深网络换取精度：综述指出由于深层网络的参数优化方法不足、且池化层丢失位置信息，加深并不带来显著提升。
- 需要词级可解释性：综述把 CNN/RNN 归为"可解释性不足、分类错误难以解释"的一类，注意力类方法才是为可解释性引入的。
- 短文本且想用大核卷积堆长上下文：没有足够序列长度可供覆盖。

## 验证状态

已验证（文献报告值，非本库复现）。综述 Table 4/Table 1 汇总的准确率：

- TextCNN：MR 81.50、SST-2 88.10。
- DCNN：SST-2 86.80、IMDB 89.40。
- CharCNN：Yelp.P 95.12、Yelp.F 62.05、AG 90.49、DBpedia 98.45。
- DPCNN：Yelp.P 97.36、Yelp.F 69.42、Amz.F 65.19、AG 93.13、DBpedia 99.12。
- TextCapsule（综述 Table 1 归入 CNN 组）：MR 82.30、SST-2 86.80、AG 92.60。
- KPCNN：MR 83.25、AG 88.36。

上述数字均为各模型原文自报、由综述汇总，未统一复现与统一切分。
