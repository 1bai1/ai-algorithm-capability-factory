# 词典法情绪因子构造

## 能力说明
用规则/词典对金融文本（新闻标题、股吧、研报）逐条打情绪分，得到可入模的连续舆情因子。
适合冷启动与快速基线；但语料实证表明通用词典在金融文本上偏差明显，本卡同时记录这些缺陷。

## 输入契约
- 文本表最小字段：ticker、headline、date；若要检验因子有效性还必须带收益字段 eventRet 与 Close（30-3、30-7）。
- 语言与语料：现有实证全部为英文财经标题（美股 AMZN/NFLX/MSFT/TSLA/YELP/AMD/ADBE，2011 年前后）；中文只能借用 9-3 的人工关键词表起步。
- 预处理链（5-1）：转小写 → 去除特殊字符与数字 → 去标点 → 分词 → 过滤停用词。
- 无标注数据要求（这是词典法相对监督模型的核心优势）。

## 输出契约
- 逐条连续分值：VADER 复合分（示例输出 0.21 / 0.86 / 0.70 / −0.04，同日期不同标题差异明显）；TextBlob 极性取值区间 [−1, 1]。
- 输出为事件表追加列：`sent_blob`（TextBlob）、`vader_sent`（VADER）；与 perc_sent、lstm 等其它方法的分数并列保存，便于多方法对照。
- 落盘示例：`sent_label_added_corpus.csv`。
- 因子化前必须聚合：同日多条新闻需再聚合为日频因子，30-7 原文未做这一步。

## 调用方式
```python
# VADER + 自建金融词典（30-7）
from nltk.sentiment.vader import SentimentIntensityAnalyzer
sia = SentimentIntensityAnalyzer()
sia.lexicon.update(custom_lexicon)          # 从 lexicon_sentiment.csv 读入并合并
df['vader_sent'] = df['headline'].apply(lambda x: sia.polarity_scores(x)['compound'])

# TextBlob 兜底（30-3）
df['sent_blob'] = df['headline'].apply(lambda row: TextBlob(row).sentiment.polarity)
```
- 规则打分细节（5-1）：统计正负词数量，对否定词做极性翻转，程度副词增强、标点强化。
- 有效性初筛（30-3、30-7）：按 ticker 分面画 `px.scatter(x='情绪分', y='eventRet', facet_col='ticker', facet_col_wrap=3)`，再用 `df.corr()` 看相关矩阵条图。
- 中文起步词表（9-3）：positive = {利好, 增长, 涨幅, 上涨, 涨停}；negative = {利空, 下跌, 跌幅, 亏损, 超跌, 下滑, 强执, 跌超}；原文明确说明这是使用者自定义列表、与模型参数无关，只能用于预处理打标或输出后处理。

## 关键参数
- VADER 使用 `nltk.sentiment.vader.SentimentIntensityAnalyzer` 的 compound 分；自定义词典文件 `lexicon_sentiment.csv`，原文采用 Oliveira 等人的金融词典。
- TextBlob 极性区间 [−1, 1]（30-3）。
- 分面散点数 `facet_col_wrap=3`（30-7）。
- 原文未给出情绪因子的聚合窗口、滞后阶数、阈值与权重参数。

## 依赖
nltk（vaderSentiment、stopwords、分词器，需 `nltk.download` 预下载词典与停用词）；TextBlob（依赖 NLTK 与 Pattern）；pandas / numpy；plotly.express。

## 适用条件
- 冷启动阶段快速建立情绪因子基线，不做标注即可出分（5-1 定位为历史最久、可解释、无需标注数据的路线）。
- 需要可解释归因时：逻辑回归的 Top 重要特征可用来检查通用词表是否误判金融术语，据此扩充领域词典（5-2-01）。
- 多方法对照实验：规则法（VADER/TextBlob）与深度学习模型对同一批标题打分，用相关性比较后选更稳定的一路入模（30-7）。

## 不适用条件
- 金融术语与通用词典冲突时不要直接用默认词典：30-7 指出通用词典不适配金融文本，必须替换或扩充；9-3 的中文 BERT 案例中前 10 条标题几乎全被判为"积极"，说明通用模型/词典在金融语料上会系统性偏移。
- 无法处理反讽、隐喻、多重否定与上下文（5-1、30-3 自述）；标题里的数字与涨跌幅符号容易干扰打分。
- 相关性弱时不要强行入模：30-3 实测分组相关性整体偏低（亚马逊和 Adobe 最低，特斯拉高于预期但未给数值），原文明确其将成为模型误差来源；9-3 的实例输出全为"积极"。
- 中文语料不能直接套用英文词典与英文预训练权重，需重建中文金融情感词典（30-7 局限）。
- 逐条标题分不等于因子：同日多条新闻必须聚合且需处理时间对齐，30-7 未做，直接使用会把事件级噪声带进模型。

## 验证状态
- 原文有真实运行结果的部分：30-7 输出逐条 VADER 分值示例（0.21 / 0.86 / 0.70 / −0.04）；30-3 输出按 ticker 分组的散点与相关矩阵，结论为"整体偏低、模型难以找到新闻内容与收益之间的关系"。
- 未给出数值的部分：30-3 各分组相关系数的具体数值与样本量未披露；5-1 两种规则方法的准确率未披露；9-3 未量化准确率、也未做人工标注校验。
- 有效性结论：情绪与收益无稳定线性关系，情绪因子是否有效未结论化（30-3）；情绪到收益的因果链未打通（30-7、9-3）。
