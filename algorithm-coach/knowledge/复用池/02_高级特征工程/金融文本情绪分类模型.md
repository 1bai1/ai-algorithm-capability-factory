# 金融文本情绪分类模型

## 能力说明
用 FinBERT / BERT 微调或 LSTM 分类器把金融文本打成正/负/中性标签，再对全量新闻批量推断生成情绪因子列。
解决"词典法无法处理语境与术语、需要更高精度情绪标签"的环节，产物可直接与事件收益对齐做下游特征。

## 输入契约
- 文本列 + 三分类标签列（positive/neutral/negative 或 积极/消极/中性）。
- 数据规模实证：FinancialNewsHeadline.csv 4846 条英文金融标题（neutral 2879、positive 1363、negative 604，类别明显不平衡）；另 9470 条专家标注标题用于泛化模型。
- 中文场景：同花顺新闻快讯 CSV 的 title 列，微调数据为带情感标签的 news_with_sentiment.csv。
- 需先统计 token 长度分布再定 max_length：9-4-1/9-4-2 统计标题长度后确定 max_length=150；5-3-01 用 128/256，并关注超过 512 上限的比例。
- 标签必须数字化：9-4-2 用 positive=2、neutral=0、negative=1；9-3 用 消极=0、积极=1、中性=2。

## 输出契约
- 训练期：验证损失、按类别准确率、加权 F1、混淆矩阵。
- 推断期：对 headline 列批量输出标签/概率，回写为新列（30-6 的 `lstm` 列），与 ticker/date/eventRet 组面板供下游使用。
- 可额外导出嵌入表示：30-6 明确提出保存训练好的嵌入喂给更快的传统机器学习模型。
- 用于因子时需把 0/1 或三分类映射为日频情绪取值；原文未给出映射规则。

## 调用方式
```python
# FinBERT 微调（9-4-2）
tok = BertTokenizer.from_pretrained("ProsusAI/finbert", do_lower_case=True)
model = AutoModelForSequenceClassification.from_pretrained(
    "ProsusAI/finbert", num_labels=3, output_attentions=False, output_hidden_states=False)
enc = tok.batch_encode_plus(texts, return_tensors='pt', add_special_tokens=True,
        return_attention_mask=True, pad_to_max_length=True, max_length=150)
```
- 训练组件：`DataLoader(dataset, sampler=RandomSampler / SequentialSampler, batch_size=5)`、`AdamW`、`get_linear_schedule_with_warmup`（9-4-2）；或 TensorDataset + DataLoader + `nn.CrossEntropyLoss()` + `torch.optim.AdamW`（9-3）。
- LSTM 路线（30-6）：Embedding(可训练) → LSTM → 二分类，`inference(df, 'headline')` 对新数据批量预测并回写标签列。
- 评估函数（9-4-1）：`get_headlines_len`、`show_headline_distribution`、`encode_sentiments_values`、`f1_score_func`（argmax 后加权 F1）、`accuracy_per_class`、`evaluate`。
- 中文微调（9-3）：`BertTokenizer.from_pretrained(path)` + `BertForSequenceClassification.from_pretrained(path, num_labels=3)`，训练后 `model.save_pretrained("fine_tuned_model")`。

## 关键参数
- FinBERT 微调：max_length=150、batch_size=5、AdamW(lr=1e-5, eps=1e-8)、线性 warmup（warmup=0）、epochs=2、训练集 RandomSampler / 验证集 SequentialSampler（9-4-2）。
- 通用 BERT 起步超参（5-3-01）：lr=2e-5、batch 16/32、epoch 5-10、Dropout 0.1、max_len 128/256、可冻结底层只调上层。
- LSTM 文本参数（30-6）：词表 20000、maxlen 50、embedding dim 100（可训练）、Adam、BCE、10 epochs、160 步/epoch（约 15–19 秒/epoch）；外层 90/10、内层 60/40 划分。
- 数据划分：9-4-2 分层切分 85% 训练 / 15% 验证（stratify=label，random_state=2022）；30-6 用 `train_test_split(test_size=0.1, random_state=32)`。
- 早停判据：验证损失由降转升即停（9-4-2 最优轮次为第 1 轮）。

## 依赖
transformers（ProsusAI/finbert、BertTokenizer、AutoModelForSequenceClassification）；torch；scikit-learn（f1_score、train_test_split）；pandas / seaborn / tqdm；Keras（30-6 的 KerasClassifier 路线）。

## 适用条件
- 英文金融标题三分类已有可复现流程与真实结果（9-4-1、9-4-2），可直接作为情绪因子生产组件。
- 标注数据量中等（数千条）时优先选领域预训练模型 + 少量 epoch 微调。
- 需要把情绪标签批量生产到新语料上时（30-6 的推断链：标注集训练分类器 → 新标题批量推断 → 与事件日收益对齐成面板）。
- 长文本、多语种、语境复杂时深度模型相对规则法优势更明显（5-2-02）。

## 不适用条件
- 类别不平衡时不能只看总体准确率：9-4-1 的负类仅 604 条，必须看加权 F1 与每类准确率；5-3-01 建议主指标用 Macro-F1 并单独考察"消极"类召回。
- 没有独立测试集的评估偏乐观：9-4-2 只有 85/15 训练验证划分，类别准确率基于验证集。
- 不要用通用中文 BERT 直接做金融标题情绪：9-3 实测前 10 条几乎全判为"积极"，作者建议先用规则词典兜底再考虑微调；该文超参（学习率、epoch、batch_size）与准确率均未披露。
- 标注量不足时不要指望大模型：30-6 在 2146 条小数据集上换 300 维嵌入几乎无改善（LR 测试 0.73 → 0.740），原文结论是标签质量的影响大于嵌入维度本身。
- 情绪标签不能直接当收益信号：全语料均未验证情绪因子与收益的统计关系，9-4-1/9-4-2/5-3-01 都止步于分类精度。
- 情感三分类无法表达强度与中性程度：30-6 指出 0/1 标签信息量受限；5-2-01 指出转折结构（"虽然亏损但长期看好"）易被误判。

## 验证状态
- 已验证：9-4-2 的 FinBERT 微调在验证集上的按类准确率——neutral 385/432、negative 81/91、positive 170/204（FinancialNewsHeadline 标题，约 4846 条，85/15 划分）；原文自述第 1 轮后即过拟合，仅跑 2 个 epoch 且未充分调参。
- 已验证：30-6 的 LSTM 训练 10 epoch，验证准确率从第 1 轮 0.9449 稳定在约 0.97，训练准确率升至 0.9996（明显过拟合）；模型随后被用于生成 lstm 标签列。
- 未验证：FinBERT/BERT 路线均未做情绪到收益的相关性/IC 检验；9-4-1 未展示完整微调超参、训练轮数与最终准确率数值；5-3-01 全篇为方法叙述加截断代码，无对比指标；5-2-02 无代码、无定量结论。
