# 预测标签构造

## 能力说明
把连续价格序列转成监督学习目标：未来 N 期收益（回归）或涨跌方向（分类），并保证特征与标签的时间对齐。
解决"模型该预测什么、标签阈值怎么定、当期特征如何对应下一期标签"的建模前置问题。

## 输入契约
- 必需列：Adj Close（优先，避免除权除息干扰）或 Close；可选 High/Low/Open/Volume。
- 频率决定 N 的语义：周频 → 下周收益（31-4）；日频 → 次日方向（29-3、6-1-03）；秒级 → 未来 5 秒（6-1-03 的论述，无实现）。
- 类别分布需先统计：31-4 训练集（1990–2014，AAPL 周频）53.7% 周收益为正，原文判断不平衡轻微、无需额外平衡；12-4 训练集正类 62.1%，明显不平衡，需 SMOTE。
- 文本事件场景另需事件表：ticker + headline + date + eventRet + Close（30-7），标签必须与收益字段对齐。

## 输出契约
- 连续目标：`returns`（当期收益列）、`cont_target`（下一期收益）。
- 分类目标：`cat_target`（下周收益 > 0 记 1，否则 0，二值 0/1）。
- 自定义阈值目标：12-4 把连续比率按分位切分后二值化（ratio ≤ 0.998 记 0、> 0.998 记 1），再 `shift(-1)` 对齐。
- 对齐后的首/末行因 shift 与 dropna 产生缺失，样本量会减少，需统计损失（31-5 指出 dropna 造成的样本损失原文未统计）。
- 标签口径要与下游评价指标匹配：分类标签配 ROC-AUC / 混淆矩阵；连续标签配 MAE/RMSE。

## 调用方式
```python
# 1) 收益与方向标签（31-4）
returns = np.round(df['Adj Close'].pct_change() * 100, 2)
cont_target = returns.shift(-1)                       # 下一期收益
cat_target  = np.where(cont_target > 0, 1, 0)

# 2) 分位阈值法确定分类边界（12-4）
np.arange(0, 1.125, 0.125) → np.quantile → pd.cut
groupby('ranges')['returns'].mean()                   # 找收益由负转正的临界点
df['target'] = np.where(ratio <= 0.998, 0, 1); df['target'] = df['target'].shift(-1); df.dropna()

# 3) 相邻两日方向标签（29-3）
Target = (Close_t > Close_{t-1}).astype(int); 所有特征先 shift(1)

# 4) 概率→信号（12-6，属信号层但决定标签用法）
position = sign.shift(1); model_returns = position * returns
```
- 不平衡处理：`SMOTE(random_state=42).fit_resample(X_train, y_train)` 只对训练集做，测试集保持原始分布（12-4）。
- 类别不平衡轻微时可跳过平衡（31-4）。
- 目标类别分布与阈值选择必须在训练段决定，阈值不能在同一测试集上反复挑选（12-6 自述阈值 0.607 存在选择偏差）。

## 关键参数
- 收益口径：`Adj Close.pct_change() * 100` 保留两位小数（31-3、31-4）。
- 预测窗口：周频下一周（31-4）；日频下一日（29-3）；12-3 的目标列即当期 `returns`（周收益率）。
- 分位阈值：12-4 用八分位（`np.arange(0, 1.125, 0.125)`），实测临界点 0.998；该比率的中位数约 1.0061。
- 信号阈值：12-6 把预测概率切成 8 等份后取 0.607 替代默认 0.5；概率高于 0.607 记 +1、否则 −1。
- SMOTE 随机种子 42（12-4）。
- 高频四类目标的定义（6-1-03，属定性描述）：价格方向（1/0）、短期波动幅度（示例"未来 5 秒涨跌幅是否超 0.1%"）、订单流压力、流动性变化。

## 依赖
pandas / numpy（pct_change、shift、where、quantile、cut）；imbalanced-learn（SMOTE、RandomOverSampler）；sklearn（分位数与评价指标）。

## 适用条件
- 可预测性优先于收益幅度时用方向分类 + AUC（31-5、12-5），需要连续收益时同时保留 cont_target 做回归对照（31-5 保留了 returns 与 cont_target 两列）。
- 训练期类别分布稳定的标的上（31-4 的 53.7% 正类）可直接用 0.5 或分位阈值。
- 需要把概率映射为可交易信号时，用分位数-收益表找阈值（12-4 与 12-6 的两步法）。

## 不适用条件
- 不要用包含当期信息的标签：29-3 明确"不平移就等于用当天数据预测当天目标，结果不可信"，所有特征必须 shift(1)。
- 不要对时序数据先重采样再切分：29-3 先用 RandomOverSampler 再按位置切分，合成样本同时进入训练与测试集，测试集被污染，0.49/0.50 的准确率不可信。
- 时序上慎用 SMOTE：12-4 用 SMOTE 会合成破坏时序结构的样本，原文未讨论该风险，也未在切分前留出验证集。
- 阈值不要从测试集反推：12-6 的 0.607 在同一测试集上挑出，属阈值选择偏差。
- 标签是模型上限：30-4 指出标签质量问题无法靠换模型解决，含噪标签（如 perc_sent 方向判定前后矛盾）会把精度上限锁死。
- 日频纯 OHLCV 的涨跌方向标签接近不可学：29-3 的基线准确率 0.49、类别 1 召回 0.92 而类别 0 召回仅 0.15，不能作为有效标签设计的证据。

## 验证状态
- 已验证：31-4 给出真实类别分布——AAPL 周频，训练集（1990–2014）53.7% 周收益为正，测试集 2014-01-01 至 2023-07-24；31-3 给出周收益分布实测（多数集中在 −11.84% ~ +12.85%，最优周 +39.74%，最差 −50.66%，2000-10-25 单周 −50.66%，2020 年最大单周 −17.53%）。
- 已验证：12-4 给出分位收益表的真实数值（ratio 阈值 0.998 以下各区平均收益 −2.44 / −0.99 / −0.43，以上从 0.03 起、最高 2.68），据此定阈值后训练集 464 行 × 36 列、正类 62.1%，SMOTE 后两类拉平。
- 已验证（负面）：29-3 的标签方案实际训练结果 accuracy 0.49（max_depth=3）→ 调参后 0.50（max_depth=7/15），类别 0 召回仅 0.15~0.21，模型几乎全部预测上涨。
- 事件收益标签（eventRet）在 30-7 中作为对齐字段出现，但口径未定义、与情绪分的相关性未结论化。
