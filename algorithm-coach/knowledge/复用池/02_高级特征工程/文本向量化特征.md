# 文本向量化特征

## 能力说明
把新闻标题、股吧与研报文本转成固定维度的数值向量（词袋/TF-IDF/静态词向量平均句向量），作为传统机器学习模型的输入特征。
解决"文本类另类数据无法进入以表格为输入的分类器/回归器"的环节；是情绪因子最轻量的实现路径。

## 输入契约
- 文本列 + 标签列约定：`headline`（文本）、`sentiment` 或 `perc_sent`（标签），按 ticker 分股票组织数据便于后续按标的对齐成因子（30-4、30-5）。
- 数据规模实证：自标注集 2146 条（词向量矩阵 2146×96）；专家标注集 9470 条（12 只以上美股，2011–2018 年）。
- 预处理链（5-2-01）：转小写 → 正则去特殊字符与标点 → 分词 → 去停用词 → 词形还原。
- 文本含乱码时需先清洗（30-5 指出标题中存在 ¡§ 类乱码，原文未说明清洗方式）。

## 输出契约
- 稀疏词频/TF-IDF 矩阵（词袋为词频统计；TF-IDF 对"词频高且在其他文本出现少"的词给更高权重）。
- 稠密句向量：spaCy 静态词向量取平均，`en_core_web_sm` 为 96 维、`en_core_web_lg` 为 300 维（30-4、30-5）。
- 向量可直接喂给 LR/KNN/CART/SVM/RF；评估输出格式为 `模型名: cv均值 (cv标准差) 训练准确率 测试准确率`，SVM/RF 另附混淆矩阵（30-5）。
- 维度选择有前提：小数据集上 96 → 300 维几乎无增益（30-5 实测 LR 测试 0.73 → 0.740、交叉验证无改善），数据量大时才生效。

## 调用方式
```python
# 1) TF-IDF（3-2）
vec = TfidfVectorizer(); X = vec.fit_transform(texts)     # 接单层全连接 PyTorch 二分类器（BCEWithLogitsLoss + Adam）

# 2) 静态词向量平均句向量（30-4/30-5）
# 逐词取 spaCy 向量后 np.mean 得到句向量；96 维 or 300 维
# 评估链：nlp_evals(df, corpus='headline', label='sentiment', spacy_model='en_core_web_lg')
#         .tts() → .define_models(models) → .kfold() → .plot_results()
# 3) 词袋 + TF-IDF 双路（5-2-01）：create_features 生成两套特征并做标签数字编码
#         → train_and_evaluate_models：朴素贝叶斯 / SVM / 逻辑回归，输出准确率与分类报告
```
- 标签生成优先级（30-4）：先抽标题里的涨跌幅百分比（最客观）→ 情感词典兜底 → beats/misses 类事件词覆盖财报新闻。
- 错分样本复盘（30-4）：导出原始字段 + 各模型预测并排查看，是提升标签质量的正反馈环节。

## 关键参数
- 句向量维度：96（en_core_web_sm）/ 300（en_core_web_lg），简单平均（30-4、30-5）。
- 划分与验证：90/10 训练测试划分 + 四折交叉验证（30-4）；30-5 固定切分与模型清单、只切换嵌入模型做对照实验。
- 模型池：LogisticRegression、KNeighborsClassifier、DecisionTreeClassifier、SVC、RandomForestClassifier（30-5）；朴素贝叶斯 / SVM / 逻辑回归（5-2-01）。
- 基线准确率：300 维句向量 + LR 测试准确率 0.869（9470 条专家标注集）。
- 原文未给出 TF-IDF 的 max_features、n-gram 范围与词表大小。

## 依赖
scikit-learn（TfidfVectorizer、LogisticRegression、SVC、RandomForest 等）；spaCy（预训练词向量）；nltk（分词、停用词、词形还原）；PyTorch（单层全连接分类器，3-2）；pandas / matplotlib / seaborn。

## 适用条件
- 需要快速建立文本因子基线、不想微调大模型时：平均句向量 + LR 即可（30-4 的定位是"无需微调大模型，适合快速建立基线"）。
- 高维稀疏文本场景：TF-IDF 适合新闻/评论这类短文本；5-2-01 指出 SVM 在高维小样本上表现好，LR 输出概率、可解释。
- 已有一定标注量且标签质量高时，升级到 300 维嵌入能显著提升（30-5：9470 条专家标注集上 LR cv 0.872 / 测试 0.869）。
- 需要可解释性审计时：逻辑回归 Top-10 重要特征可检查通用词表是否误判金融术语（5-2-01）。

## 不适用条件
- 小样本上不要盲目提高嵌入维度：30-5 实测在 2146 条自标注集上 96 → 300 维测试仅从约 0.73 微升到 0.740、交叉验证无改善，原文结论是标签质量的影响大于嵌入维度本身。
- 平均句向量会抹平否定与程度副词等关键信息（30-4），且未与其他文本表示做对比。
- 树模型在稠密平均向量上明显过拟合：30-4 中 DT/RF 训练准确率 1.0、训练-测试差距大；30-5 同样出现 CART/RF 训练 1.0。
- 文本分类的随机切分与量化要求冲突：30-4/30-5 按 90/10 或 K 折随机划分而非时序切分，存在跨期信息泄漏隐患，直接用于交易因子前必须改为按时间切分。
- 小样本实例的满分结果是过拟合：3-2 的情感二分类准确率 1.0 建立在内置 4 条示例文本上，原文自承需真实大规模情感数据。
- 中文 A 股语料不可直接沿用：现有实现全部为英文标题 + 英文词向量，迁移需重建分词、词表与标注集（30-4、5-2-01）。

## 验证状态
- 已验证：30-5 给出真实对照结果——300 维嵌入 + LR 在 9470 条专家标注集上交叉验证 0.872、测试 0.869（混淆矩阵 330/62/62/493），RF/SVM/KNN 同步改善；96 维在 2146 条自标注集上 LR cv 0.733 / 测试 0.725，换 300 维后测试 0.740 但 cv 无改善。
- 已验证（负面）：3-2 的 TF-IDF + PyTorch 二分类器在小样本上准确率 1.0，原文明确指出是小样本过拟合所致。
- 未给出数值：5-2-01 未披露任何准确率或混淆矩阵数值，方案在金融语料上的可行性无法判断，且完全没有情绪到收益的验证。
- 全部实现均止于文本分类精度，未与日频收益对齐、未构造因子、未做策略回测（30-5、5-2-01）。
