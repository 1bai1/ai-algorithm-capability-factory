# 技术指标与量价特征构造

## 能力说明
把 OHLCV 原始行情批量扩展为模型可直接使用的技术指标列、K 线形态比率、价格-均线偏离度与日历特征。
解决"原始价量尺度差异大、信息密度低，不能直接入模"的特征工程环节。

## 输入契约
- 必需列：Open / High / Low / Close / Adj Close / Volume；均线类指标一律用 Adj Close 计算，避免除权除息干扰（31-4 用 `sma_indicator(df['Adj Close'])`）。
- 支持频率：周频（12-3 期货周线、31-4 AAPL 周线）、日频（8-4-1 A 股、1-2-7 茅台）、小时频（27-3 加密）。
- 多标的场景需长表并带 tic/time 列（8-4-1 的 FinRL 路径）。
- 最小样本量原文未给硬性下限；可参考的真实规模：12-3 训练集特征工程后 465 周 × 35 列；31-4 训练 1233 周 × 21 特征、测试 479 周；8-4-1 加指标后 18270 行 × 17 列、训练集 16695 行。

## 输出契约
- 行数与索引与输入对齐，指标列追加在 OHLCV 之后；新增列名必须自带周期语义，便于后续按窗口解析。
- 已出现的命名样式：`ema8`、`close_to_ema8_ratio`、`sma_4/12/20`、`sma4_ratio`、`rsi`/`rsi_overbought`/`rsi_underbound`、`obv`/`obv_divergence_12_weeks`、`4week_vol`/`12week_vol`、`velocity`/`acceleration`、`9_days_volatility`、`macd`/`boll_ub`/`boll_lb`/`rsi_30`/`cci_30`/`dx_30`/`close_30_sma`/`close_60_sma`。
- 取值注意：RSI 类为 0–100 并另带超买/超卖二值标记列；比率类围绕 1 波动；指标前若干行因窗口不足为 NaN；成交量为 0 的样本会让 OBV/ADI 类失真。

## 调用方式
三条可选路径：
1. ta 库（12-3、31-4）：`ta.trend.sma_indicator(df['Adj Close'], window=4/12/20)`；EMA 用 `df['close'].ewm(span=N).mean()`。
2. TA-Lib 批量（14-3）：用 `talib.get_function_groups()` 枚举分组后对整表生成，输入先整体 `shift(1)` 再删含极大值与 NaN 的列。
3. FinRL 一步式（8-4-1、9-3）：`FeatureEngineer(use_technical_indicator=True).preprocess_data(df)`；或 `DataProcessor(data_source='tushare', ...)` → `download_data` → `clean_data` → `fillna` → `add_technical_indicator(config.INDICATORS)` → `fillna` → `data_split`。

落地纪律：
- 特征函数对 train 与 test **分别调用**，滚动指标各自重新起算（12-3）。
- 加完技术指标后必须再 `fillna()`（8-4-1）。
- 指标计算前统一 `shift(1)`，只用截至上一期的信息（14-3）。

## 关键参数
- 均线周期：周线 4/12/20（31-4/31-5）；EMA 8 周期、α=2/(n+1)（12-3）；小时级 EMA 13/25/32/100/200（27-3）；日线 SMA 5/20/60（1-2）；SMA 20/50（6-2-01）。
- RSI/CCI/DX 取 30、均线取 30 与 60（9-3、8-4-1 的固定 8 指标清单）。
- 价格-均线偏离：`close_to_ema8_ratio = Close / EMA8`，小于 1 视为均线下方（偏空）、大于 1 偏多，偏离 1 越远趋势越强（12-3）；`(Close-SMA50)/SMA50` 的 ±2% 阈值属信号层（6-2-01）。
- K 线形态比率：`high_low_ratio = High/Low`；`open_adjclose_ratio = AdjClose/Open`；`candle_to_wick_ratio = (AdjClose−Open)/(High−Low)`；`upper_to_lower_wick_ratio = (High−max(Open,AdjClose))/(min(Open,AdjClose)−Low)`（12-3）。
- 波幅比率：`vol_close = (High−Low)/Close`，再取 EMA 3/6/12（小时频对应 2/4/8 小时，27-3）。
- 价差类：`Price_Change = Close.diff()`、`Price_Change_Pct = pct_change()`、`Range = High−Low`、`Open_Close = Open−Close`（6-1-03、2-2-02）。
- 日历特征：星期映射 Monday=1 … Sunday=7（27-3）；`day`（星期几）作为状态列（9-3）。
- 加速度/速度类 velocity、acceleration 原文只有文字描述、未给计算式（31-4），属未验证实验特征。
- 其余参数原文未给出推荐值。

## 依赖
pandas / numpy（ewm、rolling、pct_change）；ta（sma_indicator 等）；TA-Lib（全量指标分组批量生成）；FinRL（FeatureEngineer / DataProcessor）；yfinance 或 TuShare（取数）；plotly（K 线与指标可视化）。

## 适用条件
- 单标的多周期均可直接套用：周频趋势跟踪（12-3）、周频个股方向分类（31-4/31-5）、日频 A 股与多标组合（8-4-1）、小时频加密（27-3）、日线个股 LSTM（1-2-7）。
- 适合作为树模型 / 线性模型的结构化表格输入；6-1-03 的选型建议是结构化特征先用树模型再考虑序列模型。
- 需要可解释因子（能对应"趋势、超买超卖、波动通道、量价背离"语义）的场景。

## 不适用条件
- 早期成交量缺失或长期为 0 的样本：OBV、OBV 背离、ADI 等量价类特征严重失真（12-3 的 LE=F 早期多周 Volume=0）。
- 交易频率到 10 秒/微秒级时，文中基于日均线的特征不适用；6-1-03 自述其"高频"实例实为日频降级示例。
- 样本量小且特征数大时不要全量入模：12-3 的 35 个特征只对应 465 周训练样本，原文全篇无特征选择步骤，过拟合与多重共线性风险明确存在。
- 7×24 连续交易的加密资产上，星期/小时日历特征是否有预测价值原文未验证（27-3），不要默认移植。
- A 股迁移时须重做涨跌停、停牌、T+1 处理，期货与美股微观结构不同（12-3 的迁移提醒）。

## 验证状态
- 12-5：上述特征经 `SelectKBest(f_classif)` 以 p<0.05 筛出 23 个后，测试集 LogisticRegression AUC = 0.887（标的自述为期货连续价格，品种与区间原文未交代）；其余 7 个分类器结果缺失。
- 12-6：同项目周频回测（Live Cattle Futures，2013-05-27 至 2023-05-15）策略累计收益 62.16% 对买入持有 37.56%，夏普 0.75、Sortino 1.1、年化波动 44.19% 对 44.21%、最大回撤 −39.84%；原文声明不计交易成本与滑点，且信号阈值在同一测试集上挑出。
- 8-4-1：仅给出数据形状（17960,8 → 18315,8 → 18270,17 → 训练 16695,17），无回测结果。
- 特征级消融与单指标增益全文均未做，特征集合的有效性只由上述端到端结果间接支持。
