# 标准化与归一化

## 能力说明
把量纲差异大的价量/指标列统一尺度，使模型（尤其神经网络与距离类算法）可训练。
解决"价格量级差几个数量级、成交量与指标混用导致损失失控或距离度量失效"的预处理环节，同时约束 scaler 的拟合范围以防信息泄漏。

## 输入契约
- 输入为数值型宽表（价格、收益率、技术指标、成交量可混排）；列名与 dtype 必须已确认。
- 金融时序必需前提：先完成时间切分，scaler 的统计量只能来自训练段——原文多处直接对全量变换并造成泄漏，使用时必须自行纠正。
- 缺失值先处理（金融时序用 ffill+bfill，见 2-2-02 的约定），否则 scaler 结果会被 NaN 污染。
- 特征若已做比率/差分处理（如 31-5 的特征），可不再另行标准化。

## 输出契约
- StandardScaler：输出均值 0、方差 1 的同形状矩阵，保留原分布形态；MinMaxScaler：线性映射到 [0,1] 或 [-1,1]。
- 3-3 实例输出：AAPL/GOOG/TSLA 价格列标准化后取值约落在 −0.76 ~ 0.08 区间。
- 神经网络路线必须保留逆变换闭环：预测值要能 `inverse_transform` 回原始量纲后再与真实价格比较（1-2-7、15-6）。
- 幂变换（PowerTransformer）输出近似正态化后的列，用于分布严重偏斜的特征。

## 调用方式
- 常规（3-3）：`sklearn.preprocessing` 的 `StandardScaler` / `MinMaxScaler`，对价格或特征列做 `fit_transform`。
- 正确纪律（11-3-5）：训练集 `fit_transform`，验证/测试集只 `transform`；PowerTransformer 同样遵守。
- 神经网络（1-2-7、15-6、11-4-8）：`MinMaxScaler(feature_range=(0,1))` 缩放到 [0,1]，预测后用 `scaler.inverse_transform` 还原；1-2-7 的做法是把收盘价列填回同宽数组再逆变换。
- LSTM 滑窗样本（11-4-8）：价格序列 reshape 成 (N,1) → `sc.fit_transform` → 构造 X/y → reshape 成 (样本数, 时间步, 特征数)。
- FinRL 路线（9-3）：`FeatureEngineer(...).preprocess_data(df)` 一步完成指标添加、标准化与缺失值处理（其内部标准化实现未公开，需自行确认未用全样本统计量）。

## 关键参数
- MinMaxScaler 目标区间：`(0,1)`（15-6、11-4-8、1-2-7）。
- StandardScaler 无参数；单列标准化输出示例区间 −0.76 ~ 0.08（3-3，AAPL/GOOG/TSLA 价格列，样本区间原文未给）。
- 神经网络对尺度敏感，必须缩放（1-2-7）；树模型通常不需要缩放。
- 原文未给出价格序列是否应先转对数收益率再缩放的结论。

## 依赖
scikit-learn（StandardScaler、MinMaxScaler、PowerTransformer）；pandas / numpy；TensorFlow-Keras 或 PyTorch（神经网络侧调用）。

## 适用条件
- 多标的、多量纲列入模前（3-3 的 AAPL/GOOG/TSLA 场景）：让不同标的可比是标准化最直接的用途，风险度量与波动率比较同理。
- 神经网络与距离类算法（LSTM、DBSCAN、KNN）必须缩放（1-2-7、2-2-02）。
- 线性模型输入量纲差异大时：5-3 的反例中大盘指数（3000 量级）与个股收益率未统一量纲，训练损失跳到 2046 量级。
- 需要把预测值回到价格/收益量纲做评估或展示时，必须保留逆变换链路。

## 不适用条件
- 不要对全量数据 `fit_transform`：15-6 在切分前对 504 条一次性 fit，测试段参与 scaler 参数估计，构成轻微泄漏；3-3 原文直接全量变换，未讨论该约束。
- 不要默认缩放会提升效果：3-3、11-3-5 均无缩放前后的模型效果对照，11-3-5 自述"未做模型训练与评估，无法判断缩放对检测效果的影响"。
- 价格水平本身不适合作为神经网络输入：11-4-8 用归一化后的前一日价格预测当日价格，接近随机游走的复制，loss 快速收敛到 0.0095 但无预测力。
- 标准化会抹掉价格的绝对水平信息，原文未给出对数收益率/差分等替代方案的对比（3-3 局限），价格趋势类任务慎用。
- 幂变换要求样本量充分且分布近似可正态化，直接套用到 A 股价量特征（重尾、含缺失、跨股票量纲不同）未经检验（11-3-5）。

## 验证状态
- 已验证（限于变换本身可运行）：3-3 实例对 AAPL/GOOG/TSLA 价格列做两种变换并打印结果，标准化后取值约 −0.76 ~ 0.08；原文代码块被截断，仅可见 import 行。
- 已验证：1-2-7 的茅台 LSTM 流程实际使用 MinMaxScaler 缩放至 [0,1] 并以 MSE/RMSE/MAE/R² 在反归一化后的价格尺度上评估，但原文未给出这些指标的具体数值。
- 已验证：15-6 的 BTC 周频实例在 min-max 归一化后训练线性回归/XGBoost/随机森林，输出 MAE 0.0247 / RMSE 0.0320（线性回归最优）、解释方差与 R² 训练约 0.988、测试约 0.952；同时原文自述归一化在切分前完成，存在轻微泄漏，且高 R² 主要来自价格序列强自相关。
- 未验证部分：标准化/归一化本身对模型效果的增益，没有任何一篇给出缩放前后的对照实验；11-3-5 明确定位为不适用/未验证。
