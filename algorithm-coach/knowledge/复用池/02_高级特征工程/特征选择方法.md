# 特征选择方法

## 能力说明
在时序建模前从候选因子池中筛掉冗余与噪声特征，降低维度、抑制过拟合。
覆盖五类方法：相关性阈值初筛、树模型重要性、单变量统计检验（f_classif）、互信息、递归特征消除（RFECV）；以及正则化路线（L1/L2）。

## 输入契约
- 输入为已构造好的宽表特征矩阵 X 与目标 y，要求已完成时间切分（训练段严格早于测试段）。
- 时序任务必须提供时间序交叉验证器：`TimeSeriesSplit(n_splits=5)`（31-5 明确禁止随机 K 折）。
- 先 `dropna()` 再切 X/y；31-5 的做法是先 `train = train.dropna()`，再 `X_y_split(train.drop(['returns','cont_target'], axis=1), 'cat_target')`。
- 候选规模参考：31-5 为 21 个特征（训练 1233 周 × 21、测试 479 周 × 21）；12-5 为 35 个特征筛到 23 个。
- 互信息路线需注意量纲：14-3 的实现只保留 `max(col_val) < 1e6` 的列，成交量等大量纲列会被过滤。

## 输出契约
- 相关性初筛：输出按阈值保留的特征集合（示例阈值 0.2）。
- 树模型重要性：输出 `feature_importances_` 排序（3-2 实例给出 MSE 对照：最高价 0.457 > 最低价 0.335 > 开盘价 0.208）。
- f_classif 路线：输出 `pvalues_`，按 p<0.05 过滤（12-5，注意 k 设为全特征数时 SelectKBest 本身不降维，真正生效的是 p 值过滤）。
- RFECV 路线：输出 `rfe.n_features_`（最优特征数）与 `X_train.columns[rfe.support_]`（入选列名），最优特征数由交叉验证 AUC 决定。
- 稳定性信号：被多种估计器共同选中的特征可信度更高（31-5 中 sma_12、4week_vol、12week_vol、acceleration 出现频次最高）。
- 特征子集落地：`X_train_best = X_train[selected_features]`，训练与测试必须用同一列清单。

## 调用方式
```python
# 1) 单变量统计检验（12-5）
k_best = SelectKBest(score_func=f_classif, k=len(X_train.columns)).fit(X_train, y_train)
selected = X_train.columns[k_best.get_support(indices=True)][k_best.pvalues_ < 0.05]

# 2) 时序 RFECV（31-5）
cv = TimeSeriesSplit(n_splits=5)
rfe = RFECV(estimator=GradientBoostingClassifier(random_state=seed), cv=cv, scoring='roc_auc')
rfe.fit(X_train, y_train)          # rfe.n_features_ / X_train.columns[rfe.support_]

# 3) 互信息（14-3 / 13-3）
mutual_information_lag(Gold, 'Close', 100, 10)   # 100 个滞后 → 互信息最高 10 个
```
- 模型无关解释：`permutation_importance(model, X, y, n_repeats=100, random_state=42)`，优于树模型自带的 importance，可用于任意模型（12-5）。
- 正则化路线（3-2、1-2-7）：需要稀疏化做特征选择用 L1（Lasso），需要抑制共线性用 L2（Ridge）。
- 多估计器交叉验证对比（31-5）：同一份特征跑 XGBoost / RandomForest / GradientBoosting / AdaBoost，各自 RFECV，比较入选子集。

## 关键参数
- 相关性阈值：0.2（3-2 示例）。
- 显著性水平：p < 0.05（12-5）。
- 交叉验证：`TimeSeriesSplit(n_splits=5)`；scoring='roc_auc'（31-5）。
- permutation_importance：n_repeats=100、random_state=42（12-5）；全流程 random_state 固定保证可复现。
- 互信息：滞后评估 100 个、取 top 10（13-3）；14-3 版取 k_best 列并返回全部得分字典。
- 测试集占比：train_test_split 测试集 20%（3-2）；时序任务应改为按时间切分。

## 依赖
scikit-learn（SelectKBest、f_classif、RFECV、TimeSeriesSplit、permutation_importance、各分类器）；xgboost / lightgbm / catboost（多模型对比）；sklearn.feature_selection.mutual_info_regression（互信息）；pandas / plotly（重要性条形图）。

## 适用条件
- 候选特征数远大于样本量、且特征间高度共线时（31-4 用相关性热力图确认"大量特征彼此高度相关，可能引发维度诅咒"后才做特征选择）。
- 需要给下游模型一个可解释、可复现的固定特征清单时（31-5 先定 selected_features 列表再统一切分数据）。
- 单变量 + 多模型交叉验证 + 互信息三条路线可组合使用：先粗筛再精排（3-2 的"相关性 0.2 粗筛 → 树模型重要性精排"）。

## 不适用条件
- 单变量 f_classif 只衡量线性关系，会漏掉树模型可利用的交互特征（12-5）。
- 不要在测试集上做特征选择：3-2 在全部数据上做相关性计算属前视偏差；12-5 用测试集算 permutation_importance 并解释特征，若再据此筛特征即为信息泄露。
- 不要用随机 K 折评估时序特征：31-5 明确必须用 TimeSeriesSplit，否则训练集与验证集日期顺序不一致。
- 结果对估计器高度敏感时不要当成定论：31-5 中 XGBoost 选到 Close/Adj Close，树模型选到波动率类，差异极大且原文未做稳定性检验。
- 互信息筛选会过滤大量纲列（14-3 的 1e6 规则），含成交量的因子池不要直接照搬该实现。

## 验证状态
- 已验证：31-5 给出各估计器真实选出的特征子集——梯度提升树 7 个（sma_12、sma4_ratio、rsi、obv、4week_vol、12week_vol、acceleration），随机森林 4 个（obv、4week_vol、12week_vol、acceleration），XGBoost 3 个（Close、Adj Close、sma_12），AdaBoost 3 个（原文未列名）；测试阶段汇总出 9 特征清单。原文未报告 RFECV 各步 AUC 与最终模型表现。
- 已验证：12-5 的 SelectKBest 流程实际入选 23 个特征，后续 LogisticRegression 测试集 AUC=0.887。
- 已验证：3-2 的实例输出特征重要性排序（最高价 0.457 > 最低价 0.335 > 开盘价 0.208），但原文自述数据集为虚构或极小样本，MSE≈1.93 无实际参考价值。
- 待验证部分：PCA/ICA/特征哈希/自动特征工程仅在方法层面罗列，未在金融数据上验证（3-2）；13-3/14-3 的互信息函数主体代码被截断，取其结论需谨慎。
