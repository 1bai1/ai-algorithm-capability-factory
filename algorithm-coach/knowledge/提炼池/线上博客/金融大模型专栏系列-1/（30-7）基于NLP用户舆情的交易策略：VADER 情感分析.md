# （30-7）基于NLP用户舆情的交易策略：VADER 情感分析

## 筛选结论
保留 —— 舆情情绪因子的具体构造方式（自建金融词典 + VADER 打分）以及"情绪—事件收益"的关系检验，直接对应我们的因子构建与验证环节。

## 核心内容
- VADER 是基于规则的无监督情感分析方法：词典给句子成分打情感分，再汇总为句子得分；通用词典不适配金融文本，需替换或扩充为金融词典（原文采用 Oliveira 等人的词典）。
- 流程：读取情感词典 CSV → 与 VADER 默认词典合并 → 逐条对新闻标题计算情感得分 vader_sent → 与原有字段一起落盘为带情感标签的语料。
- 数据表字段：ticker、headline、date、eventRet（事件收益）、perc_sent、lstm、vader_sent，可对照三种情感方法（TextBlob、深度学习、VADER）。
- 用按 ticker 分面的散点图观察情感极性与事件收益的关系，再用相关矩阵条形图比较各列（含各情感方法与收益）的相关性强弱。
- 示例输出显示同一日期不同标题得分差异明显（0.21 / 0.86 / 0.70 / -0.04），说明情绪是逐条标题计算的细粒度因子。

## 可复用要点
- 情绪因子构造：新闻标题 → 金融情感词典打分得到连续分值，可直接作为个股日频舆情因子；同日多条新闻需再聚合（原文未做）。
- 因子验证范式：按标的分面散点 + 相关矩阵，检验情感分值与事件收益的关系，可作为我们因子有效性初筛的模板。
- 多方法对照思路：规则法（VADER/TextBlob）与深度学习模型对同一批标题打分，用相关性比较并选稳定的一路入模。
- 用"日期 + 标的 + 标题 + 事件日收益 + 情感分"的事件表组织监督验证数据。

## 关键实现
- 关键调用：nltk.sentiment.vader.SentimentIntensityAnalyzer 初始化并合并自定义词典；对 headline 列逐条打分生成 vader_sent；px.scatter(ldf, x='vader_sent', y='eventRet', facet_col='ticker', facet_col_wrap=3)；ldf.corr()。
- 依赖 nltk、pandas、numpy、plotly.express；词典文件 lexicon_sentiment.csv，输出 sent_label_added_corpus.csv。

## 数据与假设
- 美股新闻标题语料（2011 年前后，含 AMZN/NFLX/MSFT 等），字段含事件收益 eventRet 与三种情感得分。
- 假设金融词典能修正通用词典对金融表述的误判，且标题情绪与事件收益存在可观测关系。

## 局限与风险
- 只做到散点图与相关矩阵的可视化观察，没有给出相关系数数值、显著性检验或分层收益统计，情绪因子是否有效未结论化。
- 规则词典法无法处理反讽、否定与上下文，标题中的数字与涨跌幅符号容易干扰打分。
- 词典来自外部研究语料，迁移到中文 A 股新闻需重建中文金融情感词典；原文未涉及因子入模与策略回测。
