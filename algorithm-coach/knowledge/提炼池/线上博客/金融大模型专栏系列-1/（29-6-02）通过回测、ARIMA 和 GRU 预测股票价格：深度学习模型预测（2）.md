# （29-6-02）通过回测、ARIMA 和 GRU 预测股票价格：深度学习模型预测（2）

## 筛选结论
保留 —— 深度学习时序预测的工程骨架（三维张量切分、GRU 结构、早停、MSE 评估），网络结构可直接迁移到 A 股个股收益率预测。

## 核心内容
1. 划分：按样本顺序取 75% 训练、25% 测试（threshold = int(X.shape[0] * 0.75)），训练 3468 条、测试 1156 条，不使用随机切分。
2. 输入为三维张量 (样本数, 13, 13)，即 13 个时间步 × 13 个特征的滚动窗口，标签为单一标量。
3. 网络四层：InputLayer(13,13) → GRU(64) → Dense(8, 'relu') → Dense(1, 'linear')，回归单目标。
4. 训练配置：EarlyStopping 监控验证集损失；损失函数 MSE；优化器 Adam；评估指标 RMSE；epoch 上限 100。
5. GRU 以重置门与更新门替代 LSTM 的三门结构，参数更少、计算更高效，缓解长序列上的梯度消失与爆炸。
6. 评估结果：测试集 MSE = 0.003459；同时用预测值与实际值曲线目视核对形态。
7. 原文给出的注意五条：数据必须规范化；学习率不宜过大或过小；用 dropout/L2/早停做正则化；调整层数与每层神经元数等超参；采用交叉验证、留出法或自助法验证。

## 可复用要点
- 结构基线：单层 GRU(64) + Dense(8, relu) + Dense(1, linear)，Adam + MSE，EarlyStopping，epochs ≤ 100；参数规模小，适合作 A 股个股预测的起点模型。
- 输入构造：把 (N, T, F) 三维张量对齐到单目标回归任务，T=13、F=13 是可参考的窗口与特征数量级。
- 划分纪律：严格按时间顺序切分、禁止随机 shuffle，这是时序任务与普通 ML 的关键区别。
- 入模前必做数据规范化（原文列为第一条注意事项），否则量纲差异会引入偏倚。
- 双重核对：先报 MSE 数值，再把预测与实际曲线并排目视验证。

## 关键实现
- 依赖 TensorFlow/Keras（Sequential、InputLayer、GRU、Dense、EarlyStopping）、pandas、numpy、matplotlib、sklearn.metrics.mse。
- 建模序列：Sequential() → InputLayer((X_train.shape[1], X_train.shape[2])) → GRU(64) → Dense(8,'relu') → Dense(1,'linear') → summary()。
- 预测与评估：model.predict(X_test).flatten() → DataFrame{'Test Predictions','Actuals'} → round(mse(...), 6) 打印。
- 可视化隐藏顶部与右侧边框（spines），添加图例与轴标签。

## 数据与假设
特征张量 X 形状 (4624, 13, 13)、y 为 4624 个标量；标的、频率、时间范围与 13 个特征的具体名称本篇未给出（应由前序章节定义）。隐含假设：目标口径一致、入模前已规范化、训练期与测试期分布可比。

## 局限与风险
只报 MSE 0.003459，未给 RMSE、方向准确率或与朴素基准（如"预测值=上期值"）的对比，价格近似随机走动时小 MSE 并不代表有预测力；收录文本中 EarlyStopping 与编译部分被省略，复现信息不完整；13 个时间步、13 个特征、64 隐状态等超参未做敏感性分析；仅一次性留出切分，未做滚动回测或交叉验证；未考虑交易成本、涨跌停与 T+1，模型输出不能直接充当交易信号。
