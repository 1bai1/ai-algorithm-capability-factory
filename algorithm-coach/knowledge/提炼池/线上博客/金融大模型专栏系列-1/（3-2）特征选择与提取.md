# （3-2）特征选择与提取

## 筛选结论
保留 —— 直接对应本项目的特征工程环节：既给出特征选择方法清单（方差、相关性、模型重要性、正则化、RFE），也给出金融时序与文本的特征提取清单，并附股票价格预测、涨跌分类与情感分类三个可运行实例。

## 核心内容
1. 特征选择五法：方差阈值（剔除近似常量特征）、与目标变量的相关性筛选、基于模型的重要性（随机森林/梯度提升树）、L1/L2 正则化（Lasso/Ridge）、递归特征消除 RFE。
2. 特征提取七类：PCA、ICA、特征哈希（高维稀疏）、自动特征工程（GAN/神经网络生成）、时间序列技术指标、文本特征（词袋/TF-IDF/Word2Vec/GloVe）、图像特征。
3. 金融时间序列的典型提取对象：价格与成交量的移动平均、波动性指标（标准差）、技术指标 RSI 与 MACD。
4. 实例 3-4（te.py）先用相关性阈值 0.2 初筛特征，再用随机森林回归的 feature_importances_ 排序，MSE 评估，输出最高价 0.457 > 最低价 0.335 > 开盘价 0.208 为前三重要特征。
5. 实例 3-5（zhang.py）用移动平均、技术指标、波动性、成交量特征 + 随机森林分类预测涨跌，在小样本测试集上准确率 1.0。
6. 实例 3-6/3-7 用 TF-IDF 向量化股民情感文本，接单层全连接的 PyTorch 二分类器（BCEWithLogitsLoss + Adam），并用混淆矩阵热力图展示结果。
7. 原文明确指出情感分类 100% 准确率是小样本过拟合所致，需用真实大规模情感数据。

## 可复用要点
- 特征筛选流程：先算与目标的相关性并按阈值（示例 0.2）粗筛 → 再用树模型 feature_importances_ 精排 → 保留 Top-K，以降低维度并抑制过拟合。
- 候选因子池：收盘/成交量的移动平均、波动率（标准差）、RSI、MACD、成交量变化。
- 文本情绪因子：新闻与社媒文本用 TF-IDF 或 Word2Vec/GloVe 向量化后作为分类特征。
- 评价指标：回归用 MSE，分类用 accuracy / precision / recall / F1 与混淆矩阵。
- 正则化选型：需要稀疏化做特征选择用 L1（Lasso），需要抑制共线性用 L2（Ridge）。
- 划分约定：train_test_split，测试集占 20%。

## 关键实现
依赖 scikit-learn（RandomForestRegressor/Classifier、train_test_split、mean_squared_error、accuracy_score、classification_report、TfidfVectorizer）、PyTorch（nn.Linear 单层、BCEWithLogitsLoss、Adam、DataLoader 批量训练）、matplotlib/seaborn（真实价 vs 预测价对比折线、混淆矩阵热力图）。输入为 CSV（ningde.csv、zhang.csv 含日期与开高低收/成交量）或 text+sentiment 标签的文本数据；输出为特征重要性排序、MSE/准确率与分类报告。

## 数据与假设
ningde.csv、zhang.csv 均为示例（后者原文注为虚拟数据）的日频 OHLCV 表；情感实例仅 4 条内置示例文本，升级版从 your_data.txt 读取股民情感文本与积极/消极标签。假设特征与目标之间存在可学习的相关性，且样本量足以避免记忆。

## 局限与风险
- 示例数据集为虚构或极小样本：MSE≈1.93 与准确率 1.0 无实际参考价值，原文亦承认过拟合。
- 特征筛选在全部数据上做相关性计算、评估用固定测试集，未按时间切分，存在前视偏差与选择偏差（在测试集上反复调特征）。
- PCA/ICA/特征哈希/自动特征工程只在方法层面罗列，未在金融数据上验证。
- 全程无交易成本、无信号净值和回测，不能直接得出可交易结论。
