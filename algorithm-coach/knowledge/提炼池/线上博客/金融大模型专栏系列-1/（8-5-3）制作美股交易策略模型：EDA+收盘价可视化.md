# （8-5-3）制作美股交易策略模型：EDA+收盘价可视化

## 筛选结论
保留 —— 数据体检（缺失值、多标对齐、分布与相关结构）是数据清洗的标准前置步骤，可直接用于 A 股个股画像前的数据检查。

## 核心内容
1. 完整性体检：对 GOOG、AAPL、META、AMZN、MSFT 与 GSPC 分别用 isnull().sum() 逐列统计，六份数据缺失值全为 0；原文把"无缺失"视为可靠分析的必要条件。
2. 多标的对齐：pd.concat([...], axis=1) 合并六份 Close 并重命名列，得到 2673 行 × 6 列 的对齐收盘价矩阵（自 2012-05-18 起）。
3. 箱线图（fivethirtyeight 风格）显示 META、AAPL、GOOG 收盘价存在离群值，原文解读为发生了显著事件或特殊市场条件，需要进一步归因。
4. scatter_matrix 散点矩阵展示两两关系，可观察相关性与偏斜；原文指出 META、AAPL、GOOG 偏斜明显，提示存在极端值。
5. 可视化规范：%matplotlib inline + retina 图形格式 + seaborn whitegrid 与自定义六色调色板，固定 RANDOM_SEED = 42 保证可重复。
6. 走势结论：GAFAM 股价在 2020 年初 COVID-19 危机前持续上涨，之后经历复苏与波动，其中 META 在该阶段出现显著下跌。

## 可复用要点
- 数据体检四步：逐列查缺失 → 按日期合并对齐 → 箱线图查离群与分布 → 散点矩阵查相关与偏斜，可嵌入 Agent 的数据校验环节。
- 多标对齐范式：以日期为索引 concat 各标的 Close 构成宽表，便于横截面对比、相关性分析与配对/轮动类策略。
- 离群值原则：识别出的离群点应回溯到具体事件日期，而非一律剔除（原文将其视为重大事件的信号）。
- 可复现性：固定随机种子 42；字段口径为 Open/High/Low/Close/Adj Close/Volume 六个字段。

## 关键实现
- 无自定义函数；核心调用 isnull().sum()、pd.concat([GOOG.Close, AAPL.Close, META.Close, AMZN.Close, MSFT.Close, GSPC.Close], axis=1)、dataset.columns 赋值、dataset[...].boxplot()、pd.plotting.scatter_matrix(..., figsize=(10,10))、plt.plot(dataset['GSPC'], 'grey', label='S&P 500')。
- 样式设置：rcParams['figure.figsize'] = 18, 10；sns.set(style='whitegrid', palette='muted', font_scale=1.2)；HAPPY_COLORS_PALETTE 六色；np.random.seed(42)。
- 依赖 pandas、numpy、matplotlib、seaborn。

## 数据与假设
GOOG、AAPL、META、AMZN、MSFT 与 S&P 500 指数（GSPC），日频，2012-05-18 至 2022-12-30 共 2673 个交易日，无缺失。隐含假设：各标的交易日历一致，可按日期直接对齐。

## 局限与风险
本篇仅为建模前的 EDA 与绘图，不含预测模型、交易策略或回测，无有效性结论；对齐依赖交易日相同，A 股与美股节假日不同需显式处理；箱线图与散点矩阵均为视觉判断，无统计检验或量化阈值；"META 显著下跌"属事后叙事，未做归因验证；同时出现 Close 与 Adj Close 但未说明复权口径，长期横截面对比会因复权差异累积偏差；样本期内 COVID-19 等极端时段未分段处理。
