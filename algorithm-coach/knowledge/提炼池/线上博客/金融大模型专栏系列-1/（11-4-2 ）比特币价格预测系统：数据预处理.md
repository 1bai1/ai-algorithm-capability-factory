# （11-4-2 ）比特币价格预测系统：数据预处理

## 筛选结论
保留 —— 分钟级币价到日频的清洗与聚合流程，属数据获取与清洗环节，可直接迁移为 A 股高频数据的降采样模板。

## 核心内容
- 数据为 Bitstamp 的比特币 1 分钟历史数据，覆盖 2012-01-01 至 2021-03-31。
- 主流程：时间戳（秒）转日期 → 按日分组 → 对加权平均价 Weighted_Price 取日均值，得到日频价格序列。
- 过滤只保留 2017 年及以后的数据，并以 Timestamp 为索引。
- 设定预测天数为 50，用于后续划分训练集/测试集。
- 另有两段与建模无关的辅助代码：os.walk 列出 input 目录文件、IPython HTML 自定义 notebook 标题样式。

## 可复用要点
- 字段与转换：pd.to_datetime(Timestamp, unit='s') → date；用 Weighted_Price 而非 Close 作为日价格代表值，降低单笔异常成交影响。
- 聚合模板：groupby(date).mean() 做分钟→日降采样；用时间起止过滤控制回看窗口长度。
- 关键参数：prediction_days = 50。

## 关键实现
纯 pandas/numpy 脚本。核心语句：df['date'] = pd.to_datetime(df['Timestamp'], unit='s').dt.date；Price = groupby('date')['Weighted_Price'].mean()；to_frame → reset_index → 年份过滤 → set_index("Timestamp")；Price.to_numpy()。依赖 os、pandas、numpy、IPython.display.HTML。

## 数据与假设
BitstampUSD 1 分钟颗粒度，2012-01-01 至 2021-03-31，标的 BTC/USD；假设日频加权均价可代表当日价格、2017 年后数据量足够训练。

## 局限与风险
未做缺失值、零成交时段与异常值处理；日均价抹平日内信息，不适于日内策略；2017 年前数据被直接丢弃且未说明理由；文中称"将拥有训练/测试集"，但未见实际切分代码；样式与目录遍历代码与建模无关。
