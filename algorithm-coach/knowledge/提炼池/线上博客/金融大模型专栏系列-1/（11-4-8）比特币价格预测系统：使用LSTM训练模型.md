# （11-4-8）比特币价格预测系统：使用LSTM训练模型

## 筛选结论
保留 —— 比特币价格预测系统的 LSTM 训练环节，给出了从归一化、监督样本构造到网络结构与训练参数的完整可用片段，可直接作为本项目深度学习预测模型生成的基线模板。

## 核心内容
1. 选型理由：LSTM 是 RNN 变体，能缓解长序列的梯度消失/爆炸，适合存在长期依赖的时间序列。
2. 数据准备四步：价格序列转 NumPy → reshape 成 (N,1) → MinMaxScaler 归一化到 [0,1] → 用"前一时刻价格作输入、当前时刻价格作目标"构造监督样本 → 再把 X 重塑为三维 (样本数, 时间步, 特征数)，此处为 (N-1, 1, 1)。
3. 网络结构：单层 LSTM(10 单元, activation='sigmoid', return_sequences=True, input_shape=(None,1)) + Dense(1)，共 491 个可训练参数（LSTM 480 + Dense 11）。
4. 编译与训练：loss='mean_squared_error'、optimizer='adam'、batch_size=5、epochs=20。
5. 训练过程：损失从第 1 轮 0.2960 迅速降到第 3-6 轮的 0.0134/0.0123/0.0099/0.0095，原文建议用 history 中的 loss 曲线判断过拟合/欠拟合并据以调参。
6. 提出了加深方向（注释形式保留）：继续叠加 LSTM 层并在层间加 Dropout(0.2)。

## 可复用要点
- 单变量价格预测的最小可用模板：MinMaxScaler + 一阶滞后构造 (X, y) + LSTM + Dense(1) + MSE/Adam，可直接生成价格预测基线代码。
- 输入形状约定 (样本数, 时间步, 特征数)，本例时间步与特征数均为 1；若要扩到多特征，第三维改为特征数即可。
- 超参起点：LSTM 单元 10、batch_size 5、epochs 20；加深时层间加 Dropout(0.2)。
- 归一化只对训练段 fit；预测后需 inverse_transform 还原价格量纲（原文本篇未演示）。
- 训练曲线（history）作为过拟合/欠拟合诊断依据，是模型调参的标准动作。

## 关键实现
依赖 Keras/TensorFlow（Sequential、LSTM、Dense）、sklearn.preprocessing.MinMaxScaler、numpy。无自定义函数或类。核心片段：
```
training_set = np.reshape(df_train.values, (len(training_set), 1))
training_set = sc.fit_transform(training_set)          # sc = MinMaxScaler()
X_train = training_set[0:len(training_set)-1]
y_train = training_set[1:len(training_set)]
X_train = np.reshape(X_train, (len(X_train), 1, 1))
model1 = Sequential()
model1.add(LSTM(10, activation="sigmoid", return_sequences=True, input_shape=(None, 1)))
model1.add(Dense(1))
model1.compile(loss='mean_squared_error', optimizer='adam')
history = model1.fit(X_train, y_train, batch_size=5, epochs=20)
```

## 数据与假设
比特币历史价格单变量序列（本篇未说明频率与时间范围，取自该系统前序的数据预处理章节）。假设相邻时刻价格存在可学习的依赖，且归一化后的价格序列可用单步预测建模。

## 局限与风险
- 仅用前一日价格预测当日价格、时间步长为 1，在价格水平上几乎无预测力（接近随机游走的复制），原文未与朴素基线比较。
- 未划分验证/测试集（直接在 df_train 上构造 X/y），无样本外评估，只有训练 loss，无 RMSE/MAE 等指标。
- loss 快速收敛到 0.0095 更像拟合了价格的水平值；原文未做反归一化与真实价格对比，也未说明为何 LSTM 用 sigmoid 而非默认 tanh。
- 无早停、无正则化（Dropout 被注释）、无随机种子，结果不可复现；未接交易回测，不能推断盈利性。
