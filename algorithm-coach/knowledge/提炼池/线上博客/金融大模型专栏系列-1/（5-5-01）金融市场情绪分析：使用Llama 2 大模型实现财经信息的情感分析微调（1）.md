# （5-5-01）金融市场情绪分析：使用Llama 2 大模型实现财经信息的情感分析微调（1）

## 筛选结论
部分保留 —— 金融新闻标题的情绪三分类可作情绪因子来源，其数据切分与评估指标设计可复用；但本篇主体是 LLM 微调工程流程，与行情预测模型环节不直接相关。

## 核心内容
- 动机：金融领域标注数据稀缺，用 Llama 2 在金融新闻标题数据上做三分类情感微调（positive/neutral/negative），并与基准模型对比。
- 流程：数据准备（读取→按情感标签分层切分→生成 prompt）→ 模型微调（PEFT/TRL）→ 测试集预测 → 指标评估 → 保存结果。
- 切分方案：每个情感类别 train 300 / test 300（random_state=42），剩余样本中每类抽样 50 条作评估集；训练集打乱后重排索引。
- 微调技术栈：transformers + datasets + accelerate + bitsandbytes（量化）+ peft + trl，为消费级 GPU 的常见参数高效微调组合。
- 评估函数输出总体准确率、逐类准确率、分类报告（精确率/召回率/F1）与混淆矩阵；标签映射 positive=2、neutral/none=1、negative=0。

## 可复用要点
- 情感标签数值映射与"未知标签归中性"的兜底策略，可用于情绪因子的离散化编码。
- 评估指标组合（accuracy + classification_report + confusion_matrix）适用于任何分类型因子的验证。
- 分层切分与随机种子约定（每类 train/test 各300、eval 每类50）是可复现的小样本切分模板。
- 微调组合（4bit 量化 + LoRA/PEFT + TRL）适合资源有限条件下的领域适配。

## 关键实现
- 函数：generate_prompt(data_point)（由新闻标题构造提示词）、evaluate(y_true, y_pred)（accuracy_score + classification_report + confusion_matrix）。
- 依赖：torch、transformers 4.36.2、datasets 2.16.1、accelerate 0.26.1、bitsandbytes 0.42.0、trl、peft、pandas、sklearn。
- 数据文件：sentiment-analysis-for-financial-news/all-data.csv，列名 [sentiment, text]。

## 数据与假设
- 数据源：Financial PhraseBank 风格的金融新闻标题数据集（标签+文本）；运行环境为单卡 GPU（cuda:0）或 CPU。
- 假设：新闻标题情绪与市场/个股走势相关（原文未验证）。

## 局限与风险
- 原文只写到评估函数定义，微调结果与基准对比数据均未给出，效果无验证。
- 仅用新闻标题，未做情绪与价格/收益的关联检验，作为因子的有效性未知。
- 环境版本组合存在兼容性疑问（如 torch==1.2.0 与 transformers 4.36.2 并用），照抄可能安装失败。
- 输出是离散三分类，未给出转为连续情绪因子的方案。
