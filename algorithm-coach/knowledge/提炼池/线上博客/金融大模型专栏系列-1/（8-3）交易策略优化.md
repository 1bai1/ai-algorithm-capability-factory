# （8-3）交易策略优化

## 筛选结论
保留 —— 前半部分给出交易策略的要素清单（可作为 Agent 生成策略代码的检查项），后半部分是用 TuShare 取 A 股数据训练强化学习交易策略的可运行实例。

## 核心内容
- 交易策略是生成买卖决策的规则集合，原文归纳出 12 个必须考虑的要素：买卖信号、市场参与者、时间框架、风险管理、订单类型（市价/限价/止损/止盈）、交易成本（佣金、买卖价差、滑点）、基本面分析、技术指标、回测与优化、多样化、心理因素、监管合规。
- 强调交易成本会直接侵蚀策略盈利，回测与参数优化是上线前的必经步骤。
- AI 交易策略优化被拆成 8 个环节：数据预处理与特征工程、机器学习模型、模型训练与优化、风险管理、实时决策、回测与评估、部署与监控、迭代优化。
- 实例目标：训练一个强化学习股票交易策略网络，策略由神经网络实现，加入 L2 正则化提升泛化，通过与交易环境交互最大化累积奖励。
- 数据用 TuShare Pro 接口获取浪潮信息（000977.SZ）2010-01-01 至 2020-01-01 的日线收盘价，只使用收盘价序列。
- 交易环境为自定义 gym.Env：观察空间是 [余额, 股票库存] 二维向量，动作空间为离散三动作（买入/卖出/持有）。
- 策略网络为三层全连接（128→64→动作数），L2 正则项以参数与零向量的 MSE 之和乘系数加入损失；训练 10000 个 episode 并输出奖励曲线。

## 可复用要点
- 策略规则的检查清单可直接作为 Agent 的策略代码生成模板：信号定义、订单类型、仓位、止损止盈、成本假设、回测口径缺一不可。
- 环境建模最小实现：state = [cash, holdings]，action = {buy, sell, hold}，是 A 股单标的 RL 策略的最小可用状态/动作空间设计。
- 正则化写法：`l2_loss = sum(MSE(param, zeros)) * l2_reg`，l2_reg=0.01，可用于任何策略网络的权重衰减实现。
- 数据接口：`ts.set_token(token)` + `ts.pro_api().daily(ts_code="000977.SZ", start_date=..., end_date=...)` 后取 `df["close"].values.astype(float)`，是 A 股日线取数的最小范式。
- 训练循环约定：episode 打印奖励、定期绘制奖励曲线，便于观察策略收敛。

## 关键实现
- 依赖：gym、torch（nn.Module、nn.Linear、torch.relu）、TuShare（tushare.pro_api）、matplotlib。
- 三类：`TradingEnvironment(gym.Env)`（含 observation_space、action_space、reset、step）、`PolicyNetwork(nn.Module)`（fc1=128、fc2=64、fc3=output_dim，l2_reg=0.01，forward 用 ReLU，calculate_l2_regularization 返回缩放后的 L2 损失）。
- 函数：`collect_data()` 返回收盘价数组；`train_policy_network(prices, l2_reg=0.01)` 返回策略网络与奖励序列；主函数负责训练、保存模型、绘图。
- 损失 = 策略损失（奖励项）+ L2 正则项，用优化器最小化。
- 原文源码路径标注为 daima/8/trade.py。

## 数据与假设
- 标的：浪潮信息（000977.SZ）单只 A 股；日频收盘价，2010-01-01 至 2020-01-01。
- 假设：只凭收盘价序列即可学习交易策略；环境未考虑复权、停牌、涨跌停、T+1 与交易成本。

## 局限与风险
- 奖励量级异常：输出显示 Episode 10 与 Episode 20 的 Reward 完全相同（6673009.12），既未归一化也不随训练变化，训练是否真正更新策略、奖励定义是否合理均存疑。
- 状态空间仅 [余额, 库存]，不含价格、持仓成本或技术指标，策略无法感知行情位置，等价于对价格序列做无信息决策。
- 未做样本外回测，没有收益率、夏普、最大回撤等任何评价指标，也无与买入持有基准的对比。
- 交易成本、滑点、涨跌停与 T+1 约束全部缺失，实盘结论不可采信。
- 网络用 MSE 逼近零参数做 L2，写法非常规，等价效果需验证。
