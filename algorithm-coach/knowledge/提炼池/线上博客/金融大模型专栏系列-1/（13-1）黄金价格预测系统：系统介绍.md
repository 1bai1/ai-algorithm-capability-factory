# （13-1）黄金价格预测系统：系统介绍

## 筛选结论
保留 —— 与"价格预测 + 策略模拟"的目标高度同构，模块划分与特征体系可作 Agent 生成流水线的骨架参考。

## 核心内容
1. 用机器学习预测金价高低价，再把预测价转为交易信号做策略模拟，形成"数据→特征→预测→策略→调优"闭环。
2. 七个模块：数据准备、特征选择（互信息）、LightGBM 预测、策略模拟、参数调优（Grid Search）、可视化、交互式参数输入。
3. 特征三类：滞后特征、滚动统计特征、L-moments 特征；清洗阶段剔除异常值。
4. 特征选择用互信息挑出信息量最高的滞后期特征，而非全量入模。
5. 策略模拟对比默认参数策略与网格搜索调优后的最优策略，以盈亏表现判定优劣，结论是调优策略更佳。
6. 可视化输出预测趋势图、策略盈亏曲线与调参过程图，并支持用户交互式调整模型与策略参数。

## 可复用要点
- 模块切分可映射为 Agent 的代码生成单元（数据/特征/预测/策略/调优/可视化/交互）。
- 三类特征构造模板：滞后、滚动统计、L-moments 分布形状统计。
- 用互信息做滞后阶筛选，可作特征工程模块的标准步骤。
- Grid Search 调策略参数，并以默认参数策略作为对照组。
- 评价输出用预测趋势图 + 策略盈亏曲线。

## 关键实现
原文无代码。技术栈：LightGBM（预测模型）、互信息（特征选择）、Grid Search（策略参数寻优）、Matplotlib（可视化）；模块命名为数据准备/特征选择/金价预测/交易策略模拟/参数调优/可视化/交互式功能。
