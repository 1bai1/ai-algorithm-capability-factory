# （26-5-03）基于OpenAI和LangChain的上市公司估值系统：定量分析（Quantitative Analysis）(3)计算估值

## 筛选结论
部分保留 —— 属基本面估值（股息折现与 FCFF 折现），不是时间序列预测；但"多情景估值 → 加权期望 → 估值偏离度"可作为个股横截面因子或预测标签的构造思路。

## 核心内容
- 双路径估值：同时用股息折现法（dividends_valuation）与自由现金流折现法（fcff_valuation）给同一家公司定价，两条路径互为交叉验证。
- 情景矩阵：盈利口径（TTM 实际 / NORM 正常化）× 增速口径（FIXED 固定 / TTM / NORM）共四组，每组再算一个衰退（recession=True）版本，形成 8 个估值结果。
- 加权期望：把四种正常情景与四种衰退情景的估值分别列表，按设定的衰退概率加权平均，得到 FCFF 与股息的期望估值。
- 偏离度：以每股价格/估值的比值减 1 衡量高估或低估（fcff_delta、div_delta、liquidation_delta），估值 ≤ 0 时统一置为哨兵值 10 表示异常。
- 输出示例：股息模型给出合理价格 43.88 美元；FCFF 四情景估值 [59.31, 54.00, 75.09, 71.83]，与市价一并打印便于比较。
- 中间量：预期增长率、每股收益、派息率、资本成本、累计 WACC、各期现值、终值、经营资产价值、现金与物业价值。

## 可复用要点
- 估值偏离度因子：price/value − 1 是一个可直接进入因子库的横截面特征，A 股同样可用（注意金融股与周期股的估值方法差异）。
- 情景化估值模板：口径组合（实际/正常化 × 固定/趋势增速）+ 衰退情形 + 概率加权的期望值，等价于对估值做一次蒙特卡洛式的场景离散化，可用于压力测试或不确定性度量。
- 哨兵值约定：估值非正时置为固定大值（10）而非 NaN，可避免后续排序被缺失值破坏——A 股 ST/亏损股估值失效时可直接沿用。
- 输入参数清单本身是很好的估值特征字典：增长率、派息率、股权成本、WACC、税率、负债权益比、无杠杆 beta、ERP、现金与有价证券、少数股东权益、总股本、存活概率、每股清算价值。

## 关键实现
- `dividends_valuation(...)` 与 `fcff_valuation(...)` 两个估值函数，输入为盈利、增长率、CAGR、无风险利率、行业派息率、股权成本与目标股权成本、历年 EPS 与派息率、调整后 TTM EPS、再投资 EPS、汇率、存活概率、每股清算价值等，参数以位置参数方式传入。
- 附 `dict_values_for_bi` 字典收集中间量供后续可视化/报告使用；`debug` 与 `recession` 为布尔开关。
- 期望值：`fcff_values_list` / `fcff_recession_values_list` / `div_values_list` / `div_recession_values_list` 四个列表，按衰退概率加权。
- 偏离度：`fcff_delta = price_per_share / ev_fcff - 1 if fcff_value > 0 else 10`（股息、清算价值同理）。

## 数据与假设
- 数据：上市公司财报口径的衍生指标（TTM 与正常化盈利、营收、EBIT、税率、股本、债务与现金、汇率等），来源为系列前序篇的财报解析结果；估值为美元报价。
- 假设：可用固定增长率或 TTM/正常化增长率刻画未来；存在衰退情景且可赋概率；终值按永续增长或退出倍数估算。

## 局限与风险
- 本篇是估值函数的调用与结果打印，两个估值函数内部公式定义在前序篇，本篇不含，无法独立复现。
- 输出片段被截断（FCFF 衰退情景的列表为空），且未给出最终结论或与市价的比较判定。
- 估值高度依赖增长与折现假设，原文未做敏感性分析，也未说明衰退概率如何取值，参数一改结果可能大幅偏离。
- 基本面估值与 A 股日频预测的接口是"因子/标签"，不能直接作为交易信号；原文也未做任何有效性检验。
