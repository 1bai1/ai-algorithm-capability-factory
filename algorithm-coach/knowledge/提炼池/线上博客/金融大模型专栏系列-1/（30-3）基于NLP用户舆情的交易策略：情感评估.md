# （30-3）基于NLP用户舆情的交易策略：情感评估

## 筛选结论
部分保留 —— 情绪打分与事件收益的相关性检验方法可借鉴（用于判断情绪因子是否有效），但结论为弱相关，且所用模型不适配金融语料。

## 核心内容
1. 用 TextBlob 对每条新闻标题计算情感极性，保存到 sent_blob 列；TextBlob 采用在电影评论语料上训练的朴素贝叶斯模型，原文自承可能不完全适合本任务，但胜在快速可用。
2. 数据结构为逐条事件级：ticker、headline、date、eventRet（事件收益）、Close、sent_blob，方便把情绪分与收益直接对齐。
3. 以 ticker 分面绘制 sent_blob 与 eventRet 的散点图，结果显示 Netflix、Tesla、Yelp、AMD 的散点相当分散，远非理想关系，原文明确指出这将成为模型误差来源。
4. 按 ticker 分组计算情感极性同事件收益的相关系数，并用柱状图展示。
5. 分组相关性结论：亚马逊和 Adobe 的相关性最低，特斯拉的相关性高于预期；整体偏低说明模型难以找到新闻内容与收益之间的关系。
6. 最后删除 sent_blob 列，为后续正式情感评估（更领域化的模型）让路。

## 可复用要点
- 因子有效性检验范式：先算情绪得分 → 与事件收益做散点/分组相关性分析 → 确认有效后再入模。
- 数据组织范式：ticker + headline + date + eventRet + Close + 情绪分，按标的分别统计相关性。
- 结论提示：通用情感模型在金融文本上的因子相关性弱，需金融领域词典或领域微调模型替代。
- 情感极性取值区间为 [-1, 1]，可直接作为连续型因子输入。

## 关键实现
- 打分：data_df['sent_blob'] = data_df['headline'].apply(lambda row: TextBlob(row).sentiment.polarity)。
- 可视化：plotly express 的 px.scatter(x='sent_blob', y='eventRet', facet_col='ticker', facet_col_wrap=3, template='plotly_white')。
- 分组相关性：dict(tuple(data_df.groupby('ticker')))，逐组调用 Series.corr() 求 sent_blob 与 eventRet 的线性相关。
- 依赖：TextBlob（基于 NLTK 与 Pattern）、pandas、plotly。

## 数据与假设
新闻标题数据，ticker 覆盖 AMZN、NFLX、MSFT、TSLA、YELP、AMD、ADBE 等美股，带 2011 年前后的事件收益 eventRet 与收盘价 Close，频率为事件级。假设新闻标题情绪能代表舆情，并与事件收益存在可检验的相关性。

## 局限与风险
- TextBlob 基于电影评论语料，金融文本上的情绪判断能力有限，原文自陈不匹配，属通用词典式打分的固有偏差。
- 相关系数整体偏低，情绪与收益无稳定线性关系；只按 ticker 分组，未考虑时间滞后、市场整体情绪与其它因子，因果方向不明。
- 样本与结果披露不完整：eventRet 口径未定义，各分组相关系数的具体数值与样本量均未给出。
- 事件级数据的时间对齐与收益窗口选择会影响相关性结论，原文未作说明。
