# （28-2）使用隐马尔可夫模型交易比特币：数据预处理

## 筛选结论
部分保留 —— 把零散的成交记录对齐成连续日频价格序列并补缺，属于数据清洗环节，思路可迁移到 A 股交易日序列的缺口处理，但本篇只覆盖插值这一最小环节，无特征工程内容。

## 核心内容
- 目标：为 2014-12-01 至 2019-01-07 的每一个自然日构造一个比特币价格值，缺失日记为 NaN。
- 补缺规则（局部平均插值）：某日缺失时，向后找到下一个非缺失日，用"前一日值与该非缺失值的平均"填充；若其后已无有效数据，则沿用前一日值（即前向填充兜底）。
- 缺失成因与 (3-4-01) 一致：交易所停机、API 不可用或数据采集错误导致某些时间戳无记录。
- 补缺后绘制日价格折线图，人工检查序列的连续性与合理性，作为数据预处理的收尾步骤。

## 可复用要点
- 对齐模板：用 `while date < enddate` 按自然日推进，缺值 append NaN，把稀疏成交数据整理成规整的等间隔序列——A 股需替换为交易日历（停牌日同样产生缺口）。
- 补缺策略：中值式填充 `0.5 * (前值 + 后值)` 仅适用于断点稀疏的连续变量，能保留局部水平；序列尾部无后续数据时退化为前向填充。
- 重要提醒：A 股停牌期的价格缺口不适合用简单插值填补（停牌往往伴随信息，且复牌后跳空），实际应做前向填充并加"停牌"标记，而不是取前后均值。
- 补缺完成后必须画图核对（本篇即以此收尾）。

## 关键实现
- 工具：datetime、numpy（np.nan / np.isnan）。
- 向量构造：初始化 `date = datetime.date(2014, 12, 1)`、`enddate = datetime.date(2019, 1, 7)`，循环内按 `datetime.timedelta(days=1)` 推进，命中 `Real_Price.index[j]` 则取值否则填 NaN；`BC_Prices = np.array(BC_Prices)`，`ndays = BC_Prices.shape[0]`。
- 填充：外层 `for i in range(ndays)` 判断 `np.isnan`，内层 `while j < ndays and np.isnan(BC_Prices[j])` 定位下一个有效值 `j`，再赋值。

## 数据与假设
- 数据：BTC/USD 日频价格序列（上游为 coinbaseUSD 1 分钟数据按日聚合的 Weighted_Price 均值，来自同系列 (3-4-01)）。
- 范围：2014-12-01 至 2019-01-07，按自然日推进，无休市概念。
- 假设：缺失日价格可由相邻两个有效日的均值近似。

## 局限与风险
- 插值只按时间轴前后取均值，未考虑缺失时长；连续多日缺失时该方法会生成一段人造的平滑价格，扭曲波动率与收益率分布。
- 交易日历按自然日推进，未处理时区与交易所休市差异；此逻辑不能直接搬到 A 股交易日。
- 缺失值的数量与占比未统计，无法评估插值对后续 HMM 训练的影响程度。
- 本篇无异常值剔除、无价格跳变处理、无复权概念（加密资产无此问题，A 股必须有）。
