# （26-6）基于OpenAI和LangChain的上市公司估值系统：估值报告可视化

## 筛选结论
不适用 —— 全篇只描述 Tableau / PowerBI 估值仪表板的展示效果，没有任何建模与数据代码，属 BI 工具报表范畴；仅"估值结果如何组织呈现"可作输出格式参考。

## 核心内容
- 目的：用商业智能工具把估值系统结果做成可交互仪表板，便于理解公司价值与市场环境。
- Tableau 仪表板：用 ticker 过滤器切换公司，显示当前每股价格与公司常规信息、按国家/地区的地理分布、公司最新文件各部分的表格；点击左侧文件章节可在右侧查看对应摘要（摘要由 OpenAI API 抽取生成）。
- 估值视图：可在 8 个场景间切换并对比估值结果，覆盖自由现金流估值与股息估值；图表展示未来 10 年预估收入、EBIT、自由现金流与股息；在右侧改参数即可切换场景，底部列出公司价值构成与估算每股价值。
- PowerBI 做了对应版本，差异是用瀑布图替代简单条形图（原文指出在 Tableau 中做瀑布图需要额外的数据格式处理）。
- 本篇纯工具与界面说明，无任何代码与字段定义。

## 可复用要点
- 仅有一条可参考的输出结构（非算法）：公司基础信息与股价 → 文件章节摘要 → 多情景估值（DCF 与股息）→ 未来 10 年收入/EBIT/FCF/股息预测曲线 → 企业价值构成 → 每股价值，并支持情景参数切换。可作为 Agent 生成估值/预测结果报告时的组织模板。
- 8 情景可切换的"多情景对比"呈现方式，可复用于预测结果的多假设展示。

## 关键实现
无（原文未给出任何代码、API 调用或字段定义）。

## 数据与假设
数据来自该估值系统已产出的结果（ticker、每股价格、文件章节与摘要、8 个估值情景、10 年预测财务指标）。本篇未交代数据规模、频率与来源接口。

## 局限与风险

- 原文未说明 8 个情景的参数与假设来源，未验证估值准确性；配图缺失，无法核对界面内容。
