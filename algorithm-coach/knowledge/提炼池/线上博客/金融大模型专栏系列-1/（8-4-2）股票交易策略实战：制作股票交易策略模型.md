# （8-4-2）股票交易策略实战：制作股票交易策略模型

## 筛选结论
保留 —— 给出 FinRL 股票交易强化学习环境的完整参数配置与 DDPG 训练流程，对应本项目"交易策略与回测"环节，交易成本、持仓上限、奖励缩放等参数可直接参考。

## 核心内容
- 用 StockTradingEnv 初始化训练环境，一次性定义状态空间、动作空间、技术指标列表与全部交易约束。
- 关键资金与持仓参数：stock_dim 为标的数、hmax=1000（单标的最大持仓）、initial_amount=1,000,000（初始资金）。
- 交易成本买卖分开：buy_cost_pct=6.87e-5（约万分之 0.687）、sell_cost_pct=1.0687e-3（约千分之 1.07），卖出成本约为买入的 15.6 倍，符合含印花税的真实结构。
- 交易规则开关：initial_buy=True 允许开局建仓，hundred_each_trade=True 每次按 100 股（一手）成交易。
- reward_scaling=1e-4 用于压缩奖励量级，避免大额资金下奖励数值过大导致训练不稳。
- 训练环境通过 `get_sb_env()` 转成适配 Stable Baselines3 的向量化环境。
- DDPG 配置：batch_size=256、buffer_size=50000、learning_rate=0.0005、动作噪声 NormalActionNoise(mu=0, sigma=0.1)；策略网络 pi 与值函数网络 qf 的隐藏层结构由 POLICY_KWARGS.net_arch 指定；训练 10,000 步，日志名 ddpg，本次在 CPU 上训练。
- 每个 Episode 输出 begin_total_asset、end_total_asset、total_reward、total_cost、total_trades、Sharpe、time_elapsed，构成训练期的监控报表。

## 可复用要点
- 回测成本建模：买卖费率分开设置，并按 A 股"一手 = 100 股"约束下单（hundred_each_trade）。
- 环境约束模板：最大持仓 hmax、初始资金 initial_amount、是否允许初始建仓，这些约束决定了策略的可实现性。
- 奖励缩放 reward_scaling=1e-4 是 RL 交易训练的常规做法。
- 评价字段清单：总资产（期初/期末）、累计奖励、总交易成本、成交笔数、夏普比率——可直接作为本项目策略回测报告的基础字段。
- DDPG 参数起点：batch 256、buffer 5e4、lr 5e-4、动作噪声 sigma=0.1、10k timesteps。

## 关键实现
- 依赖 FinRL（StockTradingEnv、DRLAgent）、Stable Baselines3、config.INDICATORS（技术指标清单）。
- 关键调用：`e_train_gym = StockTradingEnv(df=train, **env_kwargs)`；`env_train, _ = e_train_gym.get_sb_env()`；`agent = DRLAgent(env=env_train)`；`model_ddpg = agent.get_model("ddpg", model_kwargs=DDPG_PARAMS, policy_kwargs=POLICY_KWARGS)`；`trained_ddpg = agent.train_model(model=model_ddpg, tb_log_name='ddpg', total_timesteps=10000)`。
- env_kwargs 必填项还包括 state_space、action_space（=stock_dimension）、tech_indicator_list、print_verbosity。

## 数据与假设
训练数据为此前章节切分好的 train（多标的日线 + 技术指标列）；state_space、stock_dimension、INDICATORS 由前文 config 决定；假设单账户整手交易、按日频决策。

## 局限与风险
- 未给训练/验证/测试的时间划分，也没有样本外回测结果，训练期奖励不能证明策略有效。
- 仅训练 10,000 步，对 DDPG 类算法通常远不足以收敛，参数与收益的关系无法据此判断。
- 没有基线策略（买入持有、等权）对比，也没有任何绝对收益/回撤数值。
- 成交价口径、滑点、是否允许做空等环境细节原文未说明，实盘迁移需自行验证。
- 与系列前文强耦合（df、config、state_space 均来自前篇），本篇不能独立复现。
