# （11-4-7）比特币价格预测系统：模型诊断

## 筛选结论
部分保留 —— 属 GreyKite 预测系统的诊断与出预测环节，其模型体检清单、预测输出字段与不确定度设置可迁移到价格预测系统的验证阶段。

## 核心内容
1. 诊断三步：看成分分解图（趋势/事件假期/季节性）→ 读模型摘要判断显著性与整体质量 → 打印 pipeline 核对处理链。
2. `plot_components()` 用于判断模型是否适配数据，暴露缺失的成分与改进空间，是上线前的自检手段。
3. `result.model[-1]` 取管道最后一个 estimator，`.summary()` 返回参数估计、显著性与置信区间；本例样本 222 条、特征 96 个。
4. pipeline 结构：输入侧分别抽取日期（ts）与响应（y），响应链依次做 z-score 异常值替换与插值补缺。
5. 不确定度用 simple_conditional_residuals，取 0.025/0.975 分位；有效样本少于 5 时退化为 std_quantiles，分位改用 0.98。
6. `make_future_dataframe(periods=4, include_history=False)` 生成未来 4 个周频点，预测输出含上下界与残差标准差。

## 可复用要点
- 预测输出字段设计：forecast + forecast_lower/upper + err_std，对应策略所需信号与置信度。
- 用分位数构造预测区间，小样本切换估计方法（阈值 5，分位 0.98）。
- 预处理顺序模板：列选择 → 异常值处理 → 缺失插值（interpolate, axis=0）。
- 频率枚举自带默认预测步长（周频 horizon=12），可自动决定多步预测长度。
- 成分分解图 + 模型摘要可固化为模型产出的自动体检清单。

## 关键实现
GreyKite 预测对象：`forecast.plot_components().show()`、`result.model[-1].summary()`、`result.timeseries.make_future_dataframe(periods, include_history)`。Pipeline：ColumnSelector(ts)/(y) → ZscoreOutlierTransformer → NullTransformer(impute_algorithm='interpolate', axis=0)；uncertainty_dict 关键项：quantile_estimation_method='normal_fit'、quantiles=[0.025,0.975]、sample_size_thresh=5、uncertainty_method='simple_conditional_residuals'；SimpleTimeFrequencyEnum.WEEK（default_horizon=12）。依赖 GreyKite、pandas。

## 数据与假设
比特币周频价格序列，start_year=2017，训练样本 222 条、96 个特征，示例预测 2021-04-04 起 4 个周频点；假设历史趋势与季节性可外推。

## 局限与风险
- 预测区间下界为负（-2914 ~ -3112），对非负价格不合理，说明残差正态假设与区间估计不适配。
- 只有 API 演示，无精度评价、样本外回测或误差对比。
- 示例数据止于 2021 年，季节性参数与当前市场未必匹配。
- 异常值/插值处理顺序未论证，未讨论前视泄漏。
