# （30-1）基于NLP用户舆情的交易策略：项目介绍+数据源

## 筛选结论
保留 —— 情绪因子 + 交易策略的选题与本项目"情绪分析用作因子"及策略生成环节高度对应，数据源、标的池、合并口径与候选特征清单都可直接借用。

## 核心内容
- 目标：用新闻标题与社交媒体的情感分析识别市场情绪，并据此预测股价变化、构造交易策略。
- 方法路线：依次评估基于朴素贝叶斯的 TextBlob、传统机器学习与深度学习三类情感分析方案。
- 关键做法是定制 VADER 金融词典——用金融语料更新通用情感词典，改善财经文本上的极性判断偏差。
- 分析重点为情感倾向与"事件收益"之间的关系，并做可视化呈现。
- 数据两块：行情来自 Yahoo Finance（yfinance），舆情来自 RSS 新闻标题（JSON 存储），另有 GitHub 上专家标注的标题数据集。
- 股票池 12 只：AAPL、MSFT、AMZN、GOOG、AMD、NVDA、TSLA、YELP、NFLX、ADBE、BA、AIG，区间 2010–2018。
- 合并口径：新闻表与行情表按股票代码 + 日期对齐；须先固定"事件收益"的定义（例如是否只用收盘价差）。
- 候选特征枚举：相关资产联动、技术指标（均线、动量）、财务报告指标（ROE、P/E）、新闻报道事件。

## 可复用要点
- 情绪因子的落地方式：以日期为键把情感得分并入行情面板，成为可与技术/基本面因子拼接的时序特征。
- 领域词典必须金融化：通用情感词典在财经文本上存在系统性偏差，需用领域语料增补替换。
- 标签口径先行：事件收益（窗口长度、价格口径）必须在建模前固定，否则回测口径不可复现。
- 特征来源清单（相关资产、技术指标、财务报告指标、新闻事件）可作为股票画像的特征枚举模板。
- 数据接口：yfinance 取 OHLCV；RSS 标题以 JSON 落地后解析。

## 关键实现
- 本篇为项目介绍与数据源说明，无独立代码实现。
- 提及工具：yfinance（行情）、TextBlob（朴素贝叶斯情感）、VADER（可定制词典）、RSS 解析。
- 数据处理步骤：解析 RSS JSON 头条 → yfinance 加载 2010–2018 收盘价 → 确定事件收益口径 → 按代码+日期合并。

## 数据与假设
- 行情：Yahoo Finance，2010–2018 年，12 只美股大市值标的。
- 舆情：RSS 新闻标题（JSON 存储）+ GitHub 专家标注标题集。
- 假设：新闻情绪与后续股价变动之间存在可交易的相关性，且新闻时间可对齐到对应交易日。

## 局限与风险
- 本篇未给任何实证结果或回测，情绪到收益的关系未经验证。
- 只覆盖美股大盘股，A 股（T+1、涨跌停、散户结构）上的可迁移性未知。
- 新闻发布时间与交易日对齐（盘前/盘后、时区）未作处理说明。
- 专家标注集的规模、标注一致性与主观偏差未说明。
- 未讨论交易成本、滑点、样本内外的划分方式。
