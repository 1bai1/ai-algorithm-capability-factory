# （8-5-6）制作美股交易策略模型：投资组合模拟+可视化+结论

## 筛选结论
保留 —— 完整的均值-方差组合优化实现（随机模拟 + SLSQP 求解最大夏普/最小方差/有效前沿），可作为本项目组合与仓位模块的参考实现。

## 核心内容
- 用 Dirichlet 分布随机生成 2673 组权重（`np.full(n_assets, 0.05)` 作浓度参数），对每组计算年化预期收益、年化波动率与夏普比率，形成组合云。
- 三个优化目标：最大化夏普比率（最小化负夏普）、最小化波动率、在给定目标收益下最小化波动率（后两者构成有效前沿）。
- 约束与边界统一为：权重和为 1 的等式约束 + 每个权重∈[0,1]（不允许做空），求解器 SLSQP，初值用 Dirichlet 随机权重。
- 最优解：最大夏普组合权重以 MSFT 0.4695、AAPL 0.2695、AMZN 0.2096 为主，年化收益 23.16%、波动 24.31%、夏普 0.8496；最小方差组合以 GSPC 0.6434 为主，收益 15.23%、波动 18.97%、夏普 0.6713。
- 可视化：散点图（横轴年化波动率、纵轴年化收益、颜色为夏普比率）+ 有效前沿曲线 + 最大夏普（红星）与最小方差（绿星）标记。
- 结论：在所分析区间，微软风险调整回报最优；Meta 波动最高；组合多元化受高相关性限制。

## 可复用要点
- 组合性能函数族：`portfolio_return(weight)`、`portfolio_volatility(weight) = sqrt(w'Σw)*sqrt(252)`、`portfolio_performance(weight)` 返回（收益, 波动）。
- 年化口径：`expected_returns = np.sum(mean_returns @ w) * 252`；`expected_vol = np.sqrt(np.dot(w.T, sigma @ w)) * np.sqrt(252)`。
- 最大夏普的写法：目标函数取 `-(return_p - rf)/vol_p` 交给 minimize；若改用随机搜索，可直接最大化 `(expected_returns - rf)/expected_vol`。
- 约束模板：`({'type':'eq','fun': lambda x: np.sum(x)-1})`；`satisfying bounds=((0,1),)*n_assets`；`method='SLSQP'`。
- 有效前沿：对目标收益网格 `np.linspace(return_min, 1.02, 100)` 逐点求最小波动，得到前沿曲线；该模式可复用到 A 股组合模块。
- 风险提示：无风险利率取值不同会直接改变最优权重（本例模拟用 0 而优化用 0.025）。

## 关键实现
- `negativeSR(weight)`：取负夏普供 minimize；`max_sharpe_ratio()`：内含 `sum_one(weight)` 辅助约束（原文该函数体被截断）。
- `min_vol()`：n_assets 取自 `returns.shape[1]`，`w0 = np.random.dirichlet(np.full(n_assets,0.05)).tolist()`。
- `efficient_portfolio_target(target)`：双等式约束（组合收益=target、权重和为 1）；`efficient_frontier(return_range)` 用列表推导批量求解。
- 可视化：`plt.scatter(expected_vol, expected_returns, c=sharpe_ratio)` + `plt.colorbar().set_label('Sharpe Ratio')` + 前沿虚线 + 两个星标点。
- 依赖：numpy、scipy.optimize.minimize、matplotlib；权重结果用 `to_frame().T` 展示。

## 数据与假设
- 输入为同系列前文得到的美股日频收益率矩阵 returns（实际输出含 GOOG/AAPL/META/AMZN/MSFT/GSPC 六列，正文说用 5 个标的且未提微软）。
- 假设：历史均值-协方差可代表未来；无做空、无杠杆、无交易成本与换手约束；无风险利率在模拟阶段为 0。

## 局限与风险
- 无风险利率前后不一致：模拟循环 `rf_rate = 0.0`，`negativeSR` 内 `rf_rate = 0.025`，导致散点颜色（夏普）与最优点标准不同源。
- 正文称"夏普比率最高（0.953%）"与权重表的 0.8496 不符；`max_sharpe_port` 变量在示例中前文未定义。
- `efficient_portfolio_target` 直接引用外部 `n_assets`，依赖全局状态，非自洽函数；`max_sharpe_ratio` 代码被截断。
- 均值-方差优化对输入估计误差极敏感（历史均值噪声大），未做收缩估计、重采样稳健性检验或样本外验证，最优权重易过拟合。
- 未考虑交易成本、再平衡频率、税费与流动性；结论基于单一历史区间，不能直接外推到 A 股或未来。
