# （3-1）数据清洗与处理

## 筛选结论
保留 —— 覆盖缺失值、异常值、重复值三类清洗动作的最小可用流程，是数据预处理模块的入门模板（示例本身存在明显缺陷，需修正后使用）。

## 核心内容
1. 数据清洗与处理属于数据预处理，包含对原始数据的修复、填充、删除和转换，使其适合训练与测试。
2. 缺失值处理有两条路线：删除含缺失值的整行，或按列均值填充，结果分别落盘为 cleaned 与 filled 两个 CSV，并用箱线图对比处理前后的收盘价分布。
3. 数据质量检查与异常值检测是不同概念：前者关注准确性、完整性与一致性（类型、重复、缺失），后者关注离群点；金融领域的异常值可能代表风险或机会，需谨慎判断是忽略、修正还是调查。
4. 异常值实例用均值 ± 标准差定义阈值，超阈值者标记为异常并替换为均值，再用箱线图对比处理前后分布。
5. 重复值处理用 Python 标准库 csv 逐行读取，用集合记录已出现的行，只把首次出现的行写入 cleaned_data.csv。
6. 原文强调去重直接关系到金融决策与风险管理的准确性和可靠性，金融机构会为此投入大量资源。

## 可复用要点
- 基础清洗流水线：读取 CSV → 缺失值检查 → 删除或填充 → 落盘新文件 → 箱线图对比处理前后分布。
- 缺失值填充的简易规则：列均值填充；删除策略适合缺失比例极低的场景。
- 异常值初筛规则：均值 ± 标准差阈值，超过则用均值替换（金融时序应先做收益率分布假设检查）。
- 去重实现：集合逐行过滤，零额外依赖，适合原始数据入库前处理。
- 方法选择提示：先分清“数据质量检查”与“异常值检测”的目标，再决定清洗手段。

## 关键实现
- 依赖：pandas（read_csv、to_csv）、matplotlib（箱线图）、csv（去重）。
- 示例输入：stock_data.csv（AAPL/GOOGL/TSLA/NVDA 少量日线，字段为日期、股票代码、开盘价、收盘价、最高价、最低价、交易量）；app.csv（极端价格波动示例）；data.csv（重复记录示例）。
- 输出文件：cleaned_stock_data.csv、filled_stock_data.csv、cleaned_data.csv。

## 数据与假设
示例数据为 2023-09-01 至 2023-09-05 前后四只美股日线片段，含人工构造的缺失值、极端值与重复行。隐含假设是缺失随机发生、列均值能代表该列的正常水平。

## 局限与风险
- 填充逻辑错误：按列全表取均值而未按股票代码分组，导致 AAPL 开盘价、TSLA 开盘价被填成 1066.48 这类跨标的污染值，结果不可用。
- 异常值实例自相矛盾：正文称收盘价由 160 涨到 250 再跌回 190 属极端波动需处理，但程序输出 Outliers 为空、Cleaned Data 与原始数据完全一致，示例实际未生效。
- 均值 ± 标准差本身受异常值影响，不稳健；原文未给出“极大值”或倍数阈值等具体参数。
- 去重按整行完全匹配，无法识别“同日期+同代码但字段值不同”的重复记录。
