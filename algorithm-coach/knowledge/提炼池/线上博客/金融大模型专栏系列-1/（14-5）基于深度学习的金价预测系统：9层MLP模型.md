# （14-5）基于深度学习的金价预测系统：9层MLP模型

## 筛选结论
保留 —— 给出"滞后 + 滚动窗口特征 → 互信息选特征 → PowerTransformer 标准化 → MLP 回归预测"的通用金价预测流程，特征构造与网络结构可直接迁移到本项目的价格预测模型生成。

## 核心内容
- 统一入口是一个性能评估函数 Performance，内部串联数据准备、特征拼接、特征筛选、标准化、网络训练、测试预测与可视化。
- 特征由 Prepare（滞后项 + 滚动窗口）与 Indicator（技术指标）两部分拼接，再丢弃最前面 100 行（由窗口特征产生的无效样本）。
- 用互信息（mutual information）按滞后阶数评估每个特征对目标列的重要度，保留 MI 大于阈值 mic 的列，其余全部删除。
- 输入 X 与目标 y 各自用 PowerTransformer 做标准化（使分布更接近高斯），再切分训练/测试。
- 网络为 Keras Sequential 的全连接结构：输入维 n_steps（=特征数），隐藏层 8*n_steps(ReLU) → 64(ReLU) → 32(Sigmoid)，全部使用 he_uniform 初始化。
- 测试集固定取最后 60 个样本，输出实际价格与预测价格的对比曲线。
- 调用示例：`Performance(Gold, 'Close', [1..29], [2..59], 3)`，即滞后 1-29 期、滚动窗口 2-59 期、MI 阈值 3。

## 可复用要点
- 特征参数区间：滞后阶数 1-29、滚动窗口 2-59，可作为价格序列特征生成的默认搜索范围。
- 特征选择：`mutual_information_lag(data, col, 100)` 得到按 MI 排序的特征字典，再用阈值（mic=3）截取，兼顾相关性与降维。
- 标准化：对 X 和 y 分别用 `PowerTransformer`，比 MinMax/Z-score 更能稳定极端行情下的分布（本项目可直接采用）。
- 网络结构：`Dense(8 * n_steps, relu, kernel_initializer='he_uniform')` → `Dense(64, relu)` → `Dense(32, sigmoid)`，输入维度随特征数自适应。
- 随机性固定：`seed(111)`。
- 该模型不针对特定目标列调参，是相对通用的版本（对比前文针对 Close 调优的 Performance_tune）。

## 关键实现
- 函数签名：`Performance(Data, col, Lag_list, Roll_window, mic)`，返回预测结果、实际值与对比表（原文返回值结构未完整展示）。
- 依赖：Keras `Sequential`/`Dense`，sklearn `PowerTransformer`，numpy/pandas；`Prepare`、`Indicator`、`mutual_information_lag` 三个辅助函数在本篇未给出定义（承接前文）。
- 关键代码顺序：`data = Prepare(Data, col, Lag_list, Roll_window)` → `df = Indicator(Data)` → `pd.concat([df, data], axis=1)` → `data.tail(data.shape[0]-100)` → MI 筛选 → `X_scaler.fit_transform(X)` / `y_scaler.fit_transform(y)` → `X[:-60] / X[-60:]` 切分 → `model.fit`（原文未展示 fit 语句）→ 预测与绘图。

## 数据与假设
- 金价数据集 Gold（承接 14-2，日频，2000-2022，OHLCV 五列），目标列 Close。
- 假设：特征充分滞后即可线性/非线性映射到未来价格；测试集为最后连续 60 个交易日。

## 局限与风险
- 标题称"9 层 MLP"，但给出的代码只有 3 个 Dense 层，层数与结构描述不符，无法判断完整模型。
- 标准化在切分训练/测试之前对全量 X、y 做 `fit_transform`，构成数据泄漏，测试集精度会被高估。
- 仅用最后 60 行做单次留出测试，无滚动/多折验证，金价单边行情下结果偶然性大。
- 原文自述该模型"只实现初级功能、还存在一些问题"，未给出误差指标（MSE/MAE/MAPE）数值，只有可视化图，无法量化评估。
- 丢弃前 100 行、MI 函数的第三参数 100 的含义均未解释。
