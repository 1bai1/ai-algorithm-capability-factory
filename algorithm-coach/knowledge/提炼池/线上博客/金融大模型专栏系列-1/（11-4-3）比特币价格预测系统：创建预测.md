# （11-4-3）比特币价格预测系统：创建预测

## 筛选结论
部分保留 —— 给出用 GreyKite 对 BTC 加权价格做时序预测的最小可运行配置（时间列/值列/频率 + 模型模板 + 预测步长 + 置信水平），可直接作为价格预测基线环节的代码模板；但本篇只是章节片段，不含特征工程与精度评估。

## 核心内容
1. 预测入口用 MetadataParam 声明三要素：time_col="Timestamp"、value_col="Weighted_Price"、freq（正文文字说 'D' 每日，代码实际写 'W' 每周）。
2. 用 Forecaster().run_forecast_config(df, config) 一次返回三部分结果：未来预测值、原始时间序列、历史预测性能（backtest）。
3. ForecastConfig 的关键参数：model_template=ModelTemplateEnum.SILVERKITE、forecast_horizon=30（未来 30 步）、coverage=0.95（95% 置信区间）。
4. Silverkite 模板内部按配置自动做交叉验证，日志显示 "Fitting 3 folds for each of 1 candidates, totalling 3 fits"，即 3 折验证、1 组候选参数。
5. 结果对象自带绘图接口，result.timeseries.plot() 直接产出含历史序列与预测区间的图。

## 可复用要点
- 声明式元数据建模：只要"时间列 + 值列 + 频率"三个字段即可启动单变量时序预测，适合作为 Agent 生成基线预测代码的模板。
- 超参解耦：forecast_horizon 控制外推步数，coverage 控制预测区间宽度（0.95 即 95% 置信）。
- 频率字符串决定重采样粒度（'D' 日 / 'W' 周），必须与数据实际粒度一致，否则预测窗口含义会错。
- 输出结果以 result.timeseries.plot() 直接可视化，减少自绘成本。
- 输出结构固定为 forecast + 原始序列 + backtest 性能，便于统一接入评价环节。

## 关键实现
依赖 greykite（Forecaster、ForecastConfig、MetadataParam、ModelTemplateEnum）。输入为含 Timestamp 与 Weighted_Price 两列的 DataFrame（df_price_include）。核心代码：
- metadata = MetadataParam(time_col="Timestamp", value_col="Weighted_Price", freq="W")
- result = Forecaster().run_forecast_config(df=df_price_include, config=ForecastConfig(model_template=ModelTemplateEnum.SILVERKITE.name, forecast_horizon=30, coverage=0.95, metadata_param=metadata))
- fig = result.timeseries.plot(); fig.show()

## 数据与假设
比特币历史价格数据，实际使用 Weighted_Price（加权价）单变量，时间列为 Timestamp；假设价格序列可由单变量时序模型外推，且按周频处理。

## 局限与风险
- 正文称频率为 'D'（每日）而代码写 'W'（每周），前后矛盾且未说明，预测 30 步的含义随之不同。
- 只使用单变量价格，未引入成交量、链上数据或宏观外生变量；未报告 MAE/MAPE 等精度指标，也无交易信号与回测收益。
- 原文未交代数据时间范围、样本量与预处理过程；无交易成本与执行约束，结果不能直接当作可交易结论。
