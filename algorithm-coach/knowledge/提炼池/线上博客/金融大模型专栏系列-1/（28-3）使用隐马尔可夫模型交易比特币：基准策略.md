# （28-3）使用隐马尔可夫模型交易比特币：基准策略

## 筛选结论
保留 —— 给出可落地的最小基准策略（前一日趋势跟随）与估值/交易次数统计框架，其中"摩擦率敏感性分析 + 时间旅行者上限"是评估任何策略都通用的方法论。

## 核心内容
- 基准策略规则：初始资金 1 美元；若当日对数收益率 r ≥ 0，则把全部资产换成比特币；若 r < 0，则全部换回现金。逐日收盘后更新组合价值，并累计交易次数。
- 该策略在无摩擦环境下表现极佳，远超直接持有比特币；但它几乎每个交易日都交易，交易成本因此成为决定性变量。
- 摩擦建模：把所有市场摩擦汇总为单一摩擦率 f。卖出时实得 (1-f)·b·p；买入时实得比特币 (1-f)·c/p。
- 评估三条曲线（纵轴取对数）：策略终值按 V0[-1]·(1-f)^交易次数 衰减；直接投资比特币为不受摩擦影响的水平线；"时间旅行者上限"UB 为假设能提前看到全部未来价格时的理论最大回报，并同时记录其交易次数。
- 结论指向：随摩擦率上升，趋势跟随策略回报迅速下降；与上限的差距可用于判断策略是否还有改进空间。
- 上限曲线同时输出交易次数，可用于观察高摩擦环境下最优交易者也会主动降低交易频率。

## 可复用要点
- 摩擦率敏感性分析应作为回测必选项：把 f 从 0 扫到 0.02（100 档），逐档重算终值，可直接给出"策略在多少成本下失效"的答案。
- 用 `终值 × (1-f)^交易次数` 近似成本侵蚀，只需终值与交易次数两个数，适合作为回测摘要里的一行指标。
- 设上限参照系（预知未来价格的最优交易者）比只对比 Buy & Hold 更有信息量，能区分"策略差"与"市场本身没机会"。
- 长期净值曲线统一用对数坐标；直接持有资产的净值用 P_t / P_0 归一化后与策略对比。
- 状态机式策略只需两个状态（现金/持仓）与四个变量（现金额、持仓量、状态标识、交易计数），是策略实现的最小骨架。

## 关键实现
- 组合记账：`Portfolio0 = np.zeros((ndays, 2))`，`Portfolio0[0,0] = 1`，状态标识 `a` 取 'c'（现金）/'b'（比特币），配 pc（现金）、pb（比特币）、ntrades（交易次数）。
- 摩擦扫描与绘图：`friction = np.linspace(0, 0.02, 100)`；`plt.semilogy(friction, V0[-1] * np.power(1 - friction, ntrades), label='previous day trend follower')`；直接投资比特币用 `plt.semilogy([0, 0.02], [BC_Prices[-1]/BC_Prices[0]]*2, label='bitcoin investment')`。
- 上限计算：对每档摩擦率重置 c=1、b=0、tc=0、tb=0，逐日调整现金与比特币比例以最大化终值，把结果与交易次数分别写入 `UB = np.zeros(100)`、`TR = np.zeros(100)`。
- 曲线绘制依赖 matplotlib 的 semilogy + legend + xlabel/ylabel。

## 数据与假设
- 数据为比特币每日价格序列 BC_Prices（长度 ndays），对数收益率由相邻价格计算；本篇未给出样本区间。
- 假设无摩擦情形下可按当日价格自由全额切换，不考虑滑点、成交延迟、最小交易单位；持有现金无利息。
- 时间旅行者上限使用后视为最优解，属于带未来信息的理想化参照，不代表可实现的策略。

## 局限与风险
- 成交时点未明确：策略按当日收益率决策，若按当日收盘价成交则无前视，若按次日开盘成交则存在一日滞后，原文未交代，存在前视偏差隐患。
- 无摩擦下"表现极佳"未给出具体倍数，无法量化优劣。
- 把手续费、买卖价差、冲击成本统一压成一个与交易规模无关的常数 f，对大资金不成立。
- 上限的求解方式原文只描述为"逐日调整比例取最大"，未证明其为全局最优，可能低估真实上限。
- 交易次数统计口径未定义（买入+卖出算一笔还是两笔），直接影响 (1-f)^交易次数 的幂次选择。
- 单一标的、单一历史区间，无跨市场/跨时段稳健性验证，也未报告回撤等风险指标。
