# (8-1)资产定价模型概述

## 筛选结论
部分保留 —— 资产定价理论（CAPM/APT/三因子）与市场非理性行为为因子设计提供依据，CAPM 的 TuShare + OLS 流程可作 A 股 β 与预期收益计算的骨架，但实例本身存在明显实现缺陷。

## 核心内容
- 资产定价与交易策略互为因果：定价理论给出预期收益与风险，策略据此设计，策略表现又反过来影响定价。
- CAPM：资产预期回报与系统风险成正比，用 β 衡量系统性风险，公式为 Ri = Rf + βi(Rm − Rf)。
- APT：预期回报由多个宏观/产业因子驱动（通胀、利率、产业周期等），通过多因子模型寻找未被消除的套利机会。
- Fama-French 三因子：在市场风险之外加入市值因子 SMB（小减大）与账面市值比因子 HML（高减低）。
- 行为金融层面列出七类非理性行为：情绪驱动交易、过度自信、羊群行为、投资者焦虑、信息不对称、赌博心态、超买超卖，可用于解释价格偏离与波动放大。
- 实例用上证指数与贵州茅台 2008-2023 日频数据估 β，并换算预期年化回报，原文给出 0.0007（0.07%）的结果。

## 可复用要点
- A 股数据接口：`ts.pro_api()`；`pro.index_daily(ts_code="000001.SH", start_date, end_date)` 取指数；`pro.daily(ts_code="600519.SH", ...)` 取个股；两表均以 trade_date 为索引按内连接合并。
- 对数收益构造：`np.log(1 + pct_chg / 100)`，可直接用作 A 股收益序列生成模板。
- β 估计流程：合并指数与个股收益 → 加常数项 → OLS 回归取斜率；可用于因子暴露、组合风险与对冲比例计算。
- 因子设计思路：把市场非理性行为（情绪、羊群、超买超卖）作为情绪类因子或风险提示的动机来源。
- 多因子框架（APT/FF3）可作为 A 股特征池的组织范式（市场 + 规模 + 估值 + 宏观）。

## 关键实现
- 源码路径 daima/8/capm.py；依赖 tushare、pandas、numpy、statsmodels.api。
- 步骤：`ts.set_token(token)` → 取数 → `pd.to_datetime(trade_date)` 设为索引 → 计算 log_return → `pd.merge(..., left_index=True, right_index=True, how='inner')` → `data['Intercept'] = 1` → OLS 估 β → 代入 CAPM 算预期年化回报。
- 原文代码在 OLS 处被截断，β 提取语句与 Rf 取值未展示。

## 数据与假设
- 标的：上证指数 000001.SH 为市场组合，贵州茅台 600519.SH 为个股；范围 2008-01-01 至 2023-09-01，日频。
- 假设：CAPM 成立、以指数收益代表市场组合、无风险利率为常数（具体取值原文未给）。

## 局限与风险
- 输出显示 R-squared=1.000、F-statistic=1.94e+34，回归近乎完全拟合，说明自变量选择或合并过程有误（疑似把收益对自身回归），据此得到的 β 与 0.07% 年化预期回报不可信。
- 未给无风险利率取值、未做残差诊断与平稳性检验，也未说明是否复权、停牌与分红处理。
- 0.07% 的年化预期回报显著低于常识水平，原文仅以"模型估计"一笔带过，未做合理性检查。
- 全文为教科书式概述，无回测、无因子有效性检验；非理性行为部分纯定性，无可操作的特征定义或阈值。
