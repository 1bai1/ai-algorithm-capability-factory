# （2）大模型开发技术栈

## 筛选结论
部分保留 —— 深度学习框架/数据工具/部署方案的泛泛介绍，没有建模方法或金融特征，仅可作为技术选型清单参考，与本项目算法生成环节弱相关。

## 核心内容
- 深度学习框架二选一：TensorFlow（生态全、有 TensorBoard/Serving/TFLite）与 PyTorch（动态图、Pythonic、扩展库丰富、研究友好），两者都被原文泛举了金融 NLP、风险管理、量化策略、市场预测用途。
- 数据处理：Pandas（DataFrame/Series、多源读写、缺失与重复处理、时间序列与滚动窗口）与 NumPy（多维数组、向量化/广播、数理函数、C 底层高性能）。
- 部署：Docker 容器化 + Kubernetes 编排，配合 TensorFlow Serving、ONNX Runtime，以及云平台/边缘设备/虚机等形态。
- 训练与调优：GPU/CPU 集群、Hyperopt/Optuna 自动调参、Horovod 分布式训练；模型架构列了 CNN/RNN/Transformer 与 BERT/GPT 预训练迁移。
- 安全与监控：ELK/Prometheus/Grafana，数据加密、访问控制、模型可解释性与对抗训练。

## 可复用要点
- 工具选型参考：深度学习时序模型优先 PyTorch（Lightning/TorchText 生态利于实验）；传统机器学习用 scikit-learn + NumPy/Pandas。
- 超参搜索可选 Optuna/Hyperopt；时序处理优先用 Pandas 日期索引与滚动窗口。
- 部署建议：模型容器化（Docker）+ 推理服务（ONNX Runtime/Serving）。
