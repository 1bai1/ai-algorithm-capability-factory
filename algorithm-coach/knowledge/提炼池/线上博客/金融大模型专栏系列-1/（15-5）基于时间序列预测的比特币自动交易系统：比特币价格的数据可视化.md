# （15-5）基于时间序列预测的比特币自动交易系统：比特币价格的数据可视化

## 筛选结论
部分保留 —— 提供了一套可直接复用的行情可视化组件（蜡烛图、OHLC 图、成交量面积图、相关性热力图），适合作为量化 Agent 的结果展示与因子相关性初筛模板；但不含预测、信号与策略逻辑。

## 核心内容
1. 技术栈为 Plotly（graph_objects/express/offline）画交互式行情图、Seaborn 画统计图，价格取 Close、成交量取 Volume。
2. 封装 candelstick_chart(data, title)：用 go.Candlestick 传入 open/high/low/close，输入为以时间为索引的 DataFrame。
3. 封装 ohlc_chart(data, title)：用 go.Ohlc 画 OHLC 图，x 轴标注 Time 并开启 rangeslider 便于缩放历史区间。
4. 封装 vol_traded(data, title, color)：用 px.area 画成交量面积图，可指定线条颜色。
5. 用 BTC_Data.corr() 配合 sb.heatmap(mat, annot=True) 画相关性热力图，用于观察各列之间的相互影响。
6. 观察窗口用切片控制：BTC_Data[-90:] 看最近 90 天，BTC_Data[:-200] 剔除最后 200 天，适配不同时间尺度。
7. 图表统一以 plotly_white 模板与居中标题（x=0.5、xanchor=center）输出。

## 可复用要点
- 可视化四件套：蜡烛图 / OHLC 图 / 成交量面积图 / 相关性热力图，函数签名统一为 (data, title[, color])。
- 切片约定：data[-N:] 取近 N 期、data[:-N] 去掉尾部 N 期，用于多尺度观察。
- 相关性热力图（annot=True）可作因子冗余初筛手段，高相关因子对提示共线性。
- 数据契约：索引必须是时间类型，列名遵循 Open/High/Low/Close/Volume 约定，否则封装函数不可复用。
- Plotly 图表对象需调用 .show() 才渲染。

## 关键实现
依赖 seaborn、plotly.express、plotly.graph_objects、plotly.offline、matplotlib。BTC_Data 为含 Open/High/Low/Close/Volume 列、以时间为索引的 DataFrame。核心片段：
- go.Figure(data=[go.Scatter(x=BTC_Data.index, y=BTC_Data['Close'], name='Close')])，用 update_layout 设标题与 template="plotly_white"
- go.Candlestick(x=data.index, open=data['Open'], high=data['High'], low=data['Low'], close=data['Close'])
- go.Ohlc(...) 配 update_xaxes(title_text='Time', rangeslider_visible=True)
- px.area(...) 画成交量，line_color 指定颜色
- mat = BTC_Data.corr(); sb.heatmap(mat, annot=True)

## 数据与假设
比特币日频行情数据 BTC_Data（Open/High/Low/Close/Volume，时间索引）。前提假设：数据已完成清洗与按时间排序，可直接切片、求相关与绘图；未说明数据来源与时间范围。

## 局限与风险
- 纯展示层：无特征构造、无模型、无交易信号与回测，不能直接产生策略收益。
- 相关性为全样本线性相关，未按训练/验证窗口切分，直接用于因子筛选存在前视偏差。
