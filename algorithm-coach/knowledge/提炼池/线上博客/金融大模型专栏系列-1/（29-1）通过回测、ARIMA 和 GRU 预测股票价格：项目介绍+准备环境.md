# （29-1）通过回测、ARIMA 和 GRU 预测股票价格：项目介绍+准备环境

## 筛选结论
部分保留 —— 本篇是项目蓝图与数据字典（GOOG.csv 的 14 个字段说明），对 Agent 的数据接口定义与流水线编排有参考价值，但无模型实现与实测结果。

## 核心内容
- 项目定位：先用 ARIMA 捕捉线性趋势，再用 GRU 处理非线性与长期依赖，两者结合做股价预测，最终以测试集 MSE 评估 GRU。
- 动机判断：ARIMA 类方法假设数据线性，无法处理复杂非线性关系与长时间依赖，因此转向 RNN 及其变体；GRU 相比 LSTM 参数更少、训练性能更好。
- 功能模块共五块：数据处理与预处理（数据加载清洗、特征工程，含开盘价/最高价/最低价等及衍生特征）；时间序列分析（ARIMA 建模，用 ACF/PACF 图选参并评估）；深度学习建模（GRU 训练与 MSE 评估）；预测与结果展示（预测值 vs 实际值对比图）；性能评价（输出 MSE）。
- 数据集为 GOOG.csv，1257 行 × 14 列，字段为 symbol、date、close、high、low、open、volume、adjClose、adjHigh、adjLow、adjOpen、adjVolume、divCash、splitFactor。

## 可复用要点
- 数据字典可作 A 股数据接口的对照物：原始价与复权价成对出现（close/adjClose、high/adjHigh、low/adjLow、open/adjOpen、volume/adjVolume），外加分红 divCash 与拆股 splitFactor——特征来源可归为"行情价量 + 公司行为"两类。
- 流水线编排顺序可复用作 Agent 模板：数据清洗 → 特征工程 → 统计基线（ARIMA，ACF/PACF 定阶）→ 深度模型（GRU）→ 预测可视化 → 指标评价（MSE）。
- 先用可解释的统计模型建基线、再用深度模型对比提升，比直接上深度学习更稳妥，且便于定位增益来源。
- 评价指标至少覆盖 MSE（水平预测精度）与方向类指标，单用 MSE 会被价格量纲主导。

- 假设仅使用价格类字段（开高低收与成交量）预测后续价格或方向；运行环境为本地 Python 加上述库。
