# （5-4-01）信贷投资组合风险评估模拟程序

## 筛选结论
不适用 —— 主题是信贷组合的预期损失与 VaR 模拟，与 A 股个股价格预测无直接关系；只有组合级风险度量公式（分位数函数、风险贡献、分布拟合）可作为通用风险模块参考。

## 核心内容
- 目标：用模拟方法评估信贷组合的预期损失（EL）与风险价值（VaR），参数含曝险 EAD、违约损失率 LGD、违约概率 p、样本数 n 与贷款间相关性。
- 分位数函数：用正态分位数把置信水平 α、相关性 ρ 与违约概率 p 组合成条件违约率 π = Φ((√ρ·Φ⁻¹(α)+Φ⁻¹(p))/√(1−ρ))，再乘 n·EAD·LGD 得到损失分位数（单因子正态口径）。
- 风险度量与风险贡献：定义 g() 与 RC() 两个函数，分别计算组合整体风险与单笔贷款的边际风险贡献。
- 情景对比一：风险贡献随违约概率变化，比较 E[LGD]=70% 与 30% 两种情景。
- 情景对比二：固定 ρ=20%，比较 α=99.5%、90%、40% 下的风险贡献曲线。
- 情景对比三：固定 α=90% 与 99.9%，比较违约概率 5% 与 10% 时风险贡献随 ρ 的变化。
- 分布拟合：用矩估计法与最大似然估计法估计 Beta 分布参数，对比损失的经验分布与拟合分布。
- VaR 实现：对模拟损失排序后按置信水平取分位数。

## 可复用要点
- 相关性下的损失分位数公式 π = Φ((√ρ·Φ⁻¹(α)+Φ⁻¹(p))/√(1−ρ))，可迁移到任何"相关性 + 尾部"的风险度量场景。
- 风险贡献（组合分位数对单个头寸权重的敏感性）可迁移到持仓风险归因。
- VaR 的非参数实现：模拟损失排序取分位数，不依赖分布假设。
- 分布拟合双路径（矩估计 vs MLE）与经验分布叠图验证的做法。
- 参数取值示例：EAD=1、LGD=0.5（情景 0.7/0.3）、p=0.05（情景 0.1）、n=100、α∈[0.01,0.99]、ρ∈{0.10,0.30} 或 ρ=0.20。

## 关键实现
- 函数：quantile_func(alpha, correlation) 返回 n*EAD*LGD*pi；g(weight, LGD, default_prob, rho, alpha) 与 RC(weight, LGD, default_prob, rho, alpha)（内部用 norm.ppf(default_prob)、norm.ppf(alpha) 求中间变量 p、q 后计算贡献）。
- 依赖：numpy、scipy.stats.norm、scipy 分布拟合、matplotlib。
- 源码路径 daima/5/xin.py；原文多数代码块被截断，只保留参数片段与文字说明。

## 数据与假设
- 无真实数据：损失由参数化模型模拟生成，违约概率、相关性、LGD 均为假定值。
- 假设单因子正态结构（贷款相关性由单一系统性因子驱动）、LGD 外生给定、违约时间随机。

## 局限与风险
- 全部为模拟数据，未在任何真实信贷组合上验证；p、ρ、LGD 取值主观。
- 正态单因子假设会低估尾部相关性，极端情形下 VaR 可能偏乐观。
- 原文代码大面积缺失（g()、RC() 的函数体与 Beta 拟合部分均未给出），不可直接运行。
- 实例编号标注为"实例5-2：处理股票数据中的缺失值"，与正文内容不符，文档存在错位。
- 属信贷/组合风险领域，与个股价格预测、交易信号无衔接。
