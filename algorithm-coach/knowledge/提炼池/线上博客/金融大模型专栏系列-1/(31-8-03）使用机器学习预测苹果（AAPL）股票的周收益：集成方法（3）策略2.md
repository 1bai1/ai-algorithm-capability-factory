# (31-8-03）使用机器学习预测苹果（AAPL）股票的周收益：集成方法（3）策略2

## 筛选结论
保留 —— "信号→持仓→收益→绩效对照"的完整可运行模板，含前视偏差的标准处理与 quantstats 指标清单，可改写为 A 股回测骨架。

## 核心内容
1. 策略 2：始终保持 100% 市场暴露；模型预测下一周 AAPL 下跌（看空）时卖空，其余情况持有多头。
2. 把 Predicted 列中的 0 替换为 -1，使预测列直接表达仓位方向（1 做多、-1 做空）。
3. position 取 Predicted 的 shift(1)，即用上一期预测决定本期持仓，避免用当周信息交易当周。
4. 收益口径：model_returns = position × returns，送入 quantstats 前统一除以 100 转为小数；基准为同口径的买入持有。
5. 回测区间 2014-06-02 至 2023-07-17，无风险利率设为 0。
6. 结果：累计回报与 CAGR 优于买入持有，但夏普比率更低、最大回撤更高、Serenity Index 也更高，即收益更高而风险调整后更差；与策略 1 相比，策略 2 风险更高、回报更低，原文结论为策略 1 更优。

## 可复用要点
- 信号转持仓模板：预测 {0,1} 或 {0,1,-1} → 仓位 → shift(1)，是消除前视偏差的最小改动；A 股不可做空，可将 -1 映射为 0 得到多头/空仓切换策略。
- 绩效指标清单（quantstats full report 一次产出，基准与策略并列）：累计回报、CAGR、夏普比率、年化波动率、最大回撤、Serenity Index。
- 判定原则：仅跑赢买入持有的累计收益不足以证明策略有效，必须同看夏普与最大回撤；本例即"收益更高但风险调整后更差"的典型反例。
- 口径纪律：全流程统一小数收益；无风险利率显式设为 0 并记录，便于跨版本比较。

## 关键实现
- 依赖 quantstats（qs.reports.full(model_returns, benchmark=benchmark)），上游为含 Predicted、returns 列的测试集 DataFrame。
- 三行核心逻辑：X_test['Predicted'].replace(0, -1)；position = Predicted.shift(1)；model_returns = position * returns。
- 输出为 Benchmark 与 Strategy 两列并列的 Performance Metrics 表。

## 数据与假设
标的 Apple（AAPL），周频收益预测；测试期 2014-06-02 至 2023-07-17；returns 为百分比口径；无风险利率 0。隐含假设：可无约束做空、仓位可 100% 满仓切换、交易成本与滑点为 0。

## 局限与风险
原文自述策略 2 的最大回撤高于基准、风险调整后表现不及基准与策略 1；未计入交易成本、融券费用与做空约束，绩效数字偏乐观；样本为单一标的单一时段，无跨标的与跨市场稳健性验证；Serenity Index 仅给方向性描述，无定义与数值；本篇未交代训练/测试划分细节，仅凭本篇无法确认是否存在信息泄漏；按周切换信号，未讨论信号拥挤与容量。
