# （28-5-01）使用隐马尔可夫模型交易比特币：实现交易策略（1）

## 筛选结论
保留 —— 给出"模型输出 → 阈值信号 → 网格寻优 → 分档摩擦率回测"的完整闭环，与 Agent 的信号生成、策略参数搜索、回测验证三个环节高度重合。

## 核心内容
- 信号来自 HMM 模型的两个输出：隐藏状态概率 `mdl.get_hidden_state_probabilities(Prices)` 与期望异常收益率 `EAR = mdl.get_expected_abnormal_rates(Prices)`；策略只使用 EAR。
- 交易规则：持有现金且 EAR[t] > 买入阈值时全仓买入；持有比特币且 EAR[t] < 卖出阈值时全部卖出。状态用标识符 a='c'/'b' 表示。
- 阈值寻优在 [-0.1, 0.1] 上取 200 个点构成网格，且只遍历 j ≤ i（卖出阈值不高于买入阈值）的组合，在训练数据上回测并取收益最大的一对；收益存入 R[res,res]，交易次数存入 T[res,res]。
- 摩擦率越高，最优买卖阈值的间距越大——即策略要求看到更极端的期望异常收益才愿意动手，以摊薄交易成本。
- 对 100 档摩擦率分别寻优后实际只落地 3 组不同阈值，因此回报对摩擦率的曲线呈分段线性。
- 测试段（自第 600 天起、初始 1 美元）结论：HMM 策略总是优于直接持有比特币与前一日趋势跟随策略，但随摩擦率上升，与直接持有比特币的差距趋于零。0.5% 摩擦下策略在上涨中涨得更快、下跌中避免长期损失；更高摩擦下只能跟随部分涨幅、规避部分下跌。

## 可复用要点
- 阈值策略模板：把模型输出（期望收益/概率）转成 (buy, sell) 阈值对，在训练集上二维网格穷举、以收益选优。该范式天然得到"成本越高、阈值越宽"的结论，可直接用于 A 股信号阈值化。
- 网格设计可复用：`X = np.linspace(-0.1, 0.1, res)`，双层循环 j 从 0 到 res、i 从 j 到 res，保证 sell ≤ buy；结果矩阵 R/T 便于事后画阈值热力图与交易频率图。
- 回测必须的三条对照基线：前一日趋势跟随、HMM 阈值策略、直接持有比特币；横轴取摩擦率、纵轴取对数回报。
- 应把"参数稳定性"作为评估项输出：100 档摩擦率只选出 3 组阈值，说明训练期最优解不稳定，这是判断过拟合的关键信号。
- 分档摩擦率（0.5% / 1% / 1.5%）各画净值曲线，可直接看出策略在哪个成本水平失去优势。
- 成本敏感性下策略与 Buy & Hold 的差距缩小到零，意味着策略的真实收益来源必须能被成本解释清楚，否则不应上线。

## 关键实现
- 训练段寻优 `back_train_pol(mdl, Prices)`：内部调用模型的两个方法取状态概率与 EAR；初始化 a='c'、pc=1、pb=0、ntrades=0；买入 `pb = pc / Prices[t]; pc = 0`，卖出 `pc = pb * Prices[t]; pb = 0`，每次切换 ntrades 加一；返回 (R, T)。
- 测试段回测 `back_test_pol(mdl, friction, Buy_Price, Sell_Price, Prices)`：返回 Portfolios（100×n×2，各摩擦率下的逐日持仓）与 Value（100×n，逐日净值）。
- 对照计算：前一日趋势跟随的测试段回报 = V0[-1]/V0[train_end] × (1-f)^ntrades_in_test_period0，交易次数用 `np.sum(Portfolio0[train_end:-1] * Portfolio0[train_end+1:] > 0)` 统计。
- 绘图：`plt.semilogy(friction, V1[:,-1]/V1[:,train_end], label='基于HMM优化的买入/卖出策略')` 与比特币水平线 `BC_Prices[-1]/BC_Prices[train_end]` 对比；单档摩擦净值用 `V1[i, train_end:]/V1[i, train_end]`，下标 i=25 / 50 / 75 分别对应 0.5% / 1% / 1.5%。
- 关键变量：train_end（训练段终点）、ndays（总天数）、Prices（比特币价格序列）。

## 数据与假设
- 比特币日频价格序列 BC_Prices；测试从第 600 天开始，样本区间原文未交代。
- EAR 是"异常"收益率而非原始收益率，本篇未解释异常的基准定义与数值量纲，只知它与 [-0.1, 0.1] 的阈值网格相匹配。
- 假设全仓进出的二值状态策略、无杠杆、无最小交易单位与流动性约束；每档摩擦率独立寻优一次阈值。

## 局限与风险
- 阈值在训练集上一次性选优后直接用于测试，未做滚动重估（walk-forward）；原文自己也指出训练期最优并不总是测试期最优。
- 100 档摩擦率只选出 3 组阈值，参数分辨率极低，说明优化目标对摩擦率不敏感，策略稳健性证据不足。
- 训练寻优的收益目标是否已扣除摩擦未在原文说明；若未扣除，选出的阈值本身偏乐观。
- 对照策略用 (1-f)^交易次数 近似成本，而 HMM 策略按逐笔摩擦扣减，两者口径可能不一致，比较不完全公平。
- 代码多处被截断（循环体、EAR 计算、训练/测试边界设定、若干绘图段），无法完整复现。
- 只报告终值对比，缺最大回撤、夏普、胜率、换手率等风险与交易质量指标。
