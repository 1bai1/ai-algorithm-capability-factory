# （6-3-01）量化交易（1）

## 筛选结论
保留 —— 前半为量化交易概念与波动率指标（可作为因子与风险度量的定义来源），后半给出 Optiver 波动率预测竞赛的数据接口与字段清单，字段级信息对微观结构特征工程有直接参考价值。

## 核心内容
- 量化交易六要素：以"市场存在可预测模式"为假设、依赖大量数据（历史价格、成交量、财务指标）、算法自动执行、策略多样（市场中性/趋势跟踪/套利）、风险管理（止损、仓位控制、分散）、技术基础设施支撑。
- 波动率分两类：历史波动率（由过去实际价格计算）与隐含波动率（由期权价格反推，代表市场对未来波动性的预期，可作市场情绪指标）。
- 波动率在量化中的四种角色：交易信号（高波动意味着更多机会）、波动率建模与预测（据此在升波时保守、降波时激进）、波动率交易策略（在期权或衍生品合约间做波动率差套利）、风险管理（调节仓位）。
- 项目背景：源自 Optiver 竞赛，要求预测数百只不同行业股票的短期波动率；模型结果与竞赛结束后收集的真实市场数据比对评估；流程包括数据探索、预处理（计算加权平均价格 WAP 与对数收益率）、特征工程与可视化。
- 数据文件：train.csv、example_test_files 下的 test.csv、revealed_targets.csv、sample_submission.csv。
- 字段清单：stock_id、date_id、time_id、seconds_in_bucket、row_id、imbalance_size、imbalance_buy_sell_flag、reference_price、matched_size、far_price、near_price、bid_price、bid_size、ask_price、ask_size、wap、target。
- 观测：价格类字段在 1.0 附近小幅波动，target 有正有负（示例 2.31、-8.22），测试集 far_price/near_price 存在 NaN。

## 可复用要点
- 波动率指标用法：以历史波动率做滚动风险度量与仓位调节依据；波动率升高时策略转保守、降低时转激进。
- 特征工程模板（微观结构类）：订单不平衡（imbalance_size、imbalance_buy_sell_flag、bid_size/ask_size）、价格类（bid/ask/reference/far/near_price、wap）、成交类（matched_size）、时间分桶（date_id、time_id、seconds_in_bucket）与标的 id（stock_id）。
- 预处理约定：先由盘口价格计算加权平均价格 WAP 与对数收益率，再进入建模；对 target 先做分布可视化。
- 缺失值处理是必需项：测试集 far_price/near_price 为 NaN。

## 关键实现
- 原文只给出数据载入与查看片段：os.walk 遍历目录列出文件；pd.read_csv 读入 train / test / revealed_targets / sample_submission；train.tail()、test.head()、rev.head() 查看数据。
- 依赖 numpy、pandas、matplotlib、seaborn、tqdm；示例文件为 volatility-matters-buckets-bid-prices.ipynb。
- WAP 与对数收益率的计算代码本篇未给出，仅文字说明前序已完成。

## 数据与假设
数据来自竞赛目录 optiver-trading-at-the-close（Kaggle Optiver 竞赛），含 train.csv 与 example_test_files 下三个文件；字段覆盖标的、时间分桶、盘口价格与数量、成交、买卖不平衡、WAP 与 target；示例行 date_id 在 195/480~541 范围、stock_id 0~2、seconds_in_bucket 为 0 或 480~540；预测目标被原文描述为股票的短期波动率，评估以竞赛后收集的真实市场数据比对。

## 局限与风险
本篇只是项目开篇的数据查看，特征工程与建模均未展开，无法复现；波动率相关论述为通用教科书内容，不含本项目实证；字段含义依赖竞赛文档，原文未逐一解释（reference_price、far_price 等定义缺失）；原文称预测目标为波动率，但示例 target 含负值（2.31、-8.22），与波动率非负的定义不符，原文未解释；竞赛数据基于境外市场的收盘竞价机制，与 A 股集合竞价、T+1 制度差异大，字段不可直接照搬。
