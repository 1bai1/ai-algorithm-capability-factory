# （10-3-05-01）银行消费者投诉处理模型

## 筛选结论
不适用 —— 银行消费者投诉文本的多分类任务，属纯 NLP 文本分类与银行投诉场景，与面向 A 股个股的量化预测算法生成无直接关系。

## 核心内容
- 用 train_test_split 按标签分层划分投诉文本，得到 26100 条训练与 2901 条验证（9:1，random_state=32）。
- 标签为投诉涉及的产品类别（debt collection、student loan、prepaid card、credit reporting、bank account or service 等）。
- 用 Plotly 分组柱状图对比训练集与测试集的类别分布，用于发现类别不均衡。
- 用 Hugging Face Datasets 的 class_encode_column 处理标签，并组装成含 train/validation 两个子集的 DatasetDict。
- 用 distilbert-base-uncased 做分词（padding + truncation）并加载同款预训练模型。
- 取最后一层隐藏状态的 [CLS] 位置向量作为整句特征，批量写入数据集的 hidden_state 列。

## 可复用要点
- 无。文本分类的句向量抽取属通用 NLP 技巧，与价格、因子建模无关。

## 关键实现
- 函数：tokenise(batch)（padding=True, truncation=True）、extract_hidden_states(batch)（在 torch.no_grad 下取 last_hidden_state[:,0]，转 numpy 存入 hidden_state）。
- 用 set_format("torch", columns=["input_ids","attention_mask","label"]) 转张量，batch_size=32 批量提取。
- 依赖：transformers、datasets、torch、plotly.express、scikit-learn、pandas。

## 数据与假设
- 银行消费者投诉文本加产品类别标签；训练 26100 条、验证 2901 条，字段为 text 与 label。
- 假设 [CLS] 向量足以代表长文本语义。

## 局限与风险
- 本篇止于特征提取，没有分类器训练、评估与任何性能数字。
- 标签是产品归因而非风险或收益，对本项目仅通用 NLP 工具链层面有参考意义。
