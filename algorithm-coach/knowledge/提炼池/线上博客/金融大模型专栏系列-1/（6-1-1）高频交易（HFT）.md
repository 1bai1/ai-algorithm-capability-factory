# （6-1-1）高频交易（HFT）

## 筛选结论
部分保留 —— 策略分类清单与风险清单可作为策略库命名与风险检查项的参考，但高频场景（毫秒/微秒、做市、低延迟基础设施）与面向 A 股个股的日频预测 Agent 不匹配。

## 核心内容
1. 定义：HFT 依赖计算机算法与高度自动化系统，以毫秒或微秒级速度执行大量交易，从传统策略忽略或无法捕捉的微小价格波动中获利。
2. 六个特点：快速执行（高速数据传输 + 低延迟网络）、算法交易（可随市况调整）、充当做市商提供流动性、单笔风险低但靠交易数量累积利润、强依赖高度优化的软硬件基础设施、长期处于监管争议中。
3. 八类风险：技术（故障在极短时间内被放大）、市场（快速波动下算法来不及调整）、竞争（同质化机会争夺）、市场不确定性（价差瞬息万变）、监管、流动性（动荡时撤资反而加剧波动）、黑天鹅（历史数据无法预测突发事件）、道德（市场公平性质疑）。
4. 六类传统高频策略：做市（同时报买卖价、赚点差并快速调价控持仓风险）、跨市场套利（利用不同市场/交易所价差）、统计套利（基于相关资产价差的统计模型）、量化策略（数学模型 + 大规模数据与高性能计算）、动量策略（价格上行买入、下行卖出）、交易成本优化（用算法最小化点差、滑点与费用以取得最优成交价）。
5. 定性结论：HFT 属高风险、高回报策略，需严格风险管理、技术投入与监管合规，不适合所有投资者。

## 可复用要点
- 策略分类骨架：做市、套利、统计套利、量化、动量、成本优化六类可作为策略库的命名与归类体系；其中动量策略与 A 股日频趋势策略直接对应（涨买跌卖）。
- 风险检查清单可直接改写为策略生成 Agent 的风控校验项：技术故障、流动性枯竭、黑天鹅、竞争同质化、监管约束。
- 成本意识：原文强调交易成本优化类策略的核心是最小化点差、滑点与费用，提示 A 股回测必须显式计入佣金、印花税与滑点，否则收益会被高估。
- 边界判断：做市与套利类策略依赖流动性提供与撮合微结构，日频 A 股个股场景不具备该前提，应在策略空间中被排除。
