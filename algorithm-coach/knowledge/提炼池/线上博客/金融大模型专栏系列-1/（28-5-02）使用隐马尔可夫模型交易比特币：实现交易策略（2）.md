# （28-5-02）使用隐马尔可夫模型交易比特币：实现交易策略（2）

## 筛选结论
保留 —— 给出 HMM 异常收益率作为择时特征的双阈值交易策略与完整回测框架，并诚实报告了摩擦成本敏感性，对 Agent 的"特征→信号→回测"环节有直接参考价值。

## 核心内容
- 策略形态：用隐马尔可夫模型识别市场状态并输出每个时点的预期异常收益率 EAR（视线状态的期望收益），以 EAR 超过买入阈值时满仓、低于卖出阈值时空仓，构成 0/1 择时策略。
- HMM 在本文中的定位是特征提取器而非价格预测模型：它检测上涨/下跌趋势，为择时提供信号。
- 尝试用 HMM 采样的模拟价格序列调优阈值，结论是失败：HMM 隐藏状态切换过快，生成的样本与真实比特币价格统计特性差异大，导致模拟数据上优化的阈值在中等以上摩擦率下几乎不动手，效果明显差于在真实数据上优化的阈值；原计划的强化学习优化也因同样原因被放弃。
- 模拟数据生成：3 状态 HMM，逐日按转移概率抽样状态，回报按 r = beta*r + MU[s] + 噪声 生成，价格取 exp(cumsum(r))。
- 阈值寻优：对 100 档摩擦率，在买入/卖出阈值的二维网格上最大化 `FR = log(R) + T*log(1-f)`，其中 R 为策略收益、T 为交易次数，即把摩擦成本显式计入目标。
- 回测对比三策略：前一天趋势跟随、HMM 优化买卖策略、简单持有比特币；结论是 HMM 策略只在低摩擦（约 0.5%）下表现良好，摩擦升高即失去优势。
- 改进方向：对 NLL 优化加约束/正则化以让状态切换更慢；改用 2 状态 HMM 时模型倾向于表示"增长/快速增长"而非"增长/衰退"；缺少 r 的自回归项 beta*r(t-1) 时状态过于简单，难以做精细决策。

## 可复用要点
- 择时信号：把状态模型的期望收益（EAR）当作连续打分，用 buy/sell 双阈值转成仓位开关，天然适配 A 股的 T+1 由 0/1 仓位实现。
- 阈值寻优目标须含成本项：`log(R) + T*log(1-f)`，把交易次数 T 与单边摩擦 f 显式纳入，避免高频微利策略在成本下失效——这是可直接移植到 A 股（佣金+印花税+滑点）的目标函数形式。
- 参数网格规模：吞吐量 100 档摩擦率 × 阈值二维网格（代码中用 res 划分网格，i0/i1 由 argmax 索引反解出阈值），可直接作为超参搜索模板。
- 回测会计：Portfolios 逐日记录（现金, 持仓数量）二元状态，买卖时按 `rate=1-friction` 折算资金，价值曲线对比持有基准与趋势跟随基准。
- 摩擦率压力测试取 0.5% / 1% / 1.5% 三档，检验策略的存活边界。

## 关键实现
- 模拟数据：`s = np.random.choice(range(3), p=hmm.TP[:, s])`、`r = hmm.beta*r + hmm.MU[s] + np.random.randn()*hmm.sig`、`Psampled = np.exp(np.cumsum(Rsampled))`，n=5000 天。
- 训练期阈值寻优：`back_train_pol(hmm, Psampled)` 返回收益率 R 与交易次数 T；对 100 档 friction 求 argmax 得到最优 (Buy_Price, Sell_Price)。
- 回测函数：`back_test_pol(mdl, friction, Buy_Price, Sell_Price, Prices)`，输入模型、摩擦率数组、阈值与价格，输出 Portfolios(100, n, 2) 与 Value(100, n)；内部调用 `mdl.get_hidden_state_probabilities(Prices)` 与 `mdl.get_expected_abnormal_rates(Prices)`。
- 交易状态机：现金态下 `EAR[t] > buy` 全仓买入，持仓态下 `EAR[t] < sell` 清仓，初始状态为全现金。
- 对比曲线：趋势跟随基准按交易次数折算摩擦 `V0[-1]/V0[train_end]*(1-friction)^ntrades`；HMM 策略取 Value[:, -1]/Value[:, train_end]；比特币持有为常数线。

## 数据与假设
- 标的：比特币，日频价格序列，具体数据源与时间范围原文未给出；训练/测试按 train_end 与 ndays 划分。
- 假设：HMM 隐藏状态能代表市场趋势状态；EAR 可作为择时打分；摩擦成本按单边比例一次性扣除，不考虑滑点、冲击成本与资金费率。

## 局限与风险
- 模拟数据调参路线已被作者证伪，说明"用拟合模型自产数据做策略优化"存在分布失配风险，A 股同样应警惕。
- 策略在全仓/空仓之间切换，无仓位梯度、无止损，暴露于单边下跌中的执行风险。
- 结论中的优势是在"市场摩擦较小"前提下取得的，未给出样本外收益数字、夏普或最大回撤，只有图形。
- 未做参数稳定性检验，阈值与摩擦档位的网格密度（res、100）设定缺乏依据。
- 原文自陈若没有 beta*r(t-1) 项，状态过于简单，说明模型设定对结果影响很大，存在设定风险。
