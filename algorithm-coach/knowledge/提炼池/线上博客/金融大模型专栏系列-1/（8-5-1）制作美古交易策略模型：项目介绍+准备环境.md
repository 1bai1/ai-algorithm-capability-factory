# （8-5-1）制作美古交易策略模型：项目介绍+准备环境

## 筛选结论
部分保留 —— 选题是美股组合优化与风险调整回报（属高相关方向），但本篇只含项目介绍与环境准备，无数据区间与实现细节，需结合后续篇章使用。

## 核心内容
- 项目：由谷歌、苹果、Facebook、亚马逊、微软五只美股加 S&P500 指数构成投资组合，研究波动性、相关性与风险调整回报。
- 风险与收益口径：以波动率（回报的离散程度）衡量风险，以预期回报衡量收益，用协方差与相关系数刻画资产联动。
- 优化目标：在不同目标回报下求最优权重（有效前沿），并比较最大夏普比率组合与最小方差组合的权衡。
- 重点考察个股与 S&P500 的相关性如何影响组合整体风险，即分散化效果。
- 工程环境：Python + Jupyter Notebook，行情源 yfinance（固定 0.2.3 版本），设随机种子保证结果可复现。
- 依赖库：os、numpy、pandas、matplotlib、pandas_datareader、scipy（optimize、stats）、seaborn、datetime。

## 可复用要点
- 组合层指标：波动率、协方差/相关系数矩阵、夏普比率、有效前沿、最小方差权重。
- 优化目标设定：给定目标收益下最小化组合方差，或风险约束下最大化夏普比率。
- 基准设定：以 S&P500 作为相对基准衡量组合表现与分散化效果。
- 工程约定：数据接口库固定版本、随机种子固定，保证回测可复现。
- 与个股预测的衔接：组合层权重优化可作为个股预测信号下游的仓位分配模块。

## 关键实现
- 本篇无函数实现，仅列出导入清单与安装命令 pip install yfinance==0.2.3，具体源码在后续篇章。
- 关键依赖：scipy.optimize（权重寻优）、pandas_datareader（备选数据源）、seaborn（可视化）。

## 数据与假设
- 标的：GOOG、AAPL、FB、AMZN、MSFT + S&P500 指数，均在纽交所上市；行情来自 Yahoo Finance（yfinance）。
- 频率、时间范围、再平衡周期原文均未给出。
- 假设历史波动率与相关系数可稳定刻画未来风险，且以波动率等同于风险。

## 局限与风险
- 只有项目介绍与环境准备，缺少数据区间、调仓频率、权重约束与交易成本等关键设定，不能独立复现。
- 五只美股 + 指数样本量小，分散化能力有限；未讨论参数估计误差对最优权重的影响（均值-方差解的敏感性）。
- 未考虑 A 股约束（T+1、涨跌停、做空限制、印花税）。
- 以波动率等同风险、假设收益正态，未考虑尾部风险；历史协方差外推的稳健性未验证。
