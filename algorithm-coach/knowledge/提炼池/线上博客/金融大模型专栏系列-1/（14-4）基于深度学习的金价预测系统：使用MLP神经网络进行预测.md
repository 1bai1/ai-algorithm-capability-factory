# （14-4）基于深度学习的金价预测系统：使用MLP神经网络进行预测

## 筛选结论
保留 —— 给出了金价预测的"特征工程 → 互信息筛特征 → MLP → 误差评估"全流程，特征构造与评估口径可直接迁移到 A 股个股。

## 核心内容
- 单个函数串起全流程：数据准备 → 技术指标拼接 → 生成滞后与滚动窗口特征 → 互信息筛选 → 归一化 → 切分 → MLP 拟合 → 预测 → MAE/RMSE 评估与对比图。
- 特征选择两步走：计算滞后列与目标列的互信息，先按分值排序取列，再只保留互信息超过阈值 mic 的前若干列，其余全部丢弃。
- 特征构造参数：滞后阶数 1~29、滚动窗口 2~59；金价实例的互信息阈值设为 3。
- 特征与标签分别用 PowerTransformer 归一化，标签也要缩放，评估前再做逆变换。
- MLP 结构：输入 188 维（互信息筛选后的特征列数）→ Dense(1425) → Dropout → Dense(1)，合计约 27 万参数；n_steps 直接取特征列数。
- 测试集取最后 60 个样本，输出两套误差：逆变换前 MAE 0.0166 / RMSE 0.0183，逆变换后 MAE 8.96 / RMSE 9.89。
- 随机种子固定为 111。

## 可复用要点
- 特征配方：lag(1..29) × rolling window(2..59) 的滞后与滚动统计，叠加技术指标（Indicator 函数输出）后与目标列拼接，是一套可参数化的特征生成模板。
- 特征选择：用互信息打分加阈值截断做降维，可捕捉非线性依赖；阈值与保留列数应结合验证集确定。
- 误差必须报告逆变换后的量纲值（本例金价 MAE≈8.96），归一化域误差没有业务含义。
- "特征生成 → 筛选 → 定维 → 建模"的接口设计（X 列数直接决定输入维度）便于做成自动流水线。

## 关键实现
- 函数签名：Performance_tune(Data, col, Lag_list, Roll_window, mic)，返回预测结果、实际值与对比表（Close[2] 为实际/预测对照表）。
- 内部依赖 Prepare(Data, col, Lag_list, Roll_window)、Indicator(Data)、mutual_information_lag(data, col, 100)。
- 依赖 TensorFlow/Keras、scikit-learn(PowerTransformer)、pandas/numpy、matplotlib。

## 数据与假设
- 黄金价格数据框 Gold，目标列 'Close'；滞后 1~29、滚动窗口 2~59；测试集为最后 60 个交易日。
- 假设互信息高的滞后列信息量最大，且固定长度历史窗口足以预测价格。

## 局限与风险
- 归一化器在全量数据上 fit 后再切出最后 60 条做测试，测试集信息进入缩放参数，存在数据泄漏，误差偏乐观。
- 仅 60 个测试样本，无时间序列交叉验证；MAE 8.96 未与"沿用上一期价格"的朴素基线对比，无法判断是否有预测增益。
- 互信息在全样本上计算，阈值取 3 缺乏依据，原文未解释量纲与选取过程。
- 只做价格拟合，没有交易信号与回测。
