# （28-1）使用隐马尔可夫模型交易比特币：项目介绍+准备环境

## 筛选结论
部分保留 —— 本篇是项目开篇（目标、环境、数据集说明），无建模与回测细节；但比特币 1 分钟数据集的来源、字段、频率缺口与日度聚合方法对我们的数据层有直接参考价值。

## 核心内容
- 项目目标：用比特币历史价格拟合 HMM，并把它作为交易策略的一部分，在比特币与现金之间切换以最大化组合价值。
- 策略设计包含：固定买卖阈值的基准策略、交易成本（市场摩擦）影响研究、HMM 状态识别与买卖阈值优化、策略回测、模拟数据训练、结果可视化。
- 数据来自两家交易所：coinbaseUSD（2014-12-01 至 2019-01-09）与 bitstampUSD（2012-01-01 至 2019-03-13），1 分钟间隔。
- 字段含 OHLC、以 BTC 与本币计价的成交量、加权比特币价格（Weighted_Price）；无交易的时间戳数据为 NaN；时间戳跳变可能源于交易所或其 API 停机。
- 数据准备方式：Unix 秒时间戳转日期，按日分组取 Weighted_Price 的均值，得到日频价格序列。
- 作者明确说明：摩擦率越高交易成本越大，策略需要针对不同摩擦率分别调整阈值。

## 可复用要点
- 数据字段规范：Timestamp（Unix 秒）、Open、High、Low、Close、Volume_(BTC)、Volume_(Currency)、Weighted_Price。
- 频率聚合范例：`pd.to_datetime(df['Timestamp'], unit='s').dt.date` → 按 date 分组 → 对 Weighted_Price 取 mean，得到日线价格。
- 策略参数设置：买卖阈值需在多个摩擦率（交易成本）档位下分别优化，并输出摩擦率与交易次数/回报的关系。
- 回测对比框架：优化策略 vs 基准策略，在不同摩擦率下比较回报。

## 关键实现
- 引入库：numpy、pandas、matplotlib、datetime（本篇仅环境准备，无模型代码）。
- 数据加载片段：读取 CSV → 时间戳转日期 → `groupby('date')['Weighted_Price'].mean()` 得到 Real_Price。

## 数据与假设
- 标的：BTC（对 USD 及数据集内其他计价货币）。
- 频率：原始 1 分钟；项目使用日频聚合结果。
- 时间范围：bitstampUSD 覆盖 2012-01 至 2019-03，coinbaseUSD 覆盖 2014-12 至 2019-01。
- 假设：数据经尽力去重与校验，但作者声明使用风险自负。

## 局限与风险
- 属项目开篇，无任何策略或模型结果，所有结论均未验证。
- 数据存在缺口（停机导致的 NaN 与时间戳跳变），本篇未说明缺失处理方式。
- 加密市场 7×24 连续交易，与 A 股交易日历、涨跌停与交易成本结构差异大，阈值与摩擦模型不可直接照搬。
