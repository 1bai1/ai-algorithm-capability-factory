# （4-1）时间序列的基本概念

## 筛选结论
保留 —— 金融时间序列分析的概念总纲，给出时间序列特征清单与金融应用/模型族谱，可作为 Agent 建模前的数据体检项与模型族选型参考（无实现代码）。

## 核心内容
1. 时间序列是按时间顺序排列的观测值集合，间隔可等距（如股票每日收盘价）或不等距，分析目标是识别模式、趋势、季节性与周期以支持预测和决策。
2. 五个可分解成分：趋势（长期方向，上升/下降/平稳）、季节性（通常一年内的周期，如零售假期旺季）、周期性（长于一年的循环，如经济周期）、噪声（无法被上述模式解释的随机波动）、以及自相关（观测值与历史值相关，可用于检测模式）。
3. 与静态数据的区别：存在时间相关性、不满足独立同分布（原文称"孤立性"）、均值方差可能随时间变化（不平稳）、以预测未来为目的、数据频率决定分析方法。
4. 金融时间序列分析的应用链：数据收集与清洗（股票/汇率/债券收益率/期货价格，处理缺失值、异常值、频率不一致）→ 描述性统计与时间序列图表 → 随机游走与白噪声基准 → 时间序列分解 → 移动平均与指数平滑 → ARIMA → GARCH（波动率建模，风险管理尤其实用）→ 协整与 VAR（多序列长期关系与动态关系）→ 定价模型（CAPM 等）→ 风险度量（VaR、CVaR）→ 高频数据分析。
5. 强调随机游走与白噪声常作为基准模型，用来对比更复杂模型的性能。

## 可复用要点
- 建模前数据体检清单（可直接做成 Agent 的检查项）：是否等间隔、是否存在趋势/季节性/周期/噪声、是否自相关、均值方差是否随时间变化（平稳性）、各序列频率是否一致。
- 模型族选型对照：去噪与平稳化用移动平均/指数平滑；单序列预测用 ARIMA；波动率建模用 GARCH；多序列长期关系用协整、动态关系用 VAR；基准对照用随机游走/白噪声。
- 风险度量口径：VaR 与 CVaR 属金融时间序列分析的标准输出，可纳入本项目的风险与评价模块。
- 数据准备顺序：先处理缺失值、异常值与频率不一致，再做描述统计与可视化。
