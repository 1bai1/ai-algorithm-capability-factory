# （15-9）基于时间序列预测的比特币自动交易系统：使用时间序列法转换数据

## 筛选结论
保留 —— 给出金融时序平稳化的完整判据链（对数变换 → 逐阶差分 → ADF 检验），是 ARIMA / GRU 类模型可直接复用的预处理前置步骤。

## 核心内容
- 指数增长型序列先取对数（np.log）线性化，再画图看趋势与波动；比特币价格正属此类。
- 用三张子图并列对比对数价格、一阶差分、二阶差分，分别看线性化效果、一阶趋势与波动性。
- ADF 检验判定规则：p < 0.05 拒绝"非平稳"零假设（视为平稳），p > 0.05 不能拒绝（视为非平稳）。
- 实测：对数价格 ADF 统计量 -1.269、p = 0.643（非平稳，滞后 4 阶、样本 757）；一阶差分 p ≈ 1.62e-23；二阶差分 p ≈ 1.29e-18。
- 一阶与二阶差分均平稳，说明一阶已足够，无需继续差分。

## 可复用要点
- 平稳化判据链可固化为 Agent 的预处理校验：先看对数与逐阶差分子图，再用 ADF 的 p 值定量确认。
- 对单调上涨的价格类序列，取对数是标准第一刀：既线性化趋势，又缓解方差随价格水平放大。
- 差分阶数按最小够用原则：一阶已平稳即停止，过度差分放大噪声并额外损失样本。
- 决策规则可写成断言：p < 0.05 通过；临界值随样本量变化，应读取返回的临界值字典而非硬编码。

## 关键实现
- `from statsmodels.tsa.stattools import adfuller`；`adfuller(log_df)` 返回 (ADF 统计量, p 值, 滞后阶数, 样本数, 临界值字典, 信息准则值)，与原文元组顺序一致。
- 差分：`y_diff = log_df.diff().dropna()`、`y_diff_diff = log_df.diff().diff().dropna()`，再分别算零阶/一阶/二阶 p 值；绘图用 `px.line(log_df, x=log_df.index, y="Close")`。

## 数据与假设
- 数据为 BTC/USD 价格序列（含 Close），属该项目预处理章节；本篇未给时间范围（同项目其他节自 2020-01-01 起）。假设序列呈指数增长趋势，须先平稳化才能用于 ARIMA 类模型。

## 局限与风险
- 只做平稳性检验，未做白噪声检验，也未对比取对数与不取对数的差分效果。
- ADF 滞后阶数由默认准则确定（输出 4），未讨论阶数敏感性；含结构突变的加密序列易把突变误判为随机趋势。
- p 值计算的函数体被截断，无法完整复现；对 log 序列而非原始价格做 ADF，两者结论可能不同，原文未说明依据。
