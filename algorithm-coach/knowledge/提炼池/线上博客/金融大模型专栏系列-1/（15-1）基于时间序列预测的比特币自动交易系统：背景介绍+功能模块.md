# （15-1）基于时间序列预测的比特币自动交易系统：背景介绍+功能模块

## 筛选结论
保留 —— 给出了"数据采集→时序预测→模拟交易→实盘执行→绩效报告"的自动交易系统模块划分，可作为 Agent 生成交易策略与回测代码的骨架；本篇无技术细节，需与后续章节配合使用。

## 核心内容
- 项目目标是构建比特币自动交易系统，覆盖数据科学项目全生命周期：数据收集、预处理、基本模型、神经网络、时间序列预测模型、模拟评估、对接 Binance 实盘。
- 功能模块共 5 块：数据采集与预处理、时间序列预测模型、模拟交易环境、自动交易执行、性能评估与报告。
- 数据环节：连接 Binance 交易所获取比特币分钟级历史价格，做清理与格式转换，保证数据质量与一致性。
- 预测环节：使用 ARIMA 等传统时序模型与神经网络对比特币未来走势建模，通过模型评估与优化提升精度。
- 评估环节：在历史数据上搭建模拟交易环境，执行模拟交易并按回报率、风险等指标衡量模型表现。
- 执行环节：把预测模型接到 Binance 交易服务，满足预设条件时自动下单买卖。
- 报告环节：实时监测策略执行，输出回报率、风险指标、交易次数等报告，辅助投资决策。
- 宣称优势：降低决策负担、融合机器学习与深度学习提升预测与交易效果、模拟+实盘双重验证。

## 可复用要点
- 系统分层参考：数据源适配层 / 预处理层 / 预测模型层 / 模拟撮合层 / 实盘执行层 / 绩效报告层，可直接映射为 Agent 的代码模块划分。
- 预测模型选型思路：传统统计模型（ARIMA）与神经网络并列对比，而非单一模型。
- 评价指标集合：回报率、风险指标、交易次数（原文未给出具体定义与计算式）。
- 数据频率：分钟级行情（面向高频/短线）；对标 A 股需换为分钟或日频并按 T+1、涨跌停规则调整。
