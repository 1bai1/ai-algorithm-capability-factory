# （5-5-02）金融市场情绪分析：使用Llama 2 大模型实现财经信息的情感分析微调（2）

## 筛选结论
部分保留 —— 金融情绪三分类的建模与评测口径可用于舆情因子，但主体是 QLoRA 大模型微调工程，与量化预测模型本身关系较远。

## 核心内容
1. 用 4bit 量化的 Llama-2-7B 做财经文本三分类情绪识别，微调后测试准确率 0.847，优于 0.623 的 CONV1D+双向 LSTM 基准。
2. 未微调直接预测准确率仅 0.373，几乎全押中间类（该类召回 0.94，另两类仅 0.03 与 0.16），说明零样本直接判情绪不可行。
3. LoRA 配置：r=64、lora_alpha=16、lora_dropout=0.1、target_modules="all-linear"、bias="none"、task_type="CAUSAL_LM"。
4. 训练参数：3 epochs、batch=1、梯度累积 8、开启梯度检查点、paged_adamw_32bit、lr=2e-4（对齐 QLoRA 论文）。
5. 训练损失 0.802→0.5165，验证损失 0.700→0.714，已现过拟合苗头。
6. 流程：4bit 量化加载 → 聊天格式适配 → 训练 → 存 LoRA → 合并另存 → 重推理评测，前后清理显存。
7. 评估用分类别准确率 + 分类报告 + 混淆矩阵，并把 text/y_true/y_pred 落盘 CSV 与基准对比。

## 可复用要点
- 三分类情绪标签体系与评测口径（分类别准确率、macro-F1、混淆矩阵），可作舆情因子的质量验收。
- "先测零样本基线再微调对比"的验证范式，避免高估大模型直接可用性。
- LoRA 超参组合（r=64 / alpha=16 / dropout=0.1 / lr=2e-4 / 3 epochs）可作同类微调起点。
- 若需自建舆情因子，可把同类模型输出（标签或概率）作为特征列接入预测流程。

## 关键实现
加载：`AutoModelForCausalLM.from_pretrained(model_name, device_map, torch_dtype=float16, quantization_config=BitsAndBytesConfig(load_in_4bit=True, bnb_4bit_quant_type="nf4", bnb_4bit_compute_dtype=float16, bnb_4bit_use_double_quant=True))`；tokenizer 设 `pad_token=eos_token`、`padding_side="right"`，再 `setup_chat_format()`。推理用 transformers `pipeline(task="text-generation")` 逐条生成并截取标签；训练用 SFTTrainer + LoraConfig + TrainingArguments(output_dir="trained_weigths", num_train_epochs=3, gradient_accumulation_steps=8, optim="paged_adamw_32bit", learning_rate=2e-4)，保存后以 `AutoPeftModelForCausalLM` 加载并合并。依赖 transformers/peft/trl/bitsandbytes/torch/tqdm。

## 数据与假设
带 text 列与 3 类标签的财经文本数据集，测试集 900 条、每类 300 条（类别平衡）；模型为 Kaggle 挂载的 llama-2 7b-hf；假设情绪可由生成式模型经提示词直接判定。

## 局限与风险
- 验证损失上升而训练损失下降，仅 3 epoch 即止，超参未做调优。
- 测试集与训练集同分布同来源，未做跨时间、跨来源的泛化验证。
- 依赖"生成一个 token 再解析文本"的预测方式，脆弱且受提示词细节影响。
- 4bit 大模型成本高（微调约 1 小时、900 条推理约 4 分钟），难支撑日频/分钟级因子生产。
- 情绪得分与收益率之间的实际相关性未验证。
