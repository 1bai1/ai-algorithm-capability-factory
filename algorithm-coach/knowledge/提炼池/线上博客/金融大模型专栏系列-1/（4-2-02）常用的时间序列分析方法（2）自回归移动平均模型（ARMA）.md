# （4-2-02）常用的时间序列分析方法（2）自回归移动平均模型（ARMA）

## 筛选结论
保留 —— 给出 ARMA/ARIMA 的完整建模范式（平稳性诊断、平稳化变换、ACF/PACF 定阶、拟合并外推预测），是价格序列预测的基础模型，直接对应时间序列建模环节。

## 核心内容
- 模型定位：ARMA = AR + MA，用于分析并预测平稳时间序列；金融领域主要用于理解历史模式、预测价格/汇率/利率、估计组合价值波动与管理风险、辅助制定交易策略。
- ARIMA 与 ARMA 的关系：把 ARIMA 的差分阶数 d 设为 0 即退化为 ARMA，两者共用同一套估计代码。
- 实例流程（IMF 锌价）：加载数据并把日期设为索引 → 画时序图 → 平稳性检查（滚动均值/滚动标准差 + ADF 检验）→ 对数变换并减去滚动均值 → 再检验平稳性 → 画 ACF/PACF 定阶 → 拟合 ARIMA/ARMA → 预测未来 24 个月。
- 平稳性诊断：ADF 检验报出 T 统计量、P 值、滞后阶数与观测数及 1%/5%/10% 临界值；原始价格 P 值 0.0238（在 5% 水平勉强拒绝单位根），对数去趋势后 P 值降到 2.8e-07，平稳性显著增强。
- 定阶与拟合：根据图选定 p=2、d=5、q=1 的 ARIMA(2,5,1)（实际上作用于已去除滚动均值的对数序列）；ARMA 版本取 order=(2,0,1)，系数 ar.L1≈−1.083、ar.L2≈−0.528、ma.L1≈−0.997，均显著。
- 预测：用 DateOffset 生成未来 24 个月索引，拼接后调用模型的 predict，dynamic=False 表示不使用动态多步递推；预测结果需先做对数与滚动均值的双重逆变换才能还原成价格。
- 模型族关系提示：GARCH 可对 ARMA 残差的波动性建模，实际应用中按数据特征选择模型或模型组合。

## 可复用要点
- 平稳化套路（对价格序列可直接照搬）：取对数压缩量级 → 减 12 期滚动均值去趋势 → 用 ADF（autolag='AIC'）复检。
- 诊断图示：滚动均值/滚动标准差窗口 52 与 12 两档，用于观察趋势与波动是否随时间漂移。
- 定阶规则与显著性判读：ACF/PACF 置信带取 ±1.96/√N；模型系数看 z 值与 P>|z|；残差用 Ljung-Box（Q 统计量、Prob(Q)）检验自相关是否残留，用 Jarque-Bera 检验正态性，用 Heteroskedasticity 检验异方差。
- 外推方式：先构造未来时间索引（`DateOffset(months=x) for x in range(0,24)`）再 predict，预测值须逆变换回价格水平。
- 预测步长参考值：24 期（本例为月频）。

## 关键实现
- 依赖：statsmodels（`from statsmodels.tsa.stattools import adfuller, acf, pacf`、`from statsmodels.tsa.arima.model import ARIMA`）、pandas（DateOffset）、seaborn/matplotlib。
- 平稳性函数 `Staionarity_Check(ts)`：画 Original / Rolling Mean(window=52) / Rolling Std(window=52) 三线，再跑 `adfuller(ts, autolag='AIC')` 并把前四项与各临界值打包成 Series 打印。
- 变换：`tsl = np.log(df)`；`ma = tsl.rolling(window=12).mean()`；`ms = tsl.rolling(window=12).std()`；`tslma` 为对数减滚动均值后的序列。
- 建模：`ARIMA(tslma, order=(2,5,1)).fit()` 与 `ARIMA(tslma, order=(2,0,1)).fit()`；以 `.summary()` 查看系数、标准误、AIC/BIC/HQIC 与诊断统计量。
- 预测：拼接 `future_datest_df` 后调用 predict(start=..., end=..., dynamic=False)，并将预测结果逆对数变换与加回滚动均值后作图。

## 数据与假设
- 数据：IMF 锌价数据集 zinc.csv（字段 Date、Price），样本区间 1980-12 至 2016-02，共 423 个观测，月频；示例中的 ARIMA(2,5,1) 结果基于 423 个样本。
- 假设：对数价格减去滚动均值后序列平稳；预测期沿用样本内的趋势与滚动均值外推；不做季节性（未使用 SARIMA）。
- 原文未说明滚动均值在未来期如何取值，这直接影响逆变换的还原精度。

## 局限与风险
- 处理流程存在自相矛盾：ADF 在 5% 水平已判定对数价格平稳（P=0.0238），却仍继续做去滚动均值处理，理由未说明；且对已去均值的序列再做 5 阶差分（d=5）在统计上属过度差分，容易放大噪声。
- summary 输出标题为 ARIMA(2, 5, 1)，但代码块标注为 ARMA(2,0,1)，原文两处不一致，无法确定实际拟合的模型。
- 未来滚动均值的外推方式未交代，预测值还原成价格时如何去掉对数与滚动均值修正含糊，预测结果的可靠性无法验证。
- 全文只展示拟合与预测图，未给出 RMSE/MAPE 等误差指标，也未与朴素基准（随机游走）比较，无法判断 ARMA 是否真的优于"直接用上一期价格"。
- 单变量、线性、无外部变量的模型，面对 A 股的结构突变与政策冲击适应性有限。
