# （14-3）基于深度学习的金价预测系统：准备数据

## 筛选结论
保留 —— 提供一整套可直接复用的金融时序特征工程函数（滞后、滚动统计、差分、TA-Lib 指标批量生成、互信息筛选），是特征工程模块的高价值素材。

## 核心内容
1. Add_Lag 按滞后列表批量生成滞后列，命名 `<col>_lag:N`，插入到原列位置，用于引入时间相关性。
2. Indicator 用 TA-Lib 的 get_function_groups() 枚举全部分组指标，对 OHLCV 批量生成技术指标特征；输入先整体 shift(1) 滞后一期，再删除含极大值与 NaN 的列。
3. add_diff 为指定列计算相邻值一阶差分，生成 `<col>_difference`，前两个位置硬编码补 0。
4. Roll_Stats 对指定列先 shift(1) 再滚动，逐窗口计算均值、方差（变量名写作 std 但实际调用 rolling.var()）、最大值、最小值、极差，命名含 lag 与 win 标识。
5. Prepare_Data 串联 Add_Lag → Roll_Stats → add_diff，并要求滚动窗口最小值大于 1，否则仅打印提示而不中断。
6. Prepare 以目标列加 Open/Close/Volume/High/Low 为对象分别生成特征并合并，最后按目标列裁掉不需要的列。
7. mutual_information_lag 用互信息回归打分并降序取前 k_best 列，作为特征筛选器。

## 可复用要点
- 命名规范可直接沿用：`<col>_lag:N`、`<col>_mean_lag:1_win:W`、`<col>_diff_lag:1_win:W`，便于后续按窗口/滞后自动解析。
- 防泄漏约定：所有滚动统计与技术指标计算前统一 shift(1)，只用截至上一期的信息。
- 特征筛选：用互信息回归（mutual_info_regression）衡量非线性相关，取 Top-k 入模。
- 数据清洗：直接删除含极大值与 NaN 的列（原文未给出“极大值”的具体阈值）。

## 关键实现
- 依赖：pandas、TA-Lib（talib.get_function_groups）、sklearn.feature_selection.mutual_info_regression、random.seed(21)。
- 函数签名：Add_Lag(data, col, lag_list)；Indicator(Data)；add_diff(data, col)；Roll_Stats(data, col, Roll_Window)；Prepare_Data(data, col, Lag_list, Roll_window)；Prepare(Data, col, Lag_list, Roll_window)；mutual_information_lag(Data, target_col, k_best) 返回 (selected_col, 全部得分字典)。
- 细节：互信息筛选时只用 max(col_val) < 1e6 的列（过滤量纲过大的列，如成交量）。

## 数据与假设
金价预测系统的数据准备环节，输入字段为 Open/High/Low/Close/Volume；原文未给出数据源、频率与样本区间。假设滞后与滚动窗口特征对未来价格有预测力，且 OHLCV 本身不含未来信息。

## 局限与风险
- TA-Lib 全量指标一次性生成会产生大量高度共线特征，原文仅删除“极大值与 NaN 列”，未说明进一步去冗方案。
- Add_Lag 以固定位置插入，多次调用后列序易混乱，同名/近似名特征难以追溯。
- Roll_Stats 中 std 变量实际保存的是方差，口径不一致，直接使用会误判波动幅度。
- add_diff 前两行补 0 属于伪数据，会污染前两期样本。
- 未说明目标列构造与滞后对齐规则，存在前视偏差风险；各函数的窗口与滞后取值也未给出建议值。
