# （3-3）数据标准化与归一化

## 筛选结论
保留 —— 特征工程环节的基础预处理方法，标准化/归一化的定义、适用场景与 sklearn 落地用法可直接写入算法生成的预处理模板。

## 核心内容
- 标准化（Standardization / Z-score）：把数据转换为均值 0、标准差 1，保留原始分布形态，用于处理不同尺度或不同单位的数据，使特征间可比。
- 归一化（Normalization）：把数据线性缩放到指定区间（通常 [0,1] 或 [-1,1]），不考虑分布，只关心相对位置，常用于神经网络训练输入。
- 两者区别：标准化关注分布与单位，归一化关注映射区间；选型取决于数据性质与任务需求。
- 金融场景用途：标准化用于投资组合分析、风险管理与金融建模（如让不同股票的收益率波动性可比）；归一化用于股票价格、指数值等，使不同标的在模型内处于同一尺度。
- 示例对 AAPL、GOOG、TSLA 三只股票价格列分别做标准化与归一化，输出标准化后取值约为 -0.76~0.08 区间。

## 可复用要点
- 工具与调用：sklearn.preprocessing 的 StandardScaler 与 MinMaxScaler，对价格/特征列做 fit_transform。
- 选型规则：要跨标的比较波动性或做风险度量 → 标准化；要压到固定区间喂给神经网络 → 归一化。
- 适用于多标的（多列）价格数据的统一尺度处理，是模型输入前的标准预处理步骤。

## 关键实现
- 依赖 pandas 与 sklearn.preprocessing（StandardScaler、MinMaxScaler）。
- 示例文件为 gui.py：构造含 AAPL/GOOG/TSLA 价格的 DataFrame → 分别用两种 scaler 变换 → 打印结果。
