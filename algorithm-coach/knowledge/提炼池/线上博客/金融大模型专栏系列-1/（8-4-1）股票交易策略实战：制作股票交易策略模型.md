# （8-4-1）股票交易策略实战：制作股票交易策略模型

## 筛选结论
保留 —— 用 FinRL + TuShare 在 A 股 15 只股票上搭建强化学习交易环境的完整数据侧配置（指标集、切分、状态空间公式），是 Agent 生成 A 股策略代码时可复用的工程范式。

## 核心内容
- 目标是基于 TuShare 获取 A 股数据，用 DDPG 与 A2C 两种强化学习模型训练交易策略，最大化投资组合价值，并由模型决定买卖时点与标的。
- 采用 FinRL 库（含 DQN、DDPG、PPO、SAC 等算法）提高开发效率，配合 FinRL-Meta 仓库提供的数据处理工具。
- 标的池为 15 只上交所股票（600000.SH、600009.SH、600016.SH、600028.SH、600030.SH、600031.SH、600036.SH、600050.SH、600104.SH、600196.SH、600276.SH、600309.SH、600519.SH、600547.SH、600570.SH）。
- 时间切分：训练 2015-01-01 至 2019-08-01，交易（样本外）2019-08-01 至 2020-01-03，interval = 1d。
- 数据处理流水线：下载 → 清洗（缺失值、异常值）→ 填充缺失 → 添加技术指标 → 再次填充 → 按时间切分。
- 技术指标集合固定为 8 个：macd、boll_ub、boll_lb、rsi_30、cci_30、dx_30、close_30_sma、close_60_sma。
- 强化学习状态空间按公式 `state_space = stock_dim × (指标数 + 2) + 1` 计算：每只股票贡献"指标数 + 现金/持仓 2 个维度"，整体再加 1（通常为时间步）；本例 15 × 10 + 1 = 151。
- 数据规模：原始下载 (17960, 8) → 清洗后 (18315, 8) → 加指标后 (18270, 17) → 训练集 (16695, 17)，覆盖 15 只股票。

## 可复用要点
- A 股数据获取配置：data_source='tushare'、time_interval='1d'、token 通过 kwargs 注入 DataProcessor，起止日期覆盖训练与交易两段。
- 指标集可直接作为 Agent 的默认技术因子库（MACD、布林上下轨、RSI30、CCI30、DX30、30/60 日均线）。
- 数据产物字段：tic、time、index、open、high、low、close、adjusted_close、volume + 8 个技术指标，共 17 列。
- 状态空间构造公式为多标的 RL 环境的通用模板，可直接套到 A 股任意股票池。
- 流水线顺序（clean → fillna → add_technical_indicator → fillna → data_split）可作为标准预处理模板，注意加指标后必须再 fillna。

## 关键实现
- 安装：`pip install git+https://github.com/AI4Finance-Foundation/FinRL.git`，并 clone FinRL-Meta；目录创建可用 `check_and_make_directories()` 替代手写 os.makedirs（datasets/data/weights 等）。
- 对象：`p = DataProcessor(data_source='tushare', start_date=TRAIN_START_DATE, end_date=TRADE_END_DATE, time_interval=TIME_INTERVAL, **kwargs)`。
- 方法链：`p.download_data(ticker_list=ticker_list)` → `p.clean_data()` → `p.fillna()` → `p.add_technical_indicator(config.INDICATORS)` → `p.fillna()` → `p.data_split(p.dataframe, TRAIN_START_DATE, TRAIN_END_DATE)`。
- 关键派生量：`stock_dimension = len(train.tic.unique())`、`state_space = stock_dimension*(len(config.INDICATORS)+2)+1`。
- 原文未给出 DDPG/A2C 的模型定义与训练代码（属后续章节）。

## 数据与假设
- 数据源：TuShare（需自行注册 token），A 股日线；训练 2015-01-01~2019-08-01，交易 2019-08-01~2020-01-03。
- 标的：15 只沪市股票，含贵州茅台、招商银行、中信证券等大盘权重股。
- 假设：缺失值可直接填充而不破坏时序；技术指标在个股维度独立计算；样本外区间足够代表真实交易环境。

## 局限与风险
- 池子由大盘历史权重股构成，存在幸存者/前视偏差，2015 年时点的选股逻辑未说明。
- 训练集明显短于交易外的评估期比例未必合理，且未说明验证集如何切分（前文只说通常三分）。
- 未涉及复权处理说明（字段含 adjusted_close，但未说明是否用于建模）、涨跌停与停牌、交易成本与印花税。
- 只有数据准备与维度推导，没有回测结果、收益或风险指标，策略有效性完全未验证。
- 对 fillna 的具体策略（前向填充/常量）未交代，会直接影响指标计算。
