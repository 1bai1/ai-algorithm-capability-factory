# （11-4-9）比特币价格预测系统：模型性能可视化

## 筛选结论
部分保留 —— 比特币价格预测属高相关主题，但本篇只是整个预测系统的收尾可视化，可迁移的方法细节很少。

## 核心内容
- 用 matplotlib 画训练 loss 随 epoch 的曲线，靠"损失是否逐步下降、是否突然反弹"判断收敛与过拟合。
- 用 keras 的 plot_model 导出 LSTM 结构图（显示每层形状与层名），用于调试模型结构。
- 预测流程：测试集转 numpy → 用训练时的 scaler 变换 → reshape 成 (样本数, 1, 1) 的单变量单步输入 → 送入 LSTM 得预测价格。
- 预测结果先 reshape 成二维，再 inverse_transform 还原到价格量纲，最后与真实价格曲线叠图比较。

## 可复用要点
- 单变量 LSTM 的输入形状约定为 (样本数, 时间步, 特征数) = (N,1,1)，预测后必须做与训练一致的逆变换才能与真实价格比较。
- "loss 曲线 + 真实值/预测值叠图"是可复用的最小评估可视化组合。
- 变换用 sc.transform 对测试集逐段处理，注意 scaler 只应在训练段 fit（原文未说明）。

## 关键实现
- 关键调用：model1.predict(inputs)、sc.transform / sc.inverse_transform、keras.utils.vis_utils.plot_model(model1, to_file='model_plot.png', show_shapes=True, show_layer_names=True)。
- 依赖 keras/tensorflow、numpy、matplotlib；无自定义函数。

## 数据与假设
- BTC 价格序列，频率、区间与来源原文未交代；测试集变量为 df_test。
- 假设价格序列可由单变量 LSTM 预测，且训练/测试已按时间顺序切分。

## 局限与风险
- 没有任何误差指标（MAE/RMSE/方向准确率），只有曲线图，模型预测能力无法量化。
- 单变量输入丢弃了成交量、链上数据等信息；只做价格拟合，没有涨跌方向评估与交易信号。
- 原文未说明训练/测试如何切分及是否重拟合 scaler，若随机切分则存在未来信息泄漏。
