# （15-2）基于时间序列预测的比特币自动交易系统：准备数据

## 筛选结论
部分保留 —— 内容是加密资产历史行情的采集（yfinance 库接口 + 第三方 REST API），属于数据获取环节，采集与建表模式可借鉴；但标的是 BTC-USD，与 A 股行情源不同，且原文只演示取数、没有清洗。

## 核心内容
- 数据获取三件套：Pandas 负责整理与建表，yfinance 负责金融/加密行情，HTTP API 负责外部数据源，三者组合完成数据收集。
- 主路径：`yf.Ticker("BTC-USD")` 建对象，`.history(start, end)` 按日期区间取 BTC 对美元日线，示例区间 2014-09-01 至 2022-02-01。
- 备路径：requests 请求 CoinCodex 历史数据 API，json.loads 解析后用 `pd.DataFrame(api_data['data'])` 转成表，示例区间 2021-01-01 至 2021-09-30。
- 库接口与 REST API 双通道互为补充，是行情采集降低单一数据源风险的常见做法。
- 原文止步于"取到数据"，统一未涉及复权、缺失、时区与对齐等清洗环节。

## 可复用要点
- 行情采集范式：数据集对象 + 日期区间参数（start/end）直接返回 DataFrame；REST API 返回的 JSON 取 data 字段整体转表。
- 可迁移到本项目：用两套独立数据源交叉校验同一标的的行情一致性（价格/成交量偏差检验）。
- 若接入 A 股，需要补充交易日历对齐、复权因子与前复权/后复权口径，这些原文未给。

## 关键实现
- 依赖 numpy、pandas、matplotlib、yfinance、requests、json。
- 关键调用：`data = yf.Ticker("BTC-USD")`；`yf_df = data.history(start='2014-09-01', end='2022-02-1')`；`api_data = json.loads(requests.get('https://coincodex.com/api/coincodexcoins/get_historical_data_by_slug/bitcoin/2021-1-1/2021-9-30/1?t=5459791').text)`；`api_df = pd.DataFrame(api_data['data'])`。
- 环境准备：`!pip install yfinance`。

## 数据与假设
标的为 BTC-USD；两段示例区间 2014-09-01~2022-02-01（yfinance）与 2021-01-01~2021-09-30（CoinCodex）；日频（history 默认）；前提是接口可用且返回字段结构稳定。

## 局限与风险
- 只有取数演示，没有缺失值处理、异常值处理、频率统一与数据质量校验。
- 未说明价格是否复权、时区与日切时间；加密资产 7×24 交易与 A 股交易日历差异大，无法直接套用。
- 第三方 API 未见鉴权与限流处理，链接含固定参数，接口变更或失效即中断。
- 本篇是系列中的一节，依赖同系列其他篇章的上下文，单独使用信息不完整。
