# （5-3-02）金融市场情绪分析：基于Gemma模型的金融市场情绪分析

## 筛选结论
部分保留 —— 产出物是金融文本的情绪标签，可直接当舆情因子使用；但本篇主体是大模型 LoRA 微调，没有情绪到策略与收益的链路。

## 核心内容
- 论点：Gemma 的 2B/7B 轻量开源版本适合资源受限的金融情绪分析，优势是语义理解、单卡甚至 CPU 可跑、可金融领域微调。
- 通用流程：收集带情绪标签的金融文本（新闻标题/研报/股评）→ 清洗与统一格式 → 模板化输入 → 按 7:2:1 划分 → 冻结底层仅微调顶层 + LoRA → 评估优化。
- 通用超参建议：学习率 5e-5~1e-4、batch size 8~16、epochs 3~5、交叉熵损失，三分类（积极/中性/消极）。
- 优化手段：对稀缺的"消极"类做同义词替换/回译增强，用金融语料二次预训练，或用 2B+7B 集成提稳定性。
- 实例用 Gemma 3 1B + LoRA 微调英文财经新闻标题：零样本整体准确率 55%，微调后升到 85.3%（消极 97.7%、中性 75.3%、积极 83.0%）。
- 微调前的主要问题是中性类几乎识别不出（召回 0.14），且消极类高召回（0.90）低精确（0.44）。

## 可复用要点
- 情绪三分类标签可作为舆情/事件因子接入预测模型；评估用"标签映射 + 分类报告 + 混淆矩阵"。
- 数据组织方式可参考：每类各抽 300 条做训练与测试，评估集每类目标 50 条、不足时允许重复采样。
- LoRA 参数：r=64、lora_alpha=32、lora_dropout=0.05、bias="none"、task_type="CAUSAL_LM"、target_modules="all-linear"；训练 4 epoch，per_device_batch=1 + 梯度累积 8，adamw_torch_fused，开梯度检查点省显存。
- 提示模板思路：把"新闻文本 = "拼接后让模型续写标签，再从生成文本里解析出标签。

## 关键实现
- 函数：define_device()（按 MPS/CUDA/CPU 选设备）、generate_train_prompt()/generate_test_prompt()、predict(X_test, model, tokenizer, max_new_tokens=5, temperature=0.0)、evaluate(y_true, y_pred)（positive=2/neutral=1/negative=0）。
- 依赖：PyTorch、Transformers、TRL(SFTTrainer/SFTConfig)、PEFT(LoraConfig)、datasets、scikit-learn；数据字段为 sentiment/text。
- 流程收尾：保存 LoRA 适配器与分词器，合并基础模型后另存，并把测试集"文本/真实/预测"三列导出为 CSV。

## 数据与假设
- 英文财经新闻标题数据集（all-data.csv），三分类情绪标签；训练 900 条（每类 300）、测试 900 条、评估集每类约 50 条。
- 假设标题文本的情绪可分辨且标签可靠；运行环境为单 GPU（CUDA），基座权重来自本地路径。

## 局限与风险
- 中性类准确率仅 75%，评估集每类只有 50 条，85.3% 的结论稳健性有限。
- 用字符串解析从生成文本取标签，未命中时回落为 "none"，评测口径不严谨。
- 情绪仅三档、无强度与置信度，作因子偏粗；原文未验证情绪与收益或策略表现的关系。
- 英文语料加 Gemma 权重，迁移至中文 A 股舆情需重新标注与微调。
