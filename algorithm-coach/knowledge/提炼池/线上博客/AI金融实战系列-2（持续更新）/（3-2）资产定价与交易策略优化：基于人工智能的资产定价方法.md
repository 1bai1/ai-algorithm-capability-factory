# （3-2）资产定价与交易策略优化：基于人工智能的资产定价方法

## 筛选结论
保留 —— 梳理了传统定价模型的失效点与机器学习在资产定价中的适用性，并给出用加密货币特征给黄金定价的可运行示例（LASSO / 随机森林 / 梯度提升树），直接对应 Agent 的模型选择与验证环节。

## 核心内容
- 传统模型（CAPM、APT、Fama-French）的失效集中在四处：理性人与有效市场、无摩擦假设不成立；风险因子片面（单因子 β 不足，因子选择主观且跨市场/跨时段不稳定，非系统性风险仍可能被定价）；参数时变与非线性被忽略；对加密资产等新兴资产与动量类异象解释力弱。
- 机器学习的三条优势：正则化/特征选择/降维应对高维（如 LASSO 从大量宏观指标中剔除无关因子）；树模型与神经网络免预设函数形式，可学到条件型非线性规则；滚动窗口训练或在线学习适应市场时变。
- 强化学习被列为资产定价与投资组合动态调仓的工具之一。
- 结论是"机器学习 + 金融理论"融合：以理论筛特征、以 ML 优化模型，并以严谨验证和可解释性为前提，避免沦为数据挖掘陷阱；原文明确 ML 不替代传统金融理论。
- 黄金定价示例：数据来自 Crypto Data Since 2015.csv，用加密货币相关特征预测黄金价格，横向比较三种模型。

## 可复用要点
- 特征构造范式：由原始价格生成滞后特征（1 天前、1 周前价格）与收益率特征（1 日、7 日收益率），删缺失后以加密货币列作特征、黄金价格作目标。
- 切分与评估：时间序列分割（训练 80% / 测试 20%，不可随机打乱），特征标准化，用时间序列交叉验证，评价指标为 R² 与 MSE。
- 模型基线三件套：LASSO 回归（线性、权重可解释）、随机森林、梯度提升树；原文指出 LASSO 善于捕捉线性关系、树模型易过拟合，可作为选型先验。
- 结果呈现三张图：模型性能对比（R²/MSE）、黄金价格实际值 vs 预测值、LASSO 特征重要性。

## 关键实现
- 函数 `load_and_preprocess_data(file_path='Crypto Data Since 2015.csv')`：读取数据、日期格式转换并按时间排序、构造滞后与收益率特征、删除缺失值、分离特征与目标。原文仅保留该函数签名及首行注释，训练与评估代码未收录。
- 依赖：pandas / numpy、sklearn（LASSO 回归、随机森林、梯度提升树）及可视化库。

## 数据与假设
- 数据：Crypto Data Since 2015.csv，含加密货币与黄金价格；标的为黄金价格，特征为加密货币价格派生量。频率、样本区间、具体币种原文未交代。
- 假设：加密货币与黄金之间存在可学习的关联；价格序列可由滞后项与收益率项表达。

## 局限与风险
- 除黄金示例外全篇为教材式综述，无实证数字：未给出任何 R²/MSE 具体值，也未说明哪个模型最优；"树模型可能过拟合"属作者判断而非本文验证结果。
- 黄金定价示例代码几乎全部缺失（只剩函数定义首行），无法复现；80/20 单次时序切分未做滚动验证，存在单期过拟合风险。
- 用加密货币价格预测黄金是跨市场假设，原文未讨论交易时段错配、流动性差异与宏观共同因子的混淆效应。
- 未考虑交易成本；也未说明标准化是否仅在训练集上拟合（若用全样本标准化会造成信息泄露）。
