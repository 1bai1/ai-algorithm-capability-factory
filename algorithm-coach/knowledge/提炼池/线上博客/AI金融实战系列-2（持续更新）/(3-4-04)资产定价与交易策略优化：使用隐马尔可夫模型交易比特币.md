# (3-4-04)资产定价与交易策略优化：使用隐马尔可夫模型交易比特币

## 筛选结论
保留 —— 给出 HMM 采样数据的阈值寻优、阈值型择时回测函数与失败复盘，属交易策略与回测评价环节，可作为 A 股日频择时策略的对照组与反面案例。

## 核心内容
- HMM 模拟数据生成：按状态转移概率逐步采样隐藏状态，收益率用 r_t = β·r_{t−1} + μ_s + ε（ε ~ N(0, σ)）生成，价格取 exp(累积和)，模拟 5000 天。
- 阈值寻优：在摩擦率网格上回测各（买入阈值, 卖出阈值）组合，目标函数为 log(回报) + 交易次数·log(1−f)，取最大者为该摩擦率下的最优组合。
- 回测函数：由 HMM 输出隐藏状态概率与期望异常收益 EAR；持现金且 EAR 高于买入阈值则满仓买入，持仓且 EAR 低于卖出阈值则清仓，成交额按 (1−f) 扣减。
- 核心结论：在 HMM 采样数据上优化的阈值，样本外效果远不如在真实数据上优化的阈值；中高摩擦率下该策略干脆不交易。
- 失败归因：HMM 生成的样本与训练价格数据不相似，隐藏状态切换过快，模拟序列比真实数据更"平滑一致"。
- 定位修正：当前形态下 HMM 只作特征提取器，不作预测器。
- 改进方向：对负对数似然 NLL 施加约束或正则使状态切换更慢；改用其他 HMM 结构（两个隐藏状态时模型倾向区分"增长/快速增长"而非"增长/衰退"）；去掉 β·r_{t−1} 项会使状态过于简单、无法支撑精细决策。

## 可复用要点
- 合成行情生成器：r_t = β·r_{t−1} + μ_s + ε，状态均值 μ_s 提供分层漂移、σ 控制噪声，可作为压力测试/合成序列的最小实现。
- 阈值型择时规则：以模型输出的期望异常收益 EAR 为信号，单一买/卖阈值即可表达，便于网格搜索并显式计入摩擦。
- 寻优目标函数：log(回报) + n_trades·log(1−f)，把成本并入适应度，使最优阈值随摩擦率上移（要求更高置信度才交易）——这套"收益−成本联合目标"可直接复用于 A 股策略参数搜索。
- 双资产回测骨架：Portfolios[i, t, 0/1] 分别记录现金与持仓数量，总价值 = 现金 + 持仓 × 价格。

## 关键实现
- 采样：`s = np.random.choice(range(3), p=hmm.TP[:, s])`；`r = hmm.beta*r + hmm.MU[s] + np.random.randn()*hmm.sig`；`Psampled = np.exp(np.cumsum(Rsampled))`。
- 训练期寻优：`R, T = back_train_pol(hmm, Psampled)`；`FR = np.log(R) + T*np.log(1-f)`；`ix = np.argmax(FR)`；`i1 = np.mod(ix, res)` 解码出买卖阈值下标。
- 回测：`back_test_pol(mdl, friction, Buy_Price, Sell_Price, Prices)`，内部调用 `mdl.get_hidden_state_probabilities(Prices)` 与 `mdl.get_expected_abnormal_rates(Prices)`，对 100 组摩擦率并行模拟，`rate = 1 - friction[i]`，返回 Portfolios 与 Value。
- 样本外评估：以 train_end 为界，用 V1[:, -1] / V1[:, train_end] 计算测试期回报，摩擦率取 0.5%（i=25）、1%（i=50）、1.5%（i=75）三档分别作图对比。

## 数据与假设
- 数据：与 (3-4-01) 同源的交易所 1 分钟数据聚合出的比特币日价格序列；另用同一 HMM 生成 5000 天模拟价格。
- 模型：3 状态 HMM，参数含转移概率 TP、状态均值 MU、自回归系数 beta 与噪声 sig。
- 假设：交易成本可统一为摩擦率 f；训练集与测试集以 train_end 切分，测试期不重新训练。

## 局限与风险
- 作者自证：用模拟数据训练的策略样本外表现差、中高摩擦下退化为不交易，该做法不能照搬。
- HMM 结构偏简（无 β·r_{t−1} 项时状态过简，有该项时切换过快），改进方向只提出未验证。
- 结论基于单一标的与单一历史区间，未见参数敏感性分析和多随机种子的重复实验。
- 本篇代码依赖前序篇定义的 HMM 对象（TP/MU/beta/sig）与 back_train_pol，本篇未给完整定义，代码片段有截断，无法独立复现。
