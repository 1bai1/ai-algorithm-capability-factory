# （5-3-01）金融市场情绪分析：基于BERT模型的金融市场情绪分析

## 筛选结论
保留 —— 金融文本情绪可转化为量化舆情因子，其预处理、微调与评估流程可直接工程化为 Agent 的情绪因子生成环节。

## 核心内容
1. 用 BERT/FinBERT 等预训练模型微调新闻、公告、研报、股吧文本，输出积极/消极/中性（可细分恐慌、乐观）的量化情绪指标。
2. BERT 双向注意力适配金融文本的语境歧义、专业术语（利空、平仓、PE 估值）与反讽、隐晦评价。
3. 流程四段：数据准备与标注 → 文本预处理 → 模型微调 → 评估与优化。
4. 预处理：清洗标准化、句首加 [CLS] 句尾加 [SEP]、WordPiece 分词、长度统一 128/256 tokens、短补 [PAD] 长截断。
5. 微调：在 [CLS] 隐状态接全连接+Softmax 分类头，可冻结底层只调上层；超参 AdamW、学习率 2e-5、batch 16/32、epoch 5-10、Dropout 0.1。
6. 评估关注 Accuracy、Macro-F1 与混淆矩阵，风控场景尤其看重"消极"类识别；样本不足用同义词替换与回译增强。

## 可复用要点
- 三分类情绪标签体系，可扩展细分为恐慌、乐观等。
- BERT 输入构造规范：max_len 128/256、attention_mask、padding/truncation。
- 训练超参组合（2e-5、16/32、5-10 epoch、Dropout 0.1）可作起步值。
- 以 Macro-F1 为主、单独考察消极类召回，可作为情绪因子有效性的验收口径。
- 领域适配：在财报、研报语料上做二次预训练。

## 关键实现
实例 5-4：`FinancialDataset(Dataset)`，`__init__(texts, labels, tokenizer, max_len=128)`；`__getitem__` 调 `tokenizer.encode_plus(add_special_tokens=True, max_length=max_len, padding='max_length', truncation=True, return_attention_mask=True, return_tensors='pt')`，返回 input_ids/attention_mask/label；PyTorch 原生 AdamW + 学习率调度器；设备自动选 cuda；数据集 all-data.csv；输出损失/准确率曲线、准确率柱状图与混淆矩阵。原文代码为节选，DataLoader 与训练循环缺失。

## 数据与假设
all-data.csv 金融文本三分类情绪数据集；假设标注质量可靠，且文本情绪与市场表现存在可利用的关联。

- 全篇为方法叙述加截断代码，"性能优异"无对比指标支撑。
- 未讨论情绪指标到股价预测的实际增益、标注噪声与类别不平衡的处置。
- 代码缺失训练循环，不能直接运行。
- 未说明中文金融语料是否适配 WordPiece 分词与英文预训练权重。
