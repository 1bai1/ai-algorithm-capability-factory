# (6-3-02)高频交易与量化交易：量化交易的执行与组合优化

## 筛选结论
保留 —— 覆盖"信号生成→交易执行→组合优化"闭环，含执行成本建模、仓位约束与一个完整 LSTM 量化示例，直接对应本项目的策略生成与回测环节。

## 核心内容
- 量化流程分三段：策略信号、交易执行、组合优化；执行成本决定理论收益能否落地。
- 执行成本四类：滑点、佣金税费、市场冲击、未成交导致的机会成本。
- 执行算法按订单规模/流动性/时效选择：VWAP、TWAP、冰山订单、智能订单路由。
- 执行质量三指标：执行差额（Implementation Shortfall）、成交率、TWAP 偏离度。
- 组合优化目标为最大化夏普、最小化最大回撤，并施加单资产上限、行业集中度、流动性与杠杆约束。
- 经典模型：马科维茨均值-方差（有效前沿）、风险平价（风险贡献均等）、Black-Litterman（贝叶斯融合市场均衡收益与主观观点）、机器学习权重模型。
- 调仓分定期（月/季）与触发式（跌幅超阈值、VIX 飙升）。
- 执行与优化需闭环：优化阶段预估执行成本，实际滑点超预期则触发再优化。

## 可复用要点
- 特征：SMA20/SMA60、RSI(14)、滚动波动率、量价比、趋势强度、日收益率、成交量标准化（Volume/20 日均量）。
- 标签：未来 5 日收益率二分类；特征标准化后按时间顺序 8:2 划分训练/测试。
- 信号规则：预测概率 > 0.5 且趋势强度 > -0.01 买入；预测下跌或趋势转弱卖出；用持仓状态机控制单笔持仓。
- 成本参数：佣金 0.001、滑点 0.0005；评估用累计收益、夏普、最大回撤、超额收益。
- 仓位随波动率反向调整：高波动降低仓位上限，低波动提高。

## 关键实现
类 DeepQuantStrategy，方法链 run → load_and_preprocess → build_features（含 calculate_rsi）→ prepare_lstm_data → train_lstm_model → generate_signals → execute_trades → portfolio_optimization → evaluate_performance → visualize_results。依赖 pandas/numpy/sklearn/Keras(TensorFlow)/matplotlib。数据文件 Oracle.csv，字段 Date、Adj Close、Volume。

## 数据与假设
单标的日频行情（Oracle.csv，含复权收盘价与成交量）；假设可按当日价格成交、佣金与滑点固定、用预测概率阈值近似交易信号。原文未交代数据时间范围与所属市场。

## 局限与风险
VWAP/TWAP/冰山/智能路由仅概念说明，实例中只用固定滑点与佣金近似，未真实建模冲击成本；信号阈值被人为放宽以"确保有信号输出"，属事后调参、有拟合风险；组合优化只用波动率调仓位上限，并非真正求解均值-方差或风险平价；无样本外验证与买入持有基准对比，未考虑税费、涨跌停与 T+1；称高效执行可年化提升 2%-5% 收益，无出处与验证。
