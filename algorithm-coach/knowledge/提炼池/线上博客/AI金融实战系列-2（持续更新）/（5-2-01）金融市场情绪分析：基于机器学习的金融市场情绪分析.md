# （5-2-01）金融市场情绪分析：基于机器学习的金融市场情绪分析

## 筛选结论
部分保留 —— 金融新闻情绪分类流程可作为情绪因子的构造手段，但本篇止步于分类器对比，未接入价格预测或因子检验。

## 核心内容
1. 目标是量化新闻、社交媒体与分析师报告文本的积极/消极/中性情绪，用于捕捉短期波动与潜在风险。
2. 传统方法（规则词典、早期浅层机器学习）的失效点：语境歧义与谐音、反讽、多重否定与复杂修饰、转折结构（"虽然亏损但长期看好"易被判为中性）。
3. 领域适应性差：金融专属词（利空、平仓、套牢）不在通用词典；"波动"等词的极性与强度随领域变化，跨领域迁移需重建词典或重新标注，成本高。
4. 规则法覆盖有限、无法识别网络新词与表情符号；早期 ML 依赖人工特征（词袋、TF-IDF），难捕捉深层语义且需大量标注；纯文本方法无法处理多模态。
5. 机器学习路线把情绪分析当作分类任务：文本预处理 → 特征工程 → 分类器训练。
6. 预处理含分词、去停用词、词干/词形还原、转小写、去特殊字符与标点；特征用词袋（词频统计）与 TF-IDF（词频高且在其他文本出现少则权重高）。
7. 分类器惯例：朴素贝叶斯（简单高效）、SVM（高维小样本表现好）、逻辑回归（输出概率、可解释）。

## 可复用要点
- 情绪因子原料链路：金融新闻经预处理与向量化、由分类器输出情绪标签或概率，可作为非价格类外生因子入模。
- 可解释性审计：逻辑回归的 Top 重要特征可用来检查通用词表是否误判金融术语，据此扩充领域词典。
- 评价口径：准确率横向对比 + 逐类混淆矩阵，关注各类误差分布而非只看总体准确率。
- 工程约束：依赖大量高质量标注数据，语言随时间演变需持续维护词典；跨市场（中英文、A 股/美股）迁移需重建词典与标注。

## 关键实现
- load_data('all-data.csv')：读为含 sentiment / text 两列的 DataFrame 并输出情绪分布。
- preprocess_text：转小写、正则去特殊字符与标点、分词、去停用词、词形还原。
- create_features：词袋与 TF-IDF 两套特征，并对标签做数字编码。
- train_and_evaluate_models：划分训练/测试集，分别训练朴素贝叶斯、SVM、逻辑回归，输出准确率与分类报告。
- visualize_results：准确率对比柱状图、三张混淆矩阵热图、逻辑回归 Top-10 重要特征图。
- 依赖 nltk（nltk.download 获取停用词/分词/词形还原资源）、scikit-learn、pandas、matplotlib/seaborn。收录文本中实例代码主体未展开。
