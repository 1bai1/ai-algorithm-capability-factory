# （4-3-2）信用风险评估：制作信贷风控模型

## 筛选结论
部分保留 —— 业务域是银行信贷风控（规范中的低相关方向），但"训练回调 + 多指标评估 + 模型与预处理一起持久化"的工程流程可迁移到我们的模型训练环节。

## 核心内容
- 用 Keras 训练二分类信贷风险模型，同时挂三种回调：早停监控验证集损失、按验证集 AUC 保存最优权重、验证集损失停滞时衰减学习率。
- 训练曲线固定看 loss、accuracy、precision、recall、auc 五个指标，训练集与验证集成对绘制，用于判断过拟合与收敛状态。
- 测试集评估输出 loss/准确率/精确率/召回率/AUC，并配混淆矩阵、ROC 曲线、精确率-召回率曲线和分类报告，另做特征重要性分析。
- 预测接口按 0.5 阈值把风险概率二值化为高/低风险，返回结构化结果。
- 模型以 H5 保存，预处理管道（缺失值填充、编码等）单独以 pickle 保存，加载时两者一并恢复。
- 主流程把数据加载、探索性分析、预处理、建模、训练、评估、保存串成端到端管道，并提供示例数据演示预测。

## 可复用要点
- 回调参数可直接作为建模模板默认值：EarlyStopping(monitor=val_loss, patience=10, restore_best_weights=True)；ModelCheckpoint(monitor=val_auc, mode=max, save_best_only=True)；ReduceLROnPlateau(factor=0.2, patience=5, min_lr=1e-5)。
- 评估组合（AUC + 精确率/召回率 + PR 曲线）比单看准确率更适合类别不平衡的涨跌/风险标签，可用于信号模型验证。
- 模型与预处理管道必须成对保存与加载，避免训练/推理阶段特征口径漂移。

## 关键实现
- 方法：train_model(epochs=100, batch_size=32, patience=10)、plot_training_history()、evaluate_model()、plot_confusion_matrix()/plot_roc_curve()/plot_precision_recall_curve()、save_model()/load_saved_model()、predict_risk(data)、run_pipeline()、demo_prediction()。
- 输入为单条样本字典或 DataFrame，输出为风险标签与概率；依赖 Keras/TensorFlow、scikit-learn、joblib、matplotlib、seaborn。

## 数据与假设
- 信贷客户特征表加二值风险标签，划分为训练/验证/测试三份；原文未给出样本量、特征字段、划分比例与时间范围。
- 假设正类为"高风险"，0.5 为默认判定阈值。

## 局限与风险
- 原文只给代码与说明，没有给出模型实际准确率/AUC 数值，效果无从验证。
- 固定 0.5 阈值未做阈值寻优或代价敏感分析，信贷场景下两类错误的成本不对称被忽略。
- 未说明是否按时间切分；若含时间维度的客户数据被随机划分，会高估泛化能力。
- 与 A 股个股量化预测无直接关系，仅工程流程可借鉴。
