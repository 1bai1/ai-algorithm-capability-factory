# （4-1）信用风险评估：信用风险的概念与评估方法

## 筛选结论
不适用 —— 面向借款人违约的信用风险（PD/LGD/EAD）与信贷评分卡，属规范中"银行信贷"范畴，与 A 股个股量化预测无对应环节；仅"多维度加权打分→综合分→等级分桶"的结构形式上可迁移。

## 核心内容
- 信用风险指交易对手未按约履约造成损失的可能性，量化三要素：违约概率 PD（特定期限内违约可能性）、违约损失率 LGD（违约时损失金额 / 违约前债权总额）、风险敞口 EAD（违约时未偿还本息合计）；常以连续 90 天未付本息视为实质性违约。
- 风险来源三类：债务人自身（经营、流动性、盈利、行业周期或收入与信用记录）、宏观环境（衰退、利率、汇率、政策收紧）、交易结构（条款、担保、法律合规）。
- 传统方法：5C 评估法（品德/能力/资本/抵押/环境）、个人信用评分法（如 FICO，指标加权计分后分级）、专家判断法（适用于数据不足或复杂场景）。实务上传统方法与现代量化模型结合使用。
- 实例在德国信用数据集上按 5C 构建加权评分，映射为 AAA~BB 五档，并输出等级分布、维度相关性热图、年龄-评分散点、住房-等级堆叠图与结果 CSV。

## 可复用要点
无 —— 与 A 股个股的特征构造、预测模型、策略与回测均无交集。唯一可迁移的是"分维度打分 → 加权合成总分 → 阈值分桶定级"的评分卡形式，但因子与权重需全部重新定义。

## 关键实现
依赖 pandas、matplotlib、seaborn。函数：`load_and_preprocess_data`、`credit_evaluation_model`、`visualize_results`、`main`。
- 序数映射用 map：储蓄账户 unknown/little/moderate/quite rich/rich → 3/4/6/8/10；支票账户 → 3/4/6/10；职业 0~3 → 3/5/7/10；住房 own/rent/free → 10/6/3；信贷用途 car/furniture/…/vacation → 5~9。
- 分箱用 apply：年龄 30-50 岁得 10 分，25-30 或 50-60 得 7，20-25 或 60-65 得 5，其余 3；信贷额/期限比 <200 得 10、<500 得 7、<1000 得 5、否则 3。
- 权重：品德 0.30、能力 0.25、资本 0.20、抵押 0.15、环境 0.10；总分等级阈值 AAA≥8、AA≥6.5、A≥5、BBB≥3.5，否则 BB。
- 结果 `to_csv('credit_evaluation_results.csv')`。

## 数据与假设
german_credit_data.csv，1000 条德国客户记录，字段 Age、Sex、Job、Housing、Saving accounts、Checking account、Credit amount、Duration、Purpose；储蓄/支票账户缺失值以 'unknown' 填充。假设各维度映射分值与权重能反映违约风险。

## 局限与风险
- 权重、映射分与等级阈值全部人工设定，原文未使用数据集自带的违约标签做任何验证，无 AUC/KS 等指标，评分卡有效性完全未检验。
- 用储蓄/支票账户代"品德"、住房代"抵押"、信贷用途代"环境"，属强行替代；用途类打分（vacation 5、education 9）无依据。
- 未处理类别不平衡与样本量偏小（1000 条）问题，仅德国市场，不能迁移到 A 股。
