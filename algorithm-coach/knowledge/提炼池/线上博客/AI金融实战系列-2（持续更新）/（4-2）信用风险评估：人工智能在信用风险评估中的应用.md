# （4-2）信用风险评估：人工智能在信用风险评估中的应用

## 筛选结论
不适用 —— 属规范中排除的银行信贷方向（个人信贷违约分类）；只有"多模型横向对比 + 分层抽样 + ROC/AUC 评价 + 特征重要性"这套通用建模范式可类比到个股预测流程。

## 核心内容
- 主张：AI 把信用评估从"季度报表 + 打分卡"升级为实时多维感知，用 NLP 解析财报/新闻/电话纪要、CV 扫描发票合同、GNN 刻画担保与供应链网络，输出 PD、LGD、EAD 的分钟级滚动预测。
- 传统方法六项局限：主观性强、数据维度有限（漏掉社交与消费行为数据）、静态滞后、缺乏精细化区分、对新产品/新环境适应性差、人工审核效率低。
- 机器学习的三大优势：可整合结构化与非结构化数据、能捕捉非线性关系（如年龄与负债的交互）、可随实时数据流动态更新参数。
- 机器学习的挑战：黑箱难解释、历史数据偏见、过拟合导致极端风险事件误判。
- 宣称收益：不良率降低 20–40%，审批时效由天缩短到分钟（原文未给出处与验证方法）。
- 实例：用德国信用数据集构建违约分类模型，流程为加载与预处理 → 探索性分析 → 四模型训练 → 指标评估与可视化。

## 可复用要点
- 可迁移的建模骨架：数值特征标准化 + 分类特征编码放进预处理管道；分层抽样切分训练/测试以保持类别分布；用准确率、精确率、召回率、F1、AUC 多指标横向比模型；树模型看特征重要性。
- 与自研 Agent 的差别需注意：适用场景是横截面二分类（是否违约），不是价格时间序列；分层抽样会打乱时间顺序，不能直接用于时序任务。
- 其余无。

## 关键实现
- 函数 `load_and_preprocess_data(file_path='german_credit_data.csv')`：读 CSV、去掉 'Unnamed: 0' 索引列、对 'Saving accounts' 缺失值填 'unknown'。
- 关键缺陷：原始数据无标签，代码用规则人工合成违约标签 —— 信贷金额/期限 > 500 且 Job < 2 且储蓄账户为 little 时标为违约（`default_risk`），属自造标签。
- 模型：逻辑回归、决策树、随机森林、梯度提升树四类；输出 ROC 曲线、性能指标条形图、最佳模型混淆矩阵与特征重要性。

## 数据与假设
- 数据：德国信用数据集 german_credit_data.csv，含年龄、信贷金额、期限、Job、Saving accounts、性别、住房等字段，数百条样本量级。
- 假设：CSV 本身不含真实违约标签，需用上述规则合成；数据为横截面，无时间维度。

## 局限与风险
- 标签是自造规则生成的，模型实际是在学习该规则而非真实违约风险，全部指标不可信、不可迁移。
- 宣称的"不良率降低 20–40%、审批提速到分钟级"无数据来源与验证方式，属行业宣传口径。
- 无时间维度，不能用于时序预测；分层抽样破坏时间顺序，与量化回测的样本外要求冲突。
- 与 A 股个股的价格预测、交易信号生成无直接关联。
