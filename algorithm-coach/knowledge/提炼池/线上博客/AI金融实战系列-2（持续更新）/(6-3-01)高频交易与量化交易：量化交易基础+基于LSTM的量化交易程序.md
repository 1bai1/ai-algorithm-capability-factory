# (6-3-01)高频交易与量化交易：量化交易基础+基于LSTM的量化交易程序

## 筛选结论
保留 —— 给出量化交易六模块框架、数据规范、因子构建与检验方法，并附一个 LSTM 策略实例，与我们的"特征工程 + 模型 + 策略信号 + 回测"全链条高度对应。

## 核心内容
- 量化交易核心框架六大模块：数据层、策略层、执行层、风险控制层、资金管理层、监控迭代层，构成"数据驱动策略、策略指导执行、风控贯穿全程、迭代适应变化"的闭环。
- 数据分三类：高频（Tick 行情、订单簿快照、逐笔成交）、低频（日/周/月行情、财务数据、宏观指标）、另类（新闻舆情、社媒情绪、产业链、资金流向）；质量要求完整性、准确性、时效性、一致性。
- 预处理关键环节：清洗异常值与去重、标准化/归一化、时序平滑、按时间顺序切分训练测试以防未来信息泄露、特征工程。
- 市场特征分五类：趋势性、波动性、流动性、量价联动、市场情绪；因子是特征的可计算量化表达，构建逻辑是"从市场现象提炼规律，用数学指标量化规律"。
- 因子构建流程：识别聚焦 → 设计数学公式 → 标准化与异常值处理 → 禁止使用未来信息 → 定期回测迭代。
- 因子有效性检验四件套：IC（与未来收益的相关性）、分层回测（高因子组收益应显著高）、稳定性（跨牛熊/跨市场）、冗余性（相关 >0.8 需剔除）。
- LSTM 实例：以 60 天回溯窗口、MinMaxScaler 归一化，含 Dropout 的 LSTM + 早停训练，预测未来 5 日涨跌；信号要求预测上涨概率 >55% 且趋势因子（均线交叉）确认。
- 评估指标为累计收益、胜率、最大回撤，并与市场表现对比。

## 可复用要点
- 因子公式族：SMA_5（5 日均价）、线性回归斜率、10 日价格标准差、极差（最高-最低）、成交量/过去 20 日均量比。
- 因子预处理：Z-score 或 0–1 缩放；用分位数截断（剔前后 1%）或对数转换压异常值。
- 防泄露规则：第 t 日因子只能使用 t-4 至 t 日数据。
- 风控参数示例：单标的仓位 ≤10%、单笔亏损达 5% 平仓、杠杆 ≤2 倍；连续 3 个月跑输基准则迭代策略。
- 交易信号门槛：模型概率阈值 + 技术指标（均线交叉）双确认后再开仓，并控制持仓状态。
- 回测评价口径：累计收益、胜率、最大回撤三项对照基准。

## 关键实现
- 类 `LSTMQuantStrategy(file_path, lookback=60, test_size=0.2)`；属性含 data / features / model / signals / metrics，标准化器 `MinMaxScaler(feature_range=(0,1))`。
- 流程方法：`load_and_preprocess()`（读 CSV、Date 转 datetime 并排序、Adj Close 改名 Adj_Close、dropna）→ `build_features()`（技术因子：均线/RSI/波动率；量价因子：成交量变化率、量价比率；趋势因子；目标变量 = 未来 5 日涨跌）→ LSTM 训练（dropout + 早停）→ 信号生成 → 评估 → 可视化。
- 数据字段：Date、Open、High、Low、Close、Adj Close、Volume；示例标的为 Oracle 股票。

## 数据与假设
- 数据源：本地 CSV（示例为美股日线，含复权收盘价）。
- 频率：日频；标签为未来 5 日涨跌的二分类。
- 假设：60 天回溯窗口足以刻画序列依赖；因子已标准化且不含未来信息。
