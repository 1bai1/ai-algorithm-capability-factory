# （1-2）金融时间序列分析：移动平均法

## 筛选结论
保留 —— 均线族（SMA/WMA/EMA）是常用的特征构造算子，其金叉死叉规则可作为最简策略基线。

## 核心内容
1. 移动平均用固定窗口滑动求均值来平滑序列、突出长期趋势，窗口大小需人工设定。
2. 三种变体：SMA 对窗口内等权；WMA 对近期数据给更高权重；EMA 按指数衰减加权，对近期更敏感，适合股票价格这类需快速响应趋势变化的场景。
3. 三类用途：趋势识别、短期预测、异常值检测（原值显著偏离均线时提示异常）。
4. 优点是简单直观、适合平稳或弱趋势序列；缺点是对窗口大小敏感、无法处理强季节性与非线性趋势、长期预测能力有限。
5. 信号语义：短期上穿长期为金叉（趋势转强、潜在买入），下穿为死叉（趋势转弱、潜在卖出）；多线向上/向下发散分别指示上升/下降趋势，缠绕横盘为整理。
6. 均线属滞后指标，原文要求配合成交量、MACD 等综合判断，并常与 ARIMA 等方法结合使用。

## 可复用要点
- 特征构造：以收盘价滚动计算 5/20/60 日短中长三档均线，min_periods=1 保证窗口不足时仍出值；可扩展为价格/均线偏离度、短长均线差等可比特征（原文未构造该字段）。
- 策略基线：金叉做多、死叉平仓或做空，以多线发散方向作趋势过滤，横盘缠绕不开仓。
- 数据接口：tushare pro.daily(ts_code='600519.SH', start_date, end_date) 取日线后落盘 CSV 复用。

## 关键实现
- 依赖 tushare、pandas、matplotlib（含 dates、ticker.FuncFormatter）。
- 数据脚本 Maotai.py：ts.set_token('') → ts.pro_api() → pro.daily(...) → to_csv('maotai_stock_data.csv', index=False)。
- 分析脚本 Shijian.py：读 CSV、日期转 datetime、升序排序、校验必需字段，再以 df['close'].rolling(window=N, min_periods=1).mean() 计算并绘图；收录文本中该脚本仅展开 import 段，核心调用以文字描述为准。

## 数据与假设
贵州茅台 600519.SH 日线，2020-01-01 至 2023-09-01，本地 CSV 共 891 条记录；以收盘价为唯一分析对象；窗口取 5/20/60 日。

## 局限与风险
原文未附任何回测，金叉/死叉的胜率与扣费后收益均未验证，信号有效性属经验判断；均线滞后，原文亦提示需配合其他指标；min_periods=1 使序列前段由不足窗口的样本计算，早期均线不可靠、易产生虚假交叉；样本为单一股票单一时段，窗口参数未做敏感性分析；未考虑停牌、涨跌停与除权对均线连续性的影响。
