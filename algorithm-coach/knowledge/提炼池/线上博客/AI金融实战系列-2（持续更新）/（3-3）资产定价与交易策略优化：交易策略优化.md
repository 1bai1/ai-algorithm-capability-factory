# （3-3）资产定价与交易策略优化：交易策略优化

## 筛选结论
保留 —— 交易策略的构成要素、分类与风控规则成体系，且附"传统均线策略 vs 机器学习优化策略"的对照框架，直接对应本项目的策略生成与回测验证环节。

## 核心内容
- 交易策略的定义：在特定市场环境下，把"何时买、买什么、买多少、怎么卖"写成可重复、可验证的规则集合，形成信号生成到风险管理的闭环。
- 四要素：交易标的（股票/加密/黄金/外汇，流动性波动性决定设计）、信号体系（入场如突破 20 日均线、金叉；出场如止盈、跌破止损、死叉）、仓位管理（单笔资金占比、杠杆、加减仓规则）、风险控制（固定比例或波动率止损、最大回撤熔断如亏损 10% 暂停、分散化如同时持仓不超过 5 只）。
- 三类核心特征：规则化、可回溯（牛熊震荡分环境回测）、动态适应性（调参或切换策略逻辑）。
- 四类策略：技术分析类、基本面类、量化类、风险对冲类；目标是收益性、风险性、流动性三者的平衡。
- AI 优化的路线：强化学习（DQN/策略梯度）自动发现非线性信号、并行回测与在线迁移学习在滑点与冲击成本约束下动态调仓拆单、SHAP/LIME 可解释与风控熔断构成闭环。
- 实例：先做 5 日/20 日均线交叉并叠加 RSI 与 20/60 日均线中期趋势过滤，再用树模型预测金价次日涨跌，按置信度阈值（>55% 持有、<45% 空仓）生成信号，最后对比基准/传统/AI 三条累计收益曲线与夏普比率。

## 可复用要点
- 策略模板三段式：均线趋势过滤 + 超买超卖过滤 + 中期趋势确认；信号落地为持仓/空仓两态。
- 概率阈值规则：`p>0.55` 持有、`p<0.45` 空仓，形成带观望带的仓位决策（可作为 Agent 默认信号阈值起点）。
- 特征清单：多周期收益率、多周期均线、RSI、波动率。
- 缺失值分类型处理：价格类前向填充、指标类均值填充、收益率补 0。
- 对照评估范式：同一数据集上跑"基准市场 / 传统规则 / AI 模型"三组，比较总收益率与夏普比率，并输出特征重要性与预测概率分布用于诊断。
- 参数优化用时间序列交叉验证而非随机 K 折。

## 关键实现
- 原文标注源码示例基于 `Crypto Data Since 2015.csv`，但正文未给出代码（只有流程文字），无法复现类名与函数签名。
- 文字层面可提取的构件：均线交叉信号 + RSI 过滤 + 20/60 日均线趋势；树模型（正文先称随机森林、后称梯度提升树）做次日涨跌二分类；置信度阈值生成信号；时间序列交叉验证调参。
- 可视化三项：累计收益曲线、特征重要性、预测概率分布。
