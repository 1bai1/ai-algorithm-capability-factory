# (3-4-02)资产定价与交易策略优化：使用隐马尔可夫模型交易比特币

## 筛选结论
保留 —— 用 HMM 从价格序列推断隐藏市场状态并据此择时，直接对应我们要在个股上做的"市场状态识别 + 信号生成"环节；本篇给出可复现的参数拟合与状态解读方法。

## 核心内容
- HMM 假设系统状态不可见，只能通过可观测的价格序列反推；本文把比特币市场划成三个隐含状态。
- 状态语义：h0 快速增长、h1 较慢增长、h2 下降；状态概率随价格涨跌切换，用于判断当前所处的市场阶段。
- 训练集必须取序列的连续前段（本文取第 100–600 天共 500 天），不能随机抽样，否则无法检验对未见未来数据的泛化能力。
- 以负对数似然（NLL）为目标拟合参数；NLL 非凸，用 10 个不同随机初值重复优化取最优解。
- 定义"期望异常收益率"（EAR）：马尔可夫链状态的函数，度量给定历史下价格的短期未来行为，作者用它决定何时买卖比特币。
- 输出参数含 beta、各状态收益率均值 MU 和状态转移矩阵 P；本文拟合出的 MU 约为 +7.9%、+0.14%、-8.6%。
- 原文特别说明：基准策略与含摩擦成本的策略并未使用 HMM，仍基于价格的简单规则/趋势，HMM 是相对独立的待验证模块。

## 可复用要点
- 时序切分纪律：训练/测试只能按时间先后切，禁止随机划分。
- 非凸目标优化：多随机初始化（nstarts=10）后取最优。
- 输入特征：对数收益率 R = log(P_t / P_{t-1})。
- 信号构造：由隐藏状态后验概率 + 转移矩阵计算期望异常收益率，作为择时依据。
- 可视化套路：归一化价格与各状态概率叠加图、EAR 与价格对比图。
- 参数解读：状态均值 MU 可直接映射为"该状态下的预期收益水平"。

## 关键实现
- 类 `MHH`，三个方法：`fit_HMM(Prices, nstarts=10)`（内部先转对数收益率再优化）、`get_hidden_state_probabilities(...)`、`get_expected_abnormal_rates(...)`。
- 优化用 `scipy.optimize.minimize`；依赖 NumPy / pandas / matplotlib。
- 关键参数：`nstarts=10`；训练期由 train_start / train_end 指定，从 BC_Prices 中切片。

## 数据与假设
- 标的：比特币；本文使用项目统一的日度价格序列 BC_Prices。
- 时间：训练期取第 100 天到第 600 天的 500 天样本。
- 假设：隐状态数量固定为 3；对数收益率序列可由 HMM 刻画。

## 局限与风险
- 原文未给出该 HMM 择时策略的回测收益或与基准策略的定量对比，EAR 信号的有效性尚未验证。
- 拟合未使用解析梯度，效率低且依赖多次随机初值，存在陷入局部最优的风险。
- 状态数取 3 是人工设定，未见 BIC/AIC 等模型选择检验。
- 文中图 2-5 等图片未收录，状态概率的实际形态无法核对。
