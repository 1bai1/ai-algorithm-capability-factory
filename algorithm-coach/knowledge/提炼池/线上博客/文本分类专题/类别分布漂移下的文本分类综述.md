# Text Classification Under Class Distribution Shift: A Survey

## 筛选结论

保留 —— 该综述把"测试期会出现训练时没有的类"这一漂移场景拆成四类问题（KKC/KUC/UKC/UUC）并给出对应的三种学习框架与各自边界，另附可直接照做的开放集评测协议与常用数据集清单；对本项目「分布漂移下的任务定义、框架选型、评测数据构造」环节有用。公式推导与长篇未来工作论述只保留结论。

## 核心内容

1. **前提被打破**：机器学模型默认训练与测试同分布，但按主题的文本分类里新话题不断出现（如疫情相关新闻），闭集模型会把未知类样本硬判进已知类，拉低整体表现。
2. **四类类别的划分**：KKC（已知且有标注样本，走标准监督）、KUC（有样本但无类标签，走背景/Universum 类）、UKC（类已知但训练时无样本，走零样本）、UUC（类未知且无样本，走开放集学习与发现）。图 1 / 表 1 把这四类与对应的学习问题形式化一一对应。
3. **三种框架的能力边界**（表 2）：只有开放集能处理无界类集合与开放世界假设；背景类需要 OOD 训练数据、能检测但不能分类未知类；零样本能分类未知类但类集合固定、不能处理 UUC；开放集难以用单一目标优化（原文标"Easy to optimize"为 ✗）。
4. **背景类路线的做法**：训练分类器区分原数据与背景集；或改损失——Entropic Open-Set Loss（对 KUC 最大化熵）、Objectosphere（拉大 KKC 特征幅值、压低 KUC）、能量模型（惩罚 KKC 高能表示）、outlier exposure（用辅助 OOD 集压低置信度）、GAN 生成边界 OOD 样本 + 置信度损失。效果高度依赖背景样本的质量与多样性。
5. **零样本路线的做法**：把分类转成蕴含判断（逐类问"这段文本是关于 <class> 的吗"取最高分）；用类名原型嵌入 + 对比损失（cosine）训练；指令微调（多任务/多数据集训练后零样本迁移）；或用 LLM 合成训练集（ZeroGen 从零生成、ProGen 迭代反馈细化、ReGen 用 Wikipedia 检索增强），但合成数据收益递减且不如同规模人工标注数据。
6. **开放集路线的难点在阈值**：测试集中 UUC 占比未知，open-space risk 不可测，因此固定阈值难定；两条绕开路径——用 LOF / ABOF2 等离群因子判定，或先做异常检测再做闭集分类（检测最难）。开放式半监督（OSTC）允许训练时看到无标签的 UUC 样本，比纯开放集条件更宽。
7. **语义漂移 vs 背景漂移**：异常检测器只应检测"新类出现"（语义漂移）；若它把语气/立场这类与类无关的变化（背景漂移）也判成异常，会导致本属已知类的样本在进入分类器前就被拒识。
8. **开放集"发现"尚不成熟**：文本领域还没有把"检测未知类 + 挖掘新话题 + 给新类命名分类"打通的框架；原文指出直接提示 LLM 不够用——LLaMA2-7B 在 OOD 检测与 OSTC 上零样本/少样本都表现很差，专门设计的小模型可超过它；LLM 更适合做辅助信号（生成解释、给聚类命名）。
9. **数据构造方式**：常用数据集多为大规模（AG News 127k/4 类、DBPedia 630k/14、20NG 18k/20、Yahoo! Answers 1.4m/10、SST-2 69k/2、IMDb 50k/2、Amazon 50k/50、TMNtitle 32.6k/7、R21578title 10.8k/90）；零样本改造用"标签部分可见/完全不可见"两种设定，开放集改造则预留若干类作 UUC，已知:未知类比例在 20%~100% 间变化。

## 可复用要点

- **先判定漂移类型再选框架**：有标注的已知类 → 监督；有样本无标签（如未标注的评论流）→ 背景/Universum 类；类名先验已知但无样本 → 零样本；完全未知的新类 → 开放集检测（+ 发现）。
- **开放集评测协议可直接照做**：从标准分类数据集里预留 2/4/6 个类当 UUC，训练时完全不使用这些类的标签；测试时只要求判"属于开放空间"，不要求归类；把已知:未知类比例设 25%/50%/75% 多档做敏感性；注意 100% 已知类也不等于闭集问题，模型仍可把样本判为开放空间。
- **零样本分类的最省事落地**：任取一个会做蕴含判断的模型，对每个候选类跑蕴含式提示取最高分；有 LLM 时可用类描述而非单个词，且类名措辞会显著影响结果，需固化措辞。
- **背景类/拒识的损失组合**：分类损失 + 对未知样本提高熵或压低特征幅值，或用辅助 OOD 集做 outlier exposure。
- **阈值与拒识的坑**：不要用固定阈值的闭集分类器直接上开放场景；也不要用没在训练中见过离群点的检测器去拦所有分布外样本。
- **补数据的合成路线**：没有标注数据时可以先用 LLM 合成再训，但要预期收益递减、质量低于同规模人工标注，需要去重与多样性控制。

## 关键实现

- 综述本身不给代码；配套论文清单维护在 https://github.com/Eduard6421/Open-Set-Survey 。
- 提及的可复用组件：LOF（局部离群因子）、ABOF2（角度离群因子）、JEM（把 softmax 分类网重解释为能量生成模型）、typicality test（判断样本是否落入模型典型集）、Entropic/Objosphere/能量损失、outlier exposure、GAN 边界样本生成、Isolation Forest + k-means 的两阶段"检测+发现"流程、k-means 挑选回放样本。
- 联合目标形式：总损失 = 监督交叉熵 + α·背景类二元交叉熵 + β·未知类对比损失 + γ·未知类交叉熵；背景类取 α>0、零样本取 β>0、开放集取 γ>0。

## 数据与假设

- **性质**：文献综述，无自跑实验；结论均来自被引文献。
- **常用数据集（原文附录表 3）**：AG News（127k，4 类）、DBPedia（630k，14 类）、20 Newsgroup（18k，20 类）、Yahoo! Answers（1.4m，10 类）、SST-2（69k，2 类）、IMDb（50k，2 类）、Amazon Product Reviews（50k，50 类）、TMNtitle（32.6k，7 类）、R21578title（10.8k，90 类），并标注各自适用的零样本/开放集/持续学习设定。
- **三类框架各自的假设**：背景类需能采到 OOD 辅助数据；零样本需类名/描述等语义先验且类集合固定；开放集假设类集合无界、无 OOD 训练数据。

## 局限与风险

- **无任何自跑实验数字**：所有效果判断均为文献二手结论，落地到具体语料必须自行验证。
- **文献覆盖自陈可能不全**，且明确指出常用数据集多为十余年前构建，未必反映真实的开放场景，建议采集新语料。
- **未来工作占篇幅大**：持续学习、解耦正则、LAMOL、CoLeCLIP 等方向均为推测性建议，无文本域实测支撑。
- **阈值问题未被解决**：原文只指出难点与替代路径，未给出可直接照搬的阈值设定办法。
