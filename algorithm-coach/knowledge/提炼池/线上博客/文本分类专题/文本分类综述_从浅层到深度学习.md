# A Survey on Text Classification: From Shallow to Deep Learning

## 筛选结论

保留 —— 该综述系统梳理了文本分类从传统模型到深度学习模型的方法谱系、基准数据集与评测指标，并汇总了各模型在经典数据集上的准确率。对本项目「文本分类任务的模型选型、特征/表示构造、训练与评测」环节有直接参考价值。作者信息、致谢与参考文献段落跳过。

## 核心内容

1. **方法谱系两层**：传统模型（概率图/朴素贝叶斯、KNN、SVM、决策树、集成）与深度模型（递归神经网络、MLP、RNN、CNN、注意力、预训练、图神经网络、其他）。传统模型的收益来自特征工程与分类器设计，深度模型的收益来自表示学习、模型结构和额外数据/知识。
2. **文本表示三代**：稀疏向量空间模型（词袋、N-gram、TF-IDF）→ 静态稠密词向量（word2vec 的 CBOW/Skip-gram、GloVe，通用 50–300 维）→ 上下文嵌入（ELMo 的双向 LSTM 特征式表示、GPT 的单向 Transformer 微调、BERT 的双向 Transformer 微调）。向量空间模型简单高效但丢失语义、性能受限；语义化表示效果好但耗时。
3. **传统模型的适用画像**：小数据集上传统模型常优于深度模型（算力受限时）；朴素贝叶斯参数少、对缺失数据不敏感，但特征数量大或强相关时性能下降；SVM 适合高维非线性、泛化强但对缺失数据敏感；KNN 不建模、在类别域交叉重叠的数据上更合适，但时间/空间随数据量增长，大规模数据上极慢；决策树可解释但数据规模爆炸时低效；集成方法能利用多棵树的信息但对短文本帮助有限。
4. **深度模型的结构取舍**：RNN 按序计算、不能并行，靠 LSTM 的门结构缓解梯度消失；CNN 可并行、卷积核决定特征粒度，但池化丢失位置信息，更深层未必带来显著提升，长距离特征捕获弱；注意力机制带来词/句级权重可视化，可解释性优于 CNN/RNN；Transformer 把文本视为全连接图、可并行但长序列注意力计算量大；GNN 在有效图结构下能捕获其他方法无法替代的结构信息。
5. **预训练模型的地位**：综述汇总表显示预训练模型在多数数据集上取得最好成绩，建议实现文本分类任务时优先尝试 BERT、RoBERTa、XLNet 等；例外是 MR 与 20NG（汇总表中没有基于 BERT 的实验）。预训练 + 微调能显著提升下游任务，且 GPT 一类方法的预训练语料域不必与目标任务域相似。
6. **数据集六大类与量级**：情感分析（MR 10,662 条、SST-2 9,613、IMDB 50,000、Yelp.P 598,000、Amz.F 3,650,000）、新闻分类（20NG 18,846、R8 7,674、AG 127,600、Sogou 510,000）、主题标注（DBpedia 630,000/14 类、YahooA 1,460,000、EUR-Lex 3,956 类、Amazon670K 670 类）、问答（SQuAD、TREC、WikiQA）、自然语言推理（SNLI 570,152 句对、MNLI 433,000）、多标签（RCV1 103 类 807,595 条、AAPD 54 类 55,840 条）。
7. **评测指标与选择**：单标签常用 Accuracy/ErrorRate 与 Precision/Recall/F1，排序类任务用 MRR，多标签另有 Hamming Loss；多标签中 Micro-F1 考虑类别数量、适合不平衡分布，Macro-F1 各类等权、易受高 P/R 类别影响；类别数极多（极端多标签）时改用 P@K 或 NDCG@K。
8. **主要挑战**：零样本/少样本下模型过度依赖大量标注；外部知识（知识库/知识图谱）的引入方式未定；领域术语（金融、医疗）使现有预训练词向量难直接生效；多标签的标签语义关系在有损压缩中丢失；对抗样本会让性能显著下降；深度模型是黑箱、可解释性不足。

## 可复用要点

- **选型决策规则（可直接落到推荐逻辑）**：
  - 数据量小、算力受限 → 先试传统模型（朴素贝叶斯 / SVM / 线性模型），而不是直接上深度模型。
  - 标注充足、追求最高准确率 → 优先试预训练语言模型（BERT / RoBERTa / XLNet 一类），别从零训深度模型。
  - 数据类别域交叉重叠多 → KNN 相对更合适；特征强相关 → 慎用朴素贝叶斯；需可解释规则 → 决策树，但注意大规模低效。
  - 短文本 → 集成方法收益有限；长文本 → 避开"池化丢位置信息"的浅层 CNN，注意 Transformer 长序列注意力开销。
  - 需要文本结构信息 → 图神经网络，前提是能设计出有效图结构。
- **表示选择**：传统分类器必须配词袋/TF-IDF；深度模型配词向量嵌入矩阵；消解一词多义或需要最强效果时用上下文嵌入（预训练模型）。字符级嵌入可处理未登录词与多语言。
- **评测指标选择规则**：不平衡 → Precision/Recall/F1；多标签 → Micro-F1（不平衡）或 Macro-F1（各类等权）；类别极多 → P@K / NDCG@K；排序型问答 → MRR。
- **基准对标**：综述 Table 4 给出 MR / SST-2 / IMDB / Yelp.P / Yelp.F / Amz.F / 20NG / AG / DBpedia / SNLI 上各模型准确率，可直接作为选型参照（各数据集最好成绩：SST-2 97.0 XLNet、IMDB 96.21 XLNet-Large、Yelp.P 98.45 XLNet-Large、Yelp.F 72.20 XLNet-Large、Amz.F 67.74 XLNet-Large、SNLI 92.60 RoBERTa、MR 83.80 RNN-Capsule、20NG 96.50 BLSTM-2DCNN）。
- **数据规模参照**：用于判断任务属于"小数据"还是"大数据"的量级锚点（万级：MR/SST-2/R8/20NG；十万级：AG/Sogou；百万级：YahooA/DBpedia/Amz.F）。

- **数字可比性**：Table 4 是各论文自报结果的横向拼表，未做统一复现与统一切分，单个百分点的差距不宜当作严格可比。

- **表格结构噪声**：原文是 HTML 抓取转 Markdown，Table 1/2/4 存在单元格错位与空列（如 HAN 行与 IMDB/Amz.F 列的对齐），关键数字必须回原表复核后再引用。
- **公式与引用错乱**：评测指标一节的多处公式在转换后失真（下标、分式、引用编号被拆行），本提炼只保留指标含义不保留公式排版。
- **时效边界**：文献止于 2021 年，未覆盖其后的大规模预训练模型进展；"预训练模型优先"这一结论仅在该综述的汇总范围内成立。
- **定性结论无对照实验**："小数据上传统模型更好""Transformer 是更好的选择"等是综述的定性判断，未给出统一对照实验支撑。
