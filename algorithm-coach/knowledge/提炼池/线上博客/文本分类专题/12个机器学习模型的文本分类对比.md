# A pipeline and comparative study of 12 machine learning models for text classification

## 筛选结论

部分保留 —— 入库的只是 arXiv 摘要页（无正文），但摘要本身给出了一条可复用的对比评测做法（固定流水线比 12 个模型、按特征尺寸与超参数搜索、多指标含运行时间、加统计检验与可解释性）和一个结果数字（Enron 语料 F-score 94%）。方法与参数细节缺失，不能据摘要复现，只能作为评测流程的参照。

## 核心内容

1. **任务场景**：面向垃圾邮件/恶意消息过滤的文本分类——业务方把文本作为主要沟通方式，导致垃圾与欺诈信息滥用，需要在对用户的"攻击性"与误杀之间找平衡。
2. **做法**：在公开 Enron 邮件语料上对比 12 个机器学习文本分类器，并提出一条流水线，在预处理阶段引入基于 NLP 的专门处理，用于优化超参数选择与提升效果。
3. **研究目标**：给出一种系统考察"不同特征尺寸 × 超参数"对分类器影响的方法论，而非只报一个最优点。
4. **评价口径**：测试与评估同时用多个指标——F-score（准确率口径）、precision、recall 与运行时间。
5. **稳健性与可解释性**：用统计检验与可解释性技术支撑结论的稳健性，并识别驱动分类结果的关键词。
6. **结果**：能在 Enron 数据集上找到一个有效模型，F-score 达到 94%。
7. **出处分量**：论文被 Expert Systems with Applications 接收（2022 年 4 月），作者声明全部数据、模型与代码在 GitHub 公开。

## 可复用要点

- **对比评测的流程骨架**：同一套预处理与特征流水线跑多个模型 → 对特征尺寸与超参数做搜索 → 多指标（含耗时）汇总 → 加统计检验 → 用可解释性定位关键词，最后才下"哪个模型有效"的结论。
- **面向垃圾/违规文本过滤的指标选择**：至少同时看 precision 与 recall（漏放与误杀代价不同），并把训练/推理运行时间列入指标——它不是只比精度的任务。
- **可解释性作为验收项**：把"哪些词驱动了判定"作为交付物之一，便于业务方复核误判。
- 摘要未给出特征尺寸、超参范围、模型清单，具体数值不可复用。

## 数据与假设

- 数据：公开 Enron 邮件语料（摘要未给样本量、时间范围、划分方式与预处理细节）。
- 任务假设：垃圾邮件二分类；判定结果可被关键词解释；对"攻击性"（多判为垃圾）与误杀之间的权衡是核心业务约束。
- 语料为英文邮件，与中文短文本/评论场景的可迁移性未验证。

## 局限与风险

- **只有摘要**：模型构成、特征构造、超参网格、数据划分、是否样本外一概未知，94% 无口径可核。
- **单语料单数字**：结论只针对 Enron，不能外推到其它语料或语言。
- **12 个模型的覆盖面未知**：无法判断是否包含深度模型/预训练模型，不能据此做现代模型选型。
- 摘要自述的"优化流水线"没有给出可复用的参数与步骤，属于方法框架而非可执行规格。
