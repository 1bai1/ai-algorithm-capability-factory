## 二、关键事实

**数据源与口径**：课程提供的单标的日线 CSV（OHLCV + amount），**未复权**（无 adj close）。
harness 用 `close` 独立重算标签 `close.shift(-5)/close - 1`，算法的 `label` 列与之逐行一致
（961 个标签最大偏差 0）。601318 有分红，未复权收盘价在除权日会有向下跳空，**生产环境应改用前复权价**
（`复权口径与复权价选用` 卡，待验证）；本任务受 harness 标签口径约束，只能用 `close`。

**最终验证结论：未通过（通过 16 / 未通过 4 / 跳过 0）。**

| 模块 | 结果 |
|---|---|
| 接口规范（6 项） | 全过 |
| 功能正确性 | 行数守恒 ✓ / 标签口径对账 ✓ / 截断一致性（反前视）✓ / 预测输出有效性 ✓ / **朴素基线对比 ✗** |
| 指标表现 | 回撤约束 ✓ / 样本内外差距披露 ✓ / **精度账 ✗ / 交易账 ✗ / 成本敏感度 ✗** |
| 运行稳定性 | 时间预算 ✓ / 确定性 ✓ / 小样本不崩 ✓ / 坏数据不崩 ✓ |

**四个未通过项是同一个根因：训练段与样本外的市场状态相反。**

| | 5 日收益均值 | 上涨占比 | 零预测 RMSE |
|---|---|---|---|
| 训练段 2022-01~2024-06 | **-0.108%** | 0.433 | 3.88% |
| 样本外 2024-07~2025-12 | **+0.794%** | 0.578 | 4.18% |

训练段是熊/震荡段，样本外是强牛段（买入持有 **+72.46%**、夏普 **1.51**）。
训练段学到的截距为负、趋势状态的条件均值也为负（`close>MA60` 时未来 5 日均值 -0.53%），
于是模型在样本外系统性偏空，方向准确率 0.539 落在「全猜涨」基线 0.578 之下 3.9 个百分点，
累计收益 +27.06% 跑不过买入持有。这不是代码 bug，而是
`模型假设与适用边界失效`（有缺陷）+ `缺朴素基线导致预测力误判`（有缺陷）两卡描述的结构性问题。

**修复轮次记录**（最多三轮）：

| 轮次 | 模型 | 通过 | 关键变化 |
|---|---|---|---|
| round0 | 基线 Ridge（13 特征，alpha=10） | 16/20 | 方向准确率 0.458，样本内外差距 13.9pp（逼近 15pp 上限） |
| round1 | 8 特征 + TimeSeriesSplit 选 alpha | **15/20** | 正则更强 → 更偏空，准确率 0.439，差距 16.0pp **反而越过上限** |
| round2/3 | 趋势分类器 → 条件均值映射 | 16/20 | 准确率 0.539，样本内外差距 **1.0pp**，回撤 -16.53% < 基准 |

round1 说明「加大正则」在这条 regime shift 上是错方向；round2 按
`均线与趋势跟踪策略`（已验证）换族后诊断指标全面改善（过拟合差距从 13.9pp 降到 1.0pp），
是三轮里最稳的版本，故作为交付。

**一个被明确否决的候选**：探索中 `pred = 训练段波动率中位数 − 当期 vol60` 这一因果信号
能在本样本外窗口同时通过精度账（acc 0.586 / RMSE 4.10%）与交易账（+88% / 夏普 1.92）。
但它是**看着样本外结果挑出来的**。`robustness_check.py` 的 walk-forward 证明它只在最后一段牛市有效
（2022H2 累计 -15.7%、2023~2024H1 累计 -8.7%），属 `测试集参与调参与模型选择`（有缺陷）
的典型反例，故不交付。

## 三、接着能做什么

1. **要一个真能过 harness 的版本**：本任务的判负来自 regime shift，需要多标的/多时段数据，
   或用大盘（沪深300/上证50）做市场状态特征，让模型在样本外能识别牛熊切换
   （上游可用 `交易日对齐与多源数据合并` 卡）。
2. **换标的验证泛化**：把 `generated/algorithm.py` 原样套到其它 A 股 CSV（改 manifest 的 symbol 即可），
   用 `robustness_check.py` 的多窗口 walk-forward 看趋势模型是否稳定——单窗口结论不可外推。
3. **改复权口径重跑**：用 baostock 取 601318 前复权序列（见 `20261001_600519_A股日线数据获取` 任务的可复用脚本），
   再把 cutoff 前的窗口做 walk-forward，避免除权跳空污染 5 日标签。
4. **不要**把本次的四个未通过项当成「调参不够」——`测试集参与调参与模型选择` 与
   `阈值与参数在同一样本上寻优` 两卡已明确：用样本外结果反选模型/阈值只会把选择偏差包装成优势。
