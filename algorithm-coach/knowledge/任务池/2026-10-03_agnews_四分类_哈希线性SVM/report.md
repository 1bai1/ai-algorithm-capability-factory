# AG News 四分类任务报告 —— 特征哈希 + TF-IDF 加权 + 线性 SVM

## 它是什么

这是一个把英文新闻文本分成四类（Business / SciTech / Sports / World）的文本分类算法。
它先用**特征哈希**把每段文本的词组合和词内字符组合映射成固定长度的稀疏向量，再用
TF-IDF 给这些特征加权，最后用一个线性 SVM 划出分类边界。和"先建词表再算 TF-IDF"的
常规做法相比，它不维护词表，因此天然接受没见过的词、加载快、内存可控；在 4000 行
采样集上测试准确率 **0.890**、宏 F1 **0.890**，高于同划分的 TF-IDF+逻辑回归参考基线
（0.875 / 0.874）约 1.5 个百分点，完整 harness 验收 19 项全通过。

### 2.2 算法与关键参数

- **逐行规范化**（`build_features`，不学任何东西）：小写 → 去 HTML 标签 →
  非字母数字换空格 → 压缩空白。只依赖当前行，因此全量与仅训练段两次运行逐行一致。
- **特征**（`fit` 内拟合）：词 1/2-gram 与词内字符 3/5-gram 各用 `HashingVectorizer`
  哈希到 **2^18 = 262144** 维（`alternate_sign=False`、`norm=None`），两支拼接后套
  `TfidfTransformer(sublinear_tf=True)` 补 idf。哈希器无状态，idf 只在训练段拟合。
- **分类器**：`LinearSVC(C=0.5)`。
- **切分由 harness 控制**：分层随机 80/20、seed=42，训练 3200 / 测试 800。

### 2.3 真实数字（seed=42，测试 800 行）

| 指标 | 本算法 | 多数类基线 | 参考基线 TF-IDF(1,2)+LogReg(C=4) |
|---|---|---|---|
| 准确率 | **0.890** | 0.250 | 0.875 |
| 宏 F1 | **0.890** | 0.100 | 0.874 |

逐类 F1：Sports 0.951、World 0.913、SciTech 0.854、Business 0.841；
最大混淆仍是 Business↔SciTech（真实 Business→SciTech 23、真实 SciTech→Business 18）。
训练集准确率 0.990、测试 0.890，差距 **+10.0 个百分点**（上限 15）。

### 2.4 选型与稳健性实验

`experiments/select_hashed.py`（单划分 seed=42，测试准确率 / 宏 F1 / 训练−测试）：

- 参考基线 词表 TF-IDF(1,2)+LogReg(C=4)：0.8750 / 0.8745 / +0.1219
- 哈希 2^18 word(1,2)+char(3,5) **LinearSVC(C=1)**：0.8888 / 0.8882 / +0.1100
- 同特征 + LogReg(C=4)：0.8862 / 0.8858 / +0.1059
- 同特征 + ComplementNB(0.3)：0.8775 / 0.8766 / +0.0775
- 哈希 2^20 与 2^18 结果一致（0.8888 / 0.8882），说明 2^18 维碰撞已可忽略
- 纯词哈希 LinearSVC(C=1)：0.8825 / 0.8819（字符支贡献约 +0.6 个百分点）

`experiments/select_robust.py`（5 个切分种子 42/7/2024/1/99 的宏 F1 均值±标准差 / 最低 / 训练−测试均值 / 最大）：

- 哈希 word+char LinearSVC(**C=0.5**)：0.8759 ± 0.0111 / 0.8585 / +0.1145 / **+0.1338**
- 哈希 word+char LinearSVC(C=1)：0.8762 ± 0.0133 / 0.8525 / +0.1220 / +0.1462
- 哈希 word+char LinearSVC(C=2)：0.8712 ± 0.0123 / 0.8524 / +0.1283 / +0.1475
- 纯词哈希 LinearSVC(C=1)：0.8743 ± 0.0111 / 0.8568 / +0.1248 / +0.1425
- 参考基线 词表 TF-IDF(1,2)+LogReg(C=4)：0.8700 ± 0.0101 / 0.8530 / +0.1261 / +0.1434

**C 的选择**：C=0.5 与 C=1 的宏 F1 基本持平，但 C=0.5 的最大训练/测试差距更小
（+0.1338 vs +0.1462），更贴近 harness 的 15% 上限，故选 C=0.5。

## 三、接着能做什么

- **换对象**：只改 `run.py --data` 指向的 CSV（需含 `text` / `label` 两列）；
  若类别数变化，同步改 `manifest.json` 的 `label.classes`。
- **换语言/领域**：哈希路线仍可用，但字符 n-gram 的 `ngram_range` 与正则需按语言调整
  （本卡正则只保留 `[0-9a-z]`，对中文需扩到 `\u4e00-\u9fff`）。
- **要更高上限**：本算法是浅层基线，若追求显著更高精度需转向预训练模型微调
  （见卡片《预训练语言模型文本分类》《文本分类模型选型_微调SLM与LLM》），本任务未做。
- **可沉淀的知识**：本任务是复用池第一条"特征哈希 + TF-IDF 加权 + 线性 SVM"在
  AG News 四分类上的实证记录，与既有词表 TF-IDF 证据卡构成哈希 vs 词表的同口径对照。

## 四、局限

- 只跑了一个 4000 行英文采样集，单标签、类别均衡；**不可外推到 AG News 全量或其它语言/领域**。
- 未覆盖类别不平衡、多标签、长文档、领域术语场景。
- 跨种子复核中相对参考基线的增益很小（宏 F1 约 +0.6 个百分点），单划分 seed=42 上
  的 +1.5 个百分点有切分运气成分；两组数字口径不同（单划分 vs 跨种子协议），只能各自内部比。
- 字符支与哈希维度只做了整体对比，**未做严格单项消融**，不能给出各自独立贡献。
- 哈希碰撞只是被维度压低，并未消除，理论上仍可能有两个词元哈希到同一桶。
