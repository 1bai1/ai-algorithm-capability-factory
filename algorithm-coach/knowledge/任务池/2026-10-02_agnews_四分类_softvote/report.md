# 任务报告：AG News 四分类（词/字符 n-gram TF-IDF ∪ + ComplementNB·LogReg 软投票）

## 它是什么

这是一个**英文新闻的四分类**算法：输入一条新闻文本，输出它属于
`Business` / `SciTech` / `Sports` / `World` 中的哪一类。做法是经典浅层流水线，
不需要 GPU：先把文本逐行规范化（转小写、去 HTML 与标点），再用词 1/2-gram 与词内
字符 3/5-gram 两套 TF-IDF 表示它，拼接后**同时**喂给互补朴素贝叶斯
（ComplementNB）与逻辑回归两个分类器，把两者对四个类别的预测概率等权平均，
取平均概率最高者。在 4000 行采样集、分层随机 80/20、seed=42 的样本外 800 行上，
测试**准确率 0.890、宏 F1 0.889**，高于 harness 自带参考基线
（TF-IDF(1,2)+逻辑回归 C=4：0.875 / 0.874）约 1.5 个宏 F1 百分点，高于多数类基线
（0.250 / 0.100）一大截；训练/测试准确率差距 +8.6 个百分点（上限 15）。

### 检索到的能力卡与选型依据

先读结构本体（`复用池/nodes.csv` + `edges.csv`），在图上收窄到 5 张候选，再按

|---|---|---|

| `浅层文本分类_朴素贝叶斯与SVM` | 已验证 | 小数据无 GPU 时浅层族占优；**集成方法同属浅层族** |
| `AGNews_词字符n-gram_ComplementNB` | 已验证 | 本数据上的真实基线（宏 F1 0.884），作集成成员与对照 |
| `文本分类评估与交叉验证` | 待验证 | 特征提取随折重训、反泄漏；方法层采纳 |

`06_失败经验` 两张（`停用词表与分词器不一致`、`基线未调优导致虚假提升`）作反例参考：
本次不做停用词过滤（避免与分词器词形不一致），且对照了一条**调过的**可比的
TF-IDF+线性参考基线，不用默认值充当陪衬。

### 与已有任务 / 示例的差异

`examples/text_cls_demo` 用纯词 1/2-gram TF-IDF + 单模型 LogReg；已有任务
（`..._v2`、`..._charlinear`）沿用知识卡的**单模型 ComplementNB**。本任务不复制示例、
也不重复单模型路线，改走**软投票集成**：在 `experiments/select_model.py` 里于同一
划分下比较了 8 个候选（种子 `select_alpha.py` 跨 5 个切分复核）：

| 配置（seed=42 单划分） | 测试准确率 | 宏 F1 | 训练−测试 |
|---|---|---|---|
| 词∪字符 + ComplementNB(α=0.1) | 0.8900 | 0.8892 | +0.0616 |
| 词∪字符 + ComplementNB(α=0.3)（知识卡基线） | 0.8850 | 0.8844 | +0.0606 |
| 词∪字符 + LogReg(C=8) | 0.8800 | 0.8796 | +0.1200 |
| 词∪字符 + LinearSVC(C=1) | 0.8738 | 0.8731 | +0.1259 |
| 词∪字符 + 软投票 NB1:LR1（采用） | 0.8900 | 0.8894 | +0.0844 |
| 词∪字符 + 软投票 NB2:LR1 | 0.8912 | 0.8907 | +0.0706 |
| 词∪字符 + 软投票 NB1:LR2 | 0.8900 | 0.8896 | +0.1038 |

单次划分有偶然性，进一步跨 5 个切分种子（42/7/2024/1/99）复核：

| 配置 | 宏 F1 均值 ± 标准差 | 最低 | 训练−测试（均值 / 最大） |
|---|---|---|---|
| 软投票 NB1:LR1（**采用**） | **0.8856 ± 0.0054** | **0.8783** | +0.0895 / +0.0988 |
| 软投票 NB2:LR1 | 0.8855 ± 0.0080 | 0.8755 | +0.0780 / +0.0903 |
| 单模型 ComplementNB(α=0.3) | 0.8796 ± 0.0066 | 0.8715 | +0.0669 / +0.0759 |
| 单模型 ComplementNB(α=0.1) | 0.8798 ± 0.0090 | 0.8672 | +0.0734 / +0.0853 |

等权 NB1:LR1 的**均值最高、方差最小、最差情形最好**，故采用它；虽然过拟合差距
略大于单模型 NB（+8.95% vs +6.69%），仍远低于 harness 15% 上限。这一「集成小幅优于
单模型」的结论与《浅层文本分类》卡中「集成对短文本收益有限」的提示一致——收益存在
但不大，因此同时如实报告其代价（差距变大、推理变慢）。

### 验收关键数字（对 harness 报告）

- 精度账：准确率 **0.890**、宏 F1 **0.889**；参考基线 TF-IDF(1,2)+LogReg(C=4)
  **0.875 / 0.874**；多数类基线 **0.250 / 0.100**。
- 反泄漏：全量与仅训练段两次 `build_features`，训练段 3200 行逐行一致（最大偏差 0）。
- 确定性：同种子两次 800 个预测完全一致（集成成员均为确定性优化，无随机初始化）。
- 成本：fit/predict 3.3s、build_features 0.6s，预算 300s。
- 坏数据不崩：置空文本 + 注入无信息短文本 + 删行后全链路仍跑通（训练 2797 / 预测 1200）。

## 局限与证据边界

- 只跑一个 4000 行英文采样集、单标签、类别均衡；**不可外推到 AG News 全量（约 127k）
  或其他语言 / 领域**。
- 未覆盖类别不平衡、多标签、长文档、领域术语场景。
- 集成相对单模型的增益**很小**（宏 F1 +0.6 个百分点）且过拟合差距更大；若只追求
  最低成本与最小差距，单模型 ComplementNB 仍是合理选择。
- `char` 特征与集成成员权重尚未做严格单项消融，不能给出各自独立贡献。
- 未与预训练微调模型对照，本卡是浅层基线而非上限。

## 接着能做什么

- 若误差中的 Business↔SciTech 是业务痛点，可在现有表示上叠加标题或实体特征，
  并按《文本分类评测口径与可复现性》跨种子复核后再定结论。
- 换成别的对象：改 `manifest.json` 的 `subject` 与 `label.classes`，数据保持
  `text` / `label` 两列即可，算法与类别数无关。
- 有算力时用微调编码器（如 DistilBERT）作强基线，并按反例卡
  《基线未调优导致虚假提升》披露学习率 / 批大小 / 轮数与重复次数。
