# 任务说明：获取任意 A 股数据

- 提出人：用户
- 日期：2026-10-01
- 任务：为「任意一只 A 股」获取可复用的行情数据快照，落盘成下游建模可直接读取的文件。

## 需求拆解

1. 取数对象：任意 A 股。本次自选 **600519.SH 贵州茅台**（A 股代表性标的，知识库多篇来源也用它，
   便于横向对照）。
2. 辅助序列：**sh.000001 上证指数**，作为大盘参照（对齐 Tushare 卡片「个股 + 大盘指数」的取数惯例）。
3. 数据频率：日线。
4. 复权口径：**同时保留原始价（不复权）与前复权价（qfq）** 两套，避免「Close / Adj Close 混用」。
   按 `复权口径与复权价选用` 卡：跨除权除息日的收益率研究必须走复权价；下单/涨跌停研究走原始价。
5. 产物：UTF-8 CSV 快照 + 结构化校验 JSON + 报告。
