# Algorithm Coach —— Python 依赖
#
# 本文件够跑：harness（统一验证机制）、examples 下的算法与 run.py、scripts、tests。
#
# 本仓库是「Python + Node」双栈，注意区分：
#     · 只跑 harness，或只跑生成出来的 run.py  → 装本文件就够了，不需要 Node；
#     · 要跑 pi agent（生成算法的那一层）      → 还需要 Node ≥ 20 与 pi-main 的依赖，
#       复现方式是 `cd pi-main && npm ci`（框架已随仓库提供，自带 package-lock.json），
#       另需配置 LLM 凭据。详见 README 的「环境配置」一节。
#
# 依赖写成下限而不是精确钉版本：精确钉在别人的 Python 版本上容易装不上。
# 本项目实测通过的版本（Python 3.9.23）：
#     pandas 2.3.3 / numpy 1.26.4 / scipy 1.13.1 / scikit-learn 1.6.1 /
#     requests 2.32.5 / beautifulsoup4 4.14.3 / lxml 6.0.3
